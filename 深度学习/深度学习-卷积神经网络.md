## 一、问题定义

### 1.1 图像数据的挑战

- **维度灾难**:224×224×3 图像,MLP 第一层 1000 神经元需 1.5 亿参数
- **空间相关性**:像素间局部相关,远处弱相关
- **平移不变性**:猫在左上角和右下角都是猫
- **多尺度**:同一物体不同大小

### 1.2 CNN 三大特性

1. **局部连接**(Local Connectivity):每个神经元只看局部区域
2. **参数共享**(Parameter Sharing):同一卷积核在整张图滑动
3. **平移等变**(Translation Equivariance):输入平移,输出平移

### 1.3 应用场景

- 图像分类(ImageNet)
- 目标检测(COCO)
- 语义分割(FCN/U-Net)
- 实例分割(Mask R-CNN)
- 人脸识别(FaceNet)
- 医学影像(U-Net)
- 自动驾驶(YOLO)

## 二、直觉解释

### 2.1 卷积的直觉

卷积核(Kernel/Filter)是一个小矩阵,在图像上滑动,与每个位置的局部区域做点积。每个核学一个特征(边缘、纹理、物体部件)。

```
输入 5×5              卷积核 3×3           输出 3×3
┌─────────────┐      ┌───────┐           ┌───────┐
│1 2 0 1 2    │      │1 0 1  │           │5 4 7  │
│0 1 2 1 0    │      │0 1 0  │           │3 9 6  │
│1 0 1 2 1    │  *   │1 0 1  │    =      │7 5 8  │
│2 1 0 1 0    │      └───────┘           │       │
│1 0 2 1 1    │                          └───────┘
└─────────────┘
```

### 2.2 多通道直觉

RGB 图像 3 通道,卷积核也是 3 通道(3×H×W),点积后求和得一个标量。多个核输出多个 feature map。

### 2.3 层级特征直觉

- 浅层(1-2 层):边缘、角点、纹理(Gabor 滤波器)
- 中层(3-5 层):物体部件(眼睛、轮子)
- 深层(6+):整体概念(人脸、汽车)

### 2.4 与 MLP 对比

| 维度 | MLP | CNN |
|------|-----|-----|
| 连接 | 全连接 | 局部 |
| 参数 | 每神经元独立 | 跨空间共享 |
| 平移 | 不变(需数据增强) | 等变 |
| 数据需求 | 大 | 相对小 |

## 三、形式化推导

### 3.1 二维卷积数学定义 🎓

**严格定义**(卷积):

$$
(I * K)(i, j) = \sum_m \sum_n I(i-m, j-n) K(m, n)
$$

**互相关**(深度学习实际用):

$$
(I \star K)(i, j) = \sum_m \sum_n I(i+m, j+n) K(m, n)
$$

深度学习称"卷积"实际是互相关,因为权重可学习,翻转无意义。

### 3.2 输出尺寸公式 🎓

输入 $H \times W$,卷积核 $K \times K$,步长 $S$,填充 $P$:

$$
H' = \left\lfloor \frac{H + 2P - K}{S} \right\rfloor + 1
$$

**例**:输入 32×32,核 3×3,步长 1,填充 1 → 输出 32×32(同尺寸)
**例**:输入 32×32,核 3×3,步长 2,填充 1 → 输出 16×16(下采样)

### 3.3 参数量与计算量 🎓

**参数量**(单个卷积核):

$$
\text{Params} = C_{\text{in}} \times K_H \times K_W + 1 \text{ (bias)}
$$

**总参数量**(N 个核):

$$
\text{Params}_{\text{total}} = N \times (C_{\text{in}} K_H K_W + 1)
$$

**计算量**(FLOPs,前向):

$$
\text{FLOPs} = 2 \times N \times C_{\text{in}} \times K_H \times K_W \times H' \times W'
$$

**例**:ResNet-50 第一层 conv 7×7, 64, stride 2, 输入 224×224×3:
- 输出 112×112×64
- 参数:64 × 3 × 7 × 7 = 9408
- FLOPs:2 × 64 × 3 × 49 × 112 × 112 ≈ 236M

### 3.4 感受野(Receptive Field) 🎓

某输出像素对应输入图像的区域大小。

**递推公式**:

$$
R_\ell = R_{\ell-1} + (K_\ell - 1) \prod_{i=1}^{\ell-1} S_i
$$

**例**:3 层 3×3 卷积 stride=1:
- L1: $R_1 = 3$
- L2: $R_2 = 3 + (3-1) \times 1 = 5$
- L3: $R_3 = 5 + (3-1) \times 1 = 7$

3 个 3×3 等价 1 个 7×7,但参数 27 vs 49,且更多非线性。

### 3.5 反向传播 🎓

卷积的反向传播是"转置卷积"(deconv):

$$
\frac{\partial L}{\partial I} = \text{conv}(\frac{\partial L}{\partial O}, K^{\text{rot180}}), \quad
\frac{\partial L}{\partial K} = \text{conv}(I, \frac{\partial L}{\partial O})
$$

PyTorch 自动微分处理,但理解原理有助于设计自定义层。

## 四、池化层

### 4.1 作用

- 下采样(降低空间分辨率)
- 增加感受野
- 提供平移不变性(小幅)
- 减少参数与计算

### 4.2 类型

**Max Pooling**:取窗口最大值

```
1 2 3 4        3 4
5 6 7 8   →    7 8   (2×2 stride 2)
```

**Average Pooling**:取窗口平均

**Global Average Pooling (GAP)**:整个 feature map 取平均,常用作分类头

**Adaptive Pooling**:自适应到指定输出尺寸,PyTorch `nn.AdaptiveAvgPool2d((1,1))`

### 4.3 现代趋势

- ResNet 用 stride 卷积代替前几层池化
- ResNet 用 GAP 代替全连接
- 一些架构完全弃用池化(全用 stride 卷积)

## 五、经典架构演进

### 5.1 LeNet-5 (1998)

```
Input → Conv6 → Pool → Conv16 → Pool → FC120 → FC84 → FC10
1×32×32  6×28×28  6×14×14  16×10×10  16×5×5   120     84    10
```

- 第一个成功 CNN,识别手写数字
- 用 Tanh,Sigmoid 输出
- 参数 60K

### 5.2 AlexNet (2012)

```
Input → Conv96 → MaxPool → Conv256 → MaxPool → Conv384 → Conv384 → Conv256 → MaxPool → FC4096 → FC4096 → FC1000
3×227×227
```

- ImageNet 2012 冠军,引爆深度学习
- ReLU 首次大规模使用
- Dropout 防过拟合
- 双 GPU 训练
- 数据增强(裁剪、翻转)
- 参数 60M

### 5.3 VGG (2014)

```
VGG-16: 13 conv + 3 FC
块结构: [conv3×3, conv3×3, pool] × 5
```

- **核心思想**:用堆叠 3×3 代替大卷积
- 参数 138M(全连接占大头)
- 简单统一,广泛用作 backbone

### 5.4 GoogLeNet / Inception (2014)

```
Inception 块:
       ┌→ 1×1 conv ─┐
       ├→ 3×3 conv ─┤
input ─┼→ 5×5 conv ─┼→ concat
       ├→ 3×3 pool ─┘
       └→ 1×1 conv (瓶颈)
```

- **Inception 模块**:多尺度并行卷积
- **1×1 瓶颈**:降维减少计算(256 → 64 → 256 而非 256 → 256)
- **辅助分类器**:中间层加分类损失,缓解梯度消失
- 参数 7M(比 VGG 少 20 倍)

### 5.5 ResNet (2015) ⭐

```
残差块:
input ──→ conv → BN → ReLU → conv → BN ──→ + ──→ ReLU
   │                                          ↑
   └────────── identity (or 1×1 conv) ────────┘
```

- **核心创新**:残差连接 $\mathbf{y} = F(\mathbf{x}) + \mathbf{x}$
- **数学解释**:学残差 $F(\mathbf{x}) = \mathbf{y} - \mathbf{x}$ 比学恒等映射容易
- **梯度高速公路**:$\nabla \mathbf{y} = \nabla F(\mathbf{x}) + \nabla \mathbf{x}$,梯度直接传到浅层
- 训练出 152 层网络,前 ResNet 最深 30 层
- ImageNet top-5 错误率 3.57%(超越人类)

**ResNet 变体**:
- **ResNet-50/101/152**:不同深度
- **ResNeXt**:分组卷积 + 残差
- **DenseNet**:每层连到所有后续层
- **Wide ResNet**:加宽而非加深

### 5.6 MobileNet (2017)

**深度可分离卷积**(Depthwise Separable Conv):

```
标准卷积:  Cin × K × K × Cout
深度可分离:
  1. Depthwise: 每通道独立卷积, Cin × K × K
  2. Pointwise: 1×1 卷积升维, Cin × 1 × 1 × Cout
```

参数量减少:

$$
\frac{C_{\text{in}} K^2 + C_{\text{in}} C_{\text{out}}}{C_{\text{in}} K^2 C_{\text{out}}} = \frac{1}{C_{\text{out}}} + \frac{1}{K^2}
$$

3×3 卷积减少 8-9 倍计算。

### 5.7 EfficientNet (2019)

**复合缩放**(Compound Scaling):

$$
\text{depth} = \alpha^\phi, \quad \text{width} = \beta^\phi, \quad \text{resolution} = \gamma^\phi
$$

约束 $\alpha \beta^2 \gamma^2 \approx 2$,统一扩展深度/宽度/分辨率。EfficientNet-B0 到 B7。

### 5.8 架构对照表

| 模型 | 年份 | 参数 | Top-5 错误 | 创新 |
|------|------|------|-----------|------|
| LeNet | 1998 | 60K | - | 第一个 CNN |
| AlexNet | 2012 | 60M | 16.4% | ReLU/Dropout/GPU |
| VGG-16 | 2014 | 138M | 7.3% | 3×3 堆叠 |
| GoogLeNet | 2014 | 7M | 6.7% | Inception/1×1 |
| ResNet-152 | 2015 | 60M | 3.57% | 残差连接 |
| DenseNet | 2017 | 8M | - | 密集连接 |
| MobileNetV2 | 2018 | 3.5M | - | 深度可分离 |
| EfficientNet-B7 | 2019 | 66M | 2.0% | 复合缩放 |

## 六、特殊变体

### 6.1 1×1 卷积

**作用**:
- 通道变换(降维/升维)
- 跨通道信息融合
- 减少计算瓶颈
- 等价于每像素的全连接

### 6.2 空洞卷积(Dilated/Atrous Conv)

卷积核间隔采样,扩大感受野不增加参数不降低分辨率:

```
普通 3×3, dilated=1:        空洞 3×3, dilated=2:
× × ×                          ×   ×   ×
× × ×                          ×   ×   ×
× × ×                          ×   ×   ×
感受野 3                        感受野 5
```

用于 DeepLab 语义分割,大感受野 + 高分辨率。

### 6.3 转置卷积(Transposed Conv / Deconv)

上采样(放大空间尺寸),用于分割的解码器、GAN 生成器。

```
input 2×2, kernel 3×3, stride 2, padding 1 → output 4×4
```

注意:不是卷积的逆,而是反向传播时梯度的形状。

### 6.4 U-Net

```
编码器(下采样)            解码器(上采样)
input ──→ conv ──→ pool ──┐    ┌── upconv ──→ conv ──→ output
                          │    │
                          └── concat (skip connection)
```

- 编码器逐步降采样,提取语义
- 解码器逐步上采样,恢复分辨率
- skip connection 保留低层细节
- 医学影像分割标准

### 6.5 Depthwise + Pointwise

```python
# 标准 Conv
nn.Conv2d(32, 64, 3, padding=1)  # 参数 32*64*9 = 18K

# 深度可分离
nn.Sequential(
    nn.Conv2d(32, 32, 3, padding=1, groups=32),  # 32*9 = 288
    nn.Conv2d(32, 64, 1)                          # 32*64 = 2K
)  # 总共 2.3K,减少 8 倍
```

## 七、PyTorch 实现

### 7.1 从零实现卷积

```python
import torch
import torch.nn.functional as F

def conv2d_scratch(x, weight, bias=None, stride=1, padding=0):
    """
    x: (N, C_in, H, W)
    weight: (C_out, C_in, K, K)
    """
    N, C_in, H, W = x.shape
    C_out, _, K, _ = weight.shape
    
    # 填充
    if padding > 0:
        x = F.pad(x, (padding, padding, padding, padding))
    
    H_out = (H + 2*padding - K) // stride + 1
    W_out = (W + 2*padding - K) // stride + 1
    
    # 用 im2col 优化
    output = torch.zeros(N, C_out, H_out, W_out)
    for i in range(H_out):
        for j in range(W_out):
            h_start = i * stride
            w_start = j * stride
            receptive = x[:, :, h_start:h_start+K, w_start:w_start+K]  # (N, C_in, K, K)
            # (N, C_in, K, K) * (C_out, C_in, K, K) → (N, C_out)
            output[:, :, i, j] = torch.einsum('nckl,ockl->no', receptive, weight)
            if bias is not None:
                output[:, :, i, j] += bias
    
    return output

# 测试
x = torch.randn(1, 3, 32, 32)
weight = torch.randn(16, 3, 3, 3)
out = conv2d_scratch(x, weight, padding=1)
print(out.shape)  # (1, 16, 32, 32)

# 对比 PyTorch
out_torch = F.conv2d(x, weight, padding=1)
print(torch.allclose(out, out_torch, atol=1e-5))
```

### 7.2 实现一个简化 ResNet

```python
import torch
import torch.nn as nn

class BasicBlock(nn.Module):
    """ResNet-18/34 的 BasicBlock"""
    expansion = 1
    
    def __init__(self, in_channels, out_channels, stride=1, downsample=None):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU(inplace=True)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, stride=1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        self.downsample = downsample  # 用于改变通道数或下采样
    
    def forward(self, x):
        identity = x
        if self.downsample is not None:
            identity = self.downsample(x)
        
        out = self.conv1(x)
        out = self.bn1(out)
        out = self.relu(out)
        
        out = self.conv2(out)
        out = self.bn2(out)
        
        out += identity  # 残差连接
        out = self.relu(out)
        return out


class ResNet18(nn.Module):
    def __init__(self, num_classes=1000):
        super().__init__()
        self.in_channels = 64
        
        # Stem
        self.conv1 = nn.Conv2d(3, 64, 7, stride=2, padding=3, bias=False)
        self.bn1 = nn.BatchNorm2d(64)
        self.relu = nn.ReLU(inplace=True)
        self.maxpool = nn.MaxPool2d(3, stride=2, padding=1)
        
        # 4 个 stage,每个 2 个 BasicBlock
        self.layer1 = self._make_layer(64, 2, stride=1)
        self.layer2 = self._make_layer(128, 2, stride=2)
        self.layer3 = self._make_layer(256, 2, stride=2)
        self.layer4 = self._make_layer(512, 2, stride=2)
        
        self.avgpool = nn.AdaptiveAvgPool2d((1, 1))
        self.fc = nn.Linear(512, num_classes)
    
    def _make_layer(self, out_channels, blocks, stride):
        downsample = None
        if stride != 1 or self.in_channels != out_channels:
            downsample = nn.Sequential(
                nn.Conv2d(self.in_channels, out_channels, 1, stride=stride, bias=False),
                nn.BatchNorm2d(out_channels),
            )
        layers = [BasicBlock(self.in_channels, out_channels, stride, downsample)]
        self.in_channels = out_channels
        for _ in range(1, blocks):
            layers.append(BasicBlock(self.in_channels, out_channels))
        return nn.Sequential(*layers)
    
    def forward(self, x):
        x = self.relu(self.bn1(self.conv1(x)))
        x = self.maxpool(x)
        
        x = self.layer1(x)  # 56×56
        x = self.layer2(x)  # 28×28
        x = self.layer3(x)  # 14×14
        x = self.layer4(x)  # 7×7
        
        x = self.avgpool(x)
        x = torch.flatten(x, 1)
        x = self.fc(x)
        return x

# 测试
model = ResNet18(num_classes=10)
x = torch.randn(1, 3, 224, 224)
out = model(x)
print(out.shape)  # (1, 10)
print(f"Params: {sum(p.numel() for p in model.parameters()) / 1e6:.1f}M")  # ~11M
```

### 7.3 实现深度可分离卷积

```python
class DepthwiseSeparableConv(nn.Module):
    """MobileNet 的深度可分离卷积"""
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.depthwise = nn.Conv2d(
            in_channels, in_channels, 3, stride=stride, padding=1, 
            groups=in_channels, bias=False
        )
        self.pointwise = nn.Conv2d(in_channels, out_channels, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(in_channels)
        self.bn2 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU6(inplace=True)  # MobileNet 用 ReLU6
    
    def forward(self, x):
        x = self.relu(self.bn1(self.depthwise(x)))
        x = self.bn2(self.pointwise(x))
        return x

# 对比参数量
standard = nn.Conv2d(32, 64, 3, padding=1)
separable = DepthwiseSeparableConv(32, 64)
print(f"Standard: {sum(p.numel() for p in standard.parameters())}")  # 18496
print(f"Separable: {sum(p.numel() for p in separable.parameters())}")  # 2336
```

### 7.4 U-Net 简化版

```python
class UNet(nn.Module):
    def __init__(self, in_channels=1, num_classes=2):
        super().__init__()
        
        def double_conv(in_c, out_c):
            return nn.Sequential(
                nn.Conv2d(in_c, out_c, 3, padding=1),
                nn.BatchNorm2d(out_c),
                nn.ReLU(inplace=True),
                nn.Conv2d(out_c, out_c, 3, padding=1),
                nn.BatchNorm2d(out_c),
                nn.ReLU(inplace=True),
            )
        
        # Encoder
        self.enc1 = double_conv(in_channels, 64)
        self.enc2 = double_conv(64, 128)
        self.enc3 = double_conv(128, 256)
        self.enc4 = double_conv(256, 512)
        
        # Bottleneck
        self.bottleneck = double_conv(512, 1024)
        
        # Decoder
        self.upconv4 = nn.ConvTranspose2d(1024, 512, 2, stride=2)
        self.dec4 = double_conv(1024, 512)
        self.upconv3 = nn.ConvTranspose2d(512, 256, 2, stride=2)
        self.dec3 = double_conv(512, 256)
        self.upconv2 = nn.ConvTranspose2d(256, 128, 2, stride=2)
        self.dec2 = double_conv(256, 128)
        self.upconv1 = nn.ConvTranspose2d(128, 64, 2, stride=2)
        self.dec1 = double_conv(128, 64)
        
        self.final = nn.Conv2d(64, num_classes, 1)
        self.pool = nn.MaxPool2d(2)
    
    def forward(self, x):
        # Encoder
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
        e4 = self.enc4(self.pool(e3))
        
        # Bottleneck
        b = self.bottleneck(self.pool(e4))
        
        # Decoder + skip
        d4 = self.upconv4(b)
        d4 = self.dec4(torch.cat([d4, e4], dim=1))
        d3 = self.upconv3(d4)
        d3 = self.dec3(torch.cat([d3, e3], dim=1))
        d2 = self.upconv2(d3)
        d2 = self.dec2(torch.cat([d2, e2], dim=1))
        d1 = self.upconv1(d2)
        d1 = self.dec1(torch.cat([d1, e1], dim=1))
        
        return self.final(d1)
```

### 7.5 用 torchvision 预训练模型

```python
import torchvision
import torch.nn as nn

# 加载预训练 ResNet
model = torchvision.models.resnet50(weights='IMAGENET1K_V2')

# 微调最后一层(10 类)
model.fc = nn.Linear(model.fc.in_features, 10)

# 冻结除最后一层外的所有层(快速微调)
for param in model.parameters():
    param.requires_grad = False
model.fc.requires_grad_(True)

# 训练
optimizer = torch.optim.AdamW(model.fc.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss()
```

## 八、常见陷阱与调参经验 ⚠️

### 8.1 训练陷阱

| 陷阱 | 表现 | 解决 |
|------|------|------|
| 没用预训练 | 收敛慢 | 用 ImageNet 预训练 |
| 数据归一化错误 | 性能差 | 用 ImageNet 均值方差 |
| BN batch size 太小 | 不稳定 | 用 GroupNorm 或同步 BN |
| 学习率太大 | loss 爆炸 | 学习率预热 |
| 不数据增强 | 过拟合 | 裁剪/翻转/色彩 |
| 梯度爆炸 | NaN | 梯度裁剪 |
| 卷积核大小不当 | 慢/效果差 | 用 3×3 为主,大核用 1×1 瓶颈 |

### 8.2 调参经验

1. **从预训练开始**:几乎不要从头训练
2. **学习率**:分阶段,backbone 用 1e-4,新层用 1e-3
3. **数据增强**:训练用强增强(裁剪、翻转、MixUp、CutMix),验证不增强
4. **Batch size**:64-256,小了用 GroupNorm
5. **微调策略**:
   - **特征提取**:冻结 backbone,只训分类头,小数据
   - **微调**:全部解冻,大数据
   - **渐进解冻**:从顶层逐步解冻
6. **正则化**:Dropout 0.5 全连接,DropPath 0.1 卷积块

### 8.3 设计技巧

1. **下采样**:用 stride=2 卷积代替池化(可学习)
2. **通道变换**:用 1×1 卷积
3. **大感受野**:堆叠 3×3 而非用大核(参数少)
4. **特征复用**:残差/密集连接
5. **轻量化**:深度可分离 + 1×1 瓶颈

## 九、与其他方法的关系

### 9.1 与 MLP 对比

| 维度 | MLP | CNN |
|------|-----|-----|
| 连接 | 全连接 | 局部 |
| 参数 | 多(权重独立) | 少(权值共享) |
| 平移 | 不等变 | 等变 |
| 适合 | 表格数据 | 图像 |

### 9.2 与 RNN 对比

| 维度 | CNN | RNN |
|------|-----|-----|
| 输入 | 静态 | 序列 |
| 时间 | 一次前向 | 多步展开 |
| 长依赖 | 受感受野限制 | 理论无限(实际 LSTM) |
| 并行 | 高 | 低 |

### 9.3 与 Transformer 对比

ViT 把图像分 patch,每个 patch 当 token,纯 Transformer。CNN 与 Transformer 在视觉上各有优劣:
- CNN:归纳偏置强(局部+平移),小数据好
- ViT:归纳偏置弱,大数据好,扩展性强

现代架构(Swin/ConvNeXt)在两者间平衡。

## 十、面试速答 ⭐

- **卷积三特性**:局部连接、参数共享、平移等变
- **参数量**:$C_{\text{out}} \times C_{\text{in}} \times K \times K + C_{\text{out}}$
- **感受野**:$R_\ell = R_{\ell-1} + (K_\ell - 1) \prod S_i$
- **3 个 3×3 vs 1 个 7×7**:参数 27 vs 49,非线性更多,感受野相同
- **ResNet**:学残差比学恒等映射容易,梯度通过 skip 直达浅层
- **1×1 卷积**:跨通道融合,升降维,等价每像素 MLP
- **深度可分离**:Depthwise(每通道独立)+ Pointwise(1×1 升维),3×3 减少 8-9 倍计算
- **BN 在 CNN**:沿 batch+H+W 维归一化(每个 channel 一个统计)

1. [基础] 解释卷积的局部连接和参数共享为什么对图像有效。
2. [基础] 计算 ResNet-50 第一层 conv 7×7 stride 2 的输出尺寸与参数量。
3. [基础] 为什么 CNN 有平移不变性?池化如何增强?
4. [中等] 推导感受野递推公式。
5. [中等] 解释 ResNet 残差连接为什么能解决梯度消失。
6. [中等] 1×1 卷积有什么用?
7. [中等] Batch Norm 在 CNN 中如何归一化?
8. [中等] 深度可分离卷积为什么能减少计算?减少多少?
9. [进阶] 分析 3 个 3×3 卷积级联 vs 1 个 7×7 卷积的优劣。
10. [进阶] 设计一个 U-Net 用于 1024×1024 医学图像分割,如何减少显存?
11. [进阶] ViT 与 CNN 的归纳偏置差异,小数据哪个好?为什么?
12. [进阶] 解释空洞卷积在语义分割中的作用。

**答题要点(Q9)**:
3 个 3×3 优于 1 个 7×7:
1. 参数少:27 vs 49(单通道)
2. 非线性多:3 次 ReLU vs 1 次
3. 感受野相同:7×7
4. 计算量少:3 × 9 = 27 vs 49
劣势:3 层需更多顺序计算,但 GPU 并行后差异不大。
