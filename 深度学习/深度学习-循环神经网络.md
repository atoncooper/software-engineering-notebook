# 深度学习 —— 循环神经网络

> RNN 是序列数据的天然模型。从简单 RNN 到 LSTM/GRU,从 Seq2Seq 到注意力机制,本章覆盖序列建模的核心思路。Transformer 出现后 RNN 在 NLP 主流地位被取代,但 LSTM/GRU 在小数据、实时场景、音频处理仍广泛使用。

## 一、问题定义

### 1.1 序列数据的挑战

- **变长**:句子长度不一,无法用固定输入 MLP
- **时序依赖**:当前输出依赖历史
- **长程依赖**:句首的词影响句尾的词
- **变长输出**:翻译输入输出长度不同

### 1.2 RNN 的核心思想

权重跨时间共享,状态跨时间传递:

$$
\mathbf{h}_t = f(\mathbf{h}_{t-1}, \mathbf{x}_t)
$$

### 1.3 应用场景

- NLP:语言模型、机器翻译、文本分类
- 语音:语音识别、语音合成
- 时间序列:股价预测、天气
- 视频:动作识别、视频字幕
- 推荐:用户行为序列建模

---

## 二、直觉解释

### 2.1 状态传递直觉

RNN 像一个有"记忆"的网络:每个时间步读入新输入 $\mathbf{x}_t$,结合上一时刻隐状态 $\mathbf{h}_{t-1}$,产生新隐状态 $\mathbf{h}_t$。隐状态是过去信息的压缩。

```
h₀ → h₁ → h₂ → h₃ → ... → hₜ
     ↑    ↑    ↑           ↑
     x₁   x₂   x₃          xₜ
```

### 2.2 展开直觉

RNN 在时间上展开等价于深度网络,每层共享权重。展开后可以用反向传播,称为 BPTT(Backpropagation Through Time)。

### 2.3 长程依赖问题

简单 RNN 中,梯度要传到很久以前需要连乘 $\partial \mathbf{h}_t / \partial \mathbf{h}_{t-1}$。若该雅可比的谱半径 < 1,梯度指数衰减;> 1 则爆炸。

LSTM 的解决:引入"细胞状态"作为高速公路,梯度可长距离传播。

## 三、形式化推导

### 3.1 简单 RNN 🎓

**前向**:

$$
\begin{aligned}
\mathbf{h}_t &= \tanh(W_{hh} \mathbf{h}_{t-1} + W_{xh} \mathbf{x}_t + \mathbf{b}_h) \\
\mathbf{y}_t &= W_{hy} \mathbf{h}_t + \mathbf{b}_y
\end{aligned}
$$

**维度**:$\mathbf{h}_t \in \mathbb{R}^d$,$\mathbf{x}_t \in \mathbb{R}^m$,$W_{hh} \in \mathbb{R}^{d \times d}$,$W_{xh} \in \mathbb{R}^{d \times m}$。

### 3.2 BPTT 反向传播 🎓

损失 $L = \sum_t \ell(\mathbf{y}_t, \mathbf{y}_t^*)$。对 $W_{hh}$ 求梯度:

$$
\frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^T \frac{\partial L_t}{\partial W_{hh}} = \sum_{t=1}^T \sum_{k=1}^t \frac{\partial L_t}{\partial \mathbf{h}_t} \cdot \frac{\partial \mathbf{h}_t}{\partial \mathbf{h}_k} \cdot \frac{\partial \mathbf{h}_k}{\partial W_{hh}}
$$

其中关键项:

$$
\frac{\partial \mathbf{h}_t}{\partial \mathbf{h}_k} = \prod_{i=k+1}^t \frac{\partial \mathbf{h}_i}{\partial \mathbf{h}_{i-1}} = \prod_{i=k+1}^t \text{diag}(\sigma') W_{hh}
$$

**梯度消失**:$\|W_{hh}\| < 1$ 时连乘 → 0
**梯度爆炸**:$\|W_{hh}\| > 1$ 时连乘 → ∞

### 3.3 LSTM 数学定义 🎓

LSTM 引入细胞状态 $\mathbf{c}_t$ 和三个门:

$$
\begin{aligned}
\mathbf{f}_t &= \sigma(W_f [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_f) & \text{(遗忘门)} \\
\mathbf{i}_t &= \sigma(W_i [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_i) & \text{(输入门)} \\
\tilde{\mathbf{c}}_t &= \tanh(W_c [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_c) & \text{(候选细胞态)} \\
\mathbf{c}_t &= \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t & \text{(细胞态更新)} \\
\mathbf{o}_t &= \sigma(W_o [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_o) & \text{(输出门)} \\
\mathbf{h}_t &= \mathbf{o}_t \odot \tanh(\mathbf{c}_t) & \text{(隐状态)}
\end{aligned}
$$

### 3.4 LSTM 缓解梯度消失的原理 🎓

考虑 $\partial \mathbf{c}_t / \partial \mathbf{c}_{t-1}$:

$$
\frac{\partial \mathbf{c}_t}{\partial \mathbf{c}_{t-1}} = \mathbf{f}_t + \text{其他项}
$$

当 $\mathbf{f}_t \approx 1$ 时,梯度直传,不衰减——这就是"细胞状态作为高速公路"的数学解释。

遗忘门学到的就是"何时保留 / 何时遗忘",可学习长程依赖。

### 3.5 GRU 数学定义 🎓

GRU 简化 LSTM,合并细胞态与隐状态,合并门:

$$
\begin{aligned}
\mathbf{z}_t &= \sigma(W_z [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_z) & \text{(更新门)} \\
\mathbf{r}_t &= \sigma(W_r [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_r) & \text{(重置门)} \\
\tilde{\mathbf{h}}_t &= \tanh(W [\mathbf{r}_t \odot \mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}) & \text{(候选隐状态)} \\
\mathbf{h}_t &= (1 - \mathbf{z}_t) \odot \mathbf{h}_{t-1} + \mathbf{z}_t \odot \tilde{\mathbf{h}}_t & \text{(隐状态)}
\end{aligned}
$$

GRU 参数比 LSTM 少 1/3,性能相当,小数据更受欢迎。

### 3.6 LSTM vs GRU 对比

| 维度 | LSTM | GRU |
|------|------|-----|
| 门数 | 3(遗忘/输入/输出) | 2(更新/重置) |
| 状态 | 细胞态 + 隐状态 | 仅隐状态 |
| 参数 | 多 | 少 1/3 |
| 长依赖 | 强 | 略弱 |
| 训练速度 | 慢 | 快 |
| 默认选择 | 大数据 | 小数据 |

## 四、双向 RNN

### 4.1 动机

有些任务当前位置的信息依赖前后文(如命名实体识别),单向 RNN 只看过去,丢失未来信息。

### 4.2 结构

```
前向:  h₁ᶠ → h₂ᶠ → h₃ᶠ → ... → hₜᶠ
        ↓      ↓      ↓            ↓
        h₁    h₂    h₃    ...    hₜ   (拼接)
        ↑      ↑      ↑            ↑
后向:  h₁ᵇ ← h₂ᵇ ← h₃ᵇ ← ... ← hₜᵇ
```

$$
\mathbf{h}_t = [\mathbf{h}_t^f; \mathbf{h}_t^b]
$$

### 4.3 适用场景

- **可以**:NER、文本分类、机器翻译(编码器)
- **不可**:语言模型(生成时只能看过去)、实时语音识别(未来不可得)

## 五、Seq2Seq 与编码器-解码器

### 5.1 结构

```
Encoder              Decoder
h₁→h₂→h₃             s₁→s₂→s₃
↑  ↑  ↑               ↑  ↑  ↑
x₁ x₂ x₃              y₁ y₂ y₃
         ╲            ╱
          context (c)
```

- 编码器把输入序列编码为上下文向量 $\mathbf{c}$ (通常最后隐状态)
- 解码器以 $\mathbf{c}$ 为初始状态,逐步生成输出

### 5.2 暴露偏差(Exposure Bias)

**问题**:训练时解码器输入真实 $y_{t-1}$,推理时输入自己生成的 $\hat{y}_{t-1}$。一旦出错,后续雪上加霜。

**解决**:
- **Scheduled Sampling**:训练时以一定概率用 $\hat{y}_{t-1}$ 替代 $y_{t-1}$,概率随训练递增
- **Teacher Forcing**:始终用真实标签(标准做法)
- **最小风险训练**:用整个序列的期望损失

### 5.3 Seq2Seq 的瓶颈

固定长度上下文 $\mathbf{c}$ 必须编码全部输入信息,长序列时信息丢失。这是注意力机制诞生的动机。

## 六、PyTorch 实现

### 6.1 从零实现 LSTM

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class LSTMFromScratch(nn.Module):
    """从零实现的 LSTM(单层)"""
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.input_size = input_size
        self.hidden_size = hidden_size
        
        # 把 4 个门的权重合并为一个大矩阵,效率更高
        # i, f, g, o 各一个
        self.W_x = nn.Linear(input_size, 4 * hidden_size)
        self.W_h = nn.Linear(hidden_size, 4 * hidden_size)
        
    def forward(self, x, init_state=None):
        """
        x: (batch, seq_len, input_size)
        return: outputs (batch, seq_len, hidden_size), (h_n, c_n)
        """
        B, T, _ = x.shape
        if init_state is None:
            h = torch.zeros(B, self.hidden_size, device=x.device)
            c = torch.zeros(B, self.hidden_size, device=x.device)
        else:
            h, c = init_state
        
        outputs = []
        for t in range(T):
            gates = self.W_x(x[:, t]) + self.W_h(h)  # (B, 4H)
            i, f, g, o = gates.chunk(4, dim=-1)
            i = torch.sigmoid(i)
            f = torch.sigmoid(f)
            g = torch.tanh(g)
            o = torch.sigmoid(o)
            
            c = f * c + i * g
            h = o * torch.tanh(c)
            outputs.append(h)
        
        outputs = torch.stack(outputs, dim=1)  # (B, T, H)
        return outputs, (h, c)

# 测试
lstm = LSTMFromScratch(64, 128)
x = torch.randn(32, 10, 64)
outputs, (h, c) = lstm(x)
print(outputs.shape, h.shape, c.shape)  # (32, 10, 128), (32, 128), (32, 128)
```

### 6.2 从零实现 GRU

```python
class GRUFromScratch(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        # z, r, h_tilde 各一个
        self.W_x = nn.Linear(input_size, 3 * hidden_size)
        self.W_h = nn.Linear(hidden_size, 3 * hidden_size)
    
    def forward(self, x, h=None):
        B, T, _ = x.shape
        if h is None:
            h = torch.zeros(B, self.hidden_size, device=x.device)
        
        outputs = []
        for t in range(T):
            gates = self.W_x(x[:, t]) + self.W_h(h)
            z, r, h_tilde = gates.chunk(3, dim=-1)
            z = torch.sigmoid(z)
            r = torch.sigmoid(r)
            
            # 重置门用于候选态
            h_tilde = torch.tanh(
                self.W_x(x[:, t])[:, 2*self.hidden_size:] + 
                self.W_h(r * h)[:, 2*self.hidden_size:]
            )
            
            h = (1 - z) * h + z * h_tilde
            outputs.append(h)
        
        return torch.stack(outputs, dim=1), h
```

### 6.3 用 nn.LSTM 实现 Seq2Seq

```python
class Encoder(nn.Module):
    def __init__(self, vocab_size, embed_size, hidden_size, num_layers=2, dropout=0.1):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size, padding_idx=0)
        self.lstm = nn.LSTM(embed_size, hidden_size, num_layers=num_layers, 
                            dropout=dropout, batch_first=True, bidirectional=True)
        self.hidden_size = hidden_size
        self.num_layers = num_layers
    
    def forward(self, src):
        # src: (batch, src_len)
        embedded = self.embedding(src)  # (batch, src_len, embed)
        outputs, (hidden, cell) = self.lstm(embedded)
        # 双向 LSTM 的 hidden 是 (num_layers*2, batch, hidden)
        # 需要把两个方向拼接或压缩
        return outputs, (hidden, cell)


class Decoder(nn.Module):
    def __init__(self, vocab_size, embed_size, hidden_size, num_layers=2, dropout=0.1):
        super().__init__()
        self.vocab_size = vocab_size
        self.embedding = nn.Embedding(vocab_size, embed_size, padding_idx=0)
        # 解码器单向
        self.lstm = nn.LSTM(embed_size, hidden_size * 2, num_layers=num_layers,  # hidden*2 因编码器双向
                            dropout=dropout, batch_first=True)
        self.fc_out = nn.Linear(hidden_size * 2, vocab_size)
    
    def forward(self, input_token, hidden, cell):
        # input_token: (batch,)
        embedded = self.embedding(input_token).unsqueeze(1)  # (batch, 1, embed)
        output, (hidden, cell) = self.lstm(embedded, (hidden, cell))
        prediction = self.fc_out(output.squeeze(1))  # (batch, vocab)
        return prediction, hidden, cell


class Seq2Seq(nn.Module):
    def __init__(self, encoder, decoder, device):
        super().__init__()
        self.encoder = encoder
        self.decoder = decoder
        self.device = device
    
    def forward(self, src, trg, teacher_forcing_ratio=0.5):
        # src, trg: (batch, seq_len)
        batch_size = src.shape[0]
        trg_len = trg.shape[1]
        trg_vocab_size = self.decoder.vocab_size
        
        outputs = torch.zeros(batch_size, trg_len, trg_vocab_size).to(self.device)
        
        # 编码
        _, (hidden, cell) = self.encoder(src)
        # 调整 hidden 维度(双向 → 单向)
        # 简化:取最后两层
        hidden = hidden.view(self.decoder.lstm.num_layers, 2, batch_size, -1)
        hidden = hidden.transpose(1, 2).reshape(self.decoder.lstm.num_layers, batch_size, -1)
        cell = cell.view(self.decoder.lstm.num_layers, 2, batch_size, -1)
        cell = cell.transpose(1, 2).reshape(self.decoder.lstm.num_layers, batch_size, -1)
        
        # 第一个输入是 <sos>
        input_token = trg[:, 0]
        
        for t in range(1, trg_len):
            output, hidden, cell = self.decoder(input_token, hidden, cell)
            outputs[:, t] = output
            # teacher forcing
            teacher_force = torch.rand(1).item() < teacher_forcing_ratio
            input_token = trg[:, t] if teacher_force else output.argmax(-1)
        
        return outputs

# 训练
encoder = Encoder(vocab_size=10000, embed_size=256, hidden_size=512)
decoder = Decoder(vocab_size=10000, embed_size=256, hidden_size=512)
model = Seq2Seq(encoder, decoder, device='cuda')

optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss(ignore_index=0)  # 忽略 padding

for src, trg in dataloader:
    output = model(src, trg, teacher_forcing_ratio=0.5)
    # output: (batch, trg_len, vocab), trg: (batch, trg_len)
    output = output[:, 1:].reshape(-1, output.shape[-1])
    trg = trg[:, 1:].reshape(-1)
    loss = criterion(output, trg)
    optimizer.zero_grad()
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step()
```

### 6.4 双向 LSTM 文本分类

```python
class BiLSTMClassifier(nn.Module):
    def __init__(self, vocab_size, embed_size, hidden_size, num_classes, num_layers=2, dropout=0.3):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size, padding_idx=0)
        self.lstm = nn.LSTM(embed_size, hidden_size, num_layers=num_layers,
                           batch_first=True, bidirectional=True, dropout=dropout)
        self.dropout = nn.Dropout(dropout)
        # 双向 → 2*hidden_size
        self.fc = nn.Linear(2 * hidden_size, num_classes)
    
    def forward(self, x):
        # x: (batch, seq_len)
        embedded = self.dropout(self.embedding(x))
        # 用 packed sequence 处理变长(忽略 padding)
        lengths = (x != 0).sum(dim=1).cpu()
        packed = nn.utils.rnn.pack_padded_sequence(embedded, lengths, batch_first=True, enforce_sorted=False)
        packed_output, (hidden, cell) = self.lstm(packed)
        # hidden: (num_layers*2, batch, hidden)
        # 取最后一层的前后向
        hidden = torch.cat([hidden[-2], hidden[-1]], dim=1)  # (batch, 2*hidden)
        return self.fc(self.dropout(hidden))
```

## 七、常见陷阱与调参经验 ⚠️

### 7.1 训练陷阱

| 陷阱 | 表现 | 解决 |
|------|------|------|
| 梯度爆炸 | loss NaN | 梯度裁剪(clip 1.0) |
| 梯度消失 | 长序列学不会 | 用 LSTM/GRU,不用 vanilla RNN |
| 没用 padding mask | pad 影响结果 | pack_padded_sequence |
| teacher forcing 太高 | 推理时分歧 | Scheduled Sampling |
| 没用预训练词向量 | 小数据效果差 | 用 GloVe/BERT |
| 序列太长 | 显存爆炸 | 截断 / 滑动窗口 / Transformer |

### 7.2 调参经验

1. **hidden_size**:128-1024,小数据用小
2. **num_layers**:2-3 层,深了不收益
3. **dropout**:0.1-0.5,层间 + 全连接
4. **梯度裁剪**:clip 1.0 必加
5. **batch size**:32-128,序列长度影响显存
6. **优化器**:Adam 1e-3,SGD 1.0 需调

### 7.3 序列处理技巧

1. **Padding**:统一长度,加 mask
2. **Bucketing**:相似长度同 batch,减少 padding
3. **Truncated BPTT**:超长序列分段反向传播
4. **双向 vs 单向**:分类用双向,生成用单向

## 八、与其他方法的关系

### 8.1 RNN vs CNN vs Transformer

| 维度 | RNN | CNN | Transformer |
|------|-----|-----|-------------|
| 长依赖 | LSTM 较好 | 受感受野限制 | 自注意力好 |
| 并行 | 序列串行 | 高 | 高 |
| 复杂度(序列长 T) | O(T) | O(T) | O(T²) |
| 适合 | 长序列、小数据 | 图像、短序列 | 大数据、大模型 |

### 8.2 RNN → Attention → Transformer

- RNN 的瓶颈:Seq2Seq 的固定长度上下文
- Attention:解码时动态关注编码器不同位置
- Transformer:抛弃 RNN,纯 attention + MLP,完全并行

### 8.3 现代 RNN

- **Mamba**(2023):状态空间模型,推理 O(1),长序列优秀
- **RWKV**:RNN 风格但可并行训练
- **RetNet**:结合 RNN 与 attention 优点

## 九、面试速答 ⭐

- **RNN 梯度消失**:连乘雅可比谱半径 < 1,梯度指数衰减
- **LSTM 三门**:遗忘门(保留历史)、输入门(写新信息)、输出门(控制输出)
- **LSTM 缓解消失**:细胞态 $\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + ...$,遗忘门 ≈ 1 时梯度直传
- **GRU vs LSTM**:GRU 2 门 1 状态,LSTM 3 门 2 状态,GRU 参数少 1/3
- **BPTT**:RNN 在时间展开后用反向传播,梯度沿时间反向
- **双向 RNN**:前向后向拼接,适合分类,不能用于生成
- **Teacher Forcing**:训练时用真实标签作输入,推理用自己输出,有暴露偏差
