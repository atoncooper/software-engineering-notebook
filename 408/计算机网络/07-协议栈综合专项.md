## 7.1 报文分析专项

### 7.1.1 题型

给出报文十六进制 + 抓包信息,要求分析:
- 以太网帧首部 (源/目的 MAC)
- IP 首部 (TTL、协议、源/目的 IP)
- TCP/UDP 首部 (端口、标志位)
- 应用层协议 (HTTP 请求、DNS 查询)

### 7.1.2 解题步骤 (5 步法)

**步骤 1:拆分以太网帧** (14 字节首部 + 数据 + 4 字节 FCS)
- 目的 MAC 6B + 源 MAC 6B + 类型 2B
- 类型:0x0800 = IPv4, 0x0806 = ARP, 0x86DD = IPv6

**步骤 2:拆分 IP 首部** (20 字节固定 + 选项)
- 版本 4b + 首部长度 4b (以 4B 为单位)
- TTL、协议 (6=TCP, 17=UDP, 1=ICMP, 89=OSPF)
- 源 IP 4B + 目的 IP 4B

**步骤 3:拆分 TCP/UDP 首部**
- TCP (20B+):源端口 2B + 目的端口 2B + seq 4B + ack 4B + 数据偏移 + 标志 + 窗口 + 校验和 + 紧急指针
- UDP (8B):源端口 2B + 目的端口 2B + 长度 2B + 校验和 2B

**步骤 4:应用层识别**
- 根据端口识别协议:80=HTTP, 53=DNS, 25=SMTP, 21=FTP, 443=HTTPS
- 解析协议内容

**步骤 5:验证校验和** (如题目要求)

### 7.1.3 完整例题

**给定以太网帧前 40 字节**:
```
00 1a 2b 3c 4d 5e 00 0c 29 12 34 56 08 00 45 00
00 28 1a 2b 40 00 40 06 12 34 c0 a8 01 01 0a 00
00 01 04 d2 00 50 12 34 56 78 00 00 00 00 50 02
20 00 xx xx 00 00
```

**解析**:

| 字段 | 字节 | 解析 |
|------|------|------|
| 目的 MAC | 00 1a 2b 3c 4d 5e | 00:1a:2b:3c:4d:5e |
| 源 MAC | 00 0c 29 12 34 56 | 00:0c:29:12:34:56 |
| 类型 | 08 00 | 0x0800 = IPv4 |
| 版本+IHL | 45 | 版本 4, IHL 5 (20 字节) |
| DS | 00 | 默认 |
| 总长度 | 00 28 | 40 字节 |
| 标识 | 1a 2b | 0x1a2b |
| 标志+片偏移 | 40 00 | DF=1, MF=0, 偏移 0 |
| TTL | 40 | 0x40 = 64 |
| 协议 | 06 | 6 = TCP |
| 首部校验和 | 12 34 | (验证略) |
| 源 IP | c0 a8 01 01 | 192.168.1.1 |
| 目的 IP | 0a 00 00 01 | 10.0.0.1 |
| 源端口 | 04 d2 | 0x04d2 = 1234 |
| 目的端口 | 00 50 | 0x0050 = 80 (HTTP) |
| seq | 12 34 56 78 | 0x12345678 |
| ack | 00 00 00 00 | 0 |
| 数据偏移+标志 | 50 02 | 偏移 5 (20B), SYN=1 |
| 窗口 | 20 00 | 8192 |
| 校验和 | xx xx | (略) |
| 紧急指针 | 00 00 | 0 |

**结论**:这是一个 **TCP SYN 报文**,从 192.168.1.1:1234 到 10.0.0.1:80 (HTTP),TTL=64,发起 HTTP 连接。

### 7.1.4 例题 2 (ARP 报文)

**给定以太网帧**:
```
ff ff ff ff ff ff 00 0c 29 12 34 56 08 06 00 01
08 00 06 04 00 01 00 0c 29 12 34 56 c0 a8 01 01
00 00 00 00 00 00 0a 00 00 01
```

**解析**:
- 目的 MAC:ff:ff:ff:ff:ff:ff (**广播**)
- 源 MAC:00:0c:29:12:34:56
- 类型:0x0806 = ARP
- 硬件类型:0x0001 (以太网)
- 协议类型:0x0800 (IP)
- 硬件长度:6, 协议长度:4
- 操作:0x0001 (ARP 请求)
- 发送方 MAC:00:0c:29:12:34:56
- 发送方 IP:192.168.1.1
- 目标 MAC:00:00:00:00:00:00 (请求中未知)
- 目标 IP:10.0.0.1

**结论**:ARP 请求,192.168.1.1 询问 10.0.0.1 的 MAC。

## 7.2 路由表推演专项

### 7.2.1 题型

给定路由表,目的 IP,求下一跳或转发接口。

### 7.2.2 解题步骤

1. 与每条路由的子网掩码 AND
2. 比较结果与目的网络
3. 多匹配选最长前缀
4. 无匹配选默认路由
5. 仍无则丢弃,发 ICMP 目的不可达

### 7.2.3 完整例题 1

**路由表**:
| 目的网络 | 掩码 | 下一跳 |
|----------|------|--------|
| 192.168.0.0 | 255.255.0.0 | R1 |
| 192.168.1.0 | 255.255.255.0 | R2 |
| 10.0.0.0 | 255.0.0.0 | R3 |
| 0.0.0.0 | 0.0.0.0 | R4 (默认) |

**目的 192.168.1.5**:
- AND 255.255.0.0 = 192.168.0.0 ✓ (前缀 16)
- AND 255.255.255.0 = 192.168.1.0 ✓ (前缀 24)
- AND 255.0.0.0 ≠ 10.0.0.0 ✗
- AND 0.0.0.0 = 0.0.0.0 ✓ (前缀 0)

**最长前缀 24 → R2**

### 7.2.4 完整例题 2 (无匹配)

**目的 172.16.5.3**, 路由表同上:
- AND 255.255.0.0 ≠ 192.168.0.0 ✗
- AND 255.255.255.0 ≠ 192.168.1.0 ✗
- AND 255.0.0.0 ≠ 10.0.0.0 ✗
- AND 0.0.0.0 = 0.0.0.0 ✓ (前缀 0)

**走默认路由 → R4**

## 7.3 子网划分专项

### 7.3.1 题型

给定网段,要求分 N 个子网,每子网 M 台主机。

### 7.3.2 解题步骤

1. 确定主机位数:$2^h - 2 \geq M$ → 最小 h
2. 确定子网位数:$2^s \geq N$ → 最小 s
3. 验证 $s + h \leq$ 原主机位
4. 计算子网掩码、各子网网络号、广播号、主机范围

### 7.3.3 完整例题 1

**题**:192.168.1.0/24 分 4 个子网,每子网 50 台主机。

**解**:
1. 50 台 → h = 6 (2⁶ - 2 = 62 ≥ 50)
2. 4 子网 → s = 2 (2² = 4)
3. s + h = 8 = 原主机位 ✓
4. 掩码 /26 = 255.255.255.192
5. 子网块大小 = 64

| 子网 | 网络号 | 主机范围 | 广播号 |
|------|--------|----------|--------|
| 1 | 192.168.1.0 | 192.168.1.1 ~ 192.168.1.62 | 192.168.1.63 |
| 2 | 192.168.1.64 | 192.168.1.65 ~ 192.168.1.126 | 192.168.1.127 |
| 3 | 192.168.1.128 | 192.168.1.129 ~ 192.168.1.190 | 192.168.1.191 |
| 4 | 192.168.1.192 | 192.168.1.193 ~ 192.168.1.254 | 192.168.1.255 |

### 7.3.4 完整例题 2 (变长子网)

**题**:某公司 172.16.0.0/16,需 4 个子网,分别容纳 200、100、50、50 主机。求划分。

**解**:
1. 排序:200 > 100 > 50 > 50
2. 200 主机 → h=8 (2⁸-2=254 ≥ 200),掩码 /24
3. 100 主机 → h=7 (2⁷-2=126 ≥ 100),掩码 /25
4. 50 主机 → h=6 (2⁶-2=62 ≥ 50),掩码 /26
5. 划分:
   - 子网 1:172.16.0.0/24 (172.16.0.1~172.16.0.254)
   - 子网 2:172.16.1.0/25 (172.16.1.1~172.16.1.126)
   - 子网 3:172.16.1.128/26 (172.16.1.129~172.16.1.190)
   - 子网 4:172.16.1.192/26 (172.16.1.193~172.16.1.254)

**变长子网划分原则**:从最大需求开始,逐级细分,避免地址浪费。

## 7.4 协议栈穿透专项

### 7.4.1 发送方封装 (逐层加头)

```
应用层:  数据 (Message)
   │ + TCP 头 (20B)
传输层:  报文段 (Segment)
   │ + IP 头 (20B)
网络层:  数据报 (Datagram)
   │ + 帧头 (14B) + 帧尾 (4B FCS)
链路层:  帧 (Frame)
   │ 编码
物理层:  比特流 (Bit)
```

### 7.4.2 接收方解封装 (逐层剥头)

```
物理层:  比特流
   │ 解码
链路层:  帧 → 剥帧头帧尾 → 检 FCS
   │ 剥 IP 头
网络层:  数据报 → 查路由 → 上交/转发
   │ 剥 TCP 头
传输层:  报文段 → 查端口 → 上交应用
   │
应用层:  数据
```

### 7.4.3 跨网段转发 (核心!)

**源主机 → 默认网关 (路由器) → ... → 目的主机**:

```
源主机 (1.1.1.1)         网关 R1 (1.1.1.254)        R2 (5.5.5.254)        目的 (5.5.5.5)
     │                          │                       │                      │
     │ 帧: dst=R1 MAC, src=源 MAC │                       │                      │
     │ IP: dst=5.5.5.5, src=1.1.1.1 │                    │                      │
     │ ──────────────────────► │                       │                      │
     │                          │ 查路由表, 下一跳 R2     │                      │
     │                          │ ARP 解析 R2 MAC        │                      │
     │                          │ 帧: dst=R2 MAC, src=R1 MAC │                 │
     │                          │ IP: dst=5.5.5.5, src=1.1.1.1 (TTL-1)         │
     │                          │ ────────────────────► │                      │
     │                          │                       │ ARP 解析目的 MAC      │
     │                          │                       │ 帧: dst=目的 MAC, src=R2 MAC
     │                          │                       │ IP: dst=5.5.5.5, src=1.1.1.1 (TTL-1)
     │                          │                       │ ───────────────────► │
```

**关键规律**:
- **IP 不变**:源 IP、目的 IP 全程不变
- **MAC 变**:每跳 MAC 重新封装 (源=本跳出接口, 目=下一跳)
- **TTL 每跳 -1**
- 每跳用 ARP 解析下一跳 MAC

### 7.4.4 路由器转发流程 (完整 6 步)

1. 收到帧,剥帧头,检查 FCS
2. 检查目的 MAC 是否是本机 (或广播)
3. 剥 IP 头,检查 TTL:
   - TTL=0:丢弃,发 ICMP 超时
   - TTL>0:TTL-1
4. 查路由表 (最长前缀匹配),找下一跳与出接口
5. ARP 解析下一跳 MAC (或查 ARP 缓存)
6. 重新封装帧,从出接口转发

## 7.5 NAT 翻译专项

### 7.5.1 NAT (Network Address Translation)

**作用**:私有 IP ↔ 公网 IP 翻译,缓解 IPv4 短缺。

### 7.5.2 NAT 类型

| 类型 | 说明 |
|------|------|
| 静态 NAT | 一对一,固定映射 |
| 动态 NAT | 一对一,动态分配 |
| PAT (NAPT) | 多对一,基于端口 (最常用) |

### 7.5.3 NAPT 翻译实例

**内部主机 192.168.1.10:1234 访问 8.8.8.8:80**:

| 阶段 | 源 IP:Port | 目的 IP:Port |
|------|-----------|-------------|
| 内部→NAT | 192.168.1.10:1234 | 8.8.8.8:80 |
| NAT 翻译后 | 203.0.113.5:5000 | 8.8.8.8:80 |
| 8.8.8.8 回应 | 8.8.8.8:80 | 203.0.113.5:5000 |
| NAT 反向翻译 | 8.8.8.8:80 | 192.168.1.10:1234 |

**NAT 表**:
| 内部 IP:Port | 外部 IP:Port | 外部目的 |
|--------------|--------------|----------|
| 192.168.1.10:1234 | 203.0.113.5:5000 | 8.8.8.8:80 |

**陷阱**:NAT 修改源 IP 和源端口,目的不变。NAT 破坏了端到端原则,某些协议 (如 FTP 主动模式) 需 ALG 辅助。

## 7.7 真题陷阱 (25 条)

1. **MAC 跨网段变,IP 不变**
2. **TTL 每跳 -1**,为 0 丢弃
3. **目的端口应用层协议识别**:80=HTTP, 53=DNS, 25=SMTP
4. **以太网类型字段**:0x0800 IP, 0x0806 ARP, 0x86DD IPv6
5. **子网划分注意 -2**:网络号 + 广播号
6. **最长前缀匹配**:多条匹配选最长
7. **路由器隔离广播域**:广播帧不跨路由器
8. **ARP 不经过 IP**,直接封装在以太网帧
9. **IP 首部长度 IHL 以 4 字节为单位**
10. **TCP 数据偏移以 4 字节为单位**
11. **TCP 标志位 SYN/FIN 消耗 1 序号**
12. **NAT 修改源 IP+端口,目的不变**
13. **NAPT 多对一基于端口区分**
14. **CIDR /22 聚合**:四子网合并
15. **片偏移以 8 字节为单位**
16. **DF=1 不允许分片**,超 MTU 丢弃发 ICMP
17. **路由器转发流程**:剥帧→查TTL→查路由→ARP→重封→转发
18. **首部校验和每跳重算** (TTL 变)
19. **TCP 端口 16 位,最多 65535**
20. **ICMP 协议号 1,OSPF 89**
21. **ARP 请求广播,应答单播**
22. **集线器不隔离任何域,交换机隔离冲突域,路由器隔离广播域**
23. **变长子网从大需求开始**
24. **HTTP 1.1 默认持久连接**
25. **DHCP 跨网段需中继代理**

## 7.8 综合计算示例

### 7.8.1 报文分析综合题

**题**:某以太网帧数据:
```
ff ff ff ff ff ff 00 1a 2b 3c 4d 5e 08 06 00 01
08 00 06 04 00 01 00 1a 2b 3c 4d 5e c0 a8 01 0a
00 00 00 00 00 00 c0 a8 01 0b
```

**解析**:
1. 以太网帧:
   - 目的 MAC: ff:ff:ff:ff:ff:ff (广播)
   - 源 MAC: 00:1a:2b:3c:4d:5e
   - 类型: 0x0806 (ARP)
2. ARP 报文:
   - 硬件类型: 0x0001 (以太网)
   - 协议类型: 0x0800 (IP)
   - 硬件长度: 6, 协议长度: 4
   - 操作: 0x0001 (请求)
   - 发送方 MAC: 00:1a:2b:3c:4d:5e
   - 发送方 IP: 192.168.1.10
   - 目标 MAC: 00:00:00:00:00:00 (未知)
   - 目标 IP: 192.168.1.11

**结论**:192.168.1.10 广播 ARP 请求,询问 192.168.1.11 的 MAC。

### 7.8.2 路由+子网综合题

**题**:主机 A (192.168.1.10/24) 访问 B (10.0.0.5/8),网关 R1 (192.168.1.1),路由表:
- 10.0.0.0/8 → R2 (192.168.1.2)
- 0.0.0.0/0 → R3

求 A→B 全程 MAC 和 IP 变化。

**解**:
1. A 查掩码:192.168.1.10/24 与 10.0.0.5 不在同网段
2. A 用 ARP 解析网关 R1 MAC
3. A→R1:
   - 帧: dst=R1 MAC, src=A MAC
   - IP: dst=10.0.0.5, src=192.168.1.10, TTL=64
4. R1 查路由:10.0.0.0/8 匹配,下一跳 R2
5. R1 用 ARP 解析 R2 MAC
6. R1→R2:
   - 帧: dst=R2 MAC, src=R1 MAC
   - IP: dst=10.0.0.5, src=192.168.1.10, TTL=63
7. R2 → B (假设同网段):
   - 帧: dst=B MAC, src=R2 MAC
   - IP: dst=10.0.0.5, src=192.168.1.10, TTL=62

**规律**:IP 全程不变,MAC 每跳变,TTL 每跳 -1。

### 7.8.3 NAT 翻译题

**题**:内部 192.168.1.10:3000 访问 8.8.8.8:53,NAT 外部 IP 203.0.113.5,分配外部端口 4000。给出 NAT 表与各阶段地址。

**解**:
- NAT 表:
  | 内部 | 外部 | 目的 |
  |------|------|------|
  | 192.168.1.10:3000 | 203.0.113.5:4000 | 8.8.8.8:53 |
- 各阶段:
  1. A→NAT: 192.168.1.10:3000 → 8.8.8.8:53
  2. NAT→外: 203.0.113.5:4000 → 8.8.8.8:53
  3. 外→NAT: 8.8.8.8:53 → 203.0.113.5:4000
  4. NAT→A: 8.8.8.8:53 → 192.168.1.10:3000
