## 1.1 概念与组成

### 1.1.1 定义

**计算机网络** = 互连的、自治的计算机集合。

- **互连**:通过通信链路连接
- **自治**:无主从关系 (区别于主从终端系统)

### 1.1.2 三阶段发展

| 阶段 | 特点 | 代表 |
|------|------|------|
| 面向终端 | 主机+终端,集中控制 | SAGE |
| 分组交换 | 多主机互连,分布式 | ARPANET |
| 标准化 | OSI 参考模型 | TCP/IP |
| 互联网 | 全球互联 | Internet |

### 1.1.3 组成 (按工作方式)

```
┌─────────────────────────────────┐
│  边缘部分 (资源子网)              │
│  ┌──┐  ┌──┐  ┌──┐                │
│  │C1│  │C2│  │C3│ 主机/终端       │
│  └─┬┘  └─┬┘  └─┬┘                │
├────┼─────┼─────┼─────────────────┤
│  核心部分 (通信子网)              │
│  ┌──┴────┴─────┴──┐               │
│  │  路由器/交换机  │ 传输+交换      │
│  └────────────────┘               │
└─────────────────────────────────┘
```

- **边缘部分**:主机 (用户设备),提供资源
- **核心部分**:路由器、交换机,提供分组交换
- **通信子网**:物理层、链路层、网络层 (传输功能)
- **资源子网**:应用层 (信息处理)

### 1.1.4 组成 (按功能)

| 子系统 | 包含层 | 功能 |
|--------|--------|------|
| 通信子网 | 物理、链路、网络 | 数据传输与交换 |
| 资源子网 | 应用 (含会话/表示) | 信息处理与共享 |

## 1.3 性能指标 (公式推导)

### 1.3.1 速率 (Rate)

**定义**:单位时间传输的比特数。
- 单位:b/s (bps)、kb/s、Mb/s、Gb/s
- 换算:1 kb/s = 10³ b/s, 1 Mb/s = 10⁶ b/s (注意:不是 1024)
- 注意:存储容量用 2 的幂 (1 KB = 1024 B),速率用 10 的幂

### 1.3.2 带宽 (Bandwidth)

**两种含义**:
1. **模拟信号**:信号频带宽度,单位 Hz
2. **数字网络**:最高数据率,单位 bps

**本质**:单位时间内能通过信道的信息量上限 (奈氏准则、香农定理给出极限,见 [[02-物理层]])。

### 1.3.3 时延 (Delay) — 必背四大组成

$$
D_{总} = D_{发送} + D_{传播} + D_{处理} + D_{排队}
$$

| 时延 | 公式 | 影响因素 |
|------|------|----------|
| 发送时延 | 数据长度 L / 带宽 W | 带宽、数据量 |
| 传播时延 | 信道长度 D / 电磁波速率 V | 距离、介质 |
| 处理时延 | 路由器解析、查表 | 路由器性能 |
| 排队时延 | 等待输出链路 | 网络拥塞程度 |

**电磁波传播速率**:
- 真空/空气:3 × 10⁸ m/s
- 铜线:2 × 10⁸ m/s
- 光纤:2 × 10⁸ m/s (光纤中光速约为真空 2/3)

**陷阱**:带宽提高只减少发送时延,**不**减少传播时延!

### 1.3.4 时延带宽积

$$
时延带宽积 = 传播时延 \times 带宽
$$

**含义**:信道中"在途"的比特数,即信道容量。类似"管道中的水量"。

**例**:带宽 1 Mb/s,传播时延 100 ms,则时延带宽积 = 10⁶ × 0.1 = 10⁵ bit = 12.5 KB。

### 1.3.5 往返时延 RTT

**定义**:从发送端发送数据到收到接收端确认的双向时间。

**构成**:
- RTT ≈ 2 × 传播时延 + 处理时延 + 排队时延
- **不包括**发送时延 (RTT 是确认来回,不是数据来回)
- TCP 中 RTT 用于计算 RTO (重传超时)

### 1.3.6 利用率

| 指标 | 公式 |
|------|------|
| 信道利用率 | 有数据通过时间 / 总时间 |
| 网络利用率 | 加权平均信道利用率 |

**重要公式 (D 与 U 的关系)**:
$$
D = \frac{D_0}{1 - U}
$$
- D₀:空闲时延,U:利用率,D:实际时延
- 当 U → 1 时,D → ∞ (拥塞)

**例**:U=0.5 时,D = 2D₀;U=0.9 时,D = 10D₀。

## 1.4 分层体系结构

### 1.4.1 为什么要分层

- 各层独立,降低复杂度
- 灵活性好,某层改动不影响其他
- 易实现和维护
- 促进标准化

### 1.4.2 数据封装 (逐层加头)

```
应用层:  数据 (Message)                       ← 报文
            │ + TCP 头 (20 B)
传输层:  报文段 (Segment)                     ← 报文段/UDP 数据报
            │ + IP 头 (20 B)
网络层:  数据报 (Datagram / Packet)           ← 分组/数据报
            │ + 帧头 (14 B) + 帧尾 (4 B FCS)
链路层:  帧 (Frame)                           ← 帧
            │ 编码
物理层:  比特流 (Bit)                          ← 比特
```

**每层 PDU (协议数据单元)**:
| 层 | PDU 名称 |
|----|----------|
| 应用层 | 报文 (Message) |
| 传输层 | 报文段 (TCP) / 用户数据报 (UDP) |
| 网络层 | 数据报 / 分组 (Packet) |
| 链路层 | 帧 (Frame) |
| 物理层 | 比特 (Bit) |

### 1.4.3 服务数据单元 SDU 与协议数据单元 PDU

```
        ┌─────────── n+1 层 ───────────┐
        │   SDU (服务数据单元)          │
        │     │ 加 PCI (协议控制信息)   │
        │     ▼                        │
        │   PDU (协议数据单元)          │
        └──────┬──────────────────────┘
               │ 通过 SAP (服务访问点)
        ┌──────▼─────────── n 层 ──────┐
        │   SDU = (n+1) 层的 PDU       │
        └──────────────────────────────┘
```

- **PCI** (Protocol Control Information):协议控制信息,即"头"
- **PDU = SDU + PCI**
- **SAP** (Service Access Point):层间接口,如 IP 地址 (网络层 SAP)、端口号 (传输层 SAP)、MAC 地址 (链路层 SAP)

## 1.5 OSI 七层模型

### 1.5.1 七层详解

| 层 | 名称 | 功能 | 典型协议 | 数据单位 |
|----|------|------|----------|----------|
| 7 | 应用层 | 用户接口,网络应用 | HTTP, FTP, SMTP, DNS | 报文 |
| 6 | 表示层 | 数据格式、加密、压缩 | JPEG, SSL/TLS, ASCII | 报文 |
| 5 | 会话层 | 建立、管理、同步会话 | RPC, NetBIOS | 报文 |
| 4 | 传输层 | 端到端可靠传输 | TCP, UDP | 报文段 |
| 3 | 网络层 | 路由、寻址、转发 | IP, ICMP, OSPF | 数据报 |
| 2 | 数据链路层 | 帧封装、差错控制 | PPP, HDLC, Ethernet | 帧 |
| 1 | 物理层 | 比特传输 | RS-232, V.35 | 比特 |

**记忆口诀** (从下往上):**物 / 数 / 网 / 传 / 会 / 表 / 应**

### 1.5.2 各层功能深挖

**物理层**:规定电气、机械、规程特性,透明传输比特流。

**数据链路层**:
- 帧封装 (加帧头帧尾)
- 差错控制 (CRC)
- 流量控制 (停等/GBN/SR)
- 介质访问控制 (MAC)

**网络层**:
- 路由选择
- 寻址 (IP)
- 拥塞控制

**传输层**:
- 端到端通信 (端口复用)
- 可靠传输 (TCP)
- 流量控制、拥塞控制

**会话层**:
- 会话建立、维持、终止
- 同步点 (允许断点续传)

**表示层**:
- 数据格式转换 (ASCII ↔ EBCDIC)
- 加密/解密
- 压缩/解压

**应用层**:
- 用户网络应用接口
- 协议:HTTP/FTP/SMTP/DNS

### 1.5.3 真题陷阱

- **表示层**处理数据格式转换 (如 ASCII ↔ EBCDIC)、加密压缩,**不**做路由
- **会话层**管理会话同步点,不是建立连接 (这是传输层)
- **传输层**是第一个端到端层 (1-3 层是点到点)
- **网络层**负责寻址和路由,数据单位是数据报

## 1.6 TCP/IP 四层模型

| 层 | 功能 | 协议 |
|----|------|------|
| 应用层 | 用户接口 | HTTP, FTP, DNS, SMTP |
| 传输层 | 端到端 | TCP, UDP |
| 网际层 | 路由 | IP, ICMP, ARP, OSPF, BGP |
| 网络接口层 | 链路 + 物理 | Ethernet, PPP, WiFi |

TCP/IP 是工业事实标准,与 OSI 相比:
- 无独立表示层、会话层 (并入应用层)
- 无独立物理层、链路层 (合并为网络接口层)
- 网际层对应 OSI 网络层,但**只提供无连接服务**

### 1.6.1 TCP/IP 与 OSI 对比

| 对比项 | OSI | TCP/IP |
|--------|-----|--------|
| 层数 | 7 | 4 |
| 网络层服务 | 面向连接 + 无连接 | 仅无连接 |
| 传输层服务 | TP4 面向连接 | TCP 面向连接 + UDP 无连接 |
| 出现时间 | 先理论后实现 | 先实现后理论 |
| 实际应用 | 几乎无 | 互联网主流 |

## 1.7 五层模型 (教材常用)

综合 OSI 与 TCP/IP,教材 (谢希仁) 采用五层:

| 层 | 功能 | 协议 | PDU |
|----|------|------|-----|
| 应用层 | 用户接口 | HTTP, DNS, FTP | 报文 |
| 传输层 | 端到端 | TCP, UDP | 报文段 |
| 网络层 | 路由寻址 | IP, ICMP | 数据报 |
| 数据链路层 | 帧封装 | PPP, Ethernet | 帧 |

## 1.8 协议与服务

### 1.8.1 协议 (水平)

**协议**是**水平**的,是同层实体间通信的规则集合。

**三要素**:
| 要素 | 含义 | 例子 |
|------|------|------|
| 语法 | 数据格式 | IP 头部 20 字节固定字段 |
| 语义 | 含义、控制信息 | "目的地址字段表示接收方" |
| 同步 | 时序、应答关系 | TCP 三次握手时序 |

### 1.8.2 服务 (垂直)

**服务**是**垂直**的,是下层向上层提供的功能。

- **服务访问点 SAP**:层间接口
  - 链路层 SAP:MAC 地址
  - 网络层 SAP:IP 地址
  - 传输层 SAP:端口号
- **服务原语**:
  - 请求 (Request)
  - 指示 (Indication)
  - 响应 (Response)
  - 证实 (Confirm)

### 1.8.3 协议 vs 服务 (高频考点)

| 维度 | 协议 | 服务 |
|------|------|------|
| 方向 | 水平 (同层) | 垂直 (层间) |
| 对象 | 对等实体 | 上下层 |
| 可见性 | 对上层透明 | 上层可见 |
| 实现形式 | 本层内部实现 | 接口 |

**关键**:协议是"如何通信",服务是"提供什么能力"。本层协议的改换不影响上层服务 (服务透明)。

### 1.8.4 面向连接 vs 无连接

| 类型 | 特点 | 例子 |
|------|------|------|
| 面向连接 | 建连 → 传输 → 释放 | TCP, ATM |
| 无连接 | 直接传输 | UDP, IP, Ethernet |

### 1.8.5 可靠 vs 不可靠

**可靠传输**需具备:
1. 差错控制 (检测 + 重传)
2. 序号 (有序交付)
3. 确认 (ACK)
4. 重传 (超时/冗余 ACK)
5. 流量控制 (滑动窗口)

## 1.9 各层设备 (必背)

| 设备 | 工作层 | 功能 | 转发依据 |
|------|--------|------|----------|
| 中继器 / 集线器 | 物理层 | 信号再生 | 电气信号 |
| 网桥 / 交换机 | 链路层 | 帧转发 | MAC 地址 |
| 路由器 | 网络层 | 分组转发 | IP 地址 |
| 网关 | 应用层 | 协议转换 | 应用协议 |

**集线器 vs 交换机**:
- 集线器:物理层,广播,共享带宽,冲突域不隔离
- 交换机:链路层,基于 MAC 转发,独占带宽,隔离冲突域

**冲突域 vs 广播域**:
| 设备 | 冲突域 | 广播域 |
|------|--------|--------|
| 集线器 | 不隔离 | 不隔离 |
| 交换机 | 隔离 | 不隔离 |
| 路由器 | 隔离 | 隔离 |

## 1.10 真题陷阱与高频考点 (25 条)

1. **OSI 七层顺序**:物/数/网/传/会/表/应 (从下到上)
2. **表示层**:数据格式、加密、压缩,**不**做路由
3. **会话层**:管理会话,**不**建立连接 (传输层建立)
4. **协议是水平的,服务是垂直的**
5. **PDU 名称**:报文/报文段/数据报/帧/比特
6. **时延带宽积** = 传播时延 × 带宽
7. **带宽不影响传播时延**,只影响发送时延
8. **TCP/IP 是工业标准**,OSI 是理论参考模型
9. **传输层是端到端**,1-3 层是点到点
10. **TCP/IP 网络层只无连接**,OSI 网络层可有连接 (虚电路)
11. **SAP 各层不同**:MAC/IP/端口
12. **集线器不隔离冲突域**,交换机隔离
13. **路由器隔离广播域**
14. **协议三要素**:语法、语义、同步
15. **服务原语四类**:请求、指示、响应、证实
16. **PDU = SDU + PCI**
17. **电磁波在光纤中速率为 2×10⁸ m/s**,非 3×10⁸
18. **RTT 不含发送时延**,含 2 倍传播时延
19. **网络利用率公式** D = D₀ / (1-U),U→1 时 D→∞
20. **存储用 2 的幂,速率用 10 的幂** (1 KB=1024 B,1 kb/s=1000 b/s)
21. **物理层规定电气/机械/功能/规程四特性**
22. **链路层流量控制**:停等、GBN、SR
23. **网络层路由**:OSPF (链路状态)、BGP (路径向量)
24. **传输层端口**:熟知 0-1023,注册 1024-49151,动态 49152-65535
25. **应用层 DNS**:UDP 53 端口;**HTTP**:TCP 80
