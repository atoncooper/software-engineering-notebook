## 3.1 封装成帧

### 3.1.1 帧定界

把网络层数据报封装成帧,需标识帧的开始与结束。

**帧结构**:
```
┌────────┬────────┬─────────────┬────────┐
│ 帧首部 │  数据  │  帧尾部(FCS) │ 帧定界 │
└────────┴────────┴─────────────┴────────┘
```

### 3.1.2 四种方法

| 方法 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| 字符计数 | 帧首含长度字段 | 简单 | 计数错则全错 |
| 字符填充 (SOH/EOT) | SOH 标首,EOT 标尾,数据转义 | 直观 | 仅限文本,8-bit |
| 零比特填充 (HDLC) | 01111110 标界,5 连 1 插 0 | 透明传输 | 需位操作 |
| 违规编码法 | 用非法编码 (曼彻斯特中无跳变) | 透明 | 依赖编码 |

### 3.1.3 零比特填充完整流程

**发送方**:数据中每出现 5 个连续的 1,自动在其后插入一个 0。
**接收方**:每见到 5 个连续的 1,删除其后跟随的 0。

**例**:数据 `011111101` → 发送 `01111101**0**1` (5 连 1 后插 0)
**接收方**收到 `0111110101` → 还原 `011111101`

> **真题陷阱**:零比特填充实现透明传输,数据中可任意 0/1 序列。

### 3.1.4 字符填充完整流程

**发送方**:数据中遇 SOH/EOT/ESC 时,前面加 ESC 转义。
**接收方**:遇 ESC 则知后一字符是数据而非定界符。

**例**:数据 `SOH ... EOT ... ESC` → 发送 `ESC SOH ... ESC EOT ... ESC ESC`

## 3.2 差错控制

### 3.2.1 检错 vs 纠错

- **检错码**:能发现错,不能定位 (CRC、奇偶校验)
- **纠错码**:能定位并纠正 (海明码)

### 3.2.2 海明码 (完整推导)

**核心思想**:在数据位之间插入校验位,使任何一位错都能通过校验结果定位。

**校验位数量**:$r$ 个校验位,$k$ 个数据位,需满足:
$$
2^r \geq k + r + 1
$$

**校验位位置**:在第 $2^i$ 位 (i=0,1,2,...),即第 1, 2, 4, 8, 16, ... 位

**例**:4 位数据 1011 → 需 3 校验位 (2³ ≥ 4+3+1=8 ✓),共 7 位:
```
位置: 1  2  3  4  5  6  7
内容: r1 r2 1  r4 0  1  1
```

**校验位计算** (异或偶校验):
- r1 (位置 1,3,5,7):r1 = 1⊕0⊕1 = 0
- r2 (位置 2,3,6,7):r2 = 1⊕1⊕1 = 1
- r4 (位置 4,5,6,7):r4 = 0⊕1⊕1 = 0

发送:`0 1 1 0 0 1 1`

**纠错**:接收方计算 S = r4r2r1 (二进制),值为错位位置 (0 表示无错)。

### 3.2.3 CRC 完整计算实例

**生成多项式** $G(x)$,数据后追加 r 个 0 (r = G 最高次数),模 2 除得余数 FCS。

**模 2 除法**:**异或代替减法**,不借位。

**例**:数据 M = 101001,G(x) = x³+x²+1 = 1101,求 FCS。

**步骤**:
1. r = 3,数据后加 3 个 0:M' = 101001000
2. 模 2 除:
```
        110101      商
     _____________
1101 / 101001000
       1101
       ----
        1110
        1101
        ----
         0111
         0000
         ----
          1110
          1101
          ----
           0110
           0000
           ----
            110      余数 (FCS)
```
3. 发送:101001 **110** (原数据 + FCS)

**接收方校验**:用 G(x) 除接收数据,余数为 0 则无错。

**CRC 检错能力**:
- 所有奇数位错 (若 G 含 (x+1) 因子)
- 所有双位错 (若 G 含 $x^c+1$ 且 c ≥ 帧长)
- 所有 ≤ r 位的突发错
- $[2^{-(r-1)}]$ 比例的更长突发错 (漏检率)

**常用生成多项式**:
- CRC-16: x¹⁶+x¹⁵+x²+1 (HDLC)
- CRC-32: 802.3 标准

### 3.2.4 反馈重传 ARQ

| 协议 | 重传方式 | 窗口 |
|------|----------|------|
| 停止等待 ARQ | 单帧重传 | 1 |
| 回退 N (GBN) | 出错后所有重传 | >1 |
| 选择重传 (SR) | 只重传出错帧 | >1 |

## 3.3 流量控制与可靠传输

### 3.3.1 停止等待 (Stop-and-Wait)

发送方发一帧,等 ACK,超时重传。

- 发送窗口 = 1,接收窗口 = 1
- 信道利用率:$U = \frac{t_f}{t_f + RTT + t_a} \approx \frac{t_f}{RTT}$
- 优点:简单;缺点:利用率低

### 3.3.2 滑动窗口

发送窗口 $W_S$,接收窗口 $W_R$。

| 协议 | $W_S$ | $W_R$ |
|------|-------|-------|
| 停止等待 | 1 | 1 |
| GBN | > 1 | 1 |
| SR | > 1 | > 1 |

**信道利用率公式**:
$$
U = \frac{W \cdot t_f}{t_f + RTT + t_a}
$$
其中 W 是窗口大小,$t_f$ 发送时延,$t_a$ 确认时延。

## 3.4 滑动窗口协议

### 3.4.1 GBN (回退 N)

**特点**:
- 发送窗口 $W_S ≤ 2^n - 1$ (n 位序列号)
- 接收窗口 $W_R = 1$
- 出错:从出错帧起全部重传 (回退 N)
- **累计确认**:ACK n 表示 n 以前所有帧都已收到
- 接收方只需缓冲 1 帧

**时序图 (n=2, W_S=3)**:
```
发送方:  F0  F1  F2      (F1丢失)  F3(W)        超时重传F1
          ↓   ↓   ↓                  ↓              ↓
接收方:  F0  -   F2      F3(丢弃)              F1  F2  F3
          ↓       ↓                          ↓   ↓   ↓
确认:    A1      A1(累计)                  A2  A3  A4
          (期望F1)                          (期望F2,F3,F4)
```

**为什么 W_S ≤ 2^n - 1?**
若 W_S = 2^n,发送方发 0,1,2,3 (n=2),接收方全收并回 ACK 0 (期望 0 的新一轮)。若 ACK 全丢失,发送方超时重发 0,1,2,3,接收方误以为是新帧 (因序列号 0 又出现)。故 $W_S ≤ 2^n - 1$ 避免新旧帧混淆。

### 3.4.2 SR (选择重传)

**特点**:
- $W_S + W_R ≤ 2^n$ (硬约束)
- 通常 $W_S = W_R = 2^{n-1}$
- 只重传出错帧
- **非累计确认** (每个帧独立 ACK)
- 接收方需缓冲 W_R 帧

**时序图 (n=2, W_S=W_R=2)**:
```
发送方:  F0  F1      (F1丢失)  F2      F3(W)     超时重传F1
          ↓   ↓                  ↓        ↓           ↓
接收方:  F0   -                 F2       F3          F1
          ↓                      ↓        ↓           ↓
确认:    A0                     A2       A3          A1
```

**为什么 W_S + W_R ≤ 2^n?**
若 W_S + W_R > 2^n,接收窗口可能与发送窗口"重叠",导致接收方无法区分新旧帧。

### 3.4.3 三协议对比

| 协议 | $W_S$ | $W_R$ | 序列号上限 | 重传 | 确认 | 缓冲 |
|------|-------|-------|-----------|------|------|------|
| 停等 | 1 | 1 | 0/1 | 单帧 | 独立 | 1 |
| GBN | $2^n-1$ | 1 | $W_S ≤ 2^n-1$ | 回退 N | 累计 | 1 |
| SR | $2^{n-1}$ | $2^{n-1}$ | $W_S+W_R ≤ 2^n$ | 单帧 | 独立 | W_R |

> **必背**:$W_S + W_R ≤ 2^n$ 是 SR 的硬约束,避免新旧帧混淆。

## 3.5 介质访问控制

### 3.5.1 信道划分 (静态)

| 方式 | 描述 |
|------|------|
| FDM | 频分复用 |
| TDM | 时分复用 |
| STDM | 统计时分 (按需) |
| WDM | 波分复用 (光纤) |
| CDM | 码分复用 (CDMA) |

### 3.5.2 随机访问 (动态)

#### ALOHA

- **纯 ALOHA**:随时发,冲突则随机重传。**吞吐量峰值 18%** (G=0.5 时)
- **时隙 ALOHA**:在时隙边界发,冲突则下时隙重传。**吞吐量峰值 37%** (G=1 时)

**吞吐量公式**:
- 纯 ALOHA:$S = G \cdot e^{-2G}$
- 时隙 ALOHA:$S = G \cdot e^{-G}$

#### CSMA/CD (以太网)

**Carrier Sense Multiple Access with Collision Detection**:

1. **先听后发**:发前监听信道空闲
2. **边发边听**:发送时检测冲突
3. **冲突停发**:检测到冲突立即停止
4. **强化冲突**:发 48 位 jam 信号
5. **二进制退避**:随机等待重传

**最小帧长公式**:
$$
L_{\min} = 2 \tau \cdot C = \text{RTT} \cdot C
$$
其中 $\tau$ 是单程传播时延,C 是带宽。

**推导**:发送方必须在发送完一帧前能检测到冲突。最坏情况:信号到达对端时才冲突,冲突信号回来时刚好发完 → 帧发送时间 ≥ 2τ。

**以太网参数**:
- 10 Mbps,最大距离 2500 m,τ ≈ 25 μs
- 最小帧长 = 2 × 25 μs × 10 Mb/s = 500 bit → 取 512 bit = 64 字节
- 不足 64 字节需填充

**二进制退避算法**:
- 第 k 次冲突,$k = \min(\text{重传次数}, 10)$
- 等待时间 = $\{0, 1, \dots, 2^k - 1\}$ 中随机一个 × 2τ
- 16 次失败放弃,向上层报错

**例**:第 3 次冲突,k=3,等待 [0, 7] 中随机数 × 2τ。

**争用期 (碰撞期)**:2τ,即 RTT。在争用期内未检测到冲突,则本次发送成功。

#### CSMA/CA (无线)

无线不能用 CD (无法边发边听,且隐藏终端问题),改用 CA (避免):

- **帧间间隔 IFS**:SIFS (短)、PIFS、DIFS (长)
- **RTS/CTS 握手**:预约信道,解决隐藏终端
- **退避**:监听空闲 DIFS + 随机退避

### 3.5.3 轮询访问

| 协议 | 描述 |
|------|------|
| 令牌环 | 令牌传递,持有者可发送 |
| 轮询 | 主节点依次询问从节点 |

**令牌环优点**:无冲突,公平;**缺点**:令牌维护开销,令牌丢失则全网停。

## 3.6 局域网

### 3.6.1 IEEE 802 标准

| 标准 | 描述 |
|------|------|
| 802.3 | CSMA/CD (以太网) |
| 802.5 | 令牌环 |
| 802.11 | Wi-Fi (CSMA/CA) |
| 802.1Q | VLAN 标签 |
| 802.1D | 生成树 STP |

### 3.6.2 以太网帧 (802.3)

```
┌────────┬──────┬──────────┬─────────┬──────┬─────────────┬──────┐
│ 前导7B │SFD1B │目的MAC6B │ 源MAC6B │类型2B│ 数据 46~1500B│FCS4B │
└────────┴──────┴──────────┴─────────┴──────┴─────────────┴──────┘
```

- 最小帧长 64 B (含目的、源、类型、数据、FCS),不足 46 B 数据需填充
- **MTU = 1500 B** (Maximum Transmission Unit)
- MAC 地址 48 位,前 24 位厂商标识 (OUI),后 24 位序列号
- 类型字段:0x0800 (IP), 0x0806 (ARP), 0x86DD (IPv6)
- 前导 7B + SFD 1B 用于同步,不计入帧长

### 3.6.3 高速以太网

| 标准 | 速率 | 特点 |
|------|------|------|
| 10BASE-T | 10 Mb/s | 双绞线,星型 |
| 100BASE-TX | 100 Mb/s | 双绞线 |
| 1000BASE-T | 1 Gb/s | 双绞线 |
| 10GBASE-T | 10 Gb/s | 全双工,无 CSMA/CD |

> **陷阱**:千兆以上以太网通常全双工,不再使用 CSMA/CD。

### 3.6.4 VLAN

**虚拟局域网**:逻辑划分广播域,不受物理位置限制。

**802.1Q 标签** (4 字节,插入源 MAC 与类型之间):
```
┌──────────┬────────────┬─────────────────┬──────┐
│ TPID 2B  │  TCI 2B    │     原类型 2B    │ ...  │
│ 0x8100   │ 优先级3+VID12+...│            │      │
└──────────┴────────────┴─────────────────┴──────┘
```

- 最多 4094 个 VLAN (VID 0、4095 保留)
- 跨交换机:**Trunk 链路**,标签保留
- 同交换机访问:**Access 端口**,去掉标签

**VLAN 端口类型**:
| 端口 | 发送 | 接收 |
|------|------|------|
| Access | 去标签 | 加标签 (本 VLAN) |
| Trunk | 保留标签 | 保留标签 (允许多 VLAN) |
| Hybrid | 可配 | 可配 |

## 3.7 链路层设备

### 3.7.1 中继器与集线器 (物理层)

- 中继器:放大整形信号
- 集线器:多端口中继器,共享带宽,**不隔离冲突域**,**不隔离广播域**

### 3.7.2 网桥与交换机 (链路层)

- 网桥:连接两个局域网段,**隔离冲突域**,基于 MAC 表转发
- 交换机:多端口网桥,每端口一个冲突域,**隔离冲突域**,**不隔离广播域**

**交换机自学习完整流程**:
1. 收到帧,记录 (源 MAC, 入端口, 时间) 到 MAC 表
2. 查目的 MAC:
   - 在表中且端口≠入端口:从对应端口转发
   - 在表中且端口=入端口:过滤 (丢弃)
   - 不在表中:**泛洪** (除入端口外所有端口)
3. 表项有老化时间 (默认 300s),超时删除

**例**:
- 主机 A (端口 1) 发帧给 B
- 交换机学习:A 在端口 1
- B 不在表 → 泛洪到端口 2,3,4
- B 回复 → 交换机学习:B 在端口 2
- 后续 A→B 直接从端口 2 转发

**生成树协议 STP (802.1D)**:
- 目的:防止环路,阻断冗余链路
- 选举根桥 (最小 BID = 优先级 + MAC)
- 每个非根桥选根端口 (到根代价最小)
- 每段链路选指定端口
- 阻塞非指定端口
- 收敛时间 30-50s (快速 STP RSTP 1-3s)

### 3.7.3 路由器 (网络层)

**隔离广播域** + **隔离冲突域**。

### 3.7.4 隔离总结

| 设备 | 冲突域 | 广播域 |
|------|--------|--------|
| 集线器 | 不隔离 | 不隔离 |
| 网桥 | 隔离 | 不隔离 |
| 交换机 | 隔离 (每端口一个) | 不隔离 |
| 路由器 | 隔离 | 隔离 |
| VLAN (交换机内) | - | 隔离 (不同 VLAN) |

> **真题陷阱**:
> - 交换机不隔离广播域 (广播帧会泛洪)
> - VLAN 可在交换机内隔离广播域
> - 路由器是天然的广播域边界
> - 一个 VLAN = 一个广播域

## 3.8 真题陷阱与高频考点 (30 条)

1. **零比特填充**:5 连 1 后插 0,接收方删 0
2. **字符填充**:遇 SOH/EOT/ESC 加 ESC 转义
3. **GBN 序列号**:$W_S ≤ 2^n - 1$ (不是 $2^n$)
4. **SR 序列号**:$W_S + W_R ≤ 2^n$,通常 $2^{n-1}$
5. **CSMA/CD 最小帧长**:$2\tau C$,以太网 64 字节
6. **二进制退避**:k = min(冲突次数, 10),最大 16 次放弃
7. **VLAN 标签**:802.1Q,4 字节,VID 12 位,共 4094 个
8. **交换机自学习**:源 MAC → 端口,目的 MAC 转发或泛洪
9. **冲突域 vs 广播域**:交换机隔离冲突不隔离广播,路由器都隔离
10. **MTU**:以太网 1500 B (不含帧头)
11. **MAC 地址 48 位**:OUI 24 + 序列号 24
12. **CRC 是检错码,不能纠错**
13. **海明码可纠 1 位错**,需 $2^r ≥ k+r+1$
14. **CRC 模 2 除法**:异或代替减法,不借位
15. **GBN 累计确认**:ACK n 表示 n 以前所有帧收到
16. **SR 非累计确认**:每帧独立 ACK
17. **CSMA/CD 用于有线**,CSMA/CA 用于无线
18. **争用期 = 2τ = RTT**
19. **强化冲突 jam 信号 48 位**
20. **纯 ALOHA 峰值 18%,时隙 ALOHA 峰值 37%**
21. **千兆以上以太网全双工,无 CSMA/CD**
22. **STP 防止环路,阻塞冗余链路**
23. **Trunk 链路保留 VLAN 标签,Access 去标签**
24. **前导 7B + SFD 1B 不计入帧长**
25. **交换机表项老化时间默认 300s**
26. **海明码校验位在 2^i 位置**
27. **令牌环无冲突,但令牌丢失则全网停**
28. **数据链路层流量控制与传输层流量控制不同**:链路层是相邻节点,传输层是端到端
29. **PPP 不使用序号和确认机制** (不可靠,但提供差错检测)
30. **PPP 支持 PAP/CHAP 鉴权**

## 3.10 综合计算示例

### 3.10.1 CSMA/CD 最小帧长

**题**:10 Mb/s 以太网,电缆长度 1 km,信号传播速率 2×10⁸ m/s。求最小帧长。

**解**:
1. 单程时延 τ = 1000 / (2×10⁸) = 5 μs
2. 争用期 2τ = 10 μs
3. 最小帧长 = 10 μs × 10 Mb/s = 100 bit
4. 实际以太网取 512 bit = 64 字节 (覆盖更远距离)

### 3.10.2 GBN 窗口与利用率

**题**:卫星链路 RTT=500 ms,带宽 1 Mb/s,帧长 1000 bit,n=4,GBN。求窗口与最大利用率。

**解**:
1. GBN W_S ≤ 2⁴ - 1 = 15
2. 单帧发送时延 t_f = 1000 / 10⁶ = 1 ms
3. 利用率 U = W·t_f / (t_f + RTT) = W / (1 + 500) ≈ W/501
4. 取 W=15,U ≈ 15/501 ≈ 3% (受窗口限制)

### 3.10.3 交换机 MAC 表学习

**题**:3 端口交换机,初始 MAC 表空。A(P1)→B,B(P2)→A,C(P3)→A,A(P1)→C。给出每步 MAC 表变化与转发决策。

**解**:
| 步骤 | 源→目 | 学习 | 决策 |
|------|-------|------|------|
| 1 | A→B (P1) | A@P1 | B 不在表,泛洪 P2,P3 |
| 2 | B→A (P2) | B@P2 | A 在表,从 P1 转发 |
| 3 | C→A (P3) | C@P3 | A 在表,从 P1 转发 |
| 4 | A→C (P1) | A 已学 | C 在表,从 P3 转发 |
