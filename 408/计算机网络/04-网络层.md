## 4.1 IPv4

### 4.1.1 首部 (20 字节固定 + 选项)

```
┌─0─4─8─16──────────31─┐
│ 版本 │ IHL │ DS  │ 总长度  │
│ 标识         │DF MF│片偏移  │
│ TTL │ 协议 │ 首部校验和  │
│ 源 IP                 │
│ 目的 IP               │
│ 选项 (可变,0~40B)     │
└──────────────────────┘
```

**完整字段表**:

| 字段 | 位数 | 含义 |
|------|------|------|
| 版本 | 4 | IPv4=4, IPv6=6 |
| 首部长度 IHL | 4 | 以 4 字节为单位,最小 5 (20 B) |
| 区分服务 DS | 8 | QoS 标记 |
| 总长度 | 16 | 整个 IP 数据报字节数,最大 65535 |
| 标识 | 16 | 同一数据报各分片相同 |
| 标志 | 3 | DF (不分片) + MF (还有片) + 保留 |
| 片偏移 | 13 | 以 8 字节为单位 |
| TTL | 8 | 每经路由器 -1,0 丢弃 |
| 协议 | 8 | TCP=6, UDP=17, ICMP=1, OSPF=89 |
| 首部校验和 | 16 | 只校验首部,每跳重算 |
| 源 IP | 32 | 发送方 IP |
| 目的 IP | 32 | 接收方 IP |
| 选项 | 0-40 | 可选,如记录路由、时间戳 |

**关键陷阱**:
- **首部长度 IHL 以 4 字节为单位**,不是字节
- **片偏移以 8 字节为单位**
- **首部校验和每跳重算** (因 TTL 变化)
- **总长度最大 65535 字节**

### 4.1.2 分片完整计算

**MTU** 限制数据报大小 (以太网 1500 B)。超长则分片:
- 每片数据 = MTU - IP 首部 (1480 B)
- 各片独立路由,目的端重组
- 片偏移以 8 字节为单位,因此**片长必须是 8 的倍数**

**完整实例**:
**题**:数据报 4000 字节 (含 20 B 首部),数据 3980 B,MTU=1500 B。求分片结果。

**解**:
1. 每片最大数据 = 1500 - 20 = 1480 B (1480 是 8 的倍数 ✓)
2. 第一片:数据 1480 B,偏移 0, MF=1
3. 第二片:数据 1480 B,偏移 1480/8 = 185, MF=1
4. 第三片:数据 3980 - 1480 - 1480 = 1020 B,偏移 370, MF=0

**片偏移** = 本片数据起始字节 / 8

### 4.1.3 IP 地址分类

| 类 | 前缀 | 网络号 | 范围 | 默认掩码 |
|----|------|--------|------|----------|
| A | 0 | 8 位 | 1.0.0.0 ~ 126.255.255.255 | /8 |
| B | 10 | 16 位 | 128.0.0.0 ~ 191.255.255.255 | /16 |
| C | 110 | 24 位 | 192.0.0.0 ~ 223.255.255.255 | /24 |
| D | 1110 | 多播 | 224.0.0.0 ~ 239.255.255.255 | - |
| E | 1111 | 保留 | 240.0.0.0 ~ 255.255.255.255 | - |

**注意**:127.0.0.0/8 是环回地址,**不属于 A 类**;A 类实际从 1 开始。

**私有地址** (RFC 1918):
- A:10.0.0.0/8
- B:172.16.0.0/12 (172.16 ~ 172.31)
- C:192.168.0.0/16

**特殊地址**:
| 地址 | 含义 |
|------|------|
| 0.0.0.0 | 本网络本主机 (DHCP Discover 源) |
| 255.255.255.255 | 全网广播 (DHCP Discover 目的) |
| 127.0.0.0/8 | 环回 |
| 169.254.0.0/16 | 链路本地 (DHCP 失败) |
| 224.0.0.0/4 | 多播 |

## 4.2 子网划分与 CIDR

### 4.2.1 子网划分 (借位法)

从主机号借位作子网号,引入**子网掩码**标识。

$$
\text{子网数} = 2^{\text{借位数}}, \quad \text{主机数} = 2^{\text{剩余主机位}} - 2
$$

减 2:全 0 (网络号)、全 1 (广播)。

**完整实例 1**:
**题**:192.168.1.0/24 划分 4 个子网,求掩码、各子网地址范围、主机数。

**解**:
1. 4 个子网需借 2 位 (2²=4)
2. 子网掩码 255.255.255.192 (/26)
3. 每子网主机数 = 2⁶ - 2 = 62
4. 各子网:
   - 192.168.1.0/26:0~63 (主机 1~62,广播 63)
   - 192.168.1.64/26:64~127 (主机 65~126,广播 127)
   - 192.168.1.128/26:128~191
   - 192.168.1.192/26:192~255

**完整实例 2**:
**题**:某公司有 5 个部门,每部门最多 25 人,需从 172.16.0.0/16 划分。求最小子网划分。

**解**:
1. 每子网需容纳 25 主机 → 主机位 ≥ 5 (2⁵-2=30 ≥ 25)
2. 借 16-5 = 11 位子网号 → 子网掩码 /27
3. 子网数 = 2¹¹ = 2048 (足够)
4. 5 个子网:172.16.0.0/27, 172.16.0.32/27, 172.16.0.64/27, ...

### 4.2.2 CIDR (无分类域间路由)

打破 ABC 类边界,使用"/前缀长度"表示,如 192.168.0.0/20。

- 子网掩码 = 前 20 位 1,后 12 位 0
- 主机数 = $2^{12} - 2 = 4094$

**CIDR 优点**:
- 提高地址利用率 (按需分配)
- 减少路由表项 (路由聚合)
- 灵活,无类限制

### 4.2.3 路由聚合 (超网,Supernetting)

把多个子网合并为一个更大的 CIDR 块,减少路由表项。

**方法**:找各子网共同的最长前缀。

**完整实例**:
**题**:聚合以下 4 个子网:
- 192.168.0.0/24
- 192.168.1.0/24
- 192.168.2.0/24
- 192.168.3.0/24

**解**:
第三字节二进制:
- 0 = 00000000
- 1 = 00000001
- 2 = 00000010
- 3 = 00000011

共同前缀 = 22 位 (前两字节 16 位 + 第三字节前 6 位)
聚合:**192.168.0.0/22**

**验证**:192.168.0.0/22 覆盖 192.168.0.0 ~ 192.168.3.255,共 1024 地址。

### 4.2.4 最长前缀匹配

路由表中可能有多个匹配项,选**前缀最长** (最具体) 的。

**例**:目的 192.168.1.5,路由表:
- 192.168.0.0/16 → 下一跳 A
- 192.168.1.0/24 → 下一跳 B
- 0.0.0.0/0 (默认) → 下一跳 C

选 **192.168.1.0/24** (前缀 24 最长) → B。

**原理**:前缀越长越具体,匹配越精确。

## 4.3 ARP (Address Resolution Protocol)

### 4.3.1 作用

**IP → MAC 地址解析** (在网络层,但用链路层广播)。

### 4.3.2 完整过程

1. 主机 A 查本机 ARP 缓存,无 B 的 MAC
2. A **广播** ARP 请求 (目的 MAC = FF:FF:FF:FF:FF:FF),包含 A 的 IP、MAC、B 的 IP
3. 同网段所有主机收到,只有 B 单播 ARP 应答,返回 B 的 MAC
4. A 更新 ARP 缓存 (含 TTL,一般 20 分钟)

**ARP 报文格式**:
```
┌───────────────────────────┐
│ 硬件类型 2B (以太网=1)     │
│ 协议类型 2B (IP=0x0800)    │
│ 硬件地址长度 1B (6)        │
│ 协议地址长度 1B (4)        │
│ 操作 2B (请求=1, 应答=2)   │
│ 发送方 MAC 6B              │
│ 发送方 IP 4B               │
│ 目标 MAC 6B (请求时全0)    │
│ 目标 IP 4B                 │
└───────────────────────────┘
```

### 4.3.3 跨网段转发

A → B (不同网段):
1. A 发现 B 不在本网段 (用掩码 AND 比较)
2. A 用 ARP 解析**默认网关**的 MAC
3. 数据帧:**目的 MAC = 网关 MAC,目的 IP = B 的 IP**
4. 网关 (路由器) 收到,查路由表找下一跳
5. 路由器逐跳转发,每跳用 ARP 解析下一跳 MAC
6. 最后一个路由器用 ARP 解析 B 的 MAC,直接交付

**跨网段 ARP 解析流程图**:
```
A (1.1) → 网关 R1 → R2 → ... → Rn → B (5.5)

A 发帧:   目的MAC=R1 MAC, 目的IP=5.5
R1 发帧:  目的MAC=R2 MAC, 目的IP=5.5
...
Rn 发帧:  目的MAC=B MAC, 目的IP=5.5
```

> **真题陷阱**:
> - ARP 请求是**广播**,应答是**单播**
> - ARP 缓存有 TTL (一般 20 分钟)
> - ARP 在同网段使用,跨网段由路由器逐跳 ARP
> - ARP 直接封装在以太网帧中,**不经过 IP**

## 4.4 DHCP (Dynamic Host Configuration Protocol)

### 4.4.1 作用

动态分配 IP 地址及其他网络配置 (掩码、网关、DNS)。

### 4.4.2 四步 DORA (完整时序)

```
客户端                                  DHCP服务器
  │                                         │
  │ ─── Discover (广播, src=0.0.0.0) ────► │
  │                                         │
  │ ◄──── Offer (含 IP 候选) ────────────  │
  │                                         │
  │ ─── Request (广播, 确认某 Offer) ───►  │
  │                                         │
  │ ◄──── ACK (含 IP/掩码/网关/DNS/租约) ─ │
  │                                         │
```

1. **Discover**:客户端广播 (源 0.0.0.0,目的 255.255.255.255)
2. **Offer**:DHCP 服务器单播或广播回应,提供 IP
3. **Request**:客户端广播 Request,确认接受某 Offer (同时通知其他服务器收回)
4. **ACK**:DHCP 服务器确认,含 IP、掩码、网关、DNS、租约

### 4.4.3 跨网段

需 **DHCP 中继代理** (通常在路由器上),转发 DHCP 广播为单播到 DHCP 服务器。

**原因**:广播不能跨路由器 (路由器隔离广播域)。

### 4.4.4 租约续租

- 客户端在租约 **50%** 时尝试续租 (单播 Request 给原服务器)
- 续租失败,在 **87.5%** 时再尝试 (广播,任何 DHCP 服务器可响应)
- 仍失败则租约到期释放 IP

> **DHCP 用 UDP**:67 (服务器)、68 (客户端)

## 4.5 ICMP (Internet Control Message Protocol)

### 4.5.1 作用

网络层**差错报告 + 询问**。

### 4.5.2 报文类型

**差错报告**:

| Type | 含义 |
|------|------|
| 3 | 目的不可达 |
| 11 | 超时 (TTL=0) |
| 12 | 参数问题 |
| 5 | 改变路由 (Redirect) |

**询问**:

| Type | 含义 |
|------|------|
| 8/0 | 回送请求/应答 (Ping) |
| 13/14 | 时间戳请求/应答 |

### 4.5.3 应用

- **Ping**:ICMP Echo (Type 8/0),测连通性
- **Traceroute**:利用 TTL 递增 + ICMP 超时 (Type 11),逐跳探测路径

**Traceroute 完整流程**:
1. 源发 TTL=1 的 UDP/ICMP 报文
2. 第 1 跳路由器收到,TTL-1=0,丢弃,回 ICMP 超时
3. 源发 TTL=2,第 2 跳回超时
4. 重复,直到到达目的,目的回端口不可达或 Echo 应答

> **真题陷阱**:ICMP **不**发送差错报文的情况:
> - ICMP 差错报文本身出错
> - 广播/多播数据报
> - 分片非第一片
> - 链路层广播

## 4.6 IPv6

### 4.6.1 改进 (必背)

| 改进 | 说明 |
|------|------|
| 地址 128 位 | IPv4 32 位 |
| 首部简化 | 固定 40 字节,无校验和 |
| 无分片字段 | 移到扩展首部 (路由器不分片) |
| 流标签 Flow Label | 支持 QoS |
| 取消广播 | 用多播替代 |
| 增加任播 | 一对最近 |
| 即插即用 | SLAAC,无需 DHCP |

### 4.6.2 首部 (40 字节固定)

```
┌─0─4─12───────31─┐
│ 版本 │ 流量类别 │ 流标签      │
│ 载荷长度 16      │ 下一首部 8 │ 跳数限制 8 │
│ 源地址 (128 位)              │
│ 目的地址 (128 位)            │
└──────────────────────────────┘
```

- **下一首部**:类似 IPv4 协议字段,但可指向扩展首部
- **跳数限制**:类似 TTL

### 4.6.3 地址表示

- 8 组 4 位十六进制,冒号分隔:2001:0db8:0000:0000:0000:0000:0000:0001
- 简化:
  - 前导 0 省略:2001:db8:0:0:0:0:0:1
  - 连续全 0 用 `::` (一次):2001:db8::1

**陷阱**:`::` 只能出现一次,否则歧义。

### 4.6.4 地址分类

| 类型 | 前缀 | 说明 |
|------|------|------|
| 单播 | 2000::/3 | 全球单播 |
| 链路本地 | FE80::/10 | 自动配置 |
| 唯一本地 | FC00::/7 | 内部网络 |
| 多播 | FF00::/8 | 多播 |
| 环回 | ::1/128 | 本机 |

### 4.6.5 过渡策略

- **双栈**:主机同时配 IPv4/IPv6
- **隧道**:IPv6 封装在 IPv4 中穿越 IPv4 网络 (6to4, 6in4)
- **翻译**:NAT64, IPv4/IPv6 协议转换

## 4.7 路由协议

### 4.7.1 分类

- **静态 vs 动态**:静态手动配,动态自动学
- **域内 (IGP) vs 域间 (EGP)**:IGP 在 AS 内,EGP 在 AS 间

### 4.7.2 RIP (距离向量)

- **度量**:跳数,最大 15 跳,16 = 不可达
- **更新**:30 秒周期性向邻居发**完整路由表**
- **载体**:**UDP** 端口 520
- **算法**:距离向量 (Bellman-Ford)
- **触发更新**:拓扑变化立即更新
- **防环四机制**:
  1. 水平分割:不向学习到的方向回传
  2. 毒性逆转:学到方向回传 ∞ (16)
  3. 触发更新:变化立即发
  4. 最大跳数 15:限制环路传播

### 4.7.3 OSPF (链路状态)

- **度量**:代价 = 10⁸ / 带宽 (参考带宽可配,默认 100 Mb/s → 代价 1)
- **载体**:**IP 直接承载** (协议号 89),不经过 TCP/UDP
- **算法**:链路状态 (Dijkstra)
- **分区域**:骨干区域 0 + 其他区域,减少 LSA 泛洪
- **Hello 包**:发现邻居,10s 周期
- **LSU**:同步链路状态数据库
- **五种报文**:Hello, DD, LSR, LSU, LSAck

**OSPF 区域层次**:
```
        ┌─── 骨干区域 0 ───┐
        │  ABR           ABR │
        │   │             │  │
        │ 区域1          区域2│
        └────────────────────┘
```

### 4.7.4 BGP (路径向量)

- **度量**:路径属性 (AS_PATH, LOCAL_PREF, MED 等)
- **载体**:**TCP** 端口 179
- **算法**:路径向量 (记录 AS 路径,防环)
- **增量更新,非周期**
- **eBGP** (AS 间) + **iBGP** (AS 内)
- **四种报文**:OPEN, UPDATE, NOTIFICATION, KEEPALIVE

**AS_PATH 防环**:接收 UPDATE 时若 AS_PATH 含本 AS,拒绝 (避免环路)。

### 4.7.5 三协议对比 (必背)

| 协议 | 类型 | 度量 | 算法 | 载体 | 适用 | 收敛 |
|------|------|------|------|------|------|------|
| RIP | IGP | 跳数 ≤ 15 | 距离向量 | UDP 520 | 小型 | 慢 |
| OSPF | IGP | 代价 (10⁸/BW) | 链路状态 | IP 89 | 中大型 | 快 |
| BGP | EGP | 路径属性 | 路径向量 | TCP 179 | AS 间 | 慢 |

**关键差异**:
- RIP 用 UDP (不可靠,自己重传)
- OSPF 用 IP (不可靠,自己可靠机制)
- BGP 用 TCP (可靠,无需自己重传)

## 4.8 路由表与最长前缀匹配

### 4.8.1 路由表项

```
┌──────────┬──────┬────────┬──────┬──────┐
│ 目的网络 │ 掩码 │ 下一跳 │ 接口 │ 度量 │
└──────────┴──────┴────────┴──────┴──────┘
```

**默认路由**:0.0.0.0/0,匹配所有未匹配的目的。

**特定主机路由**:掩码 255.255.255.255,/32,匹配单台主机。

### 4.8.2 转发过程

1. 提取目的 IP
2. 与每条路由的掩码 AND,比较目的网络
3. 多条匹配选最长前缀
4. 无匹配选默认路由,仍无则丢弃,发 ICMP 目的不可达

### 4.8.3 完整实例

**路由表**:
| 目的网络 | 掩码 | 下一跳 |
|----------|------|--------|
| 192.168.1.0 | 255.255.255.0 | R1 |
| 192.168.0.0 | 255.255.0.0 | R2 |
| 0.0.0.0 | 0.0.0.0 | R3 |

**目的 IP 192.168.1.5**:
1. AND 255.255.255.0 = 192.168.1.0 ✓ (前缀 24)
2. AND 255.255.0.0 = 192.168.0.0 ✓ (前缀 16)
3. AND 0.0.0.0 = 0.0.0.0 ✓ (前缀 0)

选最长前缀 24 → R1。

## 4.9 移动 IP

### 4.9.1 概念

主机移动到外地网络仍保持原 IP 通信。

### 4.9.2 实体

- **家乡代理 (Home Agent, HA)**:原网络中的代理
- **外地代理 (Foreign Agent, FA)**:外地网络中的代理
- **永久 IP**:家乡地址 (不变)
- **转交地址 (Care-of Address, CoA)**:在外地获得的临时地址

### 4.9.3 完整过程

1. 移动节点到外地,通过 FA 获得转交地址 CoA
2. **注册**:CoA 告知家乡代理 HA
3. 通信对端 → 家乡地址,HA 截获,通过**隧道** (IP-in-IP) 转发到 CoA
4. 移动节点回送到对端 (**直接发送**,不经 HA)
5. 形成**三角路由**:对端→HA→MN,MN→对端

**三角路由问题**:对端到 MN 必须经 HA 绕路,效率低。

## 4.10 SDN 与 OpenFlow (了解)

**SDN (Software-Defined Networking)**:
- **数据平面**:转发
- **控制平面**:路由决策 (集中控制器)
- **接口**:OpenFlow (南向接口)

**传统 vs SDN**:
| 维度 | 传统 | SDN |
|------|------|-----|
| 控制平面 | 分布式 (每路由器) | 集中式 (控制器) |
| 数据平面 | 路由器 | 交换机 |
| 编程 | 难 | 易 (OpenFlow API) |

## 4.11 真题陷阱与高频考点 (35 条)

1. **TTL 每经路由器 -1**:为 0 丢弃,发 ICMP 超时 (Type 11)
2. **片偏移以 8 字节为单位**:片长需 8 倍数
3. **CIDR /22 聚合**:四子网合并
4. **最长前缀匹配**:多条匹配选最长
5. **ARP 请求广播,应答单播**:同网段
6. **ARP 不经过 IP**,直接封装在以太网帧
7. **DHCP 跨网段需中继**:路由器配中继代理
8. **DHCP 用 UDP** 67/68
9. **DHCP Discover 源=0.0.0.0,目的=255.255.255.255**
10. **ICMP 不回应广播/多播差错**
11. **ICMP 不回应分片非第一片**
12. **IPv6 :: 只能出现一次**
13. **IPv6 首部 40 字节固定**,无校验和
14. **IPv6 路由器不分片**,主机分片
15. **RIP 跳数 15 上限,16 不可达**
16. **RIP 用 UDP 520**
17. **OSPF 用 IP 直接承载** (协议号 89)
18. **OSPF 代价 = 10⁸ / 带宽**
19. **BGP 用 TCP 179**
20. **BGP AS_PATH 防环**:含本 AS 拒绝
21. **路由器隔离广播域**,不转发广播帧
22. **127.0.0.0/8 环回,不属于 A 类**
23. **169.254.0.0/16 链路本地** (DHCP 失败)
24. **私有地址**:10/8, 172.16/12, 192.168/16
25. **首部长度 IHL 以 4 字节为单位**,最小 5
26. **首部校验和每跳重算** (TTL 变)
27. **总长度最大 65535 字节**
28. **标识字段**:同一数据报各分片相同
29. **DF=1 不允许分片**,超 MTU 则丢弃发 ICMP
30. **MF=1 后面还有片**,最后一片 MF=0
31. **OSPF 五种报文**:Hello, DD, LSR, LSU, LSAck
32. **BGP 四种报文**:OPEN, UPDATE, NOTIFICATION, KEEPALIVE
33. **移动 IP 三角路由**:对端→HA→MN,MN→对端
34. **DHCP 租约 50% 续租,87.5% 广播续租**
35. **Traceroute 利用 TTL 递增 + ICMP 超时**

## 4.14 综合计算示例

### 4.14.1 子网划分

**题**:某公司 IP 192.168.10.0/24,需 6 个子网,每子网至少 25 主机。求划分方案。

**解**:
1. 6 子网需 3 位 (2³=8 ≥ 6)
2. 主机位 = 8 - 3 = 5,每子网 2⁵-2 = 30 主机 ≥ 25 ✓
3. 掩码 /27 (255.255.255.224)
4. 子网:0, 32, 64, 96, 128, 160, 192, 224

### 4.14.2 路由聚合

**题**:聚合 172.18.129.0/24, 172.18.130.0/24, 172.18.132.0/24, 172.18.133.0/24。

**解**:
第三字节:
- 129 = 10000001
- 130 = 10000010
- 132 = 10000100
- 133 = 10000101

共同前缀 = 100000 → 6 位 (前两字节 16 位 + 第三字节 6 位 = 22 位)
聚合:**172.18.128.0/22**

### 4.14.3 IP 分片

**题**:数据报数据 3800 B,MTU=1420 B,求分片。

**解**:
1. 每片最大数据 = 1420 - 20 = 1400 B (1400/8=175 ✓)
2. 第一片:1400 B,偏移 0, MF=1
3. 第二片:1400 B,偏移 175, MF=1
4. 第三片:3800 - 2800 = 1000 B,偏移 350, MF=0
