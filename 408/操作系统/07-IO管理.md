## 7.1 I/O 软件层次

```
┌────────────────────────────┐
│  用户层 I/O 软件            │  ← 库函数(printf)
│  (用户态)                   │
├────────────────────────────┤
│  系统调用接口               │  ← 统一接口(read/write)
├────────────────────────────┤
│  设备驱动程序               │  ← 设备特定操作
│  (内核态)                   │
├────────────────────────────┤
│  中断处理程序               │  ← 响应设备中断
├────────────────────────────┤
│  硬件                       │  ← 设备控制器
└────────────────────────────┘
```

**每层职责**:

| 层 | 职责 |
|----|------|
| 用户层 | 库函数封装(printf 封装 write) |
| 系统调用 | 统一接口,把 I/O 请求转驱动 |
| 驱动 | 设备特定操作(向设备寄存器写命令) |
| 中断处理 | 响应设备中断,完成 I/O |
| 硬件 | 设备控制器执行实际 I/O |

**设备独立性**:用户程序不直接操作设备,通过系统调用统一接口,OS 内部根据设备类型分派驱动。

## 7.2 缓冲

### 7.2.1 引入目的

1. **缓和 CPU 与设备速度不匹配**
2. **减少中断次数**(批量处理)
3. **提高 CPU 与设备并行度**

### 7.2.2 单缓冲

每设备**一个**缓冲区。

```
设备 → 缓冲区 → CPU
       (收数据)  (处理)
```

- 处理一块时间 = max(CPU 处理, 设备传输) + 缓冲区到用户区拷贝时间

**吞吐量**:

$$T = \frac{1}{\max(T_c, T_t) + T_{\text{copy}}}$$

- $T_c$:CPU 处理时间
- $T_t$:设备传输时间
- $T_{\text{copy}}$:缓冲区到用户区拷贝时间

### 7.2.3 双缓冲

**两个**缓冲区交替使用:一个收设备数据,另一个供 CPU 处理。

```
设备 → 缓冲1 ──→ CPU
       ↓
      缓冲2 ──→ CPU(交替)
```

- CPU 与设备**高度并行**
- 处理时间 ≈ max(CPU, 设备)

$$T = \frac{1}{\max(T_c, T_t)}$$

> **真题陷阱**:
> - 若 CPU 与设备速度相近,双缓冲吞吐量 ≈ 单缓冲的 2 倍
> - 若速度差大,双缓冲收益小(瓶颈在慢方)

### 7.2.4 循环缓冲

多个缓冲区组成**环形**,生产者/消费者模式。

```
       in →
   ┌──────────────────┐
   │ 缓1 → 缓2 → 缓3 → 缓4 │
   └──────────────────┘
       ← out
```

- 生产者(设备)写入 in 指针位置
- 消费者(CPU)读取 out 指针位置
- 缓冲区满则生产者等,空则消费者等

### 7.2.5 缓冲池

**公用**缓冲区集合,多设备**共享**,提高利用率。

- 多个缓冲区组成池
- 按需分配给各设备
- 避免每设备独占缓冲区导致浪费

### 7.2.6 缓冲方向

- **输入缓冲**:设备 → 缓冲 → CPU
- **输出缓冲**:CPU → 缓冲 → 设备

### 7.2.7 缓冲区计算例题

**例**:磁盘块传输到缓冲区需 100 μs,CPU 处理需 50 μs,缓冲区到用户区拷贝需 50 μs。

**单缓冲**:
- 每块时间 = max(100, 50) + 50 = 150 μs
- 吞吐量 = 1/150 μs ≈ 6667 块/秒

**双缓冲**:
- 每块时间 = max(100, 50) = 100 μs
- 吞吐量 = 1/100 μs = 10000 块/秒

### 7.2.8 单 vs 双缓冲对比

| 维度 | 单缓冲 | 双缓冲 |
|------|--------|--------|
| 缓冲区数 | 1 | 2 |
| 并行度 | 低 | 高 |
| 每块时间 | max + copy | max |
| 速度差大时收益 | — | 小 |
| 速度相近时收益 | — | ≈ 2 倍 |

## 7.3 SPOOLing

### 7.3.1 概念

**SPOOLing**(Simultaneous Peripheral Operations On-Line,假脱机):用**磁盘模拟独占设备**,使其变为**共享设备**。

### 7.3.2 组成

```
┌──────────────────────────────────────┐
│               SPOOLing 系统            │
│                                       │
│  ┌──────────┐    ┌──────────┐         │
│  │ 输入井   │    │ 输出井   │ ← 磁盘  │
│  └──────────┘    └──────────┘         │
│       ↑               ↓                │
│  ┌──────────┐    ┌──────────┐         │
│  │ 输入缓冲 │    │ 输出缓冲 │ ← 内存  │
│  └──────────┘    └──────────┘         │
│       ↑               ↓                │
│  ┌──────────┐    ┌──────────┐         │
│  │ 预输入   │    │ 缓输出   │ ← 程序  │
│  │ 程序     │    │ 程序     │         │
│  └──────────┘    └──────────┘         │
└──────────────────────────────────────┘
        ↑                  ↓
    输入设备            输出设备
   (键盘/读卡机)       (打印机)
```

**组成**:
- **输入井/输出井**:磁盘上的存储区,模拟脱机输入/输出
- **输入缓冲区/输出缓冲区**:内存中,暂存数据
- **预输入程序**:把数据从输入设备读到输入井
- **缓输出程序**:把数据从输出井送到输出设备
- **井管理程序**:管理井中数据

### 7.3.3 应用

- **打印机共享**:多进程"同时"打印,实际排队(独占 → 共享)
- **脱机打印**
- **电子邮件系统**

### 7.3.4 SPOOLing 特点

- **独占设备变共享设备**(打印机)
- 提高设备利用率和系统吞吐量
- 需要磁盘空间(井)和内存(缓冲区)
- **虚拟设备**技术

> **真题陷阱**:
> - SPOOLing 把**独占设备变共享设备**(打印机)
> - 提高设备利用率和系统吞吐量
> - 需要磁盘空间(井)和内存(缓冲区)

## 7.4 磁盘调度

### 7.4.1 磁盘地址

磁盘物理地址:**柱面号 + 磁头号(面) + 扇区号**(C/H/S)。

**逻辑块地址(LBA)**:线性编址,便于计算。

```
LBA = (柱面 × 磁头数 × 扇区数) + (磁头 × 扇区数) + 扇区
```

### 7.4.2 访问时间

$$T = T_{\text{寻道}} + T_{\text{旋转}} + T_{\text{传输}}$$

- **寻道时间**:磁头移动到目标柱面(最长,**优化重点**)
- **旋转延迟**:等待目标扇区转到磁头下
- **传输时间**:读写数据

**例**:磁盘 7200 RPM,平均寻道 8 ms,每磁道 500 扇区,求读 1 扇区时间。
- 转一圈 = 60/7200 = 8.33 ms
- 平均旋转延迟 = 8.33/2 = 4.17 ms
- 传输 1 扇区 = 8.33/500 = 0.017 ms
- 总 = 8 + 4.17 + 0.017 ≈ 12.19 ms

### 7.4.3 调度算法

#### (1) FCFS(先来先服务)

按请求顺序服务。

- 优点:**公平**
- 缺点:**寻道长**(来回移动)
- 适用:请求少

#### (2) SSTF(最短寻道时间优先)

选离当前磁头**最近**的请求。

- 优点:吞吐量大
- 缺点:**可能饥饿**远端请求
- 适用:负载均匀

#### (3) SCAN(电梯算法)

磁头**单向移动**到端,处理途中请求,到端**反向**。

- 优点:**无饥饿**
- 缺点:端附近请求等待长
- 像**电梯**:到顶再反向

#### (4) C-SCAN(循环扫描)

**单向移动**到端,处理途中请求,到端后**快速返回**另一端**不服务**。

- 优点:各位置响应时间均匀
- 缺点:返回时浪费

#### (5) LOOK / C-LOOK

- **LOOK**:SCAN 的变体,**不到端**,到**最远请求**即反向
- **C-LOOK**:C-SCAN 的变体,到**最远请求**即快速返回

### 7.4.4 完整推演例题

**请求队列**:98, 183, 37, 122, 14, 124, 65, 67
**磁头当前位置**:53
**方向**:向上
**磁盘柱面范围**:0~199

#### FCFS

```
53 → 98 → 183 → 37 → 122 → 14 → 124 → 65 → 67
移动:45 + 85 + 146 + 85 + 108 + 110 + 59 + 2 = 640
平均寻道距离 = 640/8 = 80
```

#### SSTF

```
53 → 65 → 67 → 37 → 14 → 98 → 122 → 124 → 183
移动:12 + 2 + 30 + 23 + 84 + 24 + 2 + 59 = 236
平均 = 236/8 = 29.5
```

#### SCAN(向上到 199 再反向)

```
53 → 65 → 67 → 98 → 122 → 124 → 183 → 199 → 37 → 14
移动:(199-53) + (199-14) = 146 + 185 = 331
(实际:53→65→67→98→122→124→183→199, 然后 199→37→14)
= (199-53) + (199-14) = 146 + 185 = 331
```

#### C-SCAN(向上到 199,快速返回 0,再向上)

```
53 → 65 → 67 → 98 → 122 → 124 → 183 → 199 → 0 → 14 → 37
移动:(199-53) + 199 + 37 = 146 + 199 + 37 = 382
```

#### LOOK(向上到最远 183 即反向)

```
53 → 65 → 67 → 98 → 122 → 124 → 183 → 37 → 14
移动:(183-53) + (183-14) = 130 + 169 = 299
```

#### C-LOOK(向上到最远 183,快速返回 14,再向上)

```
53 → 65 → 67 → 98 → 122 → 124 → 183 → 14 → 37
移动:(183-53) + (183-14) + (37-14) = 130 + 169 + 23 = 322
```

### 7.4.5 算法对比

| 算法 | 公平 | 饥饿 | 寻道 | 适用 |
|------|------|------|------|------|
| FCFS | 是 | 否 | 长 | 请求少 |
| SSTF | 否 | 是 | 短 | 负载均匀 |
| SCAN | 是 | 否 | 中 | 通用 |
| C-SCAN | 是 | 否 | 中 | 均匀响应 |
| LOOK | 是 | 否 | 较短 | 通用 |
| C-LOOK | 是 | 否 | 较短 | 均匀响应 |

> **真题陷阱**:
> - **SCAN 到端(199)才反向**;**LOOK 到最远请求(183)即反向**
> - **C-SCAN 反向时不服务请求**
> - **SSTF 可能饥饿**

## 7.5 真题精解

### 【2017 综合】磁盘 SCAN 推演

**题目**:见 7.4.4,请求队列 98, 183, 37, 122, 14, 124, 65, 67,磁头 53 向上,SCAN 算法,求总移动距离。

**答**:见 7.4.4 SCAN 部分。总移动 = 331。

### 【2019 选择】双缓冲吞吐量

**题目**:单缓冲 vs 双缓冲,下列正确的是?

A. 双缓冲吞吐量总是单缓冲的 2 倍
B. 速度差大时,双缓冲收益小
C. 双缓冲无需拷贝
D. 单缓冲吞吐量 = max(CPU, 设备)

**答案**:**B**

**解析**:
- 双缓冲吞吐量 = 1/max(CPU, 设备),单缓冲 = 1/(max + copy)
- 速度差大时,瓶颈在慢方,双缓冲收益小(B 对)
- 速度相近时,双缓冲 ≈ 2 倍,不是"总是"(A 错)
- 双缓冲仍需拷贝,只是重叠了(C 错)
- 单缓冲需加拷贝时间(D 错)

### 【2020 选择】SPOOLing 作用

**题目**:SPOOLing 系统的主要作用是?

A. 提高设备速度
B. 把独占设备变共享设备
C. 减少内存占用
D. 替代中断机制

**答案**:**B**

**解析**:SPOOLing 用磁盘模拟独占设备,使其变为共享设备(打印机共享)。

### 【2022 综合】磁盘调度对比

**题目**:对比 SSTF 和 SCAN,分析 SSTF 的缺点。

**答**:
- **SSTF**:选离当前磁头最近的请求,吞吐量大,但**可能饥饿**远端请求(若不断有近端请求到达,远端永远等不到服务)
- **SCAN**:磁头单向移动到端再反向,**无饥饿**(每个请求终会服务),但端附近请求等待长

## 7.6 真题陷阱(15 条)

1. **I/O 软件层次**:用户 → 系统调用 → 驱动 → 中断 → 硬件
2. **单缓冲吞吐量**:max(CPU, 设备) + 拷贝时间
3. **双缓冲吞吐量**:max(CPU, 设备),无拷贝重叠
4. **双缓冲速度差大时收益小**,速度相近时 ≈ 2 倍
5. **SPOOLing 把独占变共享**(打印机)
6. **SCAN 到端反向**,LOOK 到最远请求反向
7. **C-SCAN 反向不服务**,快速返回另一端
8. **C-LOOK 到最远请求快速返回**
9. **SSTF 可能饥饿**,远端请求被忽略
10. **磁盘访问时间**:寻道 + 旋转 + 传输,**寻道最长**
11. **缓冲目的**:缓和速度差、减少中断、提高并行
12. **SPOOLing 需磁盘(井)和内存(缓冲)**
13. **设备独立性**:用户程序不直接操作设备
14. **LBA**:线性编址,便于计算
15. **循环缓冲**:生产者/消费者模式

## 7.7 易混淆点深辨析

### 7.7.1 单 vs 双 vs 循环缓冲

| 维度 | 单缓冲 | 双缓冲 | 循环缓冲 |
|------|--------|--------|----------|
| 缓冲区数 | 1 | 2 | 多 |
| 并行度 | 低 | 高 | 高 |
| 每块时间 | max + copy | max | max |
| 适用 | 简单 | 通用 | 高负载 |

### 7.7.2 五种磁盘调度算法

| 算法 | 是否到端 | 反向是否服务 | 饥饿 |
|------|----------|--------------|------|
| FCFS | — | — | 否 |
| SSTF | — | — | 是 |
| SCAN | 到端 | 服务 | 否 |
| C-SCAN | 到端 | 不服务 | 否 |
| LOOK | 不到端 | 服务 | 否 |
| C-LOOK | 不到端 | 不服务 | 否 |

### 7.7.3 SCAN vs LOOK

- **SCAN**:到磁盘端(199)才反向
- **LOOK**:到最远请求(183)即反向,不走到端

### 7.7.4 SPOOLing vs 一般缓冲

| 维度 | 一般缓冲 | SPOOLing |
|------|----------|----------|
| 存储 | 内存 | 磁盘 + 内存 |
| 设备 | — | 独占变共享 |
| 规模 | 小 | 大 |
| 应用 | 暂存 | 打印机共享 |

## 7.10 延伸知识

### 7.10.1 SSD(固态硬盘)

- **无机械部件**:无寻道、无旋转
- **随机访问快**(μs 级)
- **磨损均衡**:FTL(Flash Translation Layer)
- **TRIM**:通知 SSD 哪些块可回收
- **有限擦写次数**(MLC/TLC/QLC)

### 7.10.2 NVMe

- **PCIe 接口**:替代 SATA
- **多队列**:每 CPU 一对提交/完成队列
- **低延迟**:μs 级
- **高吞吐**:GB/s 级

### 7.10.3 Linux I/O 调度器

- **CFQ(完全公平队列)**:默认,公平分配
- **Deadline**:每个请求有截止时间
- **NOOP**:简单 FIFO,适用 SSD
- **BFQ**:延迟敏感

### 7.10.4 I/O 多路复用

- **select/poll**:轮询文件描述符
- **epoll**:事件驱动,Linux 高性能
- **kqueue**:BSD
- **IOCP**:Windows

### 7.10.5 异步 I/O

- **POSIX AIO**:异步 I/O 接口
- **io_uring**:Linux 5.1+ 新接口,ring buffer
- **Windows IOCP**:完成端口

## 7.11 本章习题

1. I/O 软件层次结构?每层职责?
2. 单缓冲和双缓冲的吞吐量公式?何时双缓冲收益最大?
3. SPOOLing 的组成和作用?
4. 五种磁盘调度算法的特点?
5. SCAN 和 LOOK 的区别?C-SCAN 反向时是否服务?
6. 请求队列 98, 183, 37, 122, 14, 124, 65, 67,磁头 53 向上,求 SSTF 总移动。
7. 磁盘访问时间由哪几部分组成?哪个最长?

### 习题答案

1. 见 7.1 节。用户层(库函数) → 系统调用(统一接口) → 驱动(设备特定) → 中断处理(响应中断) → 硬件(执行 I/O)。

2. **单缓冲**:T = 1/(max(CPU, 设备) + 拷贝)。**双缓冲**:T = 1/max(CPU, 设备)。**速度相近时**双缓冲收益最大(≈ 2 倍单缓冲)。

3. 见 7.3 节。**组成**:输入井/输出井(磁盘) + 输入缓冲/输出缓冲(内存) + 预输入/缓输出程序。**作用**:把独占设备变共享设备(打印机)。

4. 见 7.4.3 和 7.7.2 表。

5. **SCAN 到端(199)才反向**,**LOOK 到最远请求(183)即反向**。**C-SCAN 反向时不服务**,快速返回另一端。

6. 见 7.4.4 SSTF 部分。总移动 = 236。

7. **寻道 + 旋转 + 传输**。**寻道时间最长**(机械移动),是优化重点。
