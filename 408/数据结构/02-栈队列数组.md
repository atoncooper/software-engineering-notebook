## 2.1 栈

### 2.1.1 形式化定义

栈是**限定仅在表尾进行插入或删除操作**的线性表。表尾端称为**栈顶** (top),表头端称为**栈底** (bottom)。

二元组定义:$L = (D, R)$,其中
- $D = \{a_1, a_2, \dots, a_n \mid n \geq 0, a_i \in \text{ElemSet}\}$
- $R = \{\langle a_{i-1}, a_i \rangle \mid i = 2, \dots, n\}$,约定 $a_n$ 为栈顶

**LIFO (Last In First Out)**:最后进栈的元素最先出栈。

```
进栈 →  ┌────┬────┬────┬────┐
        │ a4 │ a3 │ a2 │ a1 │   ← top (栈顶)
        └────┴────┴────┴────┘
                              ↑
                            bottom (栈底)
出栈 ←  
```

**基本操作**:
- `InitStack(&S)`:初始化
- `Push(&S, e)`:进栈
- `Pop(&S, &e)`:出栈
- `GetTop(S)`:取栈顶 (不删除)
- `Empty(S)`:判空
- `DestroyStack(&S)`:销毁

### 2.1.2 顺序栈

#### 2.1.2.1 定义与两种 top 约定

```c
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];
    int top;            // 栈顶指针
} SqStack;
```

**关键约定**:top 有两种合法实现,408 默认采用 **方案 A**:

| 方案 | top 含义 | 初始值 | 判空 | 判满 | Push | Pop |
|------|----------|--------|------|------|------|-----|
| A | 指向栈顶元素 | -1 | top == -1 | top == MaxSize-1 | `data[++top]=e` | `e=data[top--]` |
| B | 指向栈顶下一位置 | 0 | top == 0 | top == MaxSize | `data[top++]=e` | `e=data[--top]` |

#### 2.1.2.2 完整代码 (方案 A)

```c
void InitStack(SqStack &S) { S.top = -1; }

bool Empty(SqStack S) { return S.top == -1; }

bool Full(SqStack S) { return S.top == MaxSize - 1; }

bool Push(SqStack &S, ElemType e) {
    if (S.top == MaxSize - 1) return false;   // 栈满
    S.data[++S.top] = e;                      // 先 ++ 再存
    return true;
}

bool Pop(SqStack &S, ElemType &e) {
    if (S.top == -1) return false;            // 栈空
    e = S.data[S.top--];                      // 先取再 --
    return true;
}

bool GetTop(SqStack S, ElemType &e) {
    if (S.top == -1) return false;
    e = S.data[S.top];
    return true;
}
```

> **陷阱**:Push 与 Pop 中的 `++` `--` 顺序是 408 最爱考的细节。
> - 方案 A Push:`++S.top` (指针先移到下一空位,再存入);
> - 方案 A Pop:`S.top--` (先取出栈顶,指针再下移)。
> 二者**不能混用**,否则会覆盖元素或漏掉元素。

#### 2.1.2.3 共享栈

让两个栈共享一片连续空间,栈底分别在两端,栈顶向中间延伸。**目的**:两栈动态互补,提高空间利用率,只有两栈**之和**达到 MaxSize 才溢出。

```
索引:  0        top1            top2        MaxSize-1
      [栈1底  ...  栈1顶]  [空]  [栈2顶  ...  栈2底]
       ←  栈1 增长方向            栈2 增长方向  →
```

```c
typedef struct {
    ElemType data[MaxSize];
    int top1;   // 栈1顶,初始 -1
    int top2;   // 栈2顶,初始 MaxSize
} ShStack;

void InitShStack(ShStack &S) { S.top1 = -1; S.top2 = MaxSize; }

bool Push1(ShStack &S, ElemType e) {
    if (S.top1 + 1 == S.top2) return false;   // 栈满
    S.data[++S.top1] = e;
    return true;
}

bool Push2(ShStack &S, ElemType e) {
    if (S.top1 + 1 == S.top2) return false;
    S.data[--S.top2] = e;
    return true;
}
```

**判空/判满**:
- 栈1空:`top1 == -1`;栈2空:`top2 == MaxSize`
- **栈满**:`top1 + 1 == top2` (注意是 `+1`,不是 `==`)

> **真题陷阱**:共享栈满条件极易写错为 `top1 == top2`。当 top1 + 1 == top2 时,中间已无空位,即栈满。

### 2.1.3 链栈

带头结点的链栈,栈顶在头结点之后 (头插法进栈)。

```c
typedef struct Linknode {
    ElemType data;
    struct Linknode *next;
} *LiStack;

void InitStack(LiStack &S) {
    S = (Linknode *)malloc(sizeof(Linknode));
    S->next = NULL;
}

bool Push(LiStack S, ElemType e) {
    Linknode *s = (Linknode *)malloc(sizeof(Linknode));
    s->data = e;
    s->next = S->next;        // ① 新节点指向原栈顶
    S->next = s;              // ② 头结点指向新节点
    return true;
}

bool Pop(LiStack S, ElemType &e) {
    if (S->next == NULL) return false;
    Linknode *p = S->next;
    e = p->data;
    S->next = p->next;
    free(p);
    return true;
}
```

**特点**:
- 链栈不存在栈满 (除非内存耗尽)
- 进栈/出栈均为 O(1)
- 链栈**通常不带头结点**也行;带头结点时统一插入/删除位置,代码更简洁

## 2.2 队列

### 2.2.1 形式化定义

队列是**只允许在一端 (队尾 rear) 插入、另一端 (队头 front) 删除**的线性表。FIFO。

```
出队 ←  [front ... ... rear]  ← 入队
        队头              队尾
```

### 2.2.2 顺序队列与"假溢出"

普通顺序队列:`front` 指向队头,`rear` 指向队尾的下一位置。

```
初始:  [  ][  ][  ][  ][  ]   front=rear=0
入队 a b c: [a][b][c][  ][  ]  front=0, rear=3
出队 a b:   [  ][  ][c][  ][  ]  front=2, rear=3
入队 d e:   [  ][  ][c][d][e]  front=2, rear=5  ← rear 越界!
```

**假溢出**:front 之前仍有空闲空间,但 rear 已到达 MaxSize,无法继续入队。解决方案:**循环队列**。

### 2.2.3 循环队列判空判满 (三种方案)

#### 方案 1:牺牲一个存储单元 (最常考)

判空:`Q.front == Q.rear`
判满:`(Q.rear + 1) % MaxSize == Q.front`
队长:`(Q.rear - Q.front + MaxSize) % MaxSize`

```c
typedef struct {
    ElemType data[MaxSize];
    int front, rear;
} SqQueue;

void InitQueue(SqQueue &Q) { Q.front = Q.rear = 0; }

bool EnQueue(SqQueue &Q, ElemType e) {
    if ((Q.rear + 1) % MaxSize == Q.front) return false;   // 满
    Q.data[Q.rear] = e;
    Q.rear = (Q.rear + 1) % MaxSize;
    return true;
}

bool DeQueue(SqQueue &Q, ElemType &e) {
    if (Q.front == Q.rear) return false;                   // 空
    e = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    return true;
}

int QueueLength(SqQueue Q) {
    return (Q.rear - Q.front + MaxSize) % MaxSize;
}
```

**最多存 MaxSize - 1 个元素** (牺牲一个单元区分空/满)。

```
满 (rear 即将追上 front,rear+1=front):
    [A][B][C][D][ ]    front=0, rear=4, MaxSize=5
     ↑               ↑
   front           rear
   (rear+1)%5 = 0 = front → 满

空 (front == rear):
    [ ][ ][ ][ ][ ]    front=rear=0
```

#### 方案 2:增设 size 变量

```c
typedef struct {
    ElemType data[MaxSize];
    int front, rear;
    int size;            // 当前元素个数
} SqQueue2;

void InitQueue(SqQueue2 &Q) { Q.front = Q.rear = 0; Q.size = 0; }

bool EnQueue(SqQueue2 &Q, ElemType e) {
    if (Q.size == MaxSize) return false;                   // 满
    Q.data[Q.rear] = e;
    Q.rear = (Q.rear + 1) % MaxSize;
    Q.size++;
    return true;
}

bool DeQueue(SqQueue2 &Q, ElemType &e) {
    if (Q.size == 0) return false;                         // 空
    e = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    Q.size--;
    return true;
}
```

**最多存 MaxSize 个元素**。

#### 方案 3:增设 tag 标志位

`tag = 0` 表示**最近一次操作是删除**;`tag = 1` 表示**最近一次操作是插入**。

判空:`front == rear && tag == 0`
判满:`front == rear && tag == 1`

```c
typedef struct {
    ElemType data[MaxSize];
    int front, rear;
    int tag;              // 0:最近删除,1:最近插入
} SqQueue3;

void InitQueue(SqQueue3 &Q) { Q.front = Q.rear = 0; Q.tag = 0; }

bool EnQueue(SqQueue3 &Q, ElemType e) {
    if (Q.front == Q.rear && Q.tag == 1) return false;     // 满
    Q.data[Q.rear] = e;
    Q.rear = (Q.rear + 1) % MaxSize;
    Q.tag = 1;
    return true;
}

bool DeQueue(SqQueue3 &Q, ElemType &e) {
    if (Q.front == Q.rear && Q.tag == 0) return false;     // 空
    e = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    Q.tag = 0;
    return true;
}
```

**最多存 MaxSize 个元素**。

#### 三方案对比

| 方案 | 判空 | 判满 | 最多容量 | 复杂度 |
|------|------|------|----------|--------|
| 牺牲单元 | front==rear | (rear+1)%M==front | M-1 | 简单 |
| size 变量 | size==0 | size==M | M | 多 1 整型 |
| tag 位 | f==r && tag==0 | f==r && tag==1 | M | 多 1 位 |

> **真题陷阱**:
> 1. 牺牲单元法最多 M-1 个,问"队长为 M 时是否满"必为否;
> 2. 三方案的初始条件不同,初始化时 size=0, tag=0;
> 3. 三方案队长公式相同:`(rear-front+M)%M`,但方案 2、3 也可直接用 size。

### 2.2.4 链队列

带头结点的链队列,`front` 指向头结点,`rear` 指向尾节点。

```c
typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} LinkNode;

typedef struct {
    LinkNode *front, *rear;
} LinkQueue;

void InitQueue(LinkQueue &Q) {
    Q.front = Q.rear = (LinkNode *)malloc(sizeof(LinkNode));
    Q.front->next = NULL;
}

bool Empty(LinkQueue Q) { return Q.front == Q.rear; }

bool EnQueue(LinkQueue &Q, ElemType e) {
    LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
    s->data = e; s->next = NULL;
    Q.rear->next = s;            // ① 原尾节点指向新节点
    Q.rear = s;                  // ② rear 后移
    return true;
}

bool DeQueue(LinkQueue &Q, ElemType &e) {
    if (Q.front == Q.rear) return false;
    LinkNode *p = Q.front->next; // p 是要删除的节点 (头结点的下一)
    e = p->data;
    Q.front->next = p->next;
    if (Q.rear == p)             // ⚠ 删的是最后一个节点
        Q.rear = Q.front;        //   rear 复位到头结点
    free(p);
    return true;
}
```

> **陷阱**:删除最后一个节点时必须将 `rear` 复位到 `front`,否则 rear 悬空,下次入队会崩溃。这是 2022 年真题考点。

### 2.2.5 双端队列

两端均可进行插入和删除的队列。

| 类型 | 输入端 | 输出端 |
|------|--------|--------|
| 双端队列 | 两端 | 两端 |
| 输入受限双端队列 | 一端 | 两端 |
| 输出受限双端队列 | 两端 | 一端 |

**考点**:给定 1,2,...,n 入队序列,判断某输出序列是否合法。

```
输入受限双端队列:
  入 → [  ] → 出
       ↑↑
      (只能左端入,两端均可出)

输出受限双端队列:
  入 → [  ] ← 入
            ↓
       (两端均可入,只能右端出)
```

**判断方法**:用栈或队列模拟,枚举所有可能的输入输出顺序。

## 2.3 栈的应用

### 2.3.1 括号匹配

**算法思想**:扫描字符串,左括号入栈;遇到右括号时弹栈并匹配,匹配失败则非法;扫描完栈空则合法。

```c
bool Pair(char l, char r) {
    return (l=='(' && r==')') || (l=='[' && r==']') || (l=='{' && r=='}');
}

bool Match(char s[]) {
    SqStack S; InitStack(S);
    for (int i = 0; s[i]; i++) {
        if (s[i]=='(' || s[i]=='[' || s[i]=='{') {
            Push(S, s[i]);
        } else if (s[i]==')' || s[i]==']' || s[i]=='}') {
            if (Empty(S)) return false;        // 右括号多余
            char top; Pop(S, top);
            if (!Pair(top, s[i])) return false; // 不匹配
        }
    }
    return Empty(S);                            // 栈空才合法
}
```

**复杂度**:时间 O(n),空间 O(n)。

### 2.3.2 表达式求值

#### 2.3.2.1 中缀转后缀 (栈暂存运算符)

**算法**:
```
初始化空栈 S 用于运算符,空队列 Q 用于输出
for each token in 中缀表达式:
    if 操作数: 加入 Q
    if '(': 压入 S
    if ')': 弹出 S 顶到 '(' 之前的所有运算符加入 Q,丢弃 '('
    if 运算符 op:
        while S 非空 and S.top != '(' and 优先级(S.top) ≥ 优先级(op):
            弹出 S.top 加入 Q
        压入 op
最后弹出 S 剩余运算符加入 Q
```

**优先级**:`* /` > `+ -` > `(` (栈内最低,确保只作分隔符)

**完整示例**:中缀 `A+B*(C-D)-E/F`

| 步骤 | token | 栈 S (底→顶) | 输出 Q |
|------|-------|-------------|--------|
| 1 | A | (空) | A |
| 2 | + | + | A |
| 3 | B | + | A B |
| 4 | * | + * | A B |
| 5 | ( | + * ( | A B |
| 6 | C | + * ( | A B C |
| 7 | - | + * ( - | A B C |
| 8 | D | + * ( - | A B C D |
| 9 | ) | + * | A B C D - |
| 10 | - | - | A B C D - * + |
| 11 | E | - | A B C D - * + E |
| 12 | / | - / | A B C D - * + E |
| 13 | F | - / | A B C D - * + E F |
| 14 | 结束 | (空) | A B C D - * + E F / - |

**结果**:`A B C D - * + E F / -`

#### 2.3.2.2 后缀求值 (栈暂存操作数)

**算法**:
```
for each token in 后缀表达式:
    if 操作数: 压栈
    if 运算符 op:
        弹出 a (栈顶,原式靠右)
        弹出 b (栈次顶,原式靠左)
        计算 b op a (注意顺序!),结果压栈
最终栈中唯一元素即结果
```

**示例**:后缀 `3 4 5 * +` 求值

| 步骤 | token | 栈 (底→顶) | 动作 |
|------|-------|-----------|------|
| 1 | 3 | 3 | 压栈 |
| 2 | 4 | 3 4 | 压栈 |
| 3 | 5 | 3 4 5 | 压栈 |
| 4 | * | 3 20 | 弹 5, 弹 4, 算 4*5=20 |
| 5 | + | 23 | 弹 20, 弹 3, 算 3+20=23 |

**结果**:23 (对应中缀 `3 + 4 * 5`)

> **陷阱 (极高频)**:减法、除法**不满足交换律**。
> - 后缀 `5 3 -` 对应中缀 `5 - 3 = 2`
> - 弹栈时 a=3 (栈顶,后弹), b=5 (次顶,先弹)
> - 计算 `b - a = 5 - 3 = 2`,而非 `a - b = 3 - 5 = -2`
> - 牢记:**先弹出的在原式中靠右,作右操作数**。

#### 2.3.2.3 完整代码

```c
int precedence(char op) {
    if (op=='+' || op=='-') return 1;
    if (op=='*' || op=='/') return 2;
    return 0;  // '('
}

void InfixToPostfix(char *infix, char *postfix) {
    SqStack S; InitStack(S);
    int k = 0;
    for (int i = 0; infix[i]; i++) {
        char c = infix[i];
        if (isdigit(c) || isalpha(c)) {
            postfix[k++] = c;
        } else if (c == '(') {
            Push(S, c);
        } else if (c == ')') {
            char top;
            while (GetTop(S, top) && top != '(') {
                Pop(S, top);
                postfix[k++] = top;
            }
            Pop(S, top);  // 丢弃 '('
        } else { // 运算符
            char top;
            while (GetTop(S, top) && top != '(' && precedence(top) >= precedence(c)) {
                Pop(S, top);
                postfix[k++] = top;
            }
            Push(S, c);
        }
    }
    char top;
    while (Pop(S, top)) postfix[k++] = top;
    postfix[k] = '\0';
}

int EvalPostfix(char *postfix) {
    SqStack S; InitStack(S);
    for (int i = 0; postfix[i]; i++) {
        char c = postfix[i];
        if (isdigit(c)) {
            Push(S, c - '0');
        } else {
            int a, b;
            Pop(S, a); Pop(S, b);  // a 后弹,作右操作数
            switch (c) {
                case '+': Push(S, b + a); break;
                case '-': Push(S, b - a); break;
                case '*': Push(S, b * a); break;
                case '/': Push(S, b / a); break;
            }
        }
    }
    int result; Pop(S, result);
    return result;
}
```

### 2.3.3 递归

递归调用通过**栈**实现。每层函数调用压栈 (含局部变量、返回地址、参数),返回时弹栈。

**斐波那契递归调用树** (n=5):

```
                f(5)
              /      \
           f(4)       f(3)
          /    \     /    \
       f(3)  f(2) f(2)  f(1)
       /  \
     f(2) f(1)
```

**空间复杂度** = 递归深度 = O(n) (栈的最大深度)
**时间复杂度** = 节点数 = O(2^n) (大量重复计算)

**递归 → 非递归**:用显式栈模拟系统栈。

```c
// 递归版阶乘
int Fact(int n) {
    if (n == 0) return 1;
    return n * Fact(n - 1);
}

// 非递归版 (用栈模拟)
int FactIter(int n) {
    SqStack S; InitStack(S);
    int m = n;
    while (m > 0) { Push(S, m); m--; }   // 压栈模拟递
    int result = 1;
    while (!Empty(S)) {
        int k; Pop(S, k);
        result *= k;                      // 弹栈模拟归
    }
    return result;
}
```

> **要点**:
> - 递归空间 = O(递归深度),时间 = O(节点数);
> - 递归便于编码但效率低;非递归用栈模拟,空间相同但常数更小;
> - 尾递归可优化为 O(1) 空间 (编译器尾调用优化)。

## 2.5 数组与特殊矩阵

### 2.5.1 多维数组存储

多维数组**按行优先**或**按列优先**存储在一维空间。

**二维数组 A[m][n] 行优先**,首地址 LOC(0,0),元素大小 d:

$$
\text{LOC}(A[i][j]) = \text{LOC}(0,0) + (i \times n + j) \times d
$$

**列优先**:

$$
\text{LOC}(A[i][j]) = \text{LOC}(0,0) + (j \times m + i) \times d
$$

**推导**:行优先时,前 i 行共 i×n 个元素,第 i 行前 j 列共 j 个元素,总偏移 = i×n + j。

### 2.5.2 对称矩阵

$n$ 阶对称矩阵 $A_{ij} = A_{ji}$,只需存下三角 (含对角线),共 $\dfrac{n(n+1)}{2}$ 个元素。

**映射推导 (行优先,下标从 0 开始)**:
- 前 i 行 (第 0 到 i-1 行) 共 $1 + 2 + \dots + i = \dfrac{i(i+1)}{2}$ 个元素
- 第 i 行中 $A_{ij}$ (j ≤ i) 是第 j+1 个元素,相对位置 j
- 故 $k = \dfrac{i(i+1)}{2} + j$ (当 $i \geq j$)
- 当 $i < j$ 时,用对称性 $A_{ij} = A_{ji}$,即 $k = \dfrac{j(j+1)}{2} + i$

$$
k = \begin{cases}
\dfrac{i(i+1)}{2} + j, & i \geq j \\
\dfrac{j(j+1)}{2} + i, & i < j
\end{cases}
$$

**示例**:4 阶对称矩阵
```
原矩阵:          一维存储 B[]:
1 2 3 4          B[0]=1
2 5 6 7          B[1]=2  B[2]=5
3 6 8 9   →      B[3]=3  B[4]=6  B[5]=8
4 7 9 0          B[6]=4  B[7]=7  B[8]=9  B[9]=0
```

查 $A_{3,2}$ (i=3, j=2, i≥j):$k = \dfrac{3 \times 4}{2} + 2 = 8$,即 B[8]=9 ✓

### 2.5.3 三角矩阵

#### 下三角矩阵 (上三角全为常数 c)

元素总数 $\dfrac{n(n+1)}{2} + 1$ (下三角 + 一个常数单元)。

$$
k = \begin{cases}
\dfrac{i(i+1)}{2} + j, & i \geq j \\
\dfrac{n(n+1)}{2}, & i < j \quad \text{(常数位置)}
\end{cases}
$$

#### 上三角矩阵 (行优先,下三角全为常数 c)

第 i 行 (0 ≤ i ≤ n-1) 前有第 0~i-1 行,这些行从第 i 行起开始的列号是 i,所以第 0 行有 n 个,第 1 行有 n-1 个,...,第 i-1 行有 n-i+1 个。前 i 行共 $in - \dfrac{i(i-1)}{2} = \dfrac{i(2n-i+1)}{2}$... 重新推导:

- 第 0 行有 n 个 (列 0 到 n-1)
- 第 1 行有 n-1 个 (列 1 到 n-1)
- ...
- 第 i-1 行有 n-i+1 个
- 前 i 行共 $n + (n-1) + \dots + (n-i+1) = \dfrac{i(2n-i+1)}{2}$ 个

第 i 行中 $A_{ij}$ (j ≥ i) 是第 (j - i + 1) 个,相对位置 (j - i)。

$$
k = \dfrac{i(2n-i+1)}{2} + (j - i), \quad i \leq j
$$

化简:$k = \dfrac{i(2n-i-1)}{2} + j$ (展开合并同类项)。

### 2.5.4 三对角矩阵

只在主对角线及其上下相邻对角线有非零元。$A_{ij}$ 非零当且仅当 $|i - j| \leq 1$。

**推导 (下标从 0 开始)**:
- 前 i 行 (0 到 i-1) 非零元数:第 0 行 2 个,其余每行 3 个 → 共 $2 + 3(i-1) = 3i - 1$ 个
- 第 i 行中 $A_{ij}$ 是第几个?
  - $A_{i,i-1}$ 是第 1 个 (相对位置 0)
  - $A_{i,i}$ 是第 2 个 (相对位置 1)
  - $A_{i,i+1}$ 是第 3 个 (相对位置 2)
- 一般地,$A_{ij}$ 在第 i 行中的相对位置 = $j - i + 1$

$$
k = (3i - 1) + (j - i + 1) = 2i + j \quad (|i-j| \leq 1, \text{下标从 0 起})
$$

**反推**:给定 k,求 i, j?
- 第 i 行第一个元素 $A_{i,i-1}$ 的下标 $k_0 = 2i + (i-1) = 3i - 1$
- 故 $i = \left\lfloor \dfrac{k+1}{3} \right\rfloor$,$j = k - 2i$

**示例**:5×5 三对角矩阵
```
[1 2 0 0 0]
[3 4 5 0 0]
[0 6 7 8 0]
[0 0 9 1 2]
[0 0 0 3 4]
```
查 $A_{2,3}$:$k = 2 \times 2 + 3 = 7$,B[7] = 8 ✓

### 2.5.5 稀疏矩阵

非零元很少的矩阵 (一般 $\rho = \dfrac{\text{非零元数}}{mn} < 0.05$)。

#### 三元组表 (顺序存储)

```c
typedef struct {
    int i, j;
    ElemType v;
} Triple;

typedef struct {
    Triple data[MaxTerm];   // 行优先存储
    int m, n, t;             // 行数,列数,非零元数
} TSMatrix;
```

```
原矩阵:           三元组:
0 0 3 0 0         (0,2,3)
0 0 0 5 0   →     (1,3,5)
0 0 0 0 0         (2,4,7)
0 0 0 0 7
```

**特点**:节省空间,但随机访问需遍历,O(t)。

#### 十字链表 (链式存储)

每个非零元同时属于一行链表和一列链表。

```c
typedef struct OLNode {
    int i, j;
    ElemType v;
    struct OLNode *right, *down;   // 同行下一个,同列下一个
} OLNode;

typedef struct {
    OLNode *rhead, *chead;   // 行/列头指针数组
    int m, n, t;

```

**适用**:矩阵动态变化 (加法、乘法时插入/删除非零元)。

## 2.6 合法序列与 Catalan 数

### 2.6.1 栈混洗 (Stack Permutation)

给定入栈序列 $1, 2, \dots, n$,问哪些出栈序列合法?

**判定方法 (模拟)**:用辅助栈,按入栈序列尝试得到目标出栈序列。

```c
bool IsLegal(int out[], int n) {
    SqStack S; InitStack(S);
    int cur = 1;  // 下一个要入栈的元素
    for (int i = 0; i < n; i++) {
        while (cur <= n && (Empty(S) || GetTop(S) != out[i])) {
            Push(S, cur); cur++;
        }
        if (Empty(S) || GetTop(S) != out[i]) return false;
        int e; Pop(S, e);
    }
    return true;
}
```

**结论**:出栈序列数 = Catalan 数 $C_n = \dfrac{1}{n+1}\binom{2n}{n}$

| n | $C_n$ | 总排列 n! | 合法比例 |
|---|-------|----------|----------|
| 1 | 1 | 1 | 100% |
| 2 | 2 | 2 | 100% |
| 3 | 5 | 6 | 83% |
| 4 | 14 | 24 | 58% |
| 5 | 42 | 120 | 35% |

### 2.6.2 Catalan 数推导

$n$ 个元素依次入栈,出栈序列数等价于"在 2n 步操作中选 n 步入栈"的合法序列数。

合法要求:任意前缀中入栈数 ≥ 出栈数。这就是**括号匹配**问题:n 对括号的合法匹配数 = $C_n$。

**递推**:
$$
C_0 = 1, \quad C_{n+1} = \sum_{i=0}^{n} C_i \cdot C_{n-i} = \frac{2(2n+1)}{n+2} C_n
$$

**闭式**:
$$
C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{(n+1)! \cdot n!}
$$

### 2.6.3 非法序列判定

**特征**:出栈序列中若存在 $i < j < k$ 但出栈顺序为 $\dots k \dots i \dots j$,则非法。

**定理 (栈混洗禁形)**:出栈序列合法 ⟺ 不存在三元组 $i < j < k$ 使得 k 比 i 先出栈且 i 比 j 先出栈 (即模式 `k i j` 非法)。

**示例**:入栈 1,2,3。出栈 `3 1 2`?
- 模拟:Push 1, Push 2, Push 3, Pop 3 (得 3)
- 此时栈顶是 2,要出 1 必须先出 2,但目标是先 1 后 2 → 非法 ✓

## 2.7 真题陷阱与高频考点

1. **top 初值**:`top = -1` (指向栈顶) vs `top = 0` (指向栈顶下一位置),影响 Push/Pop 写法。
2. **循环队列判满**:牺牲单元法最多存 MaxSize - 1 个元素,这是高频陷阱。
3. **队长公式**:`(rear - front + MaxSize) % MaxSize`,注意取模。
4. **表达式求值顺序**:`b op a` 不是 `a op b` (减除不交换)。
5. **栈与递归深度**:递归深度 = 栈深度,空间 O(n)。
6. **合法出栈序列数**:Catalan 数 $C_n = \frac{1}{n+1}\binom{2n}{n}$。
7. **共享栈满条件**:`top1 + 1 == top2`,不是 `top1 == top2`。
8. **三对角映射**:$k = 2i + j$ (下标 0 起) 最常用,注意 i, j 范围。
9. **链队列出队后 rear**:删最后一个节点时 `rear = front`,否则悬空。
10. **三方案容量**:牺牲单元 M-1,其余 M 个;size/tag 方案的判空判满不能用 front==rear。
11. **tag 方案判空判满**:`f==r && tag==0` 空,`f==r && tag==1` 满。
12. **栈混洗禁形**:模式 `k i j` (i<j<k) 非法。
13. **对称矩阵查 $A_{ij}$ 当 $i<j$ 时**:用对称性转为查 $A_{ji}$,不能用 i≥j 公式。
14. **共享栈初衷**:两栈动态互补,而非"防止溢出"——只是降低溢出概率。

## 2.8 典型真题精解

### 2016 选择:循环队列队长

**题**:循环队列存储空间大小为 M,front 指向队头元素前一位置,rear 指向队尾元素,则队长为?

**解**:
- front 指向队头前一,rear 指向队尾元素 → 实际元素位置 front+1 到 rear
- 队长 = (rear - front + M) % M

**答**:`(rear - front + M) % M`

### 2018 选择:共享栈满条件

**题**:两个栈共享一片存储空间 S[0..MaxSize-1],栈1底在 0,栈2底在 MaxSize-1。栈满条件?

**解**:栈1顶指针 top1,栈2顶指针 top2。
- 栈1空:`top1 == -1`
- 栈2空:`top2 == MaxSize`
- 栈1增长方向:top1 递增
- 栈2增长方向:top2 递减
- 栈满:top1 + 1 == top2 (中间无空位)

**答**:`top1 + 1 == top2`

### 2019 选择:中缀转后缀

**题**:中缀表达式 `a+b-a*((c+d)/e-f)+g` 转后缀为?

**解**(模拟栈):
| 步骤 | token | 栈 | 输出 |
|------|-------|------|------|
| 1 | a | | a |
| 2 | + | + | a |
| 3 | b | + | a b |
| 4 | - | - | a b + |
| 5 | a | - | a b + a |
| 6 | * | - * | a b + a |
| 7 | ( | - * ( | a b + a |
| 8 | c | - * ( | a b + a c |
| 9 | + | - * ( + | a b + a c |
| 10 | d | - * ( + | a b + a c d |
| 11 | ) | - * | a b + a c d + |
| 12 | / | - * / | a b + a c d + |
| 13 | e | - * / | a b + a c d + e |
| 14 | - | - * | a b + a c d + e / |
| 15 | f | - * | a b + a c d + e / f |
| 16 | (栈弹出 * 和 -) | - | a b + a c d + e / f - * |
| 17 | + | + | a b + a c d + e / f - * - |
| 18 | g | + | a b + a c d + e / f - * - g |
| 19 | 结束 | | a b + a c d + e / f - * - g + |

**答**:`a b + a c d + e / f - * - g +`

### 2020 选择:三对角矩阵 k 值

**题**:三对角矩阵 A[0..n-1][0..n-1] 按行优先压缩存于一维 B[0..3n-3],已知 $A_{ij}$ ($|i-j| \leq 1$) 存于 $B_k$,则 $k = $?

**解**:
- 前 i 行 (0 到 i-1) 共 $2 + 3(i-1) = 3i - 1$ 个非零元
- 第 i 行中 $A_{ij}$ 相对位置 $j - i + 1$
- $k = (3i - 1) + (j - i + 1) = 2i + j$

**答**:$k = 2i + j$

### 2022 选择:链队列出队

**题**:带头结点的链队列,出队操作中删除最后一个节点时,rear 应如何处理?

**解**:删除最后一个节点 (即 `p == rear`) 后,rear 悬空。必须将 rear 复位到头结点 front,使队列变空时 rear 仍指向合法位置。

**答**:`if (Q.rear == p) Q.rear = Q.front;`

### 2024 选择:双端队列合法输出

**题**:输入序列 1,2,3,4,经过输出受限双端队列 (两端入,一端出),不可能得到的输出序列?

**解**:输出受限双端队列两端可入,左端可出。可能输出:
- 1 2 3 4 (按序入右,按序出左)
- 4 3 2 1 (倒序入左,出左)
- 4 1 2 3 (1,2,3 入右,4 入左,出左得 4,再依次出 1 2 3)
- ...

**判定**:模拟双端队列,枚举每种输入端选择。常见非法序列如 `4 2 1 3` (4 必先入,2 在 4 之后想先出,只能让 1 在 2 之前或之后入队;若 4 在左端,2 在右端,1 必在 4 后入右或 2 后入右,无论怎样都无法让 2 比 1 先出)。

**答**:模拟后判定,无法得到的序列需要逐一验证。

## 2.10 易混淆点深辨析

| 易混点 | 辨析 |
|--------|------|
| 假溢出 vs 真溢出 | 假溢出是 front 前有空但 rear 到顶;真溢出是空间真满。循环队列解决假溢出 |
| 牺牲单元 vs size 计数 | 前者最多 M-1,后者最多 M;判满条件不同 |
| 共享栈 vs 双端队列 | 共享栈是两个独立栈共享空间,各自 LIFO;双端队列是单一队列两端操作 |
| 三元组 vs 十字链表 | 三元组适合静态存储;十字链表适合动态 (矩阵加法时频繁插删) |
| top=-1 vs top=0 | 前者指向栈顶元素,Push 用 `++top`;后者指向栈顶下一,Push 用 `top++` |
| 递归 vs 迭代空间 | 递归 O(深度),迭代 O(1) (尾递归优化) |
| 栈混洗禁形 vs 括号匹配 | 栈混洗禁形 `k i j` (i<j<k) 非法;括号匹配是 Catalan 数应用 |

## 2.11 延伸知识

### 2.11.1 单调栈

**用途**:在 O(n) 内求每个元素左/右第一个比它大/小的元素位置。

**模板 (求每个元素右侧第一个比它大的下标)**:
```c
void NextGreater(int a[], int n, int nxt[]) {
    SqStack S; InitStack(S);
    for (int i = n - 1; i >= 0; i--) {
        while (!Empty(S) && a[GetTop(S)] <= a[i]) Pop(S);
        nxt[i] = Empty(S) ? -1 : GetTop(S);
        Push(S, i);
    }
}
```

**应用**:每日温度、柱状图最大矩形、接雨水。

### 2.11.2 单调队列

**用途**:在 O(n) 内求滑动窗口最值。

**模板 (滑动窗口最大值)**:
```c
void MaxSlidingWindow(int a[], int n, int k, int res[]) {
    // 双端队列存下标,队首始终是当前窗口最大
    int dq[MaxSize], head = 0, tail = 0;
    for (int i = 0; i < n; i++) {
        while (head < tail && a[dq[tail-1]] <= a[i]) tail--;  // 维护递减
        dq[tail++] = i;
        if (dq[head] <= i - k) head++;                         // 出窗口
        if (i >= k - 1) res[i-k+1] = a[dq[head]];
    }
}
```

### 2.11.3 栈实现队列 / 队列实现栈

**栈实现队列 (两个栈)**:一个入栈,一个出栈。入队直接压入栈;出队时若出栈空,把入栈全部倒入出栈再弹。

```c
typedef struct {
    SqStack in, out;
} MyQueue;

void Push(MyQueue *q, ElemType e) { Push(q->in, e); }

bool Pop(MyQueue *q, ElemType &e) {
    if (Empty(q->out)) {
        while (!Empty(q->in)) {
            ElemType t; Pop(q->in, t); Push(q->out, t);
        }
    }
    if (Empty(q->out)) return false;
    return Pop(q->out, e);
}
```

**均摊复杂度**:每个元素至多被搬运 2 次,均摊 O(1)。

## 2.13 本章习题

1. 设栈 S 和队列 Q 初始为空,依次执行:`Push(S,1); Push(S,2); Push(S,3); Pop(S,a); Push(S,a); Pop(S,b); EnQueue(Q,a); EnQueue(Q,b); Pop(S,c); EnQueue(Q,c)`,求 Q 中元素 (从队头到队尾)。
   - **答**:Push 1,2,3 → S=[1,2,3] (顶=3);Pop a=3 → S=[1,2];Push 3 → S=[1,2,3];Pop b=3 → S=[1,2];EnQ a=3;EnQ b=3;Pop c=2 → S=[1];EnQ c=2。Q = [3, 3, 2]

2. 已知栈入栈序列 1,2,3,4,5,问出栈序列 `5 4 3 1 2` 是否合法?
   - **答**:模拟:Push 1,2,3,4,5 → Pop 5,4,3 → S=[1,2] (顶=2);要出 1 必先出 2,但目标是先 1 后 2 → **不合法**。

3. 循环队列 MaxSize=6,front=4,rear=2,求队长和能再入队几个元素 (牺牲单元法)。
   - **答**:队长 = (2 - 4 + 6) % 6 = 4;可再入队 = MaxSize - 1 - 队长 = 6 - 1 - 4 = 1 个。

4. 三对角矩阵 $A[1..n][1..n]$ (下标从 1 起) 按行优先存于一维 B,求 $A_{ij}$ 对应的 k (下标从 1 起)。
   - **答**:下标从 1 起时,$k = 3(i-1) - 1 + (j - i + 1) + 1 = 2i + j - 2$ (按公式 $k = 2i + j$ 减 1 调整)。具体推导:0 起的 k = 2i+j (i,j 是 0 起);若 i,j 是 1 起,则 0 起 i'=i-1, j'=j-1,k0 = 2(i-1)+(j-1) = 2i+j-3,转 1 起 k = k0 + 1 = 2i + j - 2。

5. 给定中缀 `(a+b)*c-d/e`,求后缀。
   - **答**:`a b + c * d e / -`
