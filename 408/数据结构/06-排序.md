## 6.1 插入排序

### 6.1.1 直接插入

把第 i 个元素插入前 i-1 个已排序序列中,从后向前比较后移。

```c
void InsertSort(int A[], int n) {  // A[1..n] 存元素,A[0] 作哨兵
    for (int i = 2; i <= n; i++) {
        if (A[i] < A[i-1]) {
            A[0] = A[i];                // 哨兵暂存
            int j = i - 1;
            while (A[j] > A[0]) { A[j+1] = A[j]; j--; }
            A[j+1] = A[0];
        }
    }
}
```

**复杂度**:
- 时间:最好 $O(n)$ (已序,每轮不进 if),最坏/平均 $O(n^2)$ (逆序,每轮移动 i-1 次);
- 空间 $O(1)$;
- **稳定** (相等不交换);
- 适用:顺序表、链表均可 (链表用前插)。

**适用场景**:n 较小 (n < 50) 或基本有序。

### 6.1.2 折半插入

插入位置用**折半查找**确定,但移动元素仍 $O(n)$。

```c
void BInsertSort(int A[], int n) {
    for (int i = 2; i <= n; i++) {
        A[0] = A[i];
        int low = 1, high = i - 1;
        while (low <= high) {
            int mid = (low + high) / 2;
            if (A[mid] > A[0]) high = mid - 1;
            else low = mid + 1;
        }  // low 即插入位置
        for (int j = i - 1; j >= low; j--) A[j+1] = A[j];
        A[low] = A[0];
    }
}
```

**特点**:
- **减少了比较次数**至 $O(n \log n)$,但**移动次数不变** $O(n^2)$;
- 总时间仍 $O(n^2)$;
- 仅适用顺序表 (链表不能折半);
- **稳定**。

### 6.1.3 希尔排序 (缩小增量)

选增量序列 $d_1 > d_2 > \dots > d_k = 1$,每趟按 $d_i$ 分组组内直接插入,最后一趟 $d=1$ 全表插入。

```c
void ShellSort(int A[], int n) {
    for (int dk = n/2; dk >= 1; dk /= 2) {
        for (int i = dk + 1; i <= n; i++) {
            if (A[i] < A[i-dk]) {
                A[0] = A[i];
                int j = i - dk;
                while (j > 0 && A[j] > A[0]) { A[j+dk] = A[j]; j -= dk; }
                A[j+dk] = A[0];
            }
        }
    }
}
```

**复杂度**:
- 时间:取决于增量序列;
  - Shell 原始 ($n/2, n/4, \dots, 1$):最坏 $O(n^2)$;
  - Hibbard ($2^k - 1$):最坏 $O(n^{1.5}$);
  - Sedgewick:$O(n^{4/3})$;
  - 实测约 $O(n^{1.3})$;
- 空间 $O(1)$;
- **不稳定** (跨距离交换可能改变相等元素相对顺序);
- 仅适用顺序表。

**为何不稳定**:希尔排序在不同增量下分组排序,相等元素可能被分到不同组,跨组交换后相对顺序可能改变。

## 6.2 交换排序

### 6.2.1 冒泡排序

```c
void BubbleSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool flag = false;
        for (int j = n - 1; j > i; j--) {
            if (A[j-1] > A[j]) {
                swap(A[j-1], A[j]);
                flag = true;
            }
        }
        if (!flag) return;            // 无交换则已序
    }
}
```

**复杂度**:
- 时间:最好 $O(n)$ (已序 + flag 优化),最坏/平均 $O(n^2)$ (逆序);
- 空间 $O(1)$;
- **稳定** (相等不交换);
- 每趟把最小 (或最大) 冒到一端;
- 比较次数与初始状态有关,移动次数也与初始状态有关。

**冒泡优化**:
- **flag 标志位**:无交换则提前结束 (最好 $O(n)$);
- **记录最后交换位置**:减少内层循环次数。

### 6.2.2 快速排序

**核心**:`Partition` 选枢轴,小于枢轴的放左,大于的放右,递归处理左右两段。

```c
int Partition(int A[], int low, int high) {
    int pivot = A[low];              // 取第一个为枢轴
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];            // 比枢轴小的移到左
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];            // 比枢轴大的移到右
    }
    A[low] = pivot;                  // 枢轴归位
    return low;
}

void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int p = Partition(A, low, high);
        QuickSort(A, low, p - 1);
        QuickSort(A, p + 1, high);
    }
}
```

**复杂度**:
- 时间:最好/平均 $O(n \log n)$,最坏 $O(n^2)$ (已序或逆序且取端点);
- 空间:由递归深度决定,平均 $O(\log n)$,最坏 $O(n)$ (已序退化为链);
- **不稳定** (跨段交换);
- 是**内部排序中平均最快**的算法。

#### 6.2.2.1 三种取枢法

| 取枢法 | 描述 | 优缺点 |
|--------|------|--------|
| 取首 (或尾) | $A[low]$ 作枢轴 | 简单,但已序/逆序退化为 $O(n^2)$ |
| 三数取中 | 取 $A[low], A[mid], A[high]$ 中位数 | 避免最坏情况,实用 |
| 随机取枢 | 随机选一个作枢轴 | 期望 $O(n \log n)$,但常数大 |

**三数取中代码**:
```c
int Median3(int A[], int low, int high) {
    int mid = (low + high) / 2;
    if (A[low] > A[mid]) swap(A[low], A[mid]);
    if (A[low] > A[high]) swap(A[low], A[high]);
    if (A[mid] > A[high]) swap(A[mid], A[high]);
    // 现在 A[low] ≤ A[mid] ≤ A[high],取 A[mid] 作枢轴
    swap(A[mid], A[low]);   // 枢轴放到 low 位置
    return A[low];
}
```

#### 6.2.2.2 快排 Partition 三种写法

**写法 1:挖坑填充 (上面代码)**:pivot 暂存,左右交替填补。

**写法 2:双指针交换**:
```c
int Partition2(int A[], int low, int high) {
    int pivot = A[low];
    int i = low, j = high;
    while (i < j) {
        while (i < j && A[j] >= pivot) j--;
        while (i < j && A[i] <= pivot) i++;
        if (i < j) swap(A[i], A[j]);
    }
    swap(A[low], A[i]);
    return i;
}
```

**写法 3:单指针 (Lomuto)**:
```c
int Partition3(int A[], int low, int high) {
    int pivot = A[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (A[j] <= pivot) {
            i++;
            swap(A[i], A[j]);
        }
    }
    swap(A[i+1], A[high]);
    return i + 1;
}
```

> **真题陷阱**:
> 1. 快排最坏情况:已序/逆序 + 取端点 → $O(n^2)$,递归深度 $n$,栈空间 $O(n)$;
> 2. 快排空间复杂度由**递归深度**决定,平均 $O(\log n)$,最坏 $O(n)$;
> 3. 快排**不稳定**,但可通过稳定化技巧 (如带索引) 改进;
> 4. Partition 后枢轴位置即最终排序位置;
> 5. 快排平均最快但**最坏不如堆排和归并**。

## 6.3 选择排序

### 6.3.1 简单选择排序

```c
void SelectSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min = i;
        for (int j = i + 1; j < n; j++)
            if (A[j] < A[min]) min = j;
        if (min != i) swap(A[i], A[min]);
    }
}
```

**复杂度**:
- 时间:**恒 $O(n^2)$** (与初始状态无关,无论已序还是逆序都要比较 $n(n-1)/2$ 次);
- 空间 $O(1)$;
- **不稳定** (例:`5, 5, 2`,第一轮选 2 与首 5 交换 → `2, 5, 5`,两 5 相对顺序变);
- 比较次数固定,适合元素较大、移动成本高的场景 (移动次数最多 $3(n-1)$)。

### 6.3.2 堆排序

**堆**:完全二叉树,大根堆 (父 ≥ 子) 或小根堆。详见 [[03-树与二叉树]] §3.9。

#### 6.3.2.1 建堆 (大根堆,从最后一个非叶到根下调)

```c
void AdjustDown(int A[], int k, int n) {  // A[1..n]
    A[0] = A[k];                          // 暂存
    for (int i = 2*k; i <= n; i *= 2) {
        if (i < n && A[i] < A[i+1]) i++;  // 取较大孩子
        if (A[0] >= A[i]) break;          // 已满足堆性质
        A[k] = A[i]; k = i;               // 孩子上移
    }
    A[k] = A[0];                          // 原值落下
}

void BuildMaxHeap(int A[], int n) {
    for (int i = n/2; i >= 1; i--) AdjustDown(A, i, n);
}
```

#### 6.3.2.2 建堆时间 $O(n)$ 的证明

设堆高 $h = \log_2 n$。第 $i$ 层 (从叶向上数,叶为第 0 层) 有 $\leq n/2^{i+1}$ 个节点,每个节点最多下调 $i$ 次。

总调整次数:
$$
T \leq \sum_{i=0}^{h} \frac{n}{2^{i+1}} \cdot i = \frac{n}{2} \sum_{i=0}^{h} \frac{i}{2^i} \leq \frac{n}{2} \cdot 2 = n
$$

(因 $\sum_{i=0}^{\infty} \frac{i}{2^i} = 2$)

故建堆时间 $O(n)$,而非 $O(n \log n)$。

#### 6.3.2.3 堆排序

```c
void HeapSort(int A[], int n) {
    BuildMaxHeap(A, n);
    for (int i = n; i > 1; i--) {
        swap(A[i], A[1]);              // 最大值放到末尾
        AdjustDown(A, 1, i - 1);      // 调整剩余堆
    }
}
```

**复杂度**:
- 时间:建堆 $O(n)$ + 排序 $O(n \log n)$ = **$O(n \log n)$**;
- 空间 $O(1)$;
- **不稳定**;
- 适合大数据 top-k (维护大小 k 的小根堆) 等场景。

#### 6.3.2.4 堆的插入与删除

**插入**:新元素放末尾,**上调**:
```c
void AdjustUp(int A[], int k) {  // 新元素在 A[k]
    A[0] = A[k];
    int i = k / 2;               // 父节点
    while (i > 0 && A[i] < A[0]) {
        A[k] = A[i];
        k = i; i = k / 2;
    }
    A[k] = A[0];
}
```

**删除**:把末尾换到堆顶,**下调** (AdjustDown)。

> **真题陷阱**:
> 1. 建堆从 `n/2` 开始 (最后一个非叶节点);
> 2. 堆插入:新元素放末尾,上调 AdjustUp;
> 3. 堆删除:把末尾换到堆顶,下调 AdjustDown;
> 4. **大根堆 → 升序** (顶最大放末尾);**小根堆 → 降序**;
> 5. 堆排序**不稳定**但适合外存大数据;
> 6. 建堆 $O(n)$ 是高频考点,需会证明。

## 6.4 归并排序

二路归并:把相邻有序子序列合并。

```c
void Merge(int A[], int low, int mid, int high) {
    int *B = (int *)malloc(sizeof(int) * (high+1));
    for (int k = low; k <= high; k++) B[k] = A[k];
    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high) {
        if (B[i] <= B[j]) A[k++] = B[i++];   // 相等取左 → 稳定
        else A[k++] = B[j++];
    }
    while (i <= mid) A[k++] = B[i++];
    while (j <= high) A[k++] = B[j++];
    free(B);
}

void MergeSort(int A[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(A, low, mid);
        MergeSort(A, mid+1, high);
        Merge(A, low, mid, high);
    }
}
```

**复杂度**:
- 时间:**恒 $O(n \log n)$** (与初始状态无关);
- 空间 **$O(n)$** (辅助数组);
- **稳定** (合并时相等取左侧);
- 适合外排序、链表排序。

**k 路归并**:每趟合并 k 路,趟数 $\lceil \log_k r \rceil$ (r 个初始归并段)。败者树可降低 k 路归并中选最小的比较次数至 $O(\log k)$。

## 6.5 基数排序

按关键字各位排序,从低位到高位 (LSD) 或高位到低位 (MSD)。

```
LSD 基数排序:
对每一位 d (个位、十位、百位...):
   分配:按 d 位值分到 0~9 桶
   收集:按桶序合并
```

**示例**:排序 $\{329, 457, 657, 839, 436, 720, 355\}$ (LSD,基数 10):

| 步骤 | 位 | 桶分配后 | 收集结果 |
|------|-----|----------|----------|
| 1 | 个位 | 0:720; 5:355; 6:436; 7:457,657; 9:329,839 | 720, 355, 436, 457, 657, 329, 839 |
| 2 | 十位 | 2:329,720; 3:436; 5:355,657; 5:457; 3:839 | 720, 329, 436, 839, 355, 457, 657 |
| 3 | 百位 | 3:329,355; 4:436,457; 6:657; 7:720; 8:839 | 329, 355, 436, 457, 657, 720, 839 |

**复杂度**:
- 时间:**$O(d(n + r))$**,d 是位数,r 是基数;
- 空间 $O(r)$ (桶);
- **稳定**;
- 适合关键字位数少、值域大的场景 (如手机号、学号);
- **不需要比较**,突破了比较排序 $\Omega(n \log n)$ 下界。

## 6.6 外部排序

### 6.6.1 多路归并

外部排序分两阶段:
1. **生成初始归并段**:内存能容纳的块读入,内部排序后写回磁盘;
2. **多路归并**:多个初始归并段合并为更大归并段,直至一个。

**归并趟数** $S = \lceil \log_k r \rceil$,r 是初始归并段数,k 是路数。

**总 I/O 次数** = 2 × (初始归并段生成 I/O) + 2 × (归并趟数 × 每趟读写所有数据)。

**增大 k** 减少趟数,但每趟内选最小的比较次数增加 (k-1 次比较)。引入**败者树**,选最小只需 $O(\log k)$。

### 6.6.2 败者树

完全二叉树,叶节点是各路当前元素,内部节点记"败者" (较小者),根记"冠军" (最小者)。冠军输出后,该路补新元素,沿路径更新。

- 选最小从 $O(k)$ 降到 $O(\log k)$;
- 适合多路归并的"选最小"操作。

```
              [冠军]
              /    \
           败1     败2
           / \    / \
          L1 L2  L3 L4    ← 叶子 (各路当前元素)
```

### 6.6.3 置换-选择排序

生成初始归并段时,利用内存工作区的"未来元素"延长归并段,使段长 > 内存容量。

```
工作区 WA 容量 w,读入 w 个元素
当前段输出最小值 ≥ 当前段最后输出值 (last):
   - 从 WA 选 ≥ last 且最小的元素输出
   - 从输入补一个新元素到 WA
若 WA 中无 ≥ last 元素:
   当前段结束,开启新段
```

**结论**:平均初始归并段长度 = **2w** (证明基于斐波那契分布)。

### 6.6.4 最佳归并树

不同长度的初始归并段多路归并,I/O 次数与树的结构有关。**最佳归并树** = 带权路径长度最小的 k 叉哈夫曼树。

**构造**:每次选 k 个最短的合并,合并后长度 = 之和,放回集合,重复。

**虚段补充**:若 $(r - 1) \%(k - 1) \neq 0$,需补 $k - 1 - (r-1)\%(k-1)$ 个长度为 0 的虚段,保证每次都能合并 k 个。

**为何补虚段**:
- k 叉哈夫曼树要求每次合并 k 个;
- 若初始段数 r 不满足 $(r-1) \%(k-1) == 0$,最后一次合并不足 k 个;
- 补 0 长度虚段不影响总 I/O 但保证每次合并 k 个,使结构最优。

**示例**:5 路归并,8 个初始归并段长度 $\{9, 30, 12, 18, 3, 17, 2, 6\}$,补几个虚段?
- $(8-1) \%(5-1) = 7 \% 4 = 3 \neq 0$;
- 需补 $4 - 3 = 1$ 个虚段;
- 最终 9 个段,每次合并 5 个,共 2 次合并。

## 6.7 各排序对比表 (必背)

| 希尔 | $O(n^{1.3})$ | — | $O(n^2)$ | $O(1)$ | ❌ | 顺序表 |
| 冒泡 | $O(n^2)$ | $O(n)$ | $O(n^2)$ | $O(1)$ | ✅ | 通用 |
| 快排 | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | ❌ | 内部最快 |

| 堆排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | ❌ | 大数据 top-k |
| 归并 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ | ✅ | 外排序 |
| 基数 | $O(d(n+r))$ | $O(d(n+r))$ | $O(d(n+r))$ | $O(r)$ | ✅ | 关键字位数少 |

### 6.7.1 记忆口诀

- **不稳定**:"快选希堆" (快排、简单选择、希尔、堆);
- **时间与初始状态无关**:简单选择、归并、堆、基数 (恒定复杂度);
- **空间 O(1)**:插入、希尔、冒泡、简单选择、堆;
- **空间 O(n)**:归并;
- **空间 O(log n)**:快排 (递归栈);
- **最好 O(n)**:直接插入、冒泡 (基本有序时);
- **平均最快**:快排;
- **不需比较**:基数排序。

## 6.8 真题陷阱与高频考点

1. **稳定性判断**:稳定看"相等元素相对顺序是否变"。例:简单选择排序 `[5, 5, 2]` 排序后两 5 顺序变。
2. **快排最坏**:已序/逆序 + 取端点 → $O(n^2)$;递归深度 n,栈空间 $O(n)$。
3. **建堆 O(n)**:非 $O(n \log n)$,从 `n/2` 开始下调是关键,需会证明。
4. **堆排序方向**:大根堆 → 升序 (顶最大换末尾);小根堆 → 降序。
5. **归并空间**:辅助数组 $O(n)$。
6. **基数排序不需比较**:突破 $\Omega(n \log n)$ 下界。
7. **外部排序趟数**:$\lceil \log_k r \rceil$。
8. **最佳归并树虚段**:$k-1-(r-1)\%(k-1)$,补足使 $(r-1) \%(k-1) == 0$。
9. **冒泡优化**:flag 标志位使最好 $O(n)$。
10. **快排空间**:由递归深度决定,平均 $O(\log n)$,最坏 $O(n)$。
11. **时间与初始状态无关**:简单选择、归并、堆、基数 (4 个);
12. **折半插入**:减少比较,不减少移动,总时间仍 $O(n^2)$。
13. **希尔增量**:增量序列必含 1,最后一趟是直接插入。
14. **Partition 后枢轴归位**:枢轴位置即最终位置。
15. **败者树 vs 堆**:败者树是 k 路归并选最小;堆是优先队列。

## 6.9 典型真题精解

### 2016 选择:快排最坏情况

**题**:快速排序在什么情况下退化为 $O(n^2)$?

**解**:当每次 Partition 选到的枢轴是当前段的最小或最大值 (即未将数组分成两个均衡子段) 时,递归深度退化为 n,时间 $O(n^2)$。典型情况:
- 数组已序 + 取首 (或尾) 为枢轴;
- 数组逆序 + 取首 (或尾) 为枢轴。

**答**:已序/逆序 + 取端点为枢轴时。

### 2017 选择:堆排序建堆复杂度

**题**:对 n 个元素建堆,时间复杂度?

**解**:从最后一个非叶节点 (n/2) 开始,逐个向下调整。第 i 层节点最多下调 i 次,共 $\sum n/2^{i+1} \cdot i \leq n$。故建堆 $O(n)$。

**答**:$O(n)$。

### 2018 算法:快排 Partition 推演

**题**:对数组 $\{49, 38, 65, 97, 76, 13, 27, 49\}$,以 49 为枢轴,手动推演第一趟 Partition 过程。

**解**(挖坑填充法):
```
初始:49, 38, 65, 97, 76, 13, 27, 49
      ↑                              ↑
     low                            high
pivot = 49, A[low] 已挖坑
high 找 < 49:27,填坑 → [27, 38, 65, 97, 76, 13, _, 49]
low 找 > 49:65,填坑 high → [27, 38, _, 97, 76, 13, 65, 49]
high 找 < 49:13,填坑 low → [27, 38, 13, 97, 76, _, 65, 49]
low 找 > 49:97,填坑 high → [27, 38, 13, _, 76, 97, 65, 49]
high 找 < 49:无,low == high
pivot 归位 → [27, 38, 13, 49, 76, 97, 65, 49]
                    ↑ 枢轴位置
```

**结果**:`27, 38, 13, 49, 76, 97, 65, 49`,枢轴位置 3。

### 2019 选择:稳定性判断

**题**:下列排序算法中,哪些不稳定?

**解**:不稳定算法:希尔、快排、简单选择、堆。口诀:"快选希堆"。

**答**:快排、简单选择、希尔、堆。

### 2020 选择:外部排序趟数

**题**:5 路归并,12 个初始归并段,需多少趟?

**解**:$S = \lceil \log_5 12 \rceil = \lceil 1.544 \rceil = 2$ 趟。

**答**:2 趟。

### 2022 算法:堆调整过程

**题**:大根堆 $\{97, 76, 65, 49, 38, 13, 27, 49\}$,插入 95,画出调整过程。

**解**:
- 插入末尾:`[97, 76, 65, 49, 38, 13, 27, 49, 95]`;
- 95 与父 49 比较:95 > 49,上调 → `[97, 76, 65, 95, 38, 13, 27, 49, 49]`;
- 95 与父 76 比较:95 > 76,上调 → `[97, 95, 65, 76, 38, 13, 27, 49, 49]`;
- 95 与父 97 比较:95 < 97,停止。

**结果**:`[97, 95, 65, 76, 38, 13, 27, 49, 49]`。

### 2024 综合:最佳归并树虚段

**题**:5 路归并,8 个初始归并段,需补几个虚段?

**解**:
- $(r - 1) \%(k - 1) = (8 - 1) \%(5 - 1) = 7 \% 4 = 3 \neq 0$;
- 需补 $k - 1 - (r-1)\%(k-1) = 4 - 3 = 1$ 个虚段;
- 补虚段后总段数 9,满足 $(9-1)\%(5-1) = 0$。

**答**:补 1 个虚段。

## 6.11 易混淆点深辨析

| 易混点 | 辨析 |
|--------|------|
| 直接插入 vs 折半插入 | 折半只减少比较,移动不变;总时间仍 $O(n^2)$ |
| 简单选择 vs 堆 | 选择每次扫全部 $O(n^2)$;堆用堆结构 $O(n \log n)$ |
| 大根堆 vs 升序 | 排序要升序,用大根堆 (顶最大换末尾) |
| 归并稳定 vs 快排不稳定 | 归并合并时相等取左;快排跨段交换 |
| 基数 vs 比较 | 基数不比较,突破 $\Omega(n \log n)$ 下界 |
| 外排序趟数 vs 内排序 | 外排序关注 I/O,趟数 = $\lceil \log_k r \rceil$ |
| 快排 vs 归并空间 | 快排 $O(\log n)$ (递归栈),归并 $O(n)$ (辅助数组) |
| 堆排 vs 快排最坏 | 堆排最坏 $O(n \log n)$,快排最坏 $O(n^2)$ |
| 希尔 vs 直接插入 | 希尔增量分组,跨距离交换,不稳定 |
| 败者树 vs 堆 | 败者树内部记败者,堆内部是大/小值;败者树用于 k 路归并 |

## 6.12 延伸知识

### 6.12.1 计数排序 (Counting Sort)

适用于值域小的整数排序。$O(n+k)$ 时间,$O(k)$ 空间。**稳定** (逆序填充)。

### 6.12.2 桶排序 (Bucket Sort)

将数据分到若干桶,桶内排序后合并。$O(n+k)$ 期望,$O(n^2)$ 最坏。**稳定** (桶内用稳定排序)。

### 6.12.3 TimSort

归并 + 插入的混合排序,Python/Java 默认。利用已序段 (run),性能稳定。

### 6.12.4 内省排序 (Introsort)

快排 + 堆排 + 插入的混合。C++ STL `sort` 默认。快排为主,递归过深时切堆排,段小时切插入。

## 6.14 本章习题

1. 数组 $\{5, 2, 8, 3, 9, 1, 7\}$,写出一趟快排结果 (取首为枢轴)。
   - **答**:pivot=5,一趟后:`[1, 2, 3, 5, 9, 8, 7]`,枢轴位置 3。

2. 大根堆 $\{97, 76, 65, 49, 38, 13, 27\}$,删除堆顶 97 后的调整过程?
   - **答**:末尾 27 换到堆顶 → `[27, 76, 65, 49, 38, 13, _]`;
   - 27 与较大孩子 76 比较:27 < 76,下调 → `[76, 27, 65, 49, 38, 13]`;
   - 27 与较大孩子 49 比较:27 < 49,下调 → `[76, 49, 65, 27, 38, 13]`;
   - 27 与叶子位置比较:已是叶,停止。
   - 结果:`[76, 49, 65, 27, 38, 13]`。

3. 外部排序 4 路归并,15 个初始归并段,需几趟?补几个虚段才能最佳归并?
   - **答**:趟数 $S = \lceil \log_4 15 \rceil = \lceil 1.95 \rceil = 2$;
   - 补虚段:$(15-1)\%(4-1) = 14\%3 = 2 \neq 0$;补 $3-2 = 1$ 个虚段;补后 16 段,$(16-1)\%3 = 0$。

4. 简单选择排序为何不稳定?举例。
   - **答**:`[5a, 5b, 2]`,第一轮选最小 2 与 5a 交换 → `[2, 5b, 5a]`,5a 和 5b 相对顺序变。

5. 给定关键字 $\{329, 457, 657, 839, 436, 720, 355\}$,用 LSD 基数排序,写出每趟结果。
   - **答**:见 6.5 示例。最终:`329, 355, 436, 457, 657, 720, 839`。
