## 3.1 树的基本概念

### 3.1.1 形式化定义

树是 n (n ≥ 0) 个节点的有限集 T。n = 0 为空树;否则:
- 有且仅有一个特定的**根**节点;
- 其余节点可分为 m (m ≥ 0) 个互不相交的有限集 $T_1, \dots, T_m$,每个 $T_i$ 又是一棵树,称为根的**子树**。

**等价定义** (常考):
- 树是无回路的无向连通图;
- 树是 n 个顶点 n-1 条边的无向图 (任两顶点间恰有一条路径);
- 树是一个根节点 + 0 或多棵子树 (递归定义)。

### 3.1.2 术语

| 术语 | 定义 |
|------|------|
| 度 (degree) | 节点的子树个数 |
| 叶子 (leaf) | 度为 0 的节点 |
| 内部节点 | 非根非叶子节点 |
| 层次 | 根为第 1 层,其子节点第 2 层,... |
| 深度/高度 | 最大层次 (408 教材常混用,需看上下文) |
| 森林 | m (m ≥ 0) 棵互不相交的树的集合 |
| 祖先 | 从根到该节点路径上的所有节点 |
| 子孙 | 该节点子树中所有节点 |
| 兄弟 | 同父的节点 |

### 3.1.3 性质 (常考,必背)

1. **节点数 = 度数之和 + 1** (根节点没有"入边"):
$$n = 1 + \sum_{i=0}^{m} i \cdot n_i$$
   其中 $n_i$ 是度为 i 的节点数。

2. 度为 m 的树第 i 层至多 $m^{i-1}$ 个节点 (i ≥ 1)。

3. 高度为 h 的 m 叉树至多 $\dfrac{m^h - 1}{m - 1}$ 个节点 (等比求和)。

4. 有 n 个节点的 m 叉树最小高度 $\lceil \log_m(n(m-1)+1) \rceil$。
   - **推导**:高度 h 时最多 $\dfrac{m^h-1}{m-1}$ 节点,要让 n 节点放进 h 层,$\dfrac{m^{h-1}-1}{m-1} < n \leq \dfrac{m^h-1}{m-1}$,解得 $h = \lceil \log_m(n(m-1)+1) \rceil$。

> **真题陷阱**:"度为 m 的树" vs "m 叉树":
> - 度为 m 的树:至少有一个节点度为 m,即树的最大度为 m;
> - m 叉树:所有节点度 ≤ m,允许最大度 < m。
> 性质 4 适用于 m 叉树,不要求最大度达到 m。

## 3.2 二叉树概念与性质

### 3.2.1 定义与特殊二叉树

二叉树:每个节点至多两棵子树,有**左右之分** (不可交换)。

| 特殊二叉树 | 定义 |
|-----------|------|
| 满二叉树 | 深度 k,有 $2^k - 1$ 个节点;每层都满 |
| 完全二叉树 | 深度 k,前 k-1 层满,第 k 层从左到右连续 |
| 二叉排序树 | 左 < 根 < 右 (见 3.7) |
| 平衡二叉树 | 任意节点左右子树高度差 ≤ 1 (见 3.7) |

> **满二叉树 vs 完全二叉树**:
> - 满必完全,完全未必满;
> - 满二叉树叶子只可能在最后一层;完全二叉树叶子可在最后两层。

### 3.2.2 性质 (必背)

1. 第 i 层至多 $2^{i-1}$ 个节点 (i ≥ 1)。
2. 深度为 k 的二叉树至多 $2^k - 1$ 个节点。
3. **$n_0 = n_2 + 1$** (叶子数 = 度 2 节点数 + 1)。
4. 完全二叉树深度 $k = \lfloor \log_2 n \rfloor + 1$。
5. n 个节点的完全二叉树,节点 i (1 ≤ i ≤ n) 的:
   - 父节点:$\lfloor i/2 \rfloor$
   - 左孩子:$2i$ (若 ≤ n)
   - 右孩子:$2i + 1$ (若 ≤ n)
6. 完全二叉树最后一个非叶节点下标:$\lfloor n/2 \rfloor$。

#### 3.2.2.1 性质 3 推导 ($n_0 = n_2 + 1$)

设 $n_0, n_1, n_2$ 分别为度 0, 1, 2 的节点数。
- 总节点数:$n = n_0 + n_1 + n_2$
- 总边数 (每个节点有一条入边,根除外):$n - 1 = 0 \cdot n_0 + 1 \cdot n_1 + 2 \cdot n_2 = n_1 + 2 n_2$
- 联立:$n_0 + n_1 + n_2 - 1 = n_1 + 2 n_2$,化简得 $n_0 = n_2 + 1$ ✓

**推广**:$n_0 = 1 + \sum_{i \geq 2} (i - 1) n_i$,适用于任意 m 叉树。

### 3.2.3 存储

**顺序存储**:完全二叉树最适合,按层序编号存入数组;一般二叉树需补空 (用 0 或特殊值),空间浪费严重。

**链式存储 (二叉链表)**:
```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

**空指针数**:n 个节点的二叉链表有 **n + 1 个空指针域**。
- **推导**:总指针域 = 2n;非空指针 = n - 1 (每条边对应一个);空指针 = 2n - (n-1) = n + 1。

**三叉链表** (带父指针):
```c
typedef struct TriTNode {
    ElemType data;
    struct TriTNode *lchild, *rchild, *parent;
} TriTNode;
```

## 3.3 二叉树遍历

### 3.3.1 四种基本遍历 (递归)

```c
void PreOrder(BiTree T) {
    if (!T) return;
    visit(T);
    PreOrder(T->lchild);
    PreOrder(T->rchild);
}

void InOrder(BiTree T) {
    if (!T) return;
    InOrder(T->lchild);
    visit(T);
    InOrder(T->rchild);
}

void PostOrder(BiTree T) {
    if (!T) return;
    PostOrder(T->lchild);
    PostOrder(T->rchild);
    visit(T);
}
```

**层序 (BFS)**:
```c
void LevelOrder(BiTree T) {
    if (!T) return;
    Queue Q; InitQueue(Q);
    EnQueue(Q, T);
    while (!Empty(Q)) {
        BiTree p; DeQueue(Q, p);
        visit(p);
        if (p->lchild) EnQueue(Q, p->lchild);
        if (p->rchild) EnQueue(Q, p->rchild);
    }
}
```

**复杂度**:
- 时间 O(n) (每节点访问一次)
- 空间 O(h) (递归栈深度, h 为树高)
  - 最好 O(log n),最坏 O(n) (退化为链)

### 3.3.2 非递归遍历 (用栈)

#### 3.3.2.1 先序非递归

```c
void PreOrder2(BiTree T) {
    Stack S; InitStack(S);
    BiTree p = T;
    while (p || !Empty(S)) {
        if (p) {
            visit(p);              // 先访问
            Push(S, p);
            p = p->lchild;         // 沿左走到底
        } else {
            Pop(S, p);
            p = p->rchild;         // 转右
        }
    }
}
```

#### 3.3.2.2 中序非递归

```c
void InOrder2(BiTree T) {
    Stack S; InitStack(S);
    BiTree p = T;
    while (p || !Empty(S)) {
        if (p) {
            Push(S, p);
            p = p->lchild;         // 沿左走到底
        } else {
            Pop(S, p);
            visit(p);              // 出栈时访问
            p = p->rchild;         // 转右
        }
    }
}
```

#### 3.3.2.3 后序非递归 (最复杂)

**难点**:节点出栈后不能立即访问,需先处理右子树。判断右子树是否已处理:用 `r` 记录上次访问的节点。

```c
void PostOrder2(BiTree T) {
    Stack S; InitStack(S);
    BiTree p = T, r = NULL;
    while (p || !Empty(S)) {
        if (p) {
            Push(S, p);
            p = p->lchild;
        } else {
            GetTop(S, p);                       // 窥视栈顶
            if (p->rchild && p->rchild != r) {
                p = p->rchild;                  // 右子树未处理,转右
            } else {
                Pop(S, p);                      // 真正出栈
                visit(p);
                r = p;                          // 记录上次访问
                p = NULL;                       // 防止再沿左走
            }
        }
    }
}
```

> **陷阱**:后序非递归的 `p = NULL` 必不可少——出栈访问后必须强制下一轮走 else 分支 (看下一个栈顶),否则会无限循环。

### 3.3.3 Morris 遍历 (O(1) 空间)

利用空闲指针 (右孩子为空时指向中序后继) 实现常数空间遍历。

**中序 Morris**:
```c
void MorrisInOrder(BiTree T) {
    BiTree cur = T, *pre;
    while (cur) {
        if (!cur->lchild) {
            visit(cur);
            cur = cur->rchild;
        } else {
            // 找 cur 的中序前驱 (左子树最右)
            pre = cur->lchild;
            while (pre->rchild && pre->rchild != cur) pre = pre->rchild;
            if (!pre->rchild) {
                pre->rchild = cur;             // 建线索
                cur = cur->lchild;
            } else {
                pre->rchild = NULL;            // 拆线索
                visit(cur);
                cur = cur->rchild;
            }
        }
    }
}
```

**特点**:空间 O(1),时间 O(n) (每条边最多走 3 次),但会修改树结构 (临时建线索,事后还原)。

### 3.3.4 由遍历序列重建二叉树

#### 3.3.4.1 先序 + 中序 唯一确定

**算法**:
- 先序第一个元素 = 根;
- 在中序中找根,左侧为左子树中序,右侧为右子树中序;
- 据中序左/右子树长度切分先序,递归。

```c
BiTree Build(char pre[], char in[], int preL, int preR, int inL, int inR) {
    if (preL > preR) return NULL;
    BiTree root = (BiTree)malloc(sizeof(BiTNode));
    root->data = pre[preL];
    int k = inL;
    while (in[k] != pre[preL]) k++;            // 在中序中找根
    int numLeft = k - inL;                     // 左子树节点数
    root->lchild = Build(pre, in, preL+1, preL+numLeft, inL, k-1);
    root->rchild = Build(pre, in, preL+numLeft+1, preR, k+1, inR);
    return root;
}
```

#### 3.3.4.2 后序 + 中序 同理

后序**最后一个**元素是根,其余同先序+中序。

#### 3.3.4.3 层序 + 中序

层序第一个是根,在中序中定位后切分;再按层序顺序找下一个属于左子树的根、右子树的根。

#### 3.3.4.4 为什么先+后不能唯一确定?

**反例**:先序 AB,后序 BA。
- 可能 1:A 是根,B 是 A 的**左**孩子;
- 可能 2:A 是根,B 是 A 的**右**孩子。

两种结构的先序都是 AB,后序都是 BA。原因:**单分支节点** (只有一个孩子) 无法判断孩子是左还是右。

**定理**:当二叉树**没有度为 1 的节点** (即满二叉树) 时,先+后可唯一确定。

### 3.3.5 遍历的应用

1. **求深度**:
```c
int Depth(BiTree T) {
    if (!T) return 0;
    int l = Depth(T->lchild), r = Depth(T->rchild);
    return (l > r ? l : r) + 1;
}
```

2. **求节点数**:
```c
int Count(BiTree T) {
    if (!T) return 0;
    return 1 + Count(T->lchild) + Count(T->rchild);
}
```

3. **求叶子数**:
```c
int LeafCount(BiTree T) {
    if (!T) return 0;
    if (!T->lchild && !T->rchild) return 1;
    return LeafCount(T->lchild) + LeafCount(T->rchild);
}
```

4. **判断两树是否相同**:
```c
bool IsSame(BiTree A, BiTree B) {
    if (!A && !B) return true;
    if (!A || !B) return false;
    return A->data == B->data
        && IsSame(A->lchild, B->lchild)
        && IsSame(A->rchild, B->rchild);
}
```

5. **交换左右子树**:
```c
void Swap(BiTree T) {
    if (!T) return;
    BiTree tmp = T->lchild;
    T->lchild = T->rchild;
    T->rchild = tmp;
    Swap(T->lchild);
    Swap(T->rchild);
}
```

## 3.4 线索二叉树

### 3.4.1 动机

n 个节点的二叉链表有 n+1 个空指针,可利用这些空指针指向"前驱/后继",便于遍历和找前驱后继,**无需栈无需递归**即可遍历。

### 3.4.2 节点结构

```c
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;    // 0: 孩子指针; 1: 线索指针
} ThreadNode, *ThreadTree;
```

### 3.4.3 中序线索化

```c
ThreadNode *pre = NULL;   // 全局前驱

void InThread(ThreadTree p) {
    if (!p) return;
    InThread(p->lchild);
    if (!p->lchild) { p->ltag = 1; p->lchild = pre; }   // 当前左指前驱
    if (pre && !pre->rchild) { pre->rtag = 1; pre->rchild = p; }  // 前驱右指当前
    pre = p;
    InThread(p->rchild);
}

void CreateInThread(ThreadTree T) {
    pre = NULL;
    InThread(T);
    if (pre) pre->rchild = NULL;   // 处理最后一个节点
    if (pre) pre->rtag = 1;
}
```

### 3.4.4 线索遍历 (中序)

**找后继**:若 rtag=1,直接 rchild;若 rtag=0,右子树最左节点。

```c
ThreadNode *FirstNode(ThreadTree p) {
    while (p->ltag == 0) p = p->lchild;   // 最左
    return p;
}

ThreadNode *NextNode(ThreadNode *p) {
    if (p->rtag == 0) return FirstNode(p->rchild);
    return p->rchild;                      // 线索
}

void InOrderThreaded(ThreadTree T) {
    for (ThreadNode *p = FirstNode(T); p; p = NextNode(p))
        visit(p);
}
```

### 3.4.5 先序/后序线索化找前驱后继的难度差异

| 操作 | 中序线索 | 先序线索 | 后序线索 |
|------|----------|----------|----------|
| 找后继 | 简单 | 简单 (有孩子走孩子,否则线索) | 难 (需父指针) |
| 找前驱 | 简单 | 难 (需父指针) | 简单 (有孩子走孩子,否则线索) |

**原因**:
- 中序的前驱/后继在树中位置对称 (前驱=左子树最右;后继=右子树最左);
- 先序的"后继"=左孩子 (无左则右孩子,无右则线索);但"前驱"需要知道父节点;
- 后序的"前驱"=右孩子 (无右则左孩子,无左则线索);但"后继"需要知道父节点。

> **真题陷阱**:中序线索树找前驱后继都简单;**先序线索找前驱**和**后序线索找后继**难,需要父指针或从根重新遍历。

## 3.5 哈夫曼树与哈夫曼编码

### 3.5.1 定义

**带权路径长度 (WPL)** = $\sum_{i=1}^{n} w_i l_i$,其中 $w_i$ 是叶子权,$l_i$ 是叶到根路径长度。

**哈夫曼树**:给定 n 个叶子权值,WPL 最小的二叉树 (最优二叉树)。

### 3.5.2 构造算法

```
1. 把每个权值当作一棵独立的树,放入集合 F
2. 重复:
   - 取 F 中两棵根权最小的树 (升序前两个)
   - 合并成一棵新树,新根 = 两子树根权之和
   - 左子树取小的,右子树取大的 (约定)
   - 把新树放回 F
3. 直到 F 中只剩一棵树,即哈夫曼树
```

### 3.5.3 构造示例

**权值集合** {1, 2, 3, 4, 5}:

```
步骤1: 选 1, 2 → 新根 3
       F = {3, 3, 4, 5}

步骤2: 选 3 (旧), 3 (新) → 新根 6
       F = {4, 5, 6}

步骤3: 选 4, 5 → 新根 9
       F = {6, 9}

步骤4: 选 6, 9 → 新根 15
       F = {15}
```

**最终哈夫曼树**:
```
            15
           /  \
          6    9
         / \  / \
        3   3 4  5
       / \
      1   2
```

**WPL**:
- 叶子 1: 深度 3 → 1×3 = 3
- 叶子 2: 深度 3 → 2×3 = 6
- 叶子 3: 深度 2 → 3×2 = 6
- 叶子 4: 深度 2 → 4×2 = 8
- 叶子 5: 深度 2 → 5×2 = 10
- **WPL = 3+6+6+8+10 = 33**

**验证** (用性质 3):非叶节点权值之和 = 3 + 6 + 9 + 15 = 33 ✓

### 3.5.4 性质

1. n 个叶子构造的哈夫曼树有 **2n - 1** 个节点。
   - 证明:每次合并新增 1 个内部节点,共 n-1 次合并,新增 n-1 个内部节点;总节点 = n + (n-1) = 2n-1。

2. 没有度为 1 的节点 ($n_1 = 0$)。
   - 证明:每次合并都产生一个有 2 个孩子的内部节点。

3. **WPL = 所有非叶节点权值之和**。
   - 证明:每个叶子权值 $w_i$ 在路径上每经过一个祖先就被累加一次,路径长度 $l_i$ 等于祖先数;故 $\sum w_i l_i = \sum_{\text{非叶 } v} w_v$。

4. 哈夫曼树形态**不唯一** (左右子树可交换),但 **WPL 唯一**。

### 3.5.5 哈夫曼编码

将字符频率作为叶子权,左分支编 0、右分支编 1 (或反之),从根到叶子的路径即编码。

**前缀码**:任何编码都不是其他编码的前缀。

**哈夫曼编码是前缀码**:因叶子互不为祖先,任一叶子的路径不会是另一叶子的前缀。

**性质**:
- 编码总长度 (按频率加权) = WPL,即最优前缀码;
- 编码不唯一 (左右子树可交换、0/1 可对换),但平均码长唯一;
- 解码无歧义 (前缀码保证)。

> **真题陷阱**:
> 1. 哈夫曼编码**不唯一**,但 WPL (平均码长) 唯一;
> 2. 哈夫曼树没有度为 1 的节点;
> 3. 哈夫曼树是**严格二叉树** (满二叉树),但不是"完全二叉树"。

### 3.5.6 完整代码

```c
typedef struct {
    int weight;
    int parent, lchild, rchild;
} HTNode, *HuffmanTree;

void CreateHuffman(HuffmanTree &HT, int *w, int n) {
    if (n <= 1) return;
    int m = 2 * n - 1;
    HT = (HTNode *)malloc((m+1) * sizeof(HTNode));  // 0 号不用
    for (int i = 1; i <= m; i++) {
        HT[i].weight = i <= n ? w[i-1] : 0;
        HT[i].parent = HT[i].lchild = HT[i].rchild = 0;
    }
    for (int i = n + 1; i <= m; i++) {
        // 选两个最小且 parent==0 的
        int s1, s2;
        Select(HT, i - 1, s1, s2);
        HT[s1].parent = i; HT[s2].parent = i;
        HT[i].lchild = s1; HT[i].rchild = s2;
        HT[i].weight = HT[s1].weight + HT[s2].weight;
    }
}
```

## 3.6 并查集

### 3.6.1 定义

并查集 (Disjoint Set Union, DSU) 是一种维护不相交集合的数据结构,支持:
- `Find(x)`:返回 x 所属集合的根;
- `Union(x, y)`:合并 x 和 y 所在集合;
- `Connected(x, y)`:判断 x, y 是否同集合。

### 3.6.2 基本实现

```c
int parent[N];

void Init(int n) {
    for (int i = 0; i < n; i++) parent[i] = i;
}

int Find(int x) {
    while (parent[x] != x) x = parent[x];
    return x;
}

void Union(int x, int y) {
    int rx = Find(x), ry = Find(y);
    if (rx != ry) parent[rx] = ry;
}
```

**问题**:退化成链时,Find 为 O(n)。

### 3.6.3 优化

#### 3.6.3.1 路径压缩

Find 时把链上所有节点直接挂到根,后续 Find 近似 O(1)。

```c
int Find(int x) {
    if (parent[x] != x) parent[x] = Find(parent[x]);   // 路径压缩
    return parent[x];
}
```

#### 3.6.3.2 按秩合并 (Union by Rank)

合并时把矮树挂到高树下,避免退化。

```c
int rank[N];

void Union(int x, int y) {
    int rx = Find(x), ry = Find(y);
    if (rx == ry) return;
    if (rank[rx] < rank[ry]) parent[rx] = ry;
    else if (rank[rx] > rank[ry]) parent[ry] = rx;
    else { parent[ry] = rx; rank[rx]++; }
}
```

**复杂度**:
- 仅路径压缩:单次均摊 O(log n);
- 仅按秩合并:单次 O(log n);
- **两者结合**:单次均摊 $O(\alpha(n))$,$\alpha$ 是反阿克曼函数。

**反阿克曼函数** $\alpha(n)$:增长极慢,对任何实际 n (即使 $n = 10^{80}$) $\alpha(n) < 5$,实际近常数。

### 3.6.4 应用

- **Kruskal 最小生成树**:按边权排序,依次尝试合并两端点;若已同集合则跳过 (避免成环)。见 [[04-图]]。
- **连通分量判断**:`Connected` 检查两节点是否同分量。
- **等价类划分**。
- **最近公共祖先 (LCA) 的 Tarjan 算法**。

```c
// Kruskal 主循环
int Kruskal(Edge edges[], int n, int m) {
    sort(edges, edges + m, byWeight);  // 按权排序
    DSU dsu; dsu.init(n);
    int sum = 0, cnt = 0;
    for (int i = 0; i < m && cnt < n - 1; i++) {
        int u = edges[i].u, v = edges[i].v;
        if (dsu.Find(u) != dsu.Find(v)) {
            dsu.Union(u, v);
            sum += edges[i].w;
            cnt++;
        }
    }
    return sum;
}
```

## 3.7 二叉排序树与平衡二叉树

### 3.7.1 二叉排序树 (BST)

**定义**:左子树所有值 < 根 < 右子树所有值,左右子树也各是 BST。

#### 3.7.1.1 查找

```c
BiTree Search(BiTree T, int key) {
    while (T && T->data != key) {
        T = key < T->data ? T->lchild : T->rchild;
    }
    return T;
}
```

#### 3.7.1.2 插入

```c
bool Insert(BiTree &T, int key) {
    if (!T) {
        T = (BiTree)malloc(sizeof(BiTNode));
        T->data = key; T->lchild = T->rchild = NULL;
        return true;
    }
    if (key == T->data) return false;             // 已存在
    if (key < T->data) return Insert(T->lchild, key);
    return Insert(T->rchild, key);
}
```

#### 3.7.1.3 删除 (三种情况)

1. **叶子**:直接删。
2. **单分支** (只有一个孩子):用孩子替代。
3. **双分支** (有两个孩子):用**直接前驱** (左子树最右) 或**直接后继** (右子树最左) 替换值,再递归删除前驱/后继 (前驱/后继至多有一个孩子)。

```c
void Delete(BiTree &T, int key) {
    if (!T) return;
    if (key < T->data) Delete(T->lchild, key);
    else if (key > T->data) Delete(T->rchild, key);
    else {
        if (!T->lchild) { BiTree p = T; T = T->rchild; free(p); }
        else if (!T->rchild) { BiTree p = T; T = T->lchild; free(p); }
        else {
            // 双分支:用直接后继 (右子树最左) 替换
            BiTree succ = T->rchild;
            while (succ->lchild) succ = succ->lchild;
            T->data = succ->data;
            Delete(T->rchild, succ->data);
        }
    }
}
```

> **真题陷阱**:BST 删除用直接前驱还是直接后继,结果可能不同;但都保持 BST 性质。考试需看清题目要求。

**复杂度**:
- 最好 O(log n) (平衡);
- 最坏 O(n) (退化为链);
- 平均 O(log n) (随机插入)。

### 3.7.2 平衡二叉树 (AVL)

**定义**:任意节点左右子树高度差 (平衡因子 BF) 的绝对值 ≤ 1,且左右子树也是 AVL。

#### 3.7.2.1 四种失衡与调整

| 失衡类型 | 描述 | 调整 |
|----------|------|------|
| LL | 在左孩子的左子树插入 | 一次右旋 |
| RR | 在右孩子的右子树插入 | 一次左旋 |
| LR | 在左孩子的右子树插入 | 先左旋左孩子,再右旋根 |
| RL | 在右孩子的左子树插入 | 先右旋右孩子,再左旋根 |

#### 3.7.2.2 旋转图示

**右旋 (LL 调整)** (以 A 为失衡节点,B 是 A 的左孩子):
```
       A                B
      / \              / \
     B  T3    →      T1   A
    / \                  / \
   T1 T2               T2  T3
```

**左旋 (RR 调整)** (以 A 为失衡节点,B 是 A 的右孩子):
```
      A                  B
     / \                / \
    T1  B      →       A   T3
       / \            / \
      T2 T3          T1 T2
```

**LR 调整** (先左旋 B,再右旋 A):
```
       A                  A                  C
      / \                / \                / \
     B  T4    →         C  T4     →        B   A
    / \                / \                / \  / \
   T1  C              B  T3              T1 T2 T3 T4
      / \            / \
     T2 T3          T1 T2
```

**RL 调整** (先右旋 B,再左旋 A):
```
       A                  A                  C
      / \                / \                / \
     T1  B      →       T1  C       →      A   B
        / \                / \            / \  / \
       C  T4              T2  B          T1 T2 T3 T4
      / \                    / \
     T2 T3                  T3 T4
```

#### 3.7.2.3 旋转代码

```c
typedef struct AVLNode {
    int data;
    struct AVLNode *lchild, *rchild;
    int height;
} AVLNode, *AVLTree;

int Height(AVLTree T) { return T ? T->height : 0; }

void UpdateHeight(AVLTree T) {
    int l = Height(T->lchild), r = Height(T->rchild);
    T->height = (l > r ? l : r) + 1;
}

int BalanceFactor(AVLTree T) {
    return Height(T->lchild) - Height(T->rchild);
}

AVLTree RotateRight(AVLTree A) {       // 右旋 (LL)
    AVLTree B = A->lchild;
    A->lchild = B->rchild;
    B->rchild = A;
    UpdateHeight(A); UpdateHeight(B);
    return B;
}

AVLTree RotateLeft(AVLTree A) {        // 左旋 (RR)
    AVLTree B = A->rchild;
    A->rchild = B->lchild;
    B->lchild = A;
    UpdateHeight(A); UpdateHeight(B);
    return B;
}

AVLTree Insert(AVLTree T, int key) {
    if (!T) {
        T = (AVLTree)malloc(sizeof(AVLNode));
        T->data = key; T->lchild = T->rchild = NULL; T->height = 1;
        return T;
    }
    if (key < T->data) {
        T->lchild = Insert(T->lchild, key);
        if (BalanceFactor(T) == 2) {              // L 失衡
            if (key < T->lchild->data)            // LL
                T = RotateRight(T);
            else {                                 // LR
                T->lchild = RotateLeft(T->lchild);
                T = RotateRight(T);
            }
        }
    } else {
        T->rchild = Insert(T->rchild, key);
        if (BalanceFactor(T) == -2) {             // R 失衡
            if (key > T->rchild->data)            // RR
                T = RotateLeft(T);
            else {                                 // RL
                T->rchild = RotateRight(T->rchild);
                T = RotateLeft(T);
            }
        }
    }
    UpdateHeight(T);
    return T;
}
```

#### 3.7.2.4 AVL 高度与节点数关系

**最少节点数 $N_h$** (高度为 h 的 AVL 树最少节点):
$$N_0 = 1, \quad N_1 = 2, \quad N_h = N_{h-1} + N_{h-2} + 1$$

(类似 Fibonacci,递推证明:根 + 一棵高度 h-1 的子树 + 一棵高度 h-2 的子树)

**反推高度上界**:含 n 个节点的 AVL 高度 $h < 1.44 \log_2(n+2) - 0.328$,即 $h = O(\log n)$。

#### 3.7.2.5 插入 vs 删除的失衡传播

| 操作 | 失衡传播 |
|------|----------|
| 插入 | 调整一次最小失衡子树即可 (旋转后该子树高度恢复原值,上方不再失衡) |
| 删除 | 调整后该子树高度可能减小,导致上方失衡,需**向上检查直至根** |

> **真题陷阱**:插入只需一次调整,删除可能多次调整——这是高频考点。

## 3.8 树与森林

### 3.8.1 存储

| 存储法 | 描述 | 优劣 |
|--------|------|------|
| 双亲表示法 | 数组存父节点下标 | 易找父,难找子 |
| 孩子表示法 | 链表存每个节点的孩子 | 易找子,难找父 |
| 孩子兄弟表示法 | 左指针指向第一孩子,右指针指向下一兄弟 | 把树转成二叉树 |

**双亲表示法代码**:
```c
typedef struct {
    ElemType data;
    int parent;
} PTNode;

typedef struct {
    PTNode nodes[MAX];
    int r, n;   // 根位置,节点数
} PTree;
```

**孩子兄弟表示法** (二叉链表):
```c
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstchild, *nextsibling;
} CSNode, *CSTree;
```

### 3.8.2 树/森林 ↔ 二叉树转换

#### 3.8.2.1 树 → 二叉树 (孩子兄弟法)

- 节点的**第一孩子** → 二叉树**左孩子**
- 节点的**下一兄弟** → 二叉树**右孩子**

```
原树:               二叉树:
    A                  A
   /|\                /
  B C D              B
  |  |                \
  E  F                 C
                        \
                         D
                        /
                       E    ← 注意 E 是 B 的孩子,在二叉树中是 B 的左孩子
                       
                       (B 的下一兄弟 C → B 的右孩子)
                       (C 的下一兄弟 D → C 的右孩子)
```

#### 3.8.2.2 森林 → 二叉树

- 各树根视为**兄弟**;
- 第一棵树根 → 二叉树根;
- 第二棵树根 → 第一棵树根的右孩子 (即二叉树根的右子树);
- 第三棵树根 → 第二棵树根的右孩子;
- ...以此类推。

### 3.8.3 遍历对应关系

| 树/森林 | 二叉树 |
|---------|--------|
| 树的先根遍历 | 二叉树先序遍历 |
| 树的后根遍历 | 二叉树中序遍历 |
| 森林的先序遍历 (各树先根) | 二叉树先序遍历 |
| 森林的中序遍历 (各树后根) | 二叉树中序遍历 |

> **记忆口诀**:
> - 树/森林的"先根"对应二叉树"先序";
> - 树/森林的"后根"对应二叉树"中序"。
> 
> **注意**:森林没有"后序遍历"概念,但有"中序遍历" (即各树后根)。

## 3.9 堆与优先队列

### 3.9.1 堆的定义

**堆**是完全二叉树,满足:
- **大根堆**:每个节点值 ≥ 其孩子值 (根最大);
- **小根堆**:每个节点值 ≤ 其孩子值 (根最小)。

### 3.9.2 堆的存储

完全二叉树 → 顺序存储 (1-based):
- 父节点 i,左孩子 2i,右孩子 2i+1
- 节点 i 的父节点 $\lfloor i/2 \rfloor$

### 3.9.3 建堆 (自下而上调整)

从最后一个非叶节点 ($\lfloor n/2 \rfloor$) 开始,向前逐个**向下调整**。

```c
void AdjustDown(int a[], int k, int n) {  // 大根堆
    int tmp = a[k];
    for (int i = 2*k; i <= n; i *= 2) {
        if (i < n && a[i] < a[i+1]) i++;   // 选较大孩子
        if (tmp >= a[i]) break;
        a[k] = a[i]; k = i;
    }
    a[k] = tmp;
}

void BuildMaxHeap(int a[], int n) {
    for (int i = n/2; i >= 1; i--)
        AdjustDown(a, i, n);
}
```

**建堆时间**:$O(n)$ (严格证明用级数求和,非 $O(n \log n)$)。

### 3.9.4 堆排序

```c
void HeapSort(int a[], int n) {
    BuildMaxHeap(a, n);
    for (int i = n; i > 1; i--) {
        swap(a[1], a[i]);              // 把最大值放到末尾
        AdjustDown(a, 1, i - 1);       // 调整剩余
    }
}
```

**复杂度**:时间 $O(n \log n)$,空间 $O(1)$,**不稳定**。

详细堆排序见 [[06-排序]]。

### 3.9.5 优先队列

堆是实现优先队列的经典结构:
- `Insert(x)`:$O(\log n)$ (向上调整)
- `ExtractMax()`:$O(\log n)$ (交换根与末尾,向下调整)
- `GetMax()`:$O(1)$

## 3.10 真题陷阱与高频考点

1. **$n_0 = n_2 + 1$**:必背,常给 $n_2$ 求叶子数。
2. **空指针数**:n 个节点二叉链表 n+1 个空指针;线索化后空指针被复用。
3. **完全二叉树父子下标**:父 = ⌊i/2⌋,左 = 2i,右 = 2i+1 (1-based)。
4. **重建唯一性**:先+中、后+中、层+中可唯一;先+后不可 (单分支节点无法判断)。
5. **哈夫曼性质**:n 叶子 → 2n-1 节点;$n_1 = 0$;WPL = 非叶权值和;WPL 唯一。
6. **AVL 四种旋转**:LL 右旋、RR 左旋、LR 先左后右、RL 先右后左。
7. **AVL 插入 vs 删除**:插入一次调整即可,删除可能向上多次调整。
8. **AVL 最少节点**:$N_h = N_{h-1} + N_{h-2} + 1$,$N_0 = 1, N_1 = 2$。
9. **并查集优化**:路径压缩 + 按秩合并,均摊 $O(\alpha(n))$。
10. **孩子兄弟法**:树的后根遍历 = 二叉树的中序。
11. **度 m 的树 vs m 叉树**:前者必含度 m 节点,后者不要求。
12. **先序/后序线索找前驱后继**:先序找前驱难,后序找后继难 (需父指针)。
13. **BST 删除**:双分支用直接前驱或后继替换,二者结果不同但都保持 BST 性质。
14. **建堆时间**:O(n),不是 O(n log n)。

## 3.11 典型真题精解

### 2016 选择:完全二叉树叶子数

**题**:完全二叉树有 1000 个节点,度为 0 的节点数?

**解**:
- 完全二叉树 $n_1$ 只能是 0 或 1;
- $n = n_0 + n_1 + n_2$,$n_0 = n_2 + 1$;
- $n = 2 n_2 + 1 + n_1$;
- 1000 = $2 n_2 + 1 + n_1$,$n_1 = 999 - 2 n_2$;
- 完全二叉树 n 为偶数时 $n_1 = 1$:$2 n_2 = 998$,$n_2 = 499$,$n_0 = 500$。

**答**:$n_0 = 500$。

### 2017 选择:AVL 四种旋转

**题**:在 AVL 树中插入节点导致失衡,新插入节点在失衡节点的左孩子的右子树上,应进行何种旋转?

**解**:失衡节点为 A,插入位置是 A 的左孩子 B 的右子树 → **LR 型**,先以 B 为支点**左旋**,再以 A 为支点**右旋**。

**答**:先左旋后右旋 (LR)。

### 2018 算法:由先序+中序重建二叉树

**题**:已知先序 ABDECFG 和中序 DBEAFCG,请重建二叉树并写出后序。

**解**:
- 根 = A (先序首);
- 中序中 A 位置:DBE | A | FCG → 左子树中序 DBE,右子树中序 FCG;
- 先序对应切分:左子树先序 BDE,右子树先序 CFG;
- 左子树:根 = B,中序 D B E → B 左子树 D,右子树 E;
- 右子树:根 = C,中序 F C G → C 左子树 F,右子树 G;

```
        A
       / \
      B   C
     / \ / \
    D  E F  G
```

**后序**:DEBFGCA

### 2019 选择:哈夫曼 WPL 计算

**题**:5 个字符频率 {2, 5, 7, 9, 13},构造哈夫曼树,求 WPL。

**解**:
```
步骤1: 选 2, 5 → 7
       F = {7, 7, 9, 13}
步骤2: 选 7, 7 → 14
       F = {9, 13, 14}
步骤3: 选 9, 13 → 22
       F = {14, 22}
步骤4: 选 14, 22 → 36
       F = {36}
```

**WPL = 非叶节点权值和 = 7 + 14 + 22 + 36 = 79**

**答**:79

### 2020 选择:线索二叉树中序找前驱

**题**:在中序线索二叉树中,节点 p 的中序前驱如何找?

**解**:
- 若 p->ltag == 1:前驱 = p->lchild (直接线索);
- 若 p->ltag == 0:前驱 = p 左子树的**最右**节点 (沿右孩子走到底)。

**答**:看 ltag,ltag=1 直接走线索,否则左子树最右节点。

### 2021 算法:BST 删除节点 (双分支)

**题**:BST 中删除节点 x (x 有左右孩子),用直接后继替换的算法?

**解**:
```c
void DeleteBST(BiTree &T, int key) {
    if (!T) return;
    if (key < T->data) DeleteBST(T->lchild, key);
    else if (key > T->data) DeleteBST(T->rchild, key);
    else {
        if (!T->lchild) { BiTree p = T; T = T->rchild; free(p); }
        else if (!T->rchild) { BiTree p = T; T = T->lchild; free(p); }
        else {
            // 双分支:找直接后继 (右子树最左)
            BiTree succ = T->rchild;
            while (succ->lchild) succ = succ->lchild;
            T->data = succ->data;
            DeleteBST(T->rchild, succ->data);  // 递归删后继
        }
    }
}
```

**关键**:用直接后继替换值后,递归删除原后继位置;后继至多有一个右孩子,递归调用会落到"单分支或叶子"分支。

### 2022 选择:树后根遍历对应二叉树

**题**:树的孩子兄弟存储结构 (即转成二叉树) 后,树的后根遍历对应二叉树的哪种遍历?

**解**:
- 树的先根遍历 = 二叉树先序;
- 树的后根遍历 = 二叉树**中序**。

**答**:中序遍历。

### 2024 算法:平衡二叉树调整

**题**:依次插入 {15, 20, 5, 25, 10, 30, 8, 4, 2} 到 AVL,需进行几次调整?各是什么类型?

**解**(逐步模拟):
1. 插 15, 20, 5:平衡;
2. 插 25:20 处 RR,左旋一次 (类型:RR);
3. 插 10:平衡;
4. 插 30:平衡;
5. 插 8:平衡;
6. 插 4:5 处 LL,右旋一次 (类型:LL);
7. 插 2:失衡,类型 LL,右旋一次。

具体过程略,关键在于每次插入后从插入点向上检查 BF,找到最小失衡子树,判断类型并旋转。

**答**:3 次调整,类型依次 RR、LL、LL (具体以模拟为准)。

## 3.13 易混淆点深辨析

| 易混点 | 辨析 |
|--------|------|
| 度 m 的树 vs m 叉树 | 前者必含度 m 节点;后者不要求 |
| 满二叉树 vs 完全二叉树 | 满必完全,完全未必满 |
| 哈夫曼树 vs 完全二叉树 | 哈夫曼是严格二叉树 (无度1),但未必完全 |
| 树深 vs 树高 | 408 教材常混用,需看上下文 (严蔚敏:深度=最大层次) |
| 先序+后序 | 不能唯一重建 (单分支节点无法判断左右) |
| 直接前驱 vs 直接后继 | 前驱 = 左子树最右;后继 = 右子树最左 |
| 哈夫曼编码不唯一 | 左右可换、0/1 可换,但 WPL 唯一 |
| BST 删除前驱 vs 后继 | 二者结果可能不同,但都保持 BST 性质 |
| AVL 插入 vs 删除调整次数 | 插入一次,删除可能多次 |
| 中序线索 vs 先序线索找前驱 | 中序都简单;先序找前驱难 |
| 路径压缩 vs 按秩合并 | 单独使用均 O(log n);结合 O(α(n)) |

## 3.14 延伸知识

### 3.14.1 红黑树 (408 大纲新增,概念级)

红黑树是近似平衡的二叉搜索树,每个节点带颜色 (红/黑),满足:
1. 节点是红色或黑色;
2. 根是黑色;
3. 叶子 (NIL) 是黑色;
4. 红节点的孩子都是黑色 (不能连续红);
5. 任一节点到其叶子节点的所有路径包含相同数目的黑节点 (黑高相同)。

**性质**:高度至多 $2 \log_2(n+1)$,即 $O(\log n)$。
**优势**:插入/删除调整次数有上界 (最多 3 次旋转),优于 AVL 在频繁删除场景。

### 3.14.2 Trie 树 (前缀树)

多叉树,每条边代表一个字符,用于高效字符串检索。

```
       (root)
       /  |  \
      a   b   c
      |   |   |
      p   e   a
      |   |   |
      p   a   t
     / \  |
    l   e ...
    |
   e (结束)
```

**应用**:自动补全、拼写检查、IP 路由表。

### 3.14.3 线段树与树状数组

用于区间查询和单点修改,均 $O(\log n)$:
- **线段树**:递归分治,空间 4n;
- **树状数组 (BIT)**:利用 lowbit,空间 n,代码更短。

### 3.14.4 B 树与 B+ 树

详见 [[05-查找]]。多路平衡搜索树,用于磁盘等外存。

## 3.16 本章习题

1. 完全二叉树有 501 个节点,叶子数?
   - **答**:$n_1 = 1$ (奇数),$n = 2 n_2 + 2$,$n_2 = (501-2)/2$... 重算:n=501, $n_1 = 0$ (奇数完全二叉树), $n = 2 n_2 + 1$,$n_2 = 250$,$n_0 = 251$。

2. 给定先序 ABCDEFGH 和中序 CBEDAFHG,画出二叉树。
   - **答**:根 A;中序 CBED A FHG → 左子树 CBED (先序 BCDE),右子树 FHG (先序 FGH);
   - 左子树:根 B,中序 C B ED → B 左 C,右子树 ED (先序 DE);根 D,中序 E D → D 左 E;
   - 右子树:根 F,中序 F HG → F 右子树 HG (先序 GH);根 G,中序 H G → G 左 H;
   - 后序:CEDBHGFA

3. 哈夫曼编码 4 字符频率 {7, 5, 2, 4},求 WPL。
   - **答**:合并 2+4=6 → {5, 6, 7};合并 5+6=11 → {7, 11};合并 7+11=18 → WPL = 6+11+18 = 35。

4. AVL 树插入 1,2,3 后的形态?
   - **答**:插入 1, 2 平衡;插 3 在 1 处 RR 失衡,左旋一次 → 根为 2,左子 1,右子 3。

5. 树转二叉树后,原树的叶子节点对应二叉树的什么节点?
   - **答**:原树叶子 (无第一孩子) → 二叉树中**没有左孩子**的节点。注意:可能仍有右孩子 (即原树中的下一兄弟)。
