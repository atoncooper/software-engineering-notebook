## 1.1 定义与基本操作

### 1.1.1 逻辑定义

线性表是具有**相同数据类型**的 n (n ≥ 0) 个数据元素的**有限序列**,记为:

$$
L = (a_1, a_2, a_3, \dots, a_n)
$$

形式化用二元组表示:

$$
L = (D, R), \quad D = \{a_i \mid i = 1, 2, \dots, n, n \geq 0\}, \quad R = \{\langle a_{i-1}, a_i \rangle \mid i = 2, \dots, n\}
$$

其中:
- $D$ 是数据元素集合。
- $R$ 是关系集合,只有"邻接"关系 (前驱/后继)。
- $n$ 为表长,$n = 0$ 时为空表 $L = ()$。
- $a_1$ 是**表头** (无前驱),$a_n$ 是**表尾** (无后继)。
- 除 $a_1$ 外每个元素有且仅有一个**直接前驱**;除 $a_n$ 外每个元素有且仅有一个**直接后继**。

### 1.1.2 三个关键限定词 (必考陷阱)

| 限定词 | 含义 | 反例 |
|--------|------|------|
| **相同数据类型** | 元素同构 (类型一致) | 一个表中既存 int 又存 string 不是线性表 (但结构体数组中字段类型不同仍是同类型,因整体类型一致) |
| **有限** | 元素个数可数 | "所有整数构成的序列"不是线性表 (无限) |
| **序列** | 元素**有序** (位序关系) | 集合 {1, 3, 2} 不是线性表 (无序);但 (1, 3, 2) 是线性表 |

> **真题陷阱 (高频)**:线性表的"有序"指**位序有序** (位置有先后),不是**值有序**。$(3, 1, 4)$ 是线性表,即使值无序;若题目说"有序线性表"则要求值有序。

### 1.1.3 线性表的特征

1. **同一性**:所有元素类型相同 (决定存储空间一致)。
2. **有穷性**:元素个数有限。
3. **有序性**:元素有先后次序。
4. **首尾特殊性**:表头无前驱,表尾无后继。
5. **内部元素一致性**:除首尾外,每个元素恰有一个前驱和一个后继。

### 1.1.4 基本操作 (抽象数据类型 ADT)

```
InitList(&L)              初始化空表
DestroyList(&L)           销毁表
ListEmpty(L)              判空
ListLength(L)             求表长
GetElem(L, i, &e)         按位查找:取第 i 个元素 (1 ≤ i ≤ n)
LocateElem(L, e, compare()) 按值查找:返回首个满足关系的位序
PriorElem(L, cur_e, &pre_e) 求前驱
NextElem(L, cur_e, &next_e)  求后继
ListInsert(&L, i, e)      在第 i 位插入 e (1 ≤ i ≤ n+1)
ListDelete(&L, i, &e)     删除第 i 位元素 (1 ≤ i ≤ n)
TraverseList(L, visit())  遍历
```

> **C 语言约定**:用 `&` 表示引用传递 (C++ 风格,408 答题通用);纯 C 中需用指针 `*`。修改表结构的操作 (Init/Destroy/Insert/Delete) 必须用引用或指针。

### 1.1.5 线性表 vs 数组 vs 链表 (易混)

| 概念 | 层次 | 说明 |
|------|------|------|
| 线性表 | **逻辑结构** | 一种一对一关系的抽象数据类型 |
| 数组 | **物理实现** | 连续内存的存储方式 |
| 顺序表 | 线性表 + 数组 | 用数组实现的线性表 |
| 链表 | 线性表 + 指针 | 用指针实现的线性表 |

> **关键**:线性表是逻辑概念,数组/链表是存储概念。顺序表和链表都是线性表的实现。

## 1.2 顺序表

### 1.2.1 定义与存储结构

顺序表是用**一组地址连续**的存储单元依次存储线性表中的元素,使得逻辑上相邻的两个元素在物理位置上也相邻。

**特点**:
- 物理相邻 = 逻辑相邻。
- 随机访问 (Random Access) O(1)。
- 存储密度 = 1 (无额外指针开销)。

### 1.2.2 静态分配

```c
#define MaxSize 50              // 最大长度
typedef struct {
    ElemType data[MaxSize];     // 静态数组
    int length;                 // 当前长度
} SqList;

void InitList(SqList &L) {
    L.length = 0;               // 长度初始化为 0
}
```

**缺点**:MaxSize 固定,无法扩容;分配过大浪费,过小溢出。

### 1.2.3 动态分配

```c
#define InitSize 100            // 初始容量
typedef struct {
    ElemType *data;             // 动态数组指针
    int MaxSize;                // 当前最大容量
    int length;                 // 当前长度
} SeqList;

void InitList(SeqList &L) {
    L.data = (ElemType *)malloc(InitSize * sizeof(ElemType));
    L.MaxSize = InitSize;
    L.length = 0;
}

void IncreaseSize(SeqList &L, int len) {
    ElemType *p = L.data;
    L.data = (ElemType *)malloc((L.MaxSize + len) * sizeof(ElemType));
    for (int i = 0; i < L.length; i++)
        L.data[i] = p[i];       // 拷贝旧数据
    L.MaxSize += len;
    free(p);                    // 释放旧空间
}
```

**动态扩容策略 (工程常考)**:
- **倍增** (Doubling):容量翻倍,摊销每次插入 O(1)。
- **固定增量**:容量 +len,每次扩容 O(n)。

> **摊销分析**:倍增策略下,n 次插入总扩容成本 = 1 + 2 + 4 + ... + n ≈ 2n,平均每次 O(1)。这是动态数组的理论基础 (Vector、ArrayList)。

### 1.2.4 地址计算 (必背)

设每个元素占 d 字节,首地址为 LOC(A),则第 i 个元素 (1 ≤ i ≤ n) 的地址:

$$
\text{LOC}(A_i) = \text{LOC}(A_1) + (i - 1) \times d
$$

若数组下标从 0 开始,第 i 个元素 (1-based) 存储在 `data[i-1]`,地址:

$$
\text{LOC}(\text{data}[i-1]) = \text{LOC}(\text{data}[0]) + (i - 1) \times d
$$

**例**:int 数组,data 起始地址 2000,int 占 4 字节,求 data[5] 地址:
- 2000 + 5 × 4 = 2020。

> **真题陷阱**:注意 1-based 位序与 0-based 下标的转换。第 i 个元素 = `data[i-1]`。

### 1.2.5 按位查找 GetElem

```c
ElemType GetElem(SqList L, int i) {
    if (i < 1 || i > L.length)  // 越界检查
        exit(-1);
    return L.data[i - 1];       // O(1)
}
```

**时间复杂度**:$O(1)$ —— 顺序表最大优势。

### 1.2.6 按值查找 LocateElem

```c
int LocateElem(SqList L, ElemType e) {
    for (int i = 0; i < L.length; i++)
        if (L.data[i] == e)
            return i + 1;       // 返回位序 (1-based)
    return 0;                   // 未找到
}
```

**时间复杂度**:
- 最好 $O(1)$ (首元素即所求)。
- 最坏 $O(n)$ (末元素或未找到)。
- 平均 $O(n)$,平均比较次数 = $(n+1)/2$。

若表有序,可用折半查找 $O(\log n)$ (见 [[05-查找]])。

### 1.2.7 插入操作 ListInsert

在第 i 位 (1 ≤ i ≤ n+1) 插入元素 e:

```c
bool ListInsert(SqList &L, int i, ElemType e) {
    if (i < 1 || i > L.length + 1)    // ① 越界
        return false;
    if (L.length >= MaxSize)          // ② 表满
        return false;
    for (int j = L.length; j >= i; j--)  // ③ 从后往前移
        L.data[j] = L.data[j - 1];
    L.data[i - 1] = e;                // ④ 插入
    L.length++;                       // ⑤ 长度 +1
    return true;
}
```

**移动次数分析**:
- 在第 i 位插入,需移动 n - i + 1 个元素 (从第 i 到第 n 个后移)。
- i = 1:移动 n 个 (最坏)。
- i = n + 1:移动 0 个 (最好,尾插)。

**平均移动次数推导**:

假设每个位置等概率,$p_i = \dfrac{1}{n+1}$ (共 n+1 个可插入位置):

$$
\bar{M}_{\text{insert}} = \sum_{i=1}^{n+1} p_i \cdot (n - i + 1) = \frac{1}{n+1} \sum_{i=1}^{n+1} (n - i + 1) = \frac{1}{n+1} \cdot \frac{n(n+1)}{2} = \frac{n}{2}
$$

**结论**:平均移动 $n/2$ 次,**平均时间复杂度 $O(n)$**。

### 1.2.8 删除操作 ListDelete

删除第 i 位 (1 ≤ i ≤ n) 元素,通过引用返回:

```c
bool ListDelete(SqList &L, int i, ElemType &e) {
    if (i < 1 || i > L.length)         // ① 越界
        return false;
    e = L.data[i - 1];                 // ② 保存被删元素
    for (int j = i; j < L.length; j++) // ③ 从前往后移
        L.data[j - 1] = L.data[j];
    L.length--;                        // ④ 长度 -1
    return true;
}
```

**移动次数分析**:
- 删除第 i 位,需移动 n - i 个元素 (从第 i+1 到第 n 个前移)。
- i = 1:移动 n - 1 个 (最坏)。
- i = n:移动 0 个 (最好,尾删)。

**平均移动次数推导**:

假设每个位置等概率,$p_i = \dfrac{1}{n}$:

$$
\bar{M}_{\text{delete}} = \sum_{i=1}^{n} p_i \cdot (n - i) = \frac{1}{n} \sum_{i=1}^{n} (n - i) = \frac{1}{n} \cdot \frac{n(n-1)}{2} = \frac{n-1}{2}
$$

**结论**:平均移动 $(n-1)/2$ 次,**平均时间复杂度 $O(n)$**。

### 1.2.9 顺序表的特点

| 优点 | 缺点 |
|------|------|
| 随机访问 O(1) | 插入删除需移动大量元素 |
| 存储密度高 (无指针) | 需连续空间,容量受限 |
| 物理位置反映逻辑关系 | 静态分配可能浪费或溢出 |
| 缓存友好 (局部性好) | 动态扩容有拷贝开销 |

## 1.3 单链表

### 1.3.1 节点定义

```c
typedef struct LNode {
    ElemType data;              // 数据域
    struct LNode *next;         // 指针域
} LNode, *LinkList;
```

**存储密度**:

$$
\text{存储密度} = \frac{\text{数据本身占用}}{\text{总分配}} = \frac{\text{sizeof(ElemType)}}{\text{sizeof(ElemType)} + \text{sizeof(指针)}}
$$

若 ElemType = int (4B),指针 8B,存储密度 = 4/12 = 33%。链表存储密度 < 1。

### 1.3.2 头结点 (必考)

带头结点的单链表:第一个节点 (头结点) 不存数据,`L->next` 指向第一个真正数据节点。

| 对比项 | 带头结点 | 不带头结点 |
|--------|----------|------------|
| 空表判断 | `L->next == NULL` | `L == NULL` |
| 第一个数据节点 | `L->next` | `L` |
| 插入/删除首位 | 统一处理,无需特判 | 需特判修改头指针 |
| 推荐 | ✅ 408 默认 | ✗ |

> **带头结点的好处**:
> 1. 第一数据节点处理与其他节点一致 (无需修改头指针)。
> 2. 空表与非空表处理统一。
> 3. 简化代码,减少边界错误。

### 1.3.3 头插法建表 (逆序)

```c
LinkList HeadInsert(LinkList &L) {
    L = (LinkList)malloc(sizeof(LNode));    // 头结点
    L->next = NULL;
    int x;
    while (scanf("%d", &x) != EOF) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        s->next = L->next;    // ① 新节点指向原第一节点
        L->next = s;          // ② 头结点指向新节点
    }
    return L;
}
```

**结果**:输入 1, 2, 3,链表为 3 → 2 → 1 (逆序)。

> **致命错误** (顺序颠倒):
> ```c
> L->next = s;          // 先把头结点指向 s
> s->next = L->next;    // 此时 L->next 已经是 s,s->next = s,自指!
> ```
> 必须先 `s->next = L->next`,后 `L->next = s`。

**头插法应用**:
- 链表逆置 (见 1.6.1)。
- 链表分区 (见 1.6.7)。

### 1.3.4 尾插法建表 (顺序)

```c
LinkList TailInsert(LinkList &L) {
    L = (LinkList)malloc(sizeof(LNode));
    L->next = NULL;
    LNode *r = L;               // 尾指针,初始指向头结点
    int x;
    while (scanf("%d", &x) != EOF) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        r->next = s;            // 尾节点指向新节点
        r = s;                  // 尾指针后移
    }
    r->next = NULL;             // 尾节点 next 置空
    return L;
}
```

**结果**:输入 1, 2, 3,链表为 1 → 2 → 3 (顺序)。

**尾指针的作用**:避免每次找尾 O(n),使尾插法整体 O(n) 而非 O(n²)。

### 1.3.5 按序号查找

```c
LNode *GetElem(LinkList L, int i) {
    if (i < 0) return NULL;     // 非法
    LNode *p = L;               // 从头结点开始
    int j = 0;
    while (p && j < i) {        // 走 i 步
        p = p->next;
        j++;
    }
    return p;                   // 返回第 i 个节点 (i=0 返回头结点)
}
```

**时间复杂度**:$O(n)$,最坏走 n 步。

> **边界**:i = 0 返回头结点,i > n 返回 NULL。

### 1.3.6 按值查找

```c
LNode *LocateElem(LinkList L, ElemType e) {
    LNode *p = L->next;
    while (p && p->data != e)
        p = p->next;
    return p;                   // 找到返回节点,否则 NULL
}
```

**时间复杂度**:$O(n)$,平均比较 $(n+1)/2$ 次。

### 1.3.7 插入操作

**后插** (在节点 p 之后插入 s):

```c
s->next = p->next;
p->next = s;
```

**前插** (在 p 之前插入,但只给 p 指针 —— 经典技巧:先后插再交换数据):

```c
s->next = p->next;             // s 接到 p 之后
p->next = s;
swap(s->data, p->data);        // 交换数据,效果上 s 在 p 之前
```

**按位序插入** (在第 i 位插入):

```c
bool ListInsert(LinkList &L, int i, ElemType e) {
    LNode *p = GetElem(L, i - 1);   // 找前驱
    if (!p) return false;
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;
    p->next = s;
    return true;
}
```

**时间复杂度**:查找前驱 $O(n)$ + 插入 $O(1)$ = $O(n)$。

### 1.3.8 删除操作

**删除 p 的后继**:

```c
LNode *q = p->next;
p->next = q->next;
free(q);
```

**删除 p 自身** (只给 p,用交换技巧):

```c
LNode *q = p->next;
p->data = q->data;             // 把后继数据复制过来
p->next = q->next;
free(q);                       // 实际删除的是 q
```

> **陷阱**:此技巧在 p 是尾节点时失效 (p->next 为 NULL)。此时只能从头找前驱。

**按位序删除**:

```c
bool ListDelete(LinkList &L, int i, ElemType &e) {
    LNode *p = GetElem(L, i - 1);   // 找前驱
    if (!p || !p->next) return false;
    LNode *q = p->next;
    e = q->data;
    p->next = q->next;
    free(q);
    return true;
}
```

### 1.3.9 求表长

```c
int Length(LinkList L) {
    int len = 0;
    LNode *p = L->next;
    while (p) {
        len++;
        p = p->next;
    }
    return len;
}
```

**时间复杂度**:$O(n)$。

### 1.3.10 单链表的特点

| 优点 | 缺点 |
|------|------|
| 动态分配,无容量上限 | 随机访问 O(n) |
| 插入删除只需改指针 | 存储密度低 (指针开销) |
| 不需连续空间 | 需遍历找前驱 (单链表) |
| 适合动态变化 | 缓存不友好 |

## 1.4 双链表

### 1.4.1 动机

单链表只能单向遍历,找前驱需 O(n)。双链表每个节点含 prior 与 next 两个指针,双向可遍历。

### 1.4.2 节点定义

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinklist;
```

**存储密度**:更低 (双指针开销),ElemType = int 时 = 4 / (4 + 8 + 8) = 20%。

### 1.4.3 插入操作 (在 p 之后插入 s) —— 四步必背

```c
s->next = p->next;             // ① s 的后继 = p 的后继
if (p->next)                   // ② p 原后继的前驱 = s (注意 p 可能是尾)
    p->next->prior = s;
s->prior = p;                  // ③ s 的前驱 = p
p->next = s;                   // ④ p 的后继 = s
```

**图示**:

```
插入前:  ... ←→ p ←→ p->next ←→ ...
                 ↓ 插入 s
插入后:  ... ←→ p ←→ s ←→ p->next(原) ←→ ...

步骤:
① s->next 指向 p->next (新节点先认后继)
② p->next->prior 指向 s (后继回认 s 为前驱)
③ s->prior 指向 p (s 认前驱)
④ p->next 指向 s (p 改后继)
```

> **顺序记忆**:
> - 先连接 s 的两边 (①③),再修改外部 (②④)。
> - 口诀:**"先右后左,先内后外"**。
> - ②必须判空 (p 可能是尾节点,p->next 为 NULL)。

### 1.4.4 删除操作 (删除 p 的后继 q)

```c
p->next = q->next;             // ① p 越过 q
if (q->next)                   // ② q 的后继回认 p
    q->next->prior = p;
free(q);                       // ③ 释放 q
```

### 1.4.5 双链表的优势

- 找前驱 O(1) (单链表 O(n))。
- 双向遍历。
- 删除给定节点 O(1) (单链表需找前驱 O(n))。

## 1.5 循环链表与静态链表

### 1.5.1 循环单链表

尾节点的 next 指回头结点 (或头节点位置),形成环。

```
L -> [头] -> [a1] -> [a2] -> ... -> [an] --┐
└────────────────────────────────────────┘
```

- **判空**:`L->next == L`。
- **遍历终止条件**:`p->next != L` (而非 `p != NULL`)。

**带尾指针的循环单链表**:常用于频繁操作表尾的场景。rear 指向尾节点,rear->next 即头结点。

### 1.5.2 循环双链表

尾的 next 指头,头的 prior 指尾。

- **判空**:`L->next == L` (且 `L->prior == L`)。

### 1.5.3 两个带尾指针的循环单链表合并 (经典)

将链表 B 接到链表 A 的尾部:

```c
LinkList Connect(LinkList A, LinkList B) {
    // A、B 均带尾指针 rear,头结点为 rear->next
    LNode *p = A->rear->next;             // A 的头结点
    A->rear->next = B->rear->next->next;  // A 尾接 B 第一数据节点
    B->rear->next = p;                    // B 尾接 A 头结点
    free(B->rear->next);                  // 释放 B 的冗余头结点 (合并后只留一个)
    // 或保留 B 头结点,具体看题
    return A;
}
```

**时间复杂度**:$O(1)$ (无需遍历找尾)。

> **真题陷阱**:若用头指针,合并需遍历到尾 O(n);用尾指针可 O(1)。

### 1.5.4 静态链表

用**数组**描述链表,节点含 cursor (下一节点的数组下标)。适合不支持指针的语言 (如早期 BASIC),或内存受限场景。

```c
#define MaxSize 50
typedef struct {
    ElemType data;
    int next;                  // 下一节点下标,-1 表示结束
} SLinkList[MaxSize];
```

**初始化**:

```c
void InitSpace(SLinkList space) {
    for (int i = 0; i < MaxSize - 1; i++)
        space[i].next = i + 1; // 备用链表
    space[MaxSize - 1].next = -1;
}
```

**特点**:
- 仍需预先分配大数组 (无真正动态扩容)。
- 插入删除只需修改 next 域,无需移动元素。
- 优点:无指针语言可用;分配释放快。
- 缺点:需管理空闲链表;随机访问仍 O(n)。

> **考点**:静态链表**仍需预先分配**,不能真正动态扩容;存储密度比单链表略高 (无指针,但 next 占 int)。

## 1.6 经典算法题模板 (十大必背)

### 1.6.1 链表逆置 (头插法)

```c
void Reverse(LinkList &L) {
    LNode *p = L->next, *q;
    L->next = NULL;
    while (p) {
        q = p->next;            // 保存下一节点
        p->next = L->next;      // 头插
        L->next = p;
        p = q;
    }
}
// 时间 O(n),空间 O(1)
```

**图示**:

```
原:  L -> 1 -> 2 -> 3 -> NULL
步骤1: L -> 1 -> NULL, p = 2
步骤2: L -> 2 -> 1 -> NULL, p = 3
步骤3: L -> 3 -> 2 -> 1 -> NULL, p = NULL,结束
```

### 1.6.2 找中点 (快慢指针)

```c
LNode *FindMid(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) {
        slow = slow->next;      // 慢走 1 步
        fast = fast->next->next;// 快走 2 步
    }
    return slow;                // 偶数个返回第 n/2+1 个
}
```

**原理**:快指针到尾时,慢指针在中点。

**应用**:链表归并排序、判断回文。

### 1.6.3 判环 (Floyd 龟兔赛跑)

```c
bool HasCycle(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;  // 相遇则有环
    }
    return false;
}
```

**找环入口** (进阶):

```c
LNode *DetectCycle(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {             // 相遇
            LNode *p = L->next;
            while (p != slow) {
                p = p->next;
                slow = slow->next;
            }
            return p;                   // 环入口
        }
    }
    return NULL;
}
```

**数学证明**:设头到环入口距离 a,环长 b,相遇点距环入口 c。
- 慢指针走了 a + c。
- 快指针走了 a + c + nb (n 圈)。
- 2(a + c) = a + c + nb → a + c = nb → a = nb - c = (n-1)b + (b - c)。
- 即从头走 a 步 = 从相遇点走 a 步到达环入口 (绕 n-1 圈 + b-c)。

### 1.6.4 两个有序链表合并

```c
LinkList Merge(LinkList A, LinkList B) {
    LinkList C = (LinkList)malloc(sizeof(LNode));
    LNode *r = C, *p = A->next, *q = B->next;
    while (p && q) {
        if (p->data <= q->data) {
            r->next = p; p = p->next;
        } else {
            r->next = q; q = q->next;
        }
        r = r->next;
    }
    r->next = p ? p : q;        // 接上剩余
    free(A); free(B);           // 释放旧头结点
    return C;
}
```

**时间**:$O(n + m)$,**空间**:$O(1)$ (原地,无新建节点)。

### 1.6.5 删除倒数第 k 个节点 (双指针)

```c
LNode *RemoveKthFromEnd(LinkList &L, int k) {
    LNode *fast = L, *slow = L;
    for (int i = 0; i < k; i++)             // fast 先走 k 步
        fast = fast->next;
    while (fast->next) {                    // 同步走直到 fast 到尾
        fast = fast->next;
        slow = slow->next;
    }
    LNode *q = slow->next;                  // slow 是待删前驱
    slow->next = q->next;
    free(q);
    return L;
}
```

**关键**:fast 先走 k 步,然后 fast、slow 同步,fast 到尾时 slow 恰在倒数第 k+1 个 (待删前驱)。

### 1.6.6 两个链表的第一个公共节点

```c
LNode *FindCommon(LinkList A, LinkList B) {
    LNode *p = A->next, *q = B->next;
    while (p != q) {
        p = p ? p->next : B->next;  // p 走完 A 走 B
        q = q ? q->next : A->next;  // q 走完 B 走 A
    }
    return p;
}
```

**原理**:两指针走相同总长度 (a + b),必在公共节点相遇 (或同时为 NULL)。

```
A:  a1 → a2 → a3 ↘
                    c1 → c2 → c3 → NULL
B:  b1 → b2 ↗
```

p 路径:a1 a2 a3 c1 c2 c3 b1 b2 c1 (相遇)
q 路径:b1 b2 c1 c2 c3 a1 a2 a3 c1 (相遇)

### 1.6.7 链表分区 (绝对值 ≤ k 与 > k)

```c
void Partition(LinkList L, int k) {
    LinkList B = (LinkList)malloc(sizeof(LNode));
    B->next = NULL;
    LNode *rb = B, *ra = L, *p = L->next;
    L->next = NULL;
    while (p) {
        LNode *q = p->next;
        p->next = NULL;
        if (abs(p->data) <= k) {
            ra->next = p; ra = p;
        } else {
            rb->next = p; rb = p;
        }
        p = q;
    }
    ra->next = B->next;
    free(B);
}
```

### 1.6.8 链表去重 (保留首次出现)

```c
void Deduplicate(LinkList L) {
    LNode *p = L->next;
    while (p) {
        LNode *q = p->next, *pre = p;
        while (q) {
            if (q->data == p->data) {
                pre->next = q->next;
                free(q);
                q = pre->next;
            } else {
                pre = q; q = q->next;
            }
        }
        p = p->next;
    }
}
// 时间 O(n²),空间 O(1)
```

**哈希表优化** $O(n)$:

```c
void Deduplicate(LinkList L) {
    bool seen[MAX_VAL] = {false};
    LNode *p = L->next, *pre = L;
    while (p) {
        if (seen[p->data]) {
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {
            seen[p->data] = true;
            pre = p; p = p->next;
        }
    }
}
```

### 1.6.9 判断回文 (用栈或找中点逆置)

```c
bool IsPalindrome(LinkList L) {
    // 找中点
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) {
        slow = slow->next; fast = fast->next->next;
    }
    // 逆置后半部分
    LNode *prev = NULL, *cur = slow;
    while (cur) {
        LNode *next = cur->next;
        cur->next = prev;
        prev = cur; cur = next;
    }
    // 比较
    LNode *p1 = L->next, *p2 = prev;
    bool ok = true;
    while (p2) {
        if (p1->data != p2->data) { ok = false; break; }
        p1 = p1->next; p2 = p2->next;
    }
    // (可选) 恢复原链表
    return ok;
}
```

### 1.6.10 复制带随机指针的链表 (LeetCode 138)

```c
typedef struct RNode {
    int val;
    struct RNode *next, *random;
} RNode;

RNode *CopyRandomList(RNode *head) {
    if (!head) return NULL;
    // ① 在每个节点后插入复制节点
    for (RNode *p = head; p; p = p->next->next) {
        RNode *c = (RNode *)malloc(sizeof(RNode));
        c->val = p->val;
        c->next = p->next;
        p->next = c;
    }
    // ② 设置 random
    for (RNode *p = head; p; p = p->next->next) {
        if (p->random) p->next->random = p->random->next;
    }
    // ③ 拆分
    RNode *newHead = head->next;
    for (RNode *p = head; p; p = p->next) {
        RNode *c = p->next;
        p->next = c->next;
        if (c->next) c->next = c->next->next;
    }
    return newHead;
}
```

## 1.7 顺序表 vs 链表 (深度对比)

| 维度 | 顺序表 | 链表 |
|------|--------|------|
| 物理 | 连续 | 离散 |
| 随机访问 | O(1) ✅ | O(n) |
| 按值查找 | O(n) (无序)/O(log n) (有序) | O(n) |
| 插入删除 | O(n) (移动元素) | O(1) (改指针,但查找前驱 O(n)) |
| 空间分配 | 静态/动态扩容 | 动态,无上限 |
| 存储密度 | 1 (无额外开销) | < 1 (指针开销) |
| 缓存友好 | ✅ (连续内存) | ✗ (分散) |
| 适用 | 频繁查找、少插删 | 频繁插删、长度变化大 |
| 实现复杂度 | 简单 | 较复杂 (指针操作) |
| 内存碎片 | 需大连续块 | 小块即可 |

**工程选型经验**:
- **数据规模已知 + 频繁查找** → 顺序表 (如查表、索引)。
- **数据规模动态 + 频繁插删** → 链表 (如队列、LRU)。
- **数据量小** → 顺序表 (缓存友好,实际更快)。
- **数据量极大 + 不连续** → 链表。

## 1.8 真题陷阱与高频考点 (深度)

### 1.8.1 概念类陷阱

1. **"有序"指位序非值序**:
   - 线性表的"有序"指位置有序,不是值有序。
   - "有序线性表"才是值有序。

2. **线性表 vs 数组**:
   - 线性表是逻辑结构,数组是存储实现。
   - 数组可以存非线性结构 (如树的双亲表示)。

3. **存储密度**:
   - 顺序表 = 1 (无额外开销)。
   - 链表 < 1 (指针开销)。
   - 双链表 < 单链表 < 静态链表 < 顺序表。

4. **空表判断**:
   - 顺序表:`length == 0`。
   - 带头结点单链表:`L->next == NULL`。
   - 不带头结点单链表:`L == NULL`。

### 1.8.2 操作类陷阱

5. **头插法顺序不能反**:
   - ✅ `s->next = L->next; L->next = s;`
   - ❌ `L->next = s; s->next = L->next;` (s 自指)

6. **双链表插入四步顺序**:
   - ①`s->next = p->next` ②`p->next->prior = s` ③`s->prior = p` ④`p->next = s`。
   - ②必须判空 (p 可能是尾)。

7. **删除 p 自身的交换技巧**:
   - 把后继数据复制到 p,删除后继。
   - 但 p 是尾节点时失效 (p->next = NULL)。

8. **插入删除边界**:
   - 插入 i 的范围:1 ≤ i ≤ n+1。
   - 删除 i 的范围:1 ≤ i ≤ n。
   - 越界必须 return false。

### 1.8.3 复杂度类陷阱

9. **链表插入删除 O(1) 的条件**:
   - 仅改指针这一步 O(1)。
   - 若含查找 (按位序),整体 O(n)。
   - 题目问"插入操作时间"通常指 O(1)。

10. **平均移动次数**:
    - 插入:n/2 (n+1 个位置等概率)。
    - 删除:(n-1)/2 (n 个位置等概率)。
    - **分母不同** (n+1 vs n),易混。

11. **建表复杂度**:
    - 头插法:O(n) (每次 O(1))。
    - 尾插法:带尾指针 O(n),不带尾指针 O(n²)。

### 1.8.4 算法题陷阱

12. **释放后访问**:
    - `free(p)` 后 p 是野指针,必须先 `q = p->next` 保存。

13. **空指针解引用**:
    - 遍历前必判 `if (!L)`、`if (!p)`。
    - `p->next` 前必判 `if (p)`。

14. **快慢指针终止条件**:
    - 找中点:`while (fast && fast->next)`。
    - 判环:`while (fast && fast->next)`。
    - 不能写成 `while (fast->next)` (可能 fast 已 NULL)。

15. **结构体字段名严格按题**:
    - 题目给 `data` 不能写 `val`,给 `next` 不能写 `link`。

## 1.9 典型真题精解

### 1.9.1 2016 真题:链表存储密度

**题**:下列关于线性表存储结构的叙述,正确的是?
A. 顺序表的存储密度一定为 1
B. 链表的存储密度一定小于 1
C. 顺序表支持随机访问
D. 链表支持随机访问

**答**:C。
- A 错:顺序表存储密度 = 1 (无指针),但若题目限定"含长度字段"则 < 1,通常说"接近 1"或"= 1"。
- B 错:链表存储密度 < 1 (有指针开销),但严格说"小于 1"。
- C 对:顺序表随机访问 O(1)。
- D 错:链表随机访问 O(n)。

### 1.9.2 2017 真题:单链表插入顺序

**题**:在带头结点的单链表 L 中,在 p 所指节点后插入新节点 s,下列语句顺序正确的是?
A. `p->next = s; s->next = p->next;`
B. `s->next = p->next; p->next = s;`
C. `s->next = p; p->next = s;`
D. `p->next = s; s->next = p;`

**答**:B。先 `s->next = p->next` (保存原后继),再 `p->next = s` (改 p 的后继)。

### 1.9.3 2019 真题:顺序表 vs 链表复杂度

**题**:对长度为 n 的线性表,下列操作中,顺序表比链表快的是?
A. 在第 i 位插入
B. 在第 i 位删除
C. 访问第 i 个元素
D. 查找值为 e 的元素

**答**:C。
- A、B:顺序表需移动 O(n),链表改指针 O(1) (含查找 O(n)),链表不慢。
- C:顺序表 O(1),链表 O(n),顺序表快。✓
- D:都是 O(n)。

### 1.9.4 2020 真题:链表分区算法

**题**:设计算法,带头结点单链表 L,把所有绝对值 ≤ k 的节点移到前面,保持相对顺序。

**算法思想**:遍历一次,把 ≤ k 的节点摘下尾插到新链表 A,> k 的尾插到新链表 B,最后 A 尾接 B 头。

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

void Partition(LinkList L, int k) {
    if (!L || !L->next) return;
    LinkList B = (LinkList)malloc(sizeof(LNode));
    B->next = NULL;
    LNode *ra = L, *rb = B, *p = L->next;
    L->next = NULL;
    while (p) {
        LNode *q = p->next;
        p->next = NULL;
        if (abs(p->data) <= k) {
            ra->next = p; ra = p;
        } else {
            rb->next = p; rb = p;
        }
        p = q;
    }
    ra->next = B->next;
    free(B);
}
// 时间 O(n),空间 O(1)
```

### 1.9.5 2022 真题:链表去重

**题**:带头结点单链表 L,删除重复值节点,仅保留首次出现。

**算法思想**:双指针,外层遍历每个节点,内层删除其后所有相同值节点。或用哈希集合 O(n)。

```c
// 哈希集合版本 O(n)
void Deduplicate(LinkList L) {
    bool seen[10001] = {false};   // 假设值范围 0~10000
    LNode *pre = L, *p = L->next;
    while (p) {
        if (seen[p->data]) {
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {
            seen[p->data] = true;
            pre = p; p = p->next;
        }
    }
}
```

## 1.10 易混淆点深度辨析

### 1.10.1 头指针 vs 头结点 vs 首元节点

| 概念 | 定义 | 必有? |
|------|------|-------|
| 头指针 | 指向链表第一个节点的指针 (链表标识) | 必有 |
| 头结点 | 在首元节点之前的不存数据节点 | 可选 |
| 首元节点 | 第一个数据节点 | 非空表必有 |

```
头指针 L
   │
   ▼
[头结点] -> [首元节点 a1] -> [a2] -> ... -> [an] -> NULL
```

### 1.10.2 链表插入删除 O(1) vs O(n)

- **O(1)**:已知前驱节点,仅改指针。
- **O(n)**:按位序插入删除,需先查找前驱。

> 真题表述:"在 p 所指节点后插入" = O(1);"在第 i 位插入" = O(n)。

### 1.10.3 顺序表 vs 数组

- 数组是**物理实现**,大小固定。
- 顺序表是**逻辑结构 + 数组实现**,可有 length 字段。
- 顺序表长度可变 (≤ MaxSize),数组长度固定。

### 1.10.4 静态链表 vs 顺序表

| 对比项 | 顺序表 | 静态链表 |
|--------|--------|----------|
| 物理 | 连续 | 数组 (连续) |
| 逻辑相邻 | 物理相邻 | 通过 next 索引 |
| 插入删除 | 移动元素 O(n) | 改 next O(1) |
| 随机访问 | O(1) | O(n) |
| 适用 | 频繁查找 | 频繁插删,无指针环境 |

### 1.10.5 单链表 vs 双链表删除给定节点

| 操作 | 单链表 | 双链表 |
|------|--------|--------|
| 删除 p 的后继 | O(1) | O(1) |
| 删除 p 自身 | O(n) (需找前驱) | O(1) (p->prior->next = p->next) |

## 1.11 高频考点速查表

| 考点 | 公式/结论 |
|------|-----------|
| 顺序表插入平均移动 | $n/2$ |
| 顺序表删除平均移动 | $(n-1)/2$ |
| 顺序表随机访问 | O(1) |
| 链表存储密度 | < 1 |
| 头插法顺序 | `s->next = L->next; L->next = s;` |
| 双链表插入四步 | ①s->next=p->next ②p->next->prior=s ③s->prior=p ④p->next=s |
| 双链表删除后继 | p->next=q->next; q->next->prior=p; |
| n 节点二叉链表空指针 | n+1 |
| 找中点 | 快慢指针,fast 走 2 步 slow 走 1 步 |
| Floyd 判环 | slow == fast 则有环 |
| 两链表公共节点 | p 走 A+B,q 走 B+A,相遇 |
| 倒数第 k | fast 先走 k 步,再同步 |
| 循环链表合并 | 尾指针 O(1),头指针 O(n) |
| 静态链表 | 数组 + next 索引,无真动态扩容 |

## 1.13 拓展知识 (超纲但有助于理解)

### 1.13.1 跳表 (Skip List)

在有序链表上加多级索引,实现 O(log n) 查找。Redis 的有序集合底层用跳表。

### 1.13.2 LRU 缓存 (双向链表 + 哈希表)

- 访问节点:移到链表头。
- 新增节点:插到头,若超容删尾。
- 哈希表存 key → 节点指针,O(1) 定位。

### 1.13.3 并发链表

- 加锁 (粗粒度:整个链表一把锁;细粒度:每节点一把锁)。
- 无锁链表:CAS 操作,但实现复杂。

### 1.13.4 块状链表 (Block List)

链表节点存一个块 (数组),结合顺序表与链表优点。块内 O(√n),整体 O(√n)。
