## 4.1 基本概念

### 4.1.1 定义

图 $G = (V, E)$,V 是顶点集,E 是边集。$|V| = n$,$|E| = e$。

| 概念 | 定义 |
|------|------|
| 有向图 | 边有方向,$\langle u, v \rangle$,又称弧 |
| 无向图 | 边无方向,$(u, v)$ |
| 完全图 | 任意两顶点间有边;有向 $n(n-1)$,无向 $n(n-1)/2$ |
| 度 | 与顶点关联的边数;有向图分入度、出度 |
| 子图 | $V' \subseteq V, E' \subseteq E$ |
| 连通 (无向) | 任意两点有路径 |
| 连通分量 | 极大连通子图 |
| 强连通 (有向) | 任意两点互相可达 |
| 强连通分量 | 极大强连通子图 |
| 生成树 | 极小连通子图,n 顶点 n-1 边 |
| 生成森林 | 非连通图各连通分量的生成树集合 |
| 网 | 带权图 |
| 稠密图 | $e$ 接近 $n^2$ |
| 稀疏图 | $e$ 远小于 $n^2$ (一般 $e < n \log n$) |

### 4.1.2 性质

1. **无向图**:所有顶点度数之和 = 2 × 边数 (每条边贡献两个度)。
2. **有向图**:所有顶点入度之和 = 出度之和 = 边数。
3. n 顶点连通图至少 n-1 条边;**强连通图至少 n 条边** (构成一个环)。
4. n 顶点无向完全图有 $n(n-1)/2$ 条边;有向完全图有 $n(n-1)$ 条弧。
5. 极大连通子图 (连通分量) 必须是连通的、顶点极大的;极小连通子图 (生成树) 必须是连通的、边极小的。

## 4.2 存储结构

### 4.2.1 邻接矩阵

`A[i][j] = 1` (或权值) 表示有边 $i \to j$。无向图邻接矩阵对称。

```c
typedef struct {
    VertexType vex[MaxV];
    EdgeType edge[MaxV][MaxV];
    int vexnum, arcnum;
} MGraph;
```

- 空间 $O(n^2)$,适合**稠密图**。
- 优点:查边 O(1);求度 O(n) (有向图需同时查行列);
- 缺点:稀疏图浪费空间;增删边 O(1) 但增删顶点 O(n²)。

**性质**:
- 无向图邻接矩阵对称,$A^k[i][j]$ 表示 i 到 j 长度为 k 的路径数;
- 有向图行和 = 出度,列和 = 入度。

### 4.2.2 邻接表

每个顶点维护一个链表,存其邻接点。

```c
typedef struct ArcNode {
    int adjvex;
    struct ArcNode *next;
    InfoType info;   // 权值
} ArcNode;

typedef struct VNode {
    VertexType data;
    ArcNode *first;
} VNode, AdjList[MaxV];

typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;
```

- 空间 $O(n + e)$,适合**稀疏图**;
- 无向图同一条边存两次 (占用 2e 个边节点);
- 优点:省空间,易找邻接点 (出边);
- 缺点:查两顶点间是否有边 O(n);有向图难以直接求入度 (需逆邻接表)。

### 4.2.3 十字链表 (有向图专用)

把邻接表与逆邻接表合并,每条弧一个节点,同时挂在弧尾的出弧链与弧头的入弧链上。

```c
typedef struct ArcBox {
    int tailvex, headvex;          // 弧尾、弧头下标
    struct ArcBox *hlink, *tlink;  // 同弧头链、同弧尾链
    InfoType info;
} ArcBox;

typedef struct VexNode {
    VertexType data;
    ArcBox *firstin, *firstout;    // 第一条入弧、出弧
} VexNode;
```

- 空间 $O(n + e)$;
- 同时高效查入度与出度;
- 删弧操作简单 (链表删除)。

### 4.2.4 邻接多重表 (无向图专用)

每条边只有一个节点,但同时在两个顶点的边链上。

```c
typedef struct EBox {
    int ivex, jvex;                // 边两端顶点
    struct EBox *ilink, *jlink;    // 依附于 ivex 的下一条边、依附于 jvex 的下一条边
    InfoType info;
    bool marked;                   // 删除标记
} EBox;
```

- 优点:同一条边只存一次,删除边方便 (无向图邻接表删同一条边需操作两个链表,这里只需一个节点);
- 空间 $O(n + e)$。

### 4.2.5 四种存储对比

| 存储结构 | 适用图类型 | 空间 | 查边 | 求度 | 删边 |
|----------|------------|------|------|------|------|
| 邻接矩阵 | 通用 | $O(n^2)$ | $O(1)$ | $O(n)$ | $O(1)$ |
| 邻接表 | 通用 (稀疏) | $O(n+e)$ | $O(n)$ | $O(n)$ (有向需逆表) | $O(n)$ |
| 十字链表 | 有向图 | $O(n+e)$ | $O(n)$ | $O(1)$ 出入度同时 | $O(1)$ |
| 邻接多重表 | 无向图 | $O(n+e)$ | $O(n)$ | $O(n)$ | $O(1)$ |

## 4.3 遍历

### 4.3.1 BFS (广度优先)

用队列,逐层访问。类似树的层序遍历。

```c
bool visited[MaxV];

void BFS(Graph G, int v) {
    Queue Q; InitQueue(Q);
    visit(v); visited[v] = true; EnQueue(Q, v);
    while (!Empty(Q)) {
        int u; DeQueue(Q, u);
        for (int w = FirstNeighbor(G, u); w >= 0; w = NextNeighbor(G, u, w)) {
            if (!visited[w]) {
                visit(w); visited[w] = true;
                EnQueue(Q, w);
            }
        }
    }
}

void BFSTraverse(Graph G) {
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i]) BFS(G, i);   // 处理非连通图
}
```

**复杂度**:
- 邻接矩阵:BFS 时间 $O(n^2)$ (每点查 n 邻接);
- 邻接表:BFS 时间 $O(n + e)$ (每条边访问 1 或 2 次);
- 空间 $O(n)$ (队列 + visited)。

**应用**:
- 求无权图最短路径 (BFS 树深度即最短边数);
- 求连通分量;
- 判断二分图 (交叉染色)。

### 4.3.2 DFS (深度优先)

用栈 (或递归,递归本质是栈)。类似树的先序遍历。

```c
void DFS(Graph G, int v) {
    visit(v); visited[v] = true;
    for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
        if (!visited[w]) DFS(G, w);
}

void DFSTraverse(Graph G) {
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i]) DFS(G, i);
}
```

**复杂度**:
- 邻接矩阵:DFS 时间 $O(n^2)$;
- 邻接表:DFS 时间 $O(n + e)$;
- 空间 $O(n)$ (递归栈)。

### 4.3.3 应用

#### 4.3.3.1 连通分量

从每个未访问顶点调用一次 BFS/DFS,调用次数 = 连通分量数。

#### 4.3.3.2 判断无向图是否有环

DFS 时遇到已访问且**非父节点** → 有环。

```c
bool HasCycle(Graph G) {
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i] && DFS_Cycle(G, i, -1))
            return true;
    return false;
}

bool DFS_Cycle(Graph G, int v, int parent) {
    visited[v] = true;
    for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w)) {
        if (!visited[w]) {
            if (DFS_Cycle(G, w, v)) return true;
        } else if (w != parent) {
            return true;   // 遇到已访问且非父 → 有环
        }
    }
    return false;
}
```

#### 4.3.3.3 判断有向图是否有环

用拓扑排序 (见 4.6) 或 DFS 三色标记 (白/灰/黑):遇到灰节点即有环。

## 4.4 最小生成树 (MST)

### 4.4.1 Prim 算法

从一个顶点开始,每次加入"已选顶点集合到未选顶点"中权值最小的边,扩展生成树。

```
初始化:U = {v0}, TE = {}
重复 n-1 次:
   在所有 (u, w) 边中,u ∈ U, w ∉ U,选权值最小者 (u*, w*)
   把 w* 加入 U,边 (u*, w*) 加入 TE
```

```c
void Prim(MGraph G, int v0) {
    int lowcost[MaxV], closest[MaxV];
    bool inTree[MaxV] = {false};
    for (int i = 0; i < G.vexnum; i++) {
        lowcost[i] = G.edge[v0][i];
        closest[i] = v0;
    }
    inTree[v0] = true;
    for (int i = 1; i < G.vexnum; i++) {        // 选 n-1 条边
        int min = INF, k = -1;
        for (int j = 0; j < G.vexnum; j++)
            if (!inTree[j] && lowcost[j] < min) { min = lowcost[j]; k = j; }
        inTree[k] = true;
        // 边 (closest[k], k) 加入 TE
        for (int j = 0; j < G.vexnum; j++)
            if (!inTree[j] && G.edge[k][j] < lowcost[j]) {
                lowcost[j] = G.edge[k][j];
                closest[j] = k;
            }
    }
}
```

- 时间 $O(n^2)$ (邻接矩阵);堆优化 $O((n+e) \log n)$;
- 适合**稠密图** (与边数无关,只与顶点数有关)。

### 4.4.2 Kruskal 算法

按边权升序排序,依次加入不构成环的边,直到 n-1 条。用并查集判环。

```
所有边按权升序排序
对每条边 (u, v):
   if Find(u) != Find(v):  // 不在同一集合 (用并查集)
      Union(u, v)
      加入生成树
      若已 n-1 条,结束
```

```c
int Kruskal(Edge edges[], int n, int m) {
    sort(edges, edges + m, byWeight);
    DSU dsu; dsu.init(n);
    int sum = 0, cnt = 0;
    for (int i = 0; i < m && cnt < n - 1; i++) {
        int u = edges[i].u, v = edges[i].v;
        if (dsu.Find(u) != dsu.Find(v)) {
            dsu.Union(u, v);
            sum += edges[i].w;
            cnt++;
        }
    }
    return sum;
}
```

- 时间 $O(e \log e)$ (排序主导);
- 适合**稀疏图**。

### 4.4.3 MST 唯一性

> **真题陷阱**:
> 1. MST **权值之和唯一**,但**结构未必唯一**——当有多条相同权值边可选时,可能构造出不同的 MST;
> 2. 若图中所有边权值**互不相同**,则 MST 唯一;
> 3. Prim 和 Kruskal 在权值相同的边上的选择可能不同,但权值和相同。

## 4.5 最短路

### 4.5.1 BFS 求无权图最短路

从起点 BFS,首次到达终点的层数即最短边数。$O(n + e)$。

### 4.5.2 Dijkstra (非负权)

**贪心**:维护 dist[] (起点到各点当前最短距离),每次选最小 dist 的未确定顶点加入"已确定"集,松弛其邻接边。

```
初始化 dist[s] = 0, dist[其他] = ∞, S = {}
重复 n 次:
   选 dist 最小的 u ∉ S,加入 S
   对 u 的每条邻接边 (u, w, 权 c):
      if dist[u] + c < dist[w]:
         dist[w] = dist[u] + c
         path[w] = u
```

```c
void Dijkstra(MGraph G, int s) {
    int dist[MaxV], path[MaxV];
    bool finalized[MaxV] = {false};
    for (int i = 0; i < G.vexnum; i++) {
        dist[i] = G.edge[s][i];
        path[i] = dist[i] < INF ? s : -1;
    }
    dist[s] = 0; finalized[s] = true;
    for (int i = 1; i < G.vexnum; i++) {          // 选 n-1 次
        int min = INF, u = -1;
        for (int j = 0; j < G.vexnum; j++)
            if (!finalized[j] && dist[j] < min) { min = dist[j]; u = j; }
        if (u == -1) break;
        finalized[u] = true;
        for (int j = 0; j < G.vexnum; j++)
            if (!finalized[j] && dist[u] + G.edge[u][j] < dist[j]) {
                dist[j] = dist[u] + G.edge[u][j];
                path[j] = u;
            }
    }
}
```

- 时间 $O(n^2)$ (无堆优化);$O((n+e) \log n)$ (堆优化);
- **不能处理负权**:贪心假设"已确定点不会再被更新",但负权可破坏该假设 (后续点可能通过负权边让已确定点变短)。

**反例**:s → A (权 1),s → B (权 2),A → B (权 -3)。
- Dijkstra:先选 A (dist=1),再选 B (dist=1+(-3)=-2);
- 但 s 直接到 B 是 2,松弛后 B = -2,正确?再看 s → A 已确定,但若 s → A 走 s → B → A 呢?需要 A 也在 B 后再被更新,但 A 已 finalized → 错。

### 4.5.3 Floyd (任意权,无负环)

**动态规划**:$d^{(k)}[i][j]$ = 从 i 到 j 仅经过中间点 $\{1, \dots, k\}$ 的最短路径。

**状态转移方程**:
$$
d^{(k)}[i][j] = \min\left( d^{(k-1)}[i][j],\ d^{(k-1)}[i][k] + d^{(k-1)}[k][j] \right)
$$

含义:第 k 轮考虑是否经过顶点 k 作为中间点。要么不经过 k (沿用 $d^{(k-1)}$),要么经过 k (拆成 i→k + k→j)。

```c
void Floyd(int d[][MaxV], int n) {
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (d[i][k] + d[k][j] < d[i][j])
                    d[i][j] = d[i][k] + d[k][j];
}
```

- 时间 $O(n^3)$,空间 $O(n^2)$ (可在原矩阵上滚动,省去 k 维);
- 可处理负权 (但不能有负环);
- 可求任意两点最短路;
- 可判断负环:若最终某 d[i][i] < 0,则有负环。

### 4.5.4 三种算法对比

| 算法 | 适用 | 时间 | 负权 | 用途 |
|------|------|------|------|------|
| BFS | 无权图 | $O(n+e)$ | 不适用 | 单源最短边数 |
| Dijkstra | 非负权 | $O(n^2)$ / $O((n+e)\log n)$ | 否 | 单源最短路 |
| Floyd | 任意权 (无负环) | $O(n^3)$ | 是 | 全源最短路 |

## 4.6 拓扑排序

### 4.6.1 应用

仅对**有向无环图 (DAG)** 进行,得到顶点线性序列,使每条边 $\langle u, v \rangle$ 中 u 在 v 前。

### 4.6.2 入度法 (Kahn)

每次选入度为 0 的顶点输出,删除其出边 (邻接点入度 -1)。

```c
bool TopoSort(ALGraph G) {
    int indegree[MaxV] = {0};
    for (int i = 0; i < G.vexnum; i++)
        for (ArcNode *p = G.vertices[i].first; p; p = p->next)
            indegree[p->adjvex]++;
    Queue Q; InitQueue(Q);
    for (int i = 0; i < G.vexnum; i++)
        if (indegree[i] == 0) EnQueue(Q, i);
    int count = 0;
    while (!Empty(Q)) {
        int u; DeQueue(Q, u);
        visit(u); count++;
        for (ArcNode *p = G.vertices[u].first; p; p = p->next)
            if (--indegree[p->adjvex] == 0) EnQueue(Q, p->adjvex);
    }
    return count < G.vexnum;   // true 表示有环
}
```

- 时间 $O(n + e)$;
- 输出顶点数 < n → 图中有环;
- 用栈或队列都可以 (选择不同导致拓扑序不同)。

### 4.6.3 DFS 法

DFS 后,按"完成时间" (退出 DFS 的顺序) 逆序输出。

```c
void DFS_Topo(ALGraph G, int v, int *count) {
    visited[v] = true;
    for (ArcNode *p = G.vertices[v].first; p; p = p->next)
        if (!visited[p->adjvex]) DFS_Topo(G, p->adjvex, count);
    output[++(*count)] = v;  // 退出时记录
}
// 最终 output 逆序即拓扑序
```

- 时间 $O(n + e)$;
- 实际中 Kahn 法更直观。

> **真题陷阱**:
> 1. 拓扑排序**不唯一** (有多个 0 入度点时选择不同);但 DAG 必有拓扑序;
> 2. 若 DAG 中存在唯一 0 入度点和唯一 0 出度点,则拓扑序可能仍不唯一;
> 3. 拓扑排序可判断有向图是否有环 (输出 < n 则有环)。

## 4.7 关键路径 (AOE 网)

### 4.7.1 AOE 网

**AOE (Activity On Edge)**:有向无环图,边表示活动 (有持续时间),顶点表示事件。
- 源点:入度为 0 的顶点 (开始事件);
- 汇点:出度为 0 的顶点 (完成事件);
- AOE 网只有一个源点和一个汇点 (一般约定)。

**对比 AOV**:
- AOV (Activity On Vertex):顶点表活动,边表先后关系,用于拓扑排序;
- AOE (Activity On Edge):边表活动,顶点表事件,用于关键路径。

### 4.7.2 四个时间

#### 4.7.2.1 ve(j) 事件最早发生时间

从源点到 j 的最长路径。

$$
ve(j) = \max_{\langle i, j \rangle} \{ ve(i) + w(i, j) \}, \quad ve(\text{源}) = 0
$$

按**拓扑顺序**正向计算。

#### 4.7.2.2 vl(i) 事件最迟发生时间

不延误总工期的前提下,i 最迟发生时间。

$$
vl(i) = \min_{\langle i, j \rangle} \{ vl(j) - w(i, j) \}, \quad vl(\text{汇}) = ve(\text{汇})
$$

按**拓扑逆序**反向计算。

#### 4.7.2.3 e(k) 活动 k 最早开始时间

活动 k = $\langle i, j \rangle$,则 $e(k) = ve(i)$ (起点事件发生即可开始)。

#### 4.7.2.4 l(k) 活动 k 最迟开始时间

$l(k) = vl(j) - w(i, j)$ (终点事件最迟发生时间减去活动持续时间)。

### 4.7.3 关键活动与关键路径

- **关键活动**:$l(k) - e(k) = 0$ 的活动,即没有余量的活动;
- **关键路径**:从源点到汇点的最长路径,由关键活动组成;
- **关键路径长度** = ve(汇) = 总工期;
- **关键活动余量** $d(k) = l(k) - e(k) = 0$。

### 4.7.4 完整计算示例

```
AOE 网:
       3
   A ------→ C
   |\6       /|
 1 | \     /  | 4
   |  \ /     |
   ↓   X      ↓
   B   ↓ 2    D
   |\ /       |
 2 | X        | 5
   | / \      |
   ↓/   \     ↓
   E --→ F ←-- G
     7     3
```

(具体权值略,示意)

**计算步骤**:
1. 拓扑排序得序列,如 A B E C F D G;
2. 按拓扑序正向算 ve:ve(A)=0, ve(B)=1, ve(E)=3, ve(C)=6, ve(F)=10, ve(D)=10, ve(G)=15;
3. 按拓扑逆序反向算 vl:vl(G)=15, vl(D)=10, vl(F)=15, vl(C)=6, vl(E)=8, vl(B)=6, vl(A)=0;
4. 对每条边 (i,j) 算 e=ve(i), l=vl(j)-w(i,j);
5. 找 l-e=0 的活动,即关键活动。

### 4.7.5 关键路径性质

> **真题陷阱**:
> 1. **关键路径不唯一** (可能有多条);
> 2. **缩短关键活动不一定缩短总工期**——若有多条关键路径,需同时缩短所有关键路径上的活动;
> 3. 只有缩短**所有关键路径共有的**关键活动才能缩短总工期;
> 4. 关键活动延长一定延长总工期 (因它在最长路径上);
> 5. 非关键活动延长不一定延长总工期 (有余量)。

## 4.8 真题陷阱与高频考点

1. **邻接矩阵对称性**:无向图邻接矩阵对称;有向图不一定。
2. **DFS/BFS 复杂度**:邻接表 $O(n+e)$,邻接矩阵 $O(n^2)$。
3. **MST 唯一性**:权值和唯一,结构未必唯一;边权互不相同则 MST 唯一。
4. **Dijkstra 负权**:不能处理;若图有负权,用 Floyd 或 Bellman-Ford (超 408 大纲)。
5. **Floyd 负环**:d[i][i] < 0 表示负环。
6. **拓扑排序判断环**:输出顶点数 < n → 有环。
7. **关键路径多条**:缩短一条未必缩短总工期。
8. **连通图边数**:n 顶点连通图至少 n-1 边;强连通至少 n 边。
9. **强连通图边数**:n 顶点强连通图至少 n 条边 (构成一个环);n 个顶点强连通图至多 $n(n-1)$ 条边。
10. **十字链表 vs 邻接多重表**:前者有向图,后者无向图。
11. **完全图边数**:无向 $n(n-1)/2$,有向 $n(n-1)$。
12. **生成树边数**:n-1 (无论原图多少边)。
13. **DFS 判环 (无向图)**:遇到已访问且非父节点 → 有环。
14. **DFS 判环 (有向图)**:三色标记,遇到灰节点 (在当前递归栈中) → 有环。

## 4.9 典型真题精解

### 2016 选择:邻接矩阵存储复杂度

**题**:n 个顶点 e 条边的无向图用邻接矩阵存储,空间复杂度?

**解**:邻接矩阵固定 n×n,与边数无关。空间 $O(n^2)$。

**答**:$O(n^2)$。

### 2017 选择:Dijkstra 不能处理负权

**题**:为什么 Dijkstra 不能处理负权边?

**解**:Dijkstra 基于**贪心**:每次选当前 dist 最小的未确定顶点 u,标记为"已确定"——假设 u 的 dist 不会再被更新。但负权边可破坏此假设:若 u 已确定后,后续某点通过负权边能让 u 更短,但 u 不会被重新考虑,导致结果错误。

**答**:贪心假设"已确定点不会再被更新",负权边可破坏此假设。

### 2018 算法:DFS 判断连通分量

**题**:用 DFS 求无向图的连通分量数,写出算法思想。

**解**:
```c
int ConnectedComponents(Graph G) {
    int count = 0;
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i]) {
            DFS(G, i);
            count++;
        }
    return count;
}
```

**思想**:从每个未访问顶点调用一次 DFS,每次 DFS 完成后连通分量数 +1。最终 count 即连通分量数。

**复杂度**:邻接表 $O(n+e)$,邻接矩阵 $O(n^2)$。

### 2019 算法:拓扑排序实现

**题**:用入度法实现拓扑排序,并判断图中是否有环。

**解**:见 4.6.2 代码。关键点:
1. 计算各顶点入度;
2. 入度为 0 的顶点入队;
3. 出队一个顶点输出,其邻接点入度 -1,若变 0 则入队;
4. 重复直到队空;
5. 输出顶点数 < n → 有环。

**复杂度**:$O(n+e)$。

### 2020 选择:关键路径性质

**题**:关于 AOE 网关键路径,下列哪个正确?
A. 关键路径唯一
B. 缩短任一关键活动都能缩短总工期
C. 关键活动延长一定延长总工期
D. 非关键活动延长一定不延误总工期

**解**:
- A 错:关键路径可能有多条;
- B 错:多条关键路径时,缩短一条不一定缩短总工期;
- C 对:关键活动在最长路径上,延长一定延长总工期;
- D 错:非关键活动延长超过余量也会延误。

**答**:C。

### 2022 选择:Prim vs Kruskal 适用

**题**:n 顶点 e 条边的图,n 较小、e 接近 $n^2$ (稠密图),求 MST 用哪种算法更优?

**解**:
- Prim:$O(n^2)$,与 e 无关,适合稠密图;
- Kruskal:$O(e \log e)$,当 e 接近 $n^2$ 时退化为 $O(n^2 \log n)$,劣于 Prim。

**答**:Prim,$O(n^2)$。

### 2024 算法:Dijkstra 手动推演

**题**:给定有向图,从 v0 出发,用 Dijkstra 算法逐步推演 dist 数组变化。

**解**:模拟每轮:
1. 初始 dist[v0]=0,其他 INF;
2. 第 1 轮:选 v0 加入 S,松弛邻接点;
3. 第 2 轮:选当前 dist 最小且未确定的 u,松弛其邻接点;
4. 重复 n 轮,所有点确定。

每轮列出 dist 数组即可。具体数值依图而定,关键是**每轮选最小且未确定**,松弛时更新 `dist[w] = min(dist[w], dist[u] + c)`。

## 4.11 易混淆点深辨析

| 易混点 | 辨析 |
|--------|------|
| 连通图 vs 强连通图 | 前者无向,后者有向 |
| 极大连通子图 vs 极小连通子图 | 前者是连通分量,后者是生成树 |
| Prim vs Kruskal | 前者 $O(n^2)$ 稠密;后者 $O(e \log e)$ 稀疏 |
| Dijkstra vs Floyd | 前者单源非负权;后者全源任意权 |
| AOV vs AOE | AOV 顶点表活动 (拓扑排序);AOE 边表活动 (关键路径) |
| ve vs vl | ve 最早 (拓扑序正算),vl 最迟 (拓扑序逆算) |
| 十字链表 vs 邻接多重表 | 前者有向图专用,后者无向图专用 |
| 关键活动 vs 关键路径 | 关键活动 $l-e=0$;关键路径是关键活动组成的最长路径 |
| MST vs 最短路 | MST 连通所有点且总权最小;最短路是单源到其他点的最短 |
| 关键路径 vs 最长路径 | AOE 网中关键路径 = 源点到汇点的最长路径 |

## 4.12 延伸知识

### 4.12.1 Bellman-Ford 算法

可处理负权 (单源最短路)。每轮松弛所有边,共 n-1 轮;若第 n 轮仍能松弛,则有负环。

- 时间 $O(n \cdot e)$;
- 408 大纲不要求,但可作为 Dijkstra 的对比。

### 4.12.2 SPFA

Bellman-Ford 的队列优化,平均 $O(n+e)$,最坏 $O(n \cdot e)$。

### 4.12.3 二分图匹配 (匈牙利算法)

判断二分图 + 求最大匹配。408 一般不考,了解即可。

### 4.12.4 Tarjan 算法

求强连通分量、割点、桥、双连通分量。线性时间 $O(n+e)$。

## 4.14 本章习题

1. 6 个顶点的无向图,最多多少条边?最少多少条边保证连通?
   - **答**:最多 $6 \times 5 / 2 = 15$ 条;最少 5 条 (生成树)。

2. 6 个顶点的有向图,最多多少条弧?最少多少条弧保证强连通?
   - **答**:最多 $6 \times 5 = 30$ 条;最少 6 条 (构成一个环)。

3. 用 Dijkstra 求下图中 v0 到其他点的最短路:
   ```
   v0 --1-- v1 --2-- v2
    \       |       /
     4      3      5
      \     |     /
       v3 --1-- v4
   ```
   - **答**:依次选 v0 (dist 0), v1 (1), v3 (3 via v0), v2 (3 via v1), v4 (4 via v3)。具体依图的连接和权值。

4. 何时 Dijkstra 与 Floyd 都不能给出正确结果?
   - **答**:存在负环时。Dijkstra 还不能处理任何负权边。

5. AOE 网中,某活动余量 $d = l - e = 3$,含义?
   - **答**:该活动的开始时间最多可推迟 3 个时间单位而不延误总工期,是非关键活动。
