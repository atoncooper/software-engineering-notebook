## 7.1 十大核心模板

### 7.1.1 链表逆置 (头插法)

```c
void Reverse(LinkList &L) {
    LNode *p = L->next, *q;
    L->next = NULL;
    while (p) {
        q = p->next;
        p->next = L->next;
        L->next = p;
        p = q;
    }
}
// O(n), O(1)
```

### 7.1.2 链表找中点 (快慢指针)

```c
LNode *FindMid(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
// O(n), O(1)
```

### 7.1.3 链表判环 (Floyd)

```c
bool HasCycle(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
// O(n), O(1)
```

### 7.1.4 两个有序链表合并

```c
LinkList Merge(LinkList A, LinkList B) {
    LinkList C = (LinkList)malloc(sizeof(LNode));
    LNode *r = C, *p = A->next, *q = B->next;
    while (p && q) {
        if (p->data <= q->data) { r->next = p; p = p->next; }
        else                     { r->next = q; q = q->next; }
        r = r->next;
    }
    r->next = p ? p : q;
    return C;
}
// O(n+m), O(1)
```

### 7.1.5 快排 Partition

```c
int Partition(int A[], int low, int high) {
    int pivot = A[low];
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];
    }
    A[low] = pivot;
    return low;
}
// O(n), O(1)
```

### 7.1.6 二叉树先序遍历 (递归)

```c
void PreOrder(BiTree T, void (*visit)(BiTree)) {
    if (T) {
        visit(T);
        PreOrder(T->lchild, visit);
        PreOrder(T->rchild, visit);
    }
}
// O(n), O(h)
```

### 7.1.7 二叉树层序 (BFS)

```c
void LevelOrder(BiTree T) {
    if (!T) return;
    Queue Q; InitQueue(Q); EnQueue(Q, T);
    while (!Empty(Q)) {
        BiTree p; DeQueue(Q, p);
        visit(p);
        if (p->lchild) EnQueue(Q, p->lchild);
        if (p->rchild) EnQueue(Q, p->rchild);
    }
}
// O(n), O(w)
```

### 7.1.8 由先序+中序重建二叉树

```c
BiTree Build(int pre[], int in[], int preL, int preR, int inL, int inR) {
    if (preL > preR) return NULL;
    BiTree root = (BiTree)malloc(sizeof(BiTNode));
    root->data = pre[preL];
    int k = inL;
    while (in[k] != root->data) k++;
    int numLeft = k - inL;
    root->lchild = Build(pre, in, preL+1, preL+numLeft, inL, k-1);
    root->rchild = Build(pre, in, preL+numLeft+1, preR, k+1, inR);
    return root;
}
// O(n), O(n)
```

### 7.1.9 图 BFS

```c
void BFS(Graph G, int v) {
    bool visited[MAX] = {false};
    Queue Q; InitQueue(Q);
    visit(v); visited[v] = true; EnQueue(Q, v);
    while (!Empty(Q)) {
        int u; DeQueue(Q, u);
        for (int w = FirstNeighbor(G, u); w >= 0; w = NextNeighbor(G, u, w))
            if (!visited[w]) {
                visit(w); visited[w] = true; EnQueue(Q, w);
            }
    }
}
// O(n+e), O(n)
```

### 7.1.10 Dijkstra

```c
void Dijkstra(Graph G, int s, int dist[]) {
    bool S[MAX] = {false};
    for (int i = 0; i < G.vexnum; i++) dist[i] = G.edge[s][i];
    S[s] = true; dist[s] = 0;
    for (int i = 1; i < G.vexnum; i++) {
        int u = -1, min = INF;
        for (int j = 0; j < G.vexnum; j++)
            if (!S[j] && dist[j] < min) { u = j; min = dist[j]; }
        if (u == -1) break;
        S[u] = true;
        for (int j = 0; j < G.vexnum; j++)
            if (!S[j] && dist[u] + G.edge[u][j] < dist[j])
                dist[j] = dist[u] + G.edge[u][j];
    }
}
// O(n²), O(n)
```

## 7.2 真题分类

### 7.2.1 链表题 (30%)

**典型题**:
- 链表分区 (绝对值 ≤ k 与 > k 分两段,保持相对顺序)
- 链表去重 (保留首次出现)
- 删除倒数第 k 个节点
- 两个链表第一个公共节点
- 链表加法 (链表表示的数相加)

**通用思路**:
- 双指针 (快慢、首尾、前后)
- 头插法 (逆置、分区)
- 哈希集合 (去重、判公共)

### 7.2.2 树题 (25%)

**典型题**:
- 由遍历序列重建
- 求二叉树高度/宽度
- 判断是否 BST / 平衡
- 找所有路径满足某和
- 二叉树的最近公共祖先

**通用思路**:
- 递归 (后序回溯最常用)
- BFS 求宽度
- 中序遍历 + 验证单调

### 7.2.3 图题 (15%)

**典型题**:
- DFS/BFS 应用
- 连通分量
- 拓扑排序
- Dijkstra 手动推演

**通用思路**:
- visited 数组
- 队列 BFS / 栈 DFS
- 入度数组 (拓扑)

### 7.2.4 查找/排序应用 (30%)

**典型题**:
- 折半查找应用
- 双指针 (有序数组两数之和)
- 堆应用 (top-k)
- 散列表构造

**通用思路**:
- 折半框架
- 堆调整

## 7.3 答题模板 (完整示例)

**题目**:给定带头结点的单链表 L,把所有绝对值 ≤ k 的节点移到前面,保持相对顺序。

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

void Partition(LinkList L, int k) {
    // 算法思想:遍历一次,把 ≤ k 的节点摘下来用尾插法挂到新链表 A,
    // 其余挂到新链表 B,最后 A 末尾接 B 头。原链表头结点复用为 A。
    // 时间 O(n),空间 O(1)
    
    if (!L || !L->next) return;
    
    LinkList B = (LinkList)malloc(sizeof(LNode));
    B->next = NULL;
    LNode *rb = B, *ra = L, *p = L->next;
    L->next = NULL;
    
    while (p) {
        LNode *q = p->next;
        p->next = NULL;
        if (abs(p->data) <= k) {
            ra->next = p; ra = p;
        } else {
            rb->next = p; rb = p;
        }
        p = q;
    }
    ra->next = B->next;
    free(B);
}
```

## 7.4 高频陷阱

1. **指针操作顺序**:头插法 `s->next = L->next; L->next = s;` 不能反。
2. **释放后访问**:`free(p)` 后 `p` 是野指针,需先保存 `q = p->next`。
3. **空指针解引用**:遍历前判 `if (!L)`。
4. **越界**:`i < n` 不是 `i <= n`;递归 `preL > preR` 终止。
5. **递归深度**:数据规模大时栈溢出,可改用栈模拟。
6. **复杂度忽略查找**:链表插入删除"O(1)"仅指改指针,含查找是 O(n)。
7. **返回类型**:题目要求返回 `int` 别返回 `LNode*`。
8. **结构体字段名**:严格按题目给的,不能自己改。
