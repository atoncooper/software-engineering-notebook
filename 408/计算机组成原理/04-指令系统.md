## 4.1 指令格式

### 4.1.1 形式化定义

指令是 CPU 能直接识别和执行的机器命令,一台计算机所有指令的集合称为**指令系统(Instruction Set)**。

**指令格式**形式化定义:

```
Instruction = (OP, A_1, A_2, ..., A_n)
```

- **OP (Opcode)**:操作码字段,指明操作类型(ADD / LOAD / JMP 等)
- **A_i (Address)**:地址码字段,可以是操作数地址、寄存器号、或立即数

```
┌─────────┬─────────┬─────────┬─────────┐
│   OP    │   A1    │   A2    │   A3    │
└─────────┴─────────┴─────────┴─────────┘
   操作码      地址码(0~多个)
```

### 4.1.2 按地址数分类

| 类型 | 格式 | 指令长度 | 执行访存次数 | 应用 |
|------|------|----------|--------------|------|
| 零地址 | OP | 短 | 0 | NOP、HALT、堆栈操作(隐含栈顶) |
| 一地址 | OP A | 中 | 2(取指 + 读 A) | INC A、隐含 ACC:AC ← AC OP A |
| 二地址 | OP A1 A2 | 长 | 3(取指 + 读 A1 + 读 A2) | A1 ← A1 OP A2 |
| 三地址 | OP A1 A2 A3 | 最长 | 4(取指 + 读 A1 + 读 A2 + 写 A3) | A3 ← A1 OP A2 |

> **访存次数推导**:取指令 1 次必算;每个地址码若需读操作数 +1,若需写结果 +1。
> - 一地址隐含 ACC:`AC ← AC OP M[A]`,访存 2 次(取指 + 读 A);若写回 A 则 3 次
> - 二地址:`M[A1] ← M[A1] OP M[A2]`,访存 3 次(取指 + 读 A1 + 读 A2;写回 A1 算 4 次)

### 4.1.3 操作码格式

**固定长度操作码**:
- 所有指令操作码长度相同
- 优点:译码简单,速度快
- 缺点:操作数少时浪费空间
- 例:8 位操作码 → 最多 256 条指令

**可变长度操作码(扩展操作码)**:
- 操作码长度随地址数变化
- 优点:节省空间,指令集可扩展
- 缺点:译码复杂
- 见 4.4 节

### 4.1.4 指令长度设计

- **定长指令**:所有指令长度相同(RISC,MIPS)
- **变长指令**:指令长度可变(CISC,x86 1~15 字节)

**地址码位数与寻址空间关系**:
- 地址码 n 位 → 直接寻址空间 2^n
- 若主存 4GB,需地址码 32 位

## 4.2 寻址方式

**寻址方式(Addressing Mode)**:确定本指令中**操作数有效地址**的方法。

**关键概念区分**:
- **形式地址 A**:指令中给出的地址字段
- **有效地址 EA**:操作数实际所在内存地址

### 4.2.1 八大寻址方式完整对比

| 方式 | 有效地址 EA | 访存次数 | 特点 |
|------|-------------|----------|------|
| 立即寻址 | 无(操作数 = A) | 0 | 最快,数值范围受限 |
| 直接寻址 | EA = A | 1 | 简单,寻址范围受 A 位数限制 |
| 间接寻址 | EA = (A) | 2+ | 灵活,扩大寻址范围 |
| 寄存器寻址 | EA = R(操作数在 R) | 0 | 快,寄存器数量有限 |
| 寄存器间接寻址 | EA = (R) | 1 | 快 + 寻址范围大 |
| 基址寻址 | EA = (BR) + A | 1 | 程序浮动 |
| 变址寻址 | EA = (IX) + A | 1 | 数组循环 |
| 相对寻址 | EA = (PC) + A | 1 | 转移指令 |

> **访存次数计算**:取指令的 1 次访存通常**不包含**在"寻址访存次数"中,但题目若问"总访存次数"需加上。

### 4.2.2 立即寻址 (Immediate Addressing)

```
┌──────┬───────────┐
│  OP  │ 立即数 A   │   操作数 = A 本身
└──────┴───────────┘
```

- 执行:`Data ← A`
- 访存:0 次(操作数在指令中,取指令时已取到)
- 优点:快,无需访存
- 缺点:数值范围受 A 位数限制(如 8 位 → -128~127)
- 应用:`MOV R1, #5`、`ADD R1, #10`

### 4.2.3 直接寻址 (Direct Addressing)

```
┌──────┬───────────┐
│  OP  │   A        │   EA = A
└──────┴───────────┘
        ↓
        内存[A] → 操作数
```

- 执行:`Data ← M[A]`
- 访存:1 次
- 优点:简单
- 缺点:寻址范围受 A 位数限制(A=16 位 → 64KB)
- 应用:`MOV R1, [0x1000]`

### 4.2.4 间接寻址 (Indirect Addressing)

```
┌──────┬───────────┐
│  OP  │   A        │   EA = (A) = M[A]
└──────┴───────────┘
        ↓
        内存[A] → EA
                 ↓
                 内存[EA] → 操作数
```

- 执行:`EA ← M[A]`,`Data ← M[EA]`
- 访存:**2 次**(读 A 处取 EA,再读 EA 处取操作数)
- 多次间接:EA 单元最高位为 1 表示继续间接
- 优点:扩大寻址范围(若 A=16,但 M[A] 是 32 位,可寻址 4GB)
- 缺点:慢(多次访存)
- 应用:早期机器指针访问

### 4.2.5 寄存器寻址 (Register Addressing)

```
┌──────┬───────────┐
│  OP  │  R_id      │   操作数 = R[R_id]
└──────┴───────────┘
```

- 执行:`Data ← R[R_id]`
- 访存:0 次
- 优点:快,不访存
- 缺点:寄存器数量有限(如 32 个寄存器需 5 位编码)
- 应用:`MOV R1, R2`

### 4.2.6 寄存器间接寻址 (Register Indirect)

```
┌──────┬───────────┐
│  OP  │  R_id      │   EA = R[R_id]
└──────┴───────────┘
        ↓
        内存[R[R_id]] → 操作数
```

- 执行:`EA ← R[R_id]`,`Data ← M[EA]`
- 访存:1 次
- 优点:快(寄存器读 EA)+ 寻址范围大(寄存器 32 位可寻址 4GB)
- 应用:`MOV R1, [R2]` —— 循环中常用(指针遍历)

### 4.2.7 偏移寻址(基址 / 变址 / 相对)

**共同形式**:

$$EA = (R) + A$$

其中 R 是某个寄存器,A 是指令中的形式地址(偏移量)。

详见 4.3 节。

## 4.3 偏移寻址深度对比

### 4.3.1 三种偏移寻址对比表

| 类型 | 寄存器 | EA 公式 | 谁变谁不变 | 主要用途 |
|------|--------|---------|------------|----------|
| 基址寻址 | BR (基址寄存器) | EA = (BR) + A | BR 变(由 OS 设),A 不变 | 程序重定位、浮动 |
| 变址寻址 | IX (变址寄存器) | EA = (IX) + A | IX 变(循环递增),A 不变 | 数组遍历、循环 |
| 相对寻址 | PC (程序计数器) | EA = (PC) + A | PC 变(自动 +1),A 不变 | 转移指令、位置无关代码 |

### 4.3.2 基址寻址(Base Addressing)详解

```
┌──────┬───────────┐
│  OP  │  偏移 A    │   EA = (BR) + A
└──────┴───────────┘
                    BR 由操作系统在程序装入时设置
```

**特点**:
- BR 内容**由 OS 设定**(程序装入时),程序运行中**不变**
- 偏移 A **可变**(不同指令不同 A)
- 适合**程序重定位**:程序在内存中浮动只需改 BR,无需改指令

**例**:程序装入地址 0x1000,BR = 0x1000,指令 `LOAD R1, [0x50]` 实际访问 0x1050。
若程序浮动到 0x2000,只需 BR = 0x2000,指令不变。

### 4.3.3 变址寻址(Index Addressing)详解

```
┌──────┬───────────┐
│  OP  │  起始 A    │   EA = (IX) + A
└──────┴───────────┘
                    IX 在循环中递增:IX ← IX + 1
```

**特点**:
- IX 内容**程序员可控**(循环中递增)
- 起始地址 A **不变**
- 适合**数组遍历**:A 是数组首地址,IX 是下标

**例**:数组首地址 0x1000,遍历数组:
```
LOAD IX, #0          ; IX = 0
LOOP: LOAD R1, [IX + 0x1000]   ; EA = (IX) + 0x1000
      INC IX                   ; IX++
      ...
```

### 4.3.4 相对寻址(Relative Addressing)详解

```
┌──────┬───────────┐
│  OP  │  偏移 A    │   EA = (PC) + A
└──────┴───────────┘
                    PC 是当前指令地址(取指后 PC 已 +1)
```

**特点**:
- PC 内容**自动变化**(取指后自动 +1)
- 偏移 A **不变**(通常用补码,可正可负)
- 适合**转移指令**:实现位置无关代码

**关键细节**:相对寻址中 PC 的值是**取当前指令后 PC 的值**(已指向下一条指令)。

**例**:
```
地址 1000: JMP +5    ; 转移目标 = 1000 + 指令长度 + 5
地址 1002: ...        ; 假设指令长度 2 字节,PC = 1002
                     ; 转移目标 = 1002 + 5 = 1007
```

> **真题陷阱**:相对寻址 PC 的值要分清"取指前"还是"取指后"。多数教材用"取指后"的 PC。

### 4.3.5 三种偏移寻址本质区别

```
              谁是"基准"  谁是"变化量"
基址寻址:        A          BR        → BR 由 OS 设,A 变 → 程序浮动
变址寻址:        A          IX        → A 不变,IX 变 → 数组遍历
相对寻址:        A          PC        → A 不变,PC 自动变 → 转移
```

**口诀**:
- **基址面向 OS**(BR 由 OS 管,程序浮动)
- **变址面向程序员**(IX 由程序员管,数组循环)
- **相对面向编译器**(PC 自动变,位置无关)

## 4.4 扩展操作码

### 4.4.1 设计思想

扩展操作码:操作码长度**可变**,通过**保留前缀**实现不同长度操作码共存。

**核心原则(前缀编码)**:短操作码不能是长操作码的前缀,否则译码歧义。

### 4.4.2 完整设计示例

**问题**:16 位指令,4 位操作码字段,要求:
- 三地址指令 15 条
- 二地址指令 15 条
- 一地址指令 15 条
- 零地址指令 16 条

**设计**:

```
┌────────┬────────┬────────┬────────┐
│  4位   │  4位   │  4位   │  4位   │
└────────┴────────┴────────┴────────┘

三地址: OP=0000~1110  (15 条)   1111 保留作扩展
        ┌────────┬────────┬────────┬────────┐
        │ 0xxx   │  A1    │  A2    │  A3    │
        └────────┴────────┴────────┴────────┘

二地址: OP=1111 0000~1110  (15 条)   1111 1111 保留
        ┌────────┬────────┬────────┬────────┐
        │ 1111   │ 0xxx   │  A2    │  A3    │
        └────────┴────────┴────────┴────────┘

一地址: OP=1111 1111 0000~1110  (15 条)   1111 1111 1111 保留
        ┌────────┬────────┬────────┬────────┐
        │ 1111   │ 1111   │ 0xxx   │  A3    │
        └────────┴────────┴────────┴────────┘

零地址: OP=1111 1111 1111 0000~1111  (16 条)
        ┌────────┬────────┬────────┬────────┐
        │ 1111   │ 1111   │ 1111   │  xxxx  │
        └────────┴────────┴────────┴────────┘
```

**设计步骤**:
1. 三地址:4 位 OP 共 16 种编码,用 0000~1110 (15 条),1111 保留
2. 二地址:1111 + 4 位 = 8 位 OP,16 种,用 1111 0000~1111 1110 (15 条),1111 1111 保留
3. 一地址:1111 1111 + 4 位 = 12 位 OP,16 种,用 1111 1111 0000~1110 (15 条),1111 1111 1111 保留
4. 零地址:1111 1111 1111 + 4 位 = 16 位 OP,16 种全用

### 4.4.3 计数公式

设操作码长度可扩展,每扩展一次增加 m 位:

- 三地址条数:$N_3 \le 2^m - 1$(保留 1 个扩展标志)
- 二地址条数:$N_2 \le (2^m - 1) \times 2^m$
- 一地址条数:$N_1 \le (2^m - 1)^2 \times 2^m$
- 零地址条数:$N_0 \le (2^m - 1)^3 \times 2^m$

> **真题陷阱**:扩展操作码每段最多保留 1 个编码作为扩展标志,所以是 $2^m - 1$ 而不是 $2^m$。

### 4.4.4 前缀编码(唯一可译码)

**前缀编码原则**:任何一个操作码不能是另一个操作码的前缀。

**反例**(错误设计):
- 三地址:0000~1111 (16 条,用满)
- 二地址:无扩展空间 ❌

**正例**(正确设计):
- 三地址:0000~1110 (15 条),1111 保留
- 二地址:1111 0000~1111 1110 (15 条)
- 译码:读到 1111 就知道是二地址以上,继续读下 4 位

### 4.4.5 扩展操作码真题

**【2017 真题改编】** 16 位指令,4 位 OP,设计扩展操作码:
- 三地址 15 条,二地址 30 条,一地址 60 条,零地址 16 条

**设计**:
- 三地址:0000~1110 (15 条),1111 保留
- 二地址:1111 0000~1111 1111 (16 条) → 但需 30 条,扩展 5 位 OP → 1111 + 5 位 = 9 位 OP
  - 实际:1111 00000~1111 11101 (30 条,共 32 种,留 2 个),1111 11110 / 1111 11111 保留
- 一地址:1111 11110 + 4 位 = 12 位 OP,16 种,不够 60 条
  - 需重新设计:1111 11110 + 6 位 = 14 位 OP,64 种,用 60 条留 4 个
- 零地址:剩余 2 位 + 全 4 位 = 16 种

(题目灵活,核心是**前缀编码**和**保留扩展标志**)

## 4.5 CISC vs RISC

### 4.5.1 完整对比表

| 对比项 | CISC (复杂指令集) | RISC (精简指令集) |
|--------|-------------------|-------------------|
| 指令数目 | 多 (100~1000+) | 少 (~100) |
| 指令长度 | 可变 (1~15 字节) | 固定 (通常 4 字节) |
| 指令格式 | 多样 | 少且规整 |
| 寻址方式 | 多 (10+) | 少 (≤5) |
| 通用寄存器 | 少 (8~16) | 多 (32+) |
| 执行时间 | 不定(多周期) | 多数 1 周期 |
| 访存指令 | 任意指令可访存 | 只有 LOAD/STORE |
| 控制方式 | 微程序 | 硬布线 |
| 流水线 | 难(变长) | 易(定长) |
| 编译 | 简单(指令丰富) | 复杂(组合简单指令) |
| 优化 | 复杂指令硬件实现 | 寄存器优化、流水线 |
| 代表 | x86、VAX | ARM、MIPS、RISC-V |

### 4.5.2 RISC 五大设计原则

1. **简单指令**:只包含使用频率高的简单指令
2. **固定长度**:指令长度固定,易译码、易流水
3. **Load/Store 结构**:只有 LOAD/STORE 访存,其他操作在寄存器间
4. **大寄存器堆**:32+ 通用寄存器,减少访存
5. **硬布线控制**:不用微程序,速度快

### 4.5.3 为什么 RISC 流水线友好?

```
CISC 变长指令流水线问题:
┌──────┬────────────┬───────────┬─┬─────┐
│ 1 字节│  3 字节    │  2 字节   │1│ ... │  ← 长度不一,译码困难
└──────┴────────────┴───────────┴─┴─────┘

RISC 定长指令流水线:
┌─────────┬─────────┬─────────┬─────────┐
│ 4 字节  │ 4 字节  │ 4 字节  │ 4 字节  │  ← 长度固定,流水整齐
└─────────┴─────────┴─────────┴─────────┘
```

- 定长 → 取指阶段固定取 4 字节
- 单周期 → 各阶段时间均衡,流水线无气泡
- Load/Store → 数据通路统一,访存阶段只在 LOAD/STORE 出现

### 4.5.4 Load/Store 结构的意义

```
CISC:                    RISC:
ADD [A], R1              LOAD R2, [A]      ; 只 LOAD 访存
                         ADD R2, R2, R1
                         STORE [A], R2     ; 只 STORE 访存
```

- **优点**:其他指令不访存 → 流水线数据通路统一 → 流水线优化简单
- **缺点**:指令数变多 → 代码体积可能增大(但寄存器优化后通常影响小)

### 4.5.5 CISC vs RISC 本质

```
CISC:复杂指令 → 硬件实现复杂功能 → 编译器简单
RISC:简单指令 → 编译器组合简单指令 → 硬件简单、流水线快

本质:软件/硬件分工不同
CISC 把复杂度交给硬件
RISC 把复杂度交给编译器
```

## 4.6 指令系统实例

### 4.6.1 MIPS 指令系统(RISC 典型)

#### 4.6.1.1 基本特征

| 特征 | 取值 |
|------|------|
| 指令长度 | 32 位定长 |
| 指令格式 | 3 种 (R / I / J) |
| 寻址方式 | 5 种 (立即/寄存器/基址/相对/伪直接) |
| 通用寄存器 | 32 个 ($0~$31,$0 恒为 0) |
| 访存指令 | 仅 LW / SW |
| 数据对齐 | 字地址 4 字节对齐 |

#### 4.6.1.2 三种指令格式

```
R 型 (寄存器运算):
 31    26 25   21 20   16 15   11 10     6 5      0
┌────────┬───────┬───────┬───────┬────────┬────────┐
│  op    │  rs   │  rt   │  rd   │ shamt  │ funct  │
│ 6 位   │ 5 位  │ 5 位  │ 5 位  │ 5 位   │ 6 位   │
└────────┴───────┴───────┴───────┴────────┴────────┘
  操作码   源1    源2    目的    移位量   功能码
```

```
I 型 (立即数 / 访存 / 条件转移):
 31    26 25   21 20   16 15                0
┌────────┬───────┬───────┬────────────────────┐
│  op    │  rs   │  rt   │      imm           │
│ 6 位   │ 5 位  │ 5 位  │     16 位          │
└────────┴───────┴───────┴────────────────────┘
  操作码   源     目的    立即数/偏移/地址
```

```
J 型 (无条件跳转):
 31    26 25                0
┌────────┬────────────────────┐
│  op    │    address         │
│ 6 位   │      26 位         │
└────────┴────────────────────┘
  操作码   伪直接地址(左移2位+PC高4位)
```

#### 4.6.1.3 寄存器约定

| 寄存器 | 编号 | 用途 | 调用约定 |
|--------|------|------|----------|
| $0 | 0 | 恒为 0 | — |
| $at | 1 | 汇编临时 | 保留 |
| $v0-$v1 | 2-3 | 返回值 | 调用者保存 |
| $a0-$a3 | 4-7 | 参数 | 调用者保存 |
| $t0-$t7 | 8-15 | 临时 | 调用者保存 |
| $s0-$s7 | 16-23 | 保存 | 被调用者保存 |
| $t8-$t9 | 24-25 | 临时 | 调用者保存 |
| $gp | 28 | 全局指针 | 保留 |
| $sp | 29 | 栈指针 | 被调用者保存 |
| $fp | 30 | 帧指针 | 被调用者保存 |
| $ra | 31 | 返回地址 | 调用者保存 |

#### 4.6.1.4 寻址方式与有效地址

| 寻址方式 | 有效地址 | 例 |
|----------|----------|----|
| 立即数 | — (操作数在指令中) | `addi $t0,$t1,5` |
| 寄存器 | R[rs] / R[rt] | `add $t0,$t1,$t2` |
| 基址/偏移 | R[rs] + imm | `lw $t0,8($sp)` |
| PC 相对 | PC + 4 + (imm << 2) | `beq $t0,$t1,L1` |
| 伪直接 | (PC+4)[31:28] \| (addr << 2) | `j L1` |

#### 4.6.1.5 典型指令示例

```
add  $1,$2,$3      # R[1] = R[2] + R[3]        (R 型)
addi $1,$2,100     # R[1] = R[2] + 100         (I 型,立即数符号扩展)
lw   $1,8($2)      # R[1] = M[R[2]+8]          (I 型,访存)
sw   $1,8($2)      # M[R[2]+8] = R[1]          (I 型,访存)
beq  $1,$2,L1      # if R[1]==R[2] goto L1     (I 型,条件转移)
j    L1            # goto L1                   (J 型,无条件跳转)
jal  L1            # $ra = PC+4; goto L1       (J 型,函数调用)
jr   $ra           # PC = $ra                  (R 型,函数返回)
sll  $1,$2,4       # R[1] = R[2] << 4          (R 型,移位)
```

### 4.6.2 x86 指令系统(CISC 典型)

#### 4.6.2.1 复杂指令格式(变长)

```
┌──────┬────────┬──────┬──────┬──────┬────────┬────────┐
│前缀  │操作码  │ModR/M│ SIB  │偏移  │立即数  │  长度  │
│0~4B  │1~3B    │ 0/1B │ 0/1B │0~4B  │0~4B    │ 1~15B  │
└──────┴────────┴──────┴──────┴──────┴────────┴────────┘
```

| 字段 | 作用 |
|------|------|
| 前缀 | 修饰操作数大小、地址大小、段覆盖、LOCK、REP |
| 操作码 | 1~3 字节,指定操作 |
| ModR/M | 指定寻址方式和寄存器(mod + reg + r/m) |
| SIB | Scale-Index-Base,用于复杂寻址(如 `[base + index*scale]`) |
| 偏移 | 1/2/4 字节地址偏移 |
| 立即数 | 1/2/4 字节立即数 |

#### 4.6.2.2 寄存器与寻址

- **8 个通用寄存器**(32 位):EAX/EBX/ECX/EDX/ESI/EDI/EBP/ESP
- **64 位扩展**:RAX/RBX/...(前缀 R)
- **任意指令可访存**:`ADD EAX, [EBX + ECX*4 + 0x100]`
- **寻址方式丰富**:立即、寄存器、直接、寄存器间接、基址变址、比例变址

#### 4.6.2.3 典型指令示例

```asm
MOV EAX, [EBX]              ; 寄存器间接
MOV EAX, [EBX + 0x10]       ; 基址 + 偏移
MOV EAX, [EBX + ECX*4]      ; 基址 + 比例变址
MOV EAX, [EBX + ECX*4 + 0x100]  ; 完整寻址
ADD EAX, EBX                ; 寄存器加
PUSH EAX                    ; 入栈(隐含操作栈)
IMUL EAX, [EBX], 4          ; 乘法(三操作数)
REP MOVSD                   ; 重复串操作(隐含 ECX 计数)
```

#### 4.6.2.4 x86 内部的 RISC 化

现代 x86 (P6 后)前端有**解码器**把 CISC 指令拆为**微操作 μop**(类 RISC):

```
x86 指令:  ADD EAX, [EBX+8]
   ↓ 解码器
μop1: LOAD tmp, [EBX+8]     ; 访存
μop2: ADD  EAX, EAX, tmp    ; 运算
```

- 复杂指令拆为多条 μop
- μop 进入 RISC 内核流水线
- 优点:保留 x86 二进制兼容 + 获得 RISC 流水线性能

### 4.6.3 RISC-V 指令系统(现代 RISC)

| 特征 | 取值 |
|------|------|
| 指令长度 | 32 位定长(可扩展 16 位压缩 / 64+ 位长指令) |
| 指令格式 | 4 种 (R/I/S/U/B/J) |
| 模块化 | RV32I(基础) + M(乘除) + A(原子) + F/D(浮点) + C(压缩) + V(向量) |
| 寄存器 | 32 个 (x0 恒为 0) |
| 访存 | 仅 LW / SW(Load/Store 结构) |

**RV32I 基础整数指令集**仅 47 条指令,极简设计。

### 4.6.4 三种 ISA 对比

| 维度 | MIPS | x86 | RISC-V |
|------|------|-----|--------|
| 类型 | RISC | CISC | RISC |
| 指令长度 | 32 位定长 | 1~15 字节变长 | 32 位(可压缩 16 位) |
| 指令数 | ~100 | ~1000+ | 47(RV32I)+模块 |
| 寻址方式 | 5 种 | 10+ 种 | 5 种 |
| 通用寄存器 | 32 | 16(64 位) | 32 |
| 访存指令 | LW/SW | 任意 | LW/SW |
| 控制方式 | 硬布线 | 微程序+μop | 硬布线 |
| 模块化 | 否 | 否 | 是 |
| 应用 | 嵌入式、路由器 | PC、服务器 | IoT、AI、自定义加速器 |
| 授权模式 | 商业授权 | 闭源 | 开源 |

> **真题陷阱**:
> - **MIPS 只有 LW/SW 访存**,其他指令纯寄存器运算
> - **MIPS $0 恒为 0**,写入无效
> - **x86 变长指令**对流水线不友好,需解码为 μop
> - **RISC-V 模块化设计**是最大特点,基础指令集极简

## 4.7 真题精解

### 【2016 选择】基址寻址与变址寻址的区别

**题目**:下列关于基址寻址和变址寻址的描述,正确的是?

A. 基址寄存器内容由程序员控制,变址寄存器内容由 OS 控制
B. 基址寄存器内容由 OS 控制,变址寄存器内容由程序员控制
C. 两者都由程序员控制
D. 两者都由 OS 控制

**答案**:**B**

**解析**:
- 基址寻址:BR 由 OS 在程序装入时设置,程序运行中**不变**,用于程序浮动
- 变址寻址:IX 由程序员控制(循环中递增),用于数组遍历

### 【2018 选择】间接寻址访存次数

**题目**:某指令采用间接寻址,指令中地址码 A 给出操作数有效地址的地址,则该指令执行时访存次数为?

A. 1 次  B. 2 次  C. 3 次  D. 4 次

**答案**:**B**(2 次)

**解析**:
- 第 1 次访存:读 M[A] 得到有效地址 EA
- 第 2 次访存:读 M[EA] 得到操作数
- (取指令的访存不算在"寻址访存次数"内)

### 【2020 选择】相对寻址

**题目**:相对寻址中,转移目标地址 = ?

A. PC + 偏移量  B. PC + 指令长度 + 偏移量
C. 指令地址 + 偏移量  D. 指令地址 + 指令长度 + 偏移量

**答案**:**B**(PC 取指后已指向下一条指令)

**解析**:
- 取当前指令后,PC 自动 + 指令长度(指向下一条指令)
- 转移目标 = 当前 PC + 偏移量 = (当前指令地址 + 指令长度) + 偏移量

### 【2022 选择】RISC 特点

**题目**:下列哪项不是 RISC 的特点?

A. 固定指令长度  B. 硬布线控制
C. 丰富的寻址方式  D. Load/Store 结构

**答案**:**C**

**解析**:RISC 寻址方式少(通常 ≤5 种),CISC 才有丰富寻址方式。

### 【2019 扩展操作码大题改编】

**题目**:16 位机,4 位 OP,设计扩展操作码:
- 三地址指令 15 条
- 二地址指令 15 条
- 一地址指令 15 条
- 零地址指令 16 条

**设计**(见 4.4.2 节完整设计):
- 三地址:OP = 0000~1110 (15 条),1111 扩展
- 二地址:OP = 1111 0000~1111 1110 (15 条),1111 1111 扩展
- 一地址:OP = 1111 1111 0000~1110 (15 条),1111 1111 1111 扩展
- 零地址:OP = 1111 1111 1111 0000~1111 (16 条)

### 【2021 综合】寻址方式计算

**题目**:主存 1MB,寄存器 32 位,寄存器寻址、寄存器间接、直接、间接寻址的地址码位数?

**解析**:
- 主存 1MB → 地址 20 位
- **寄存器寻址**:地址码 = 寄存器号位数(若 16 个寄存器 → 4 位)
- **寄存器间接**:地址码 = 寄存器号位数(4 位,EA 由 32 位寄存器给出)
- **直接寻址**:地址码 = 主存地址位数 = 20 位
- **间接寻址**:地址码 = 主存地址位数 = 20 位(若 A=20,读出的 EA 也是 20 位)

**关键**:直接/间接寻址的地址码位数 = 主存地址位数;寄存器/寄存器间接的地址码位数 = 寄存器号位数。

## 4.8 真题陷阱(15 条)

1. **零地址指令**:不仅是 NOP/HALT,堆栈操作也是零地址(隐含栈顶)
2. **一地址指令**:可能隐含 ACC(AC ← AC OP A)
3. **访存次数计算**:取指令不算寻址访存,但"总访存次数"要算
4. **间接寻址访存 2 次**,多次间接可更多(看 EA 最高位)
5. **基址 vs 变址**:基址 BR 由 OS 设(程序浮动),变址 IX 由程序员设(数组循环)
6. **相对寻址 PC 的值**:通常是**取指后**的 PC(已指向下一条指令)
7. **扩展操作码**:短操作码不能是长操作码前缀(前缀编码)
8. **扩展操作码计数**:每段保留 1 个扩展标志,$N \le 2^m - 1$
9. **RISC 用硬布线,CISC 用微程序**
10. **RISC 流水线友好**:定长 + 单周期 + Load/Store
11. **Load/Store 结构**:只有 LOAD/STORE 访存,其他指令只在寄存器间
12. **RISC 寄存器多**(32+),CISC 寄存器少
13. **CISC 指令长度可变**,RISC 固定
14. **寄存器间接寻址**:寄存器内容是 EA,不是操作数
15. **基址寻址 BR 内容运行中不变**,变址寻址 IX 内容运行中可变

## 4.9 易混淆点深辨析

### 4.9.1 基址 vs 变址 vs 相对

| 维度 | 基址寻址 | 变址寻址 | 相对寻址 |
|------|----------|----------|----------|
| 寄存器 | BR | IX | PC |
| 寄存器内容谁控制 | OS | 程序员 | 硬件自动 |
| 运行中变不变 | 不变 | 可变(循环递增) | 自动变(取指 +1) |
| 偏移 A 谁定 | 程序员(指令中) | 程序员(指令中) | 程序员(指令中) |
| 偏移 A 变不变 | 不同指令不同 A | 同一指令 A 不变 | 同一指令 A 不变 |
| 用途 | 程序重定位 | 数组遍历 | 转移指令 |
| 面向 | OS | 程序员 | 编译器 |

### 4.9.2 直接 vs 间接 vs 寄存器间接

| 方式 | 地址码含义 | 访存次数 |
|------|------------|----------|
| 直接 | A 就是 EA | 1 |
| 间接 | M[A] 是 EA | 2 |
| 寄存器间接 | R[A] 是 EA | 1 |

### 4.9.3 立即 vs 直接

- **立即寻址**:A **就是操作数本身**
- **直接寻址**:A **是操作数的地址**

### 4.9.4 扩展操作码 vs 可变长度操作码

- **可变长度操作码**:操作码字段长度可变(但通常通过扩展操作码实现)
- **扩展操作码**:可变长度操作码的**一种实现方式**(通过前缀编码扩展)

## 4.10 速查表

| 考点 | 结论 |
|------|------|
| 立即寻址 | 不访存,最快,数值范围受限 |
| 直接寻址 | 访存 1 次,EA = A |
| 间接寻址 | 访存 2 次,EA = (A) |
| 寄存器寻址 | 不访存,EA = R |
| 寄存器间接寻址 | 访存 1 次,EA = (R) |

| 变址寻址 | EA = (IX) + A,IX 可变,数组循环 |

| 扩展操作码 | 前缀编码,每段保留 1 个扩展标志 |
| CISC | 微程序,变长,寄存器少,指令多 |
| RISC | 硬布线,定长,寄存器多,Load/Store |
| RISC 流水线友好 | 定长 + 单周期 + Load/Store |
| MIPS | RISC,32 位定长,3 种格式(R/I/J) |

## 4.12 延伸知识

### 4.12.1 MIPS 五级流水线

```
IF(取指) → ID(译码) → EX(执行) → MEM(访存) → WB(写回)
```

每级 1 周期,CPI 理想 = 1。

### 4.12.2 RISC-V 指令系统

- 开源指令集(2010 加州大学伯克利分校)
- 模块化设计:RV32I(基础整数)+ M(乘除)+ A(原子)+ F(单精度)+ D(双精度)
- 定长 32 位,Load/Store 结构
- 比 MIPS 更简洁(去掉延迟槽等)

### 4.12.3 x86-64 指令前缀

- REX 前缀(40h~4Fh):扩展到 64 位
- 操作码:1~3 字节
- ModR/M 字节:指定寻址方式
- SIB 字节:Scale-Index-Base(变址寻址)

### 4.12.4 指令集虚拟化

- 不同 ISA 间通过**二进制翻译**实现兼容(QEMU)
- 同一 ISA 不同版本通过**向后兼容**(x86 30 年兼容)

## 4.13 本章习题

1. 某机 16 位指令,4 位操作码,采用扩展操作码设计三地址 15 条、二地址 30 条、一地址 15 条、零地址 16 条,给出设计方案。
2. 主存 4MB,有 16 个通用寄存器(32 位),分别求直接寻址、寄存器寻址、寄存器间接寻址、间接寻址的地址码位数。
3. 解释为什么 RISC 流水线比 CISC 友好。
4. 某转移指令地址 0x1000,指令长度 4 字节,相对寻址偏移量 +6,求转移目标地址(取指后 PC 已更新)。
5. 对比基址、变址、相对寻址的"谁变谁不变"。

### 习题答案

1. 三地址:0000~1110(15 条),1111 扩展;二地址:1111 + 5 位 = 9 位 OP,00000~11101(30 条),留 11110/11111 扩展;一地址:1111 11110 + 4 位 = 13 位 OP,0000~1110(15 条),1111 11110 1111 扩展;零地址:1111 11110 1111 + 4 位 = 16 位 OP,全 16 条。

2. 主存 4MB → 地址 22 位。
   - 直接寻址:22 位
   - 寄存器寻址:4 位(16 个寄存器)
   - 寄存器间接:4 位
   - 间接寻址:22 位

3. RISC 流水线友好的原因:
   - **定长指令**:取指阶段固定取 4 字节,IF 阶段统一
   - **单周期执行**:各阶段时间均衡,无气泡
   - **Load/Store 结构**:数据通路统一,只有 LOAD/STORE 访存
   - **简单寻址**:译码简单,ID 阶段快速
   - **大寄存器堆**:减少数据冲突

4. PC 取指后 = 0x1000 + 4 = 0x1004,转移目标 = 0x1004 + 6 = 0x100A。

5. 见 4.3.5 节表。
