## 8.1 Cache 计算专项

### 8.1.1 地址划分模板

**给定**:
- 主存地址位数 A
- Cache 大小 C,行(块)大小 L
- 映射方式(直接 / 全相联 / k 路组相联)

**步骤**:
1. **Cache 行数** = C / L
2. **行内地址(块内偏移)** b = log₂ L
3. **行号 或 组号**:
   - 直接映射:行号 = log₂(行数)
   - 全相联:无行号/组号(全部是标记)
   - k 路组相联:组数 = 行数 / k,组号 = log₂(组数)
4. **标记 Tag** = A - 行内 - 行号(或组号)

### 8.1.2 三种映射地址划分例题

**例**:主存 32 位,Cache 32 KB,行 64 B。

| 映射方式 | 行数 | 组数 | 行内 | 行号/组号 | 标记 |
|----------|------|------|------|-----------|------|
| 直接映射 | 512 | - | 6 | 9(行号) | 32-6-9 = 17 |
| 全相联 | 512 | - | 6 | 0 | 32-6 = 26 |
| 2 路组相联 | 512 | 256 | 6 | 8(组号) | 32-6-8 = 18 |
| 4 路组相联 | 512 | 128 | 6 | 7(组号) | 32-6-7 = 19 |
| 8 路组相联 | 512 | 64 | 6 | 6(组号) | 32-6-6 = 20 |

**直接映射地址格式**:
```
| 17 位 Tag | 9 位行号 | 6 位块内偏移 |
```

**全相联地址格式**:
```
| 26 位 Tag | 6 位块内偏移 |
```

**2 路组相联地址格式**:
```
| 18 位 Tag | 8 位组号 | 6 位块内偏移 |
```

### 8.1.3 命中率与平均访问时间

**命中率**:

$$h = \frac{\text{命中次数}}{\text{总访问次数}}$$

**平均访问时间**:

**顺序访问**(先查 Cache,缺失再访主存):
$$t_a = h \cdot t_c + (1-h) \cdot (t_c + t_m)$$

**同时访问**(Cache 与主存同时启动):
$$t_a = h \cdot t_c + (1-h) \cdot t_m$$

**例**:Cache 命中率 h = 0.95,t_c = 4 ns,t_m = 100 ns。

- 顺序:$t_a = 0.95 \times 4 + 0.05 \times (4 + 100) = 3.8 + 5.2 = 9.0$ ns
- 同时:$t_a = 0.95 \times 4 + 0.05 \times 100 = 3.8 + 5 = 8.8$ ns

### 8.1.4 Cache 替换算法推演

**例**:Cache 4 行,直接映射(块号 mod 4),LRU 替换,访问序列:1, 2, 3, 4, 1, 2, 5, 1。

| 访问 | 块号 | 映射行 | Cache 状态(行0~3) | 命中? |
|------|------|--------|---------------------|-------|
| 1 | 1 | 1 | [-, 1, -, -] | 缺失 |
| 2 | 2 | 2 | [-, 1, 2, -] | 缺失 |
| 3 | 3 | 3 | [-, 1, 2, 3] | 缺失 |
| 4 | 4 | 0 | [4, 1, 2, 3] | 缺失 |
| 1 | 1 | 1 | [4, 1, 2, 3] | **命中** |
| 2 | 2 | 2 | [4, 1, 2, 3] | **命中** |
| 5 | 5 | 1 | [4, 5, 2, 3] | 缺失(替换行1 的 1) |
| 1 | 1 | 1 | [4, 1, 2, 3] | 缺失(替换行1 的 5) |

命中率 = 2/8 = 25%。

### 8.1.5 多级 Cache 例题

**例**:L1 Cache 命中率 95%,命中时间 1 ns;L2 Cache 命中率 80%(对 L1 缺失的),命中时间 10 ns;主存 100 ns。求平均访问时间。

**解**:
- L1 命中:1 ns,概率 0.95
- L1 缺失 → L2 命中:1 + 10 = 11 ns,概率 0.05 × 0.80 = 0.04
- L1 缺失 → L2 缺失 → 主存:1 + 10 + 100 = 111 ns,概率 0.05 × 0.20 = 0.01

$t_a = 0.95 \times 1 + 0.04 \times 11 + 0.01 \times 111 = 0.95 + 0.44 + 1.11 = 2.50$ ns

### 8.1.6 Cache 写策略题

- **写命中**:
  - 全写法(Write-Through):同时写 Cache 和主存
  - 写回法(Write-Back):只写 Cache,设置脏位,替换时写回主存
- **写缺失**:
  - 写分配(Write-Allocate):把块调入 Cache 再写
  - 非写分配(No-Write-Allocate):直接写主存,不调入

**常见组合**:
- 写回 + 写分配(现代 Cache 常用)
- 全写 + 非写分配

## 8.2 流水线推演专项

### 8.2.1 时空图绘制模板

**横轴**:时钟周期(1, 2, 3, ...)
**纵轴**:指令(I1, I2, I3, ...)
**每格**:IF / ID / EX / MEM / WB / stall(气泡)

### 8.2.2 数据冲突判断与转发

**冲突检测**:
- 后续指令 ID 段读寄存器 R
- 前面指令 EX/MEM/WB 段写同一 R
- 且前面指令还未 WB → RAW 冲突

**转发路径**:

| 转发路径 | 适用 | 说明 |
|----------|------|------|
| EX/MEM → EX | 前指令 EX 已算出,后指令 EX 需要 | 最常见 |
| MEM/WB → EX | 前指令 MEM,后指令 EX | LOAD 后跟用,需停顿 |
| WB → EX | 前指令 WB,后指令 EX(前半写后半读) | 同周期 |

**Load-Use 冲突**(转发无法解决,需停顿 1 拍):

```
I1: LW  R1, 0(R2)    (R1 在 MEM 末才有)
I2: ADD R3, R1, R4    (EX 需要 R1)

指令   1  2  3  4  5  6  7
I1    IF ID EX MEM WB
I2       IF ID --  EX  MEM WB    ← 停顿 1 拍,MEM/WB → EX 转发
```

### 8.2.3 完整例题

**【例 1】5 段流水线,无冲突,10 条指令,每段 1 ns。求总时间、加速比、吞吐率、效率。**

**解**:
- 总时间 $T = (5 + 10 - 1) \times 1 = 14$ ns
- 非流水线 $T_{seq} = 10 \times 5 \times 1 = 50$ ns
- 加速比 $S = 50/14 \approx 3.57$
- 吞吐率 $TP = 10/14 \approx 0.714$ 条/ns
- 效率 $E = 3.57/5 \approx 71.4\%$

**【例 2】5 段流水线,带转发,指令序列:**

```
I1: ADD R1, R2, R3
I2: SUB R4, R1, R5
I3: OR  R6, R1, R7
I4: AND R8, R1, R9
```

**分析**:I2/I3/I4 都读 R1(I1 写),均可转发,无停顿。

**时空图**:
```
指令   1  2  3  4  5  6  7
I1    IF ID EX MEM WB
I2       IF ID  EX  MEM WB    ← EX/MEM → EX 转发
I3          IF  ID  EX  MEM WB ← MEM/WB → EX 转发
I4              IF  ID  EX  MEM WB ← WB → EX 转发
```

总时间 = 8 周期。

**【例 3】Load-Use 停顿:**

```
I1: LW  R1, 0(R2)
I2: ADD R3, R1, R4
I3: SUB R5, R6, R7
```

**时空图**:
```
指令   1  2  3  4  5  6  7
I1    IF ID EX MEM WB
I2       IF ID --  EX  MEM WB    ← 停顿 1 拍,MEM/WB → EX 转发
I3          IF  ID  EX  MEM WB    ← I3 不受影响
```

总时间 = 7 周期(若 I2 不停顿则 6 周期,因停顿 +1)。

### 8.2.4 CPI 计算题

**例**:5 段流水线,20% 指令 LOAD,50% LOAD 后立即用需 1 气泡。求 CPI。

**解**:
- 无冲突 CPI = 1
- LOAD 占 20%,其中 50% 后跟用 → 20% × 50% = 10% 指令需 1 气泡
- 平均 CPI = 1 + 0.10 × 1 = 1.10

### 8.2.5 控制冲突题

**例**:5 段流水线,15% 转移指令,转移预测准确率 80%,预测错误损失 2 周期。求 CPI。

**解**:
- 无冲突 CPI = 1
- 转移指令占 15%,预测错误率 20% → 15% × 20% = 3% 指令需 2 气泡
- 平均 CPI = 1 + 0.03 × 2 = 1.06

### 8.2.6 加速比公式

$$S = \frac{n \cdot k}{k + n - 1}$$

**例**:5 段流水线,1000 条指令:
$$S = \frac{1000 \times 5}{5 + 1000 - 1} = \frac{5000}{1004} \approx 4.98$$

## 8.3 浮点运算专项

### 8.3.1 IEEE 754 单精度格式

```
| 1 位 S | 8 位 E | 23 位 M |
```

**值**(规格化):
$$V = (-1)^S \times 1.M \times 2^{E-127}$$

- S:符号位(0 正,1 负)
- E:阶码(偏置 127),范围 1~254(0 和 255 特殊)
- M:尾数(隐藏 1)

### 8.3.2 十进制 → IEEE 754 完整流程

**例**:-12.75 → IEEE 754 单精度

**步骤 1**:转二进制
- 12 = 1100
- 0.75 = 0.11
- 12.75 = 1100.11

**步骤 2**:规格化
- 1100.11 = 1.10011 × 2³

**步骤 3**:计算各字段
- S = 1(负数)
- E = 3 + 127 = 130 = 10000010
- M = 10011000...0(去掉隐藏 1,补 0 至 23 位)

**步骤 4**:组装
```
1 10000010 10011000000000000000000
= 1100 0001 0100 1100 0000 0000 0000 0000
= C14C0000 H
```

### 8.3.3 IEEE 754 → 十进制

**例**:40490FDB → ?

**步骤 1**:转二进制
- 40490FDB = 0100 0000 0100 1001 0000 1111 1101 1011

**步骤 2**:分字段
- S = 0
- E = 10000000 = 128
- M = 10010010000111111011011

**步骤 3**:计算
- 阶码真实值 e = 128 - 127 = 1
- 尾数真实值 = 1.10010010000111111011011
- V = +1.10010010000111111011011 × 2¹ = 11.0010010000111111011011

**步骤 4**:转十进制
- 整数部分:11 = 3
- 小数部分:0.0010010000111111011011 ≈ 0.1415926...
- V ≈ 3.1415926 ≈ π

### 8.3.4 浮点加减完整流程

**五步**:对阶 → 尾数加减 → 规格化 → 舍入 → 溢出判断

**例**:0.5 + 0.25

**步骤 1**:对阶(小阶向大阶,尾数右移)
- 0.5 = 1.0 × 2⁻¹
- 0.25 = 1.0 × 2⁻² → 对齐到 2⁻¹:0.1 × 2⁻¹

**步骤 2**:尾数加
- 1.0 + 0.1 = 1.1

**步骤 3**:规格化
- 1.1 × 2⁻¹ 已规格化(尾数最高位为 1)

**步骤 4**:舍入(无需)

**步骤 5**:溢出判断(无)

**结果**:1.1 × 2⁻¹ = 0.11₂ = 0.75

### 8.3.5 浮点乘除

**乘法**:
- 阶码相加:E = E1 + E2 - Bias(减一次 Bias,因加了两倍)
- 尾数相乘:M = M1 × M2
- 规格化 + 舍入

**除法**:
- 阶码相减:E = E1 - E2 + Bias
- 尾数相除:M = M1 / M2
- 规格化 + 舍入

### 8.3.6 范围与精度

| 类型 | 范围 | 精度 | 阶码 | 尾数 |
|------|------|------|------|------|
| 单精度 (32 位) | ±3.4 × 10³⁸ | ~7 位十进制 | 8 位 | 23 位 |
| 双精度 (64 位) | ±1.8 × 10³⁰⁸ | ~15 位十进制 | 11 位 | 52 位 |

**特殊值**:

| E | M | 值 |
|---|---|------|
| 0 | 0 | ±0 |
| 0 | ≠0 | 非规格化数($2^{-126}$ 量级) |
| 1~254 | 任意 | 规格化数 |
| 255 | 0 | ±∞ |
| 255 | ≠0 | NaN |

### 8.3.7 int → float 精度损失

- int 32 位,精度 32 位
- float 尾数 23 位 + 隐藏 1 = 24 位精度
- **2²⁴ + 1 = 16777217 在 float 中无法精确表示**(丢失)

### 8.3.8 非规格化数

- E = 0,M ≠ 0
- 阶码真实值 = **1 - Bias = -126**(单精度),不是 0 - Bias = -127
- 尾数**无隐藏 1**:V = (-1)^S × 0.M × 2^{-126}
- 目的:**平滑过渡**到 0(最小规格化数 = 1.0 × 2^{-126},最大非规格化 = 0.111... × 2^{-126} ≈ 1.0 × 2^{-126})

## 8.4 CPU 性能计算专项

### 8.4.1 基本公式

$$T_{CPU} = I \times CPI \times T = I \times CPI / f$$

- I:指令数
- CPI:每条指令平均周期数
- T:时钟周期 = 1/f
- f:主频

**MIPS**:

$$MIPS = \frac{I}{T_{CPU} \times 10^6} = \frac{f}{CPI \times 10^6}$$

### 8.4.2 CPI 加权平均

**例**:某程序 100 万条指令,各类指令占比如下:

| 指令类型 | 占比 | CPI |
|----------|------|-----|
| 算术逻辑 | 60% | 1 |
| LOAD/STORE | 20% | 2 |
| 转移 | 15% | 3 |
| 浮点 | 5% | 4 |

**加权 CPI** = 0.6×1 + 0.2×2 + 0.15×3 + 0.05×4 = 0.6 + 0.4 + 0.45 + 0.20 = 1.65

**总周期** = 100 万 × 1.65 = 165 万周期

### 8.4.3 CPU 时间计算

**例**:2 GHz 主频,CPI 2.5,10⁶ 条指令,求 CPU 时间、MIPS。

**解**:
- T = 1/f = 0.5 ns
- $T_{CPU} = 10^6 \times 2.5 \times 0.5$ ns = 1.25 × 10⁶ ns = 1.25 ms
- MIPS = 10⁶ / (1.25 × 10⁶ × 10⁻⁹) / 10⁶ = 10⁶ / 1.25 × 10⁻³ / 10⁶ = 800 MIPS

(或:MIPS = f / (CPI × 10⁶) = 2×10⁹ / (2.5 × 10⁶) = 800)

### 8.4.4 Amdahl 加速比

$$S = \frac{1}{(1-f) + f/r}$$

- f:可加速部分占比
- r:加速比
- 上限:$S_{max} = 1/(1-f)$(当 r → ∞)

**例**:某部件占 40%,加速 10 倍,求系统加速比。

**解**:
- f = 0.4, r = 10
- $S = 1 / (0.6 + 0.4/10) = 1 / 0.64 = 1.5625$

### 8.4.5 多部件 Amdahl

**例**:浮点运算占 50%,加速 5 倍;内存访问占 20%,加速 2 倍。

**解**:
$$S = \frac{1}{(1 - 0.5 - 0.2) + 0.5/5 + 0.2/2} = \frac{1}{0.3 + 0.1 + 0.1} = \frac{1}{0.5} = 2$$

### 8.4.6 主频与 CPI 关系

**陷阱**:主频高 ≠ 性能高(CPI 可能不同)

**例**:
- 机器 A:主频 2 GHz,CPI 2.5 → 800 MIPS
- 机器 B:主频 3 GHz,CPI 3.0 → 1000 MIPS

机器 B 主频高且 CPI 高,但 MIPS 仍高(因主频提升 > CPI 提升)。

## 8.5 磁盘容量与寻址专项

### 8.5.1 磁盘容量

$$\text{容量} = \text{柱面数} \times \text{每柱面磁道数} \times \text{每磁道扇区数} \times \text{每扇区字节数}$$

**例**:磁盘 1024 柱面,每柱面 8 磁道,每磁道 64 扇区,每扇区 512 B。求容量。

**解**:
$$\text{容量} = 1024 \times 8 \times 64 \times 512 = 268435456 \text{ B} = 256 \text{ MB}$$

### 8.5.2 平均寻址时间

$$t_{\text{寻址}} = t_{\text{平均寻道}} + t_{\text{平均旋转延迟}}$$

- 平均寻道时间:磁头移到目标磁道(通常为最大寻道时间的 1/3)
- 平均旋转延迟:磁盘转半圈 = (1/转速) / 2

**例**:磁盘 7200 RPM,平均寻道 8 ms。求平均寻址时间。

**解**:
- 转一圈 = 60/7200 = 8.33 ms
- 平均旋转延迟 = 8.33/2 = 4.17 ms
- 平均寻址 = 8 + 4.17 = 12.17 ms

### 8.5.3 数据传输率

$$\text{传输率} = \text{每磁道字节数} \times \text{转速}$$

**例**:每磁道 64 扇区 × 512 B = 32 KB,7200 RPM = 120 转/秒。

$$\text{传输率} = 32 \text{ KB} \times 120 = 3840 \text{ KB/s} \approx 3.75 \text{ MB/s}$$

## 8.6 综合应用题答题模板

### 8.6.1 Cache 题模板

```
1. 计算 Cache 行数 = C / L,组数 = 行数 / k
2. 划分地址:| Tag | 组号/行号 | 块内偏移 |
3. 推演访问序列(列表记录命中/缺失)
4. 计算命中率 h = 命中数 / 总访问数
5. 计算平均访问时间(明确顺序 vs 同时)
6. 注明公式与单位
```

### 8.6.2 流水线题模板

```
1. 画时空图(横轴周期,纵轴指令,每格标段名)
2. 标注冲突类型(结构/数据/控制)
3. 标注转发路径(EX→EX、MEM/WB→EX)
4. 标注气泡(用 -- 或 stall)
5. 套公式计算总时间、加速比、吞吐率、效率
6. 计算平均 CPI(若有冲突)
```

### 8.6.3 浮点题模板

```
1. 十进制 → 二进制(整数 + 小数部分)
2. 规格化:1.xxx × 2^e
3. 计算 S、E = e + 127、M(去隐藏 1,补 0 至 23 位)
4. 组装二进制
5. 转十六进制(每 4 位一组)
6. (若是加减):对阶 → 尾数加减 → 规格化 → 舍入 → 溢出
```

### 8.6.4 CPU 性能题模板

```
1. 列指令类型 + CPI + 占比
2. 计算加权 CPI = Σ(CPI_i × 占比_i)
3. 计算 CPU 时间 = I × CPI / f
4. 计算 MIPS = f / (CPI × 10⁶)
5. (若是 Amdahl):列可加速部分 f、加速比 r
6. 套公式 S = 1 / ((1-f) + f/r)
```

## 8.7 高频陷阱(20 条)

1. **Cache 块大小 vs 行大小**:通常相同,但题目可能区分
2. **k 路组相联组号**:行数 / k(不是行数)
3. **同时访问 vs 顺序访问**:平均时间公式不同
4. **流水线气泡数**:数据冲突转发可减少但不能消除 Load-Use
5. **浮点对阶**:小阶向大阶,尾数右移(可能丢失精度)
6. **隐藏位**:规格化数有,非规格化无
7. **阶码全 0/255 是特殊值**,不是规格化
8. **非规格化阶码 = 1 - Bias**(不是 0 - Bias)
9. **int → float 精度损失**:2²⁴+1 无法精确表示
10. **CPU 时间 = I × CPI × T**,注意 T = 1/f
11. **MIPS = f / (CPI × 10⁶)**,不要忘记 10⁶
12. **Amdahl 上限 = 1/(1-f)**,加速比不可能超过此值
13. **主频高 ≠ 性能高**,CPI 也很重要
14. **平均寻道时间**:通常为最大寻道的 1/3(不是 1/2)
15. **平均旋转延迟**:转半圈时间(不是 1/4)
16. **流水线加速比 n→∞ 趋近 k**(不是无限大)
17. **流水线效率 n→∞ 趋近 1**(不是 100% 立即达到)
18. **数据冲突 RAW 最常见**,Load-Use 必须停顿
19. **WAR/WAW 在基本流水线不出现**
20. **写回法需脏位**,全写法不需

```
I1: LW  R1, 0(R2)

```
分析冲突,画时空图(带转发)。

### 习题 5(浮点)
将 -26.625 转为 IEEE 754 单精度(十六进制)。

### 习题 6(浮点)
计算 0.75 + 0.125(IEEE 754,给出对阶/规格化步骤)。

### 习题 7(CPU 性能)
某程序 10⁹ 条指令,各类指令:
- 算术 60%,CPI 1
- 访存 25%,CPI 2
- 转移 10%,CPI 3
- 浮点 5%,CPI 4

主频 3 GHz。求加权 CPI、CPU 时间、MIPS。

### 习题 8(Amdahl)
浮点部件占 40%,加速 8 倍,求系统加速比和上限。

### 习题 9(磁盘)
磁盘 2048 柱面,16 磁道/柱面,128 扇区/磁道,512 B/扇区,7200 RPM,平均寻道 6 ms。求容量、平均寻址时间、传输率。

### 习题答案

1. 行数 = 64K/32 = 2048,组数 = 2048/4 = 512,组号 = 9 位,块内 = 5 位,Tag = 32-9-5 = 18 位。

2. 顺序:$0.9 \times 5 + 0.1 \times (5+100) = 4.5 + 10.5 = 15$ ns;同时:$0.9 \times 5 + 0.1 \times 100 = 4.5 + 10 = 14.5$ ns。

3. $T = (5+50-1) \times 0.5 = 27$ ns;$T_{seq} = 50 \times 5 \times 0.5 = 125$ ns;$S = 125/27 \approx 4.63$;$E = 4.63/5 \approx 92.6\%$。

4. I1 与 I2 是 Load-Use,需停顿 1 拍 + MEM/WB → EX 转发;I2 与 I3 是 EX/MEM → EX 转发,无停顿。时空图(略,参考 8.2.3 例 3)。

5. -26.625 = -11010.101 = -1.1010101 × 2⁴。S=1, E=4+127=131=10000011, M=10101010000...0(23 位)。组装:1 10000011 10101010000000000000000 = C1D50000 H。

6. 0.75 = 1.1 × 2⁻¹,0.125 = 1.0 × 2⁻³。对阶:0.125 → 0.01 × 2⁻¹。尾数加:1.1 + 0.01 = 1.11。规格化:1.11 × 2⁻¹。结果 = 0.875。

7. 加权 CPI = 0.6×1 + 0.25×2 + 0.10×3 + 0.05×4 = 0.6 + 0.5 + 0.30 + 0.20 = 1.60。CPU 时间 = 10⁹ × 1.60 / 3×10⁹ = 0.533 s。MIPS = 3×10⁹ / (1.60 × 10⁶) = 1875 MIPS。

8. $S = 1/(0.6 + 0.4/8) = 1/0.65 \approx 1.538$;上限 = 1/0.6 ≈ 1.667。

9. 容量 = 2048 × 16 × 128 × 512 = 2^11 × 2^4 × 2^7 × 2^9 = 2^31 B = 2 GB。平均旋转 = 60/7200/2 = 4.17 ms,平均寻址 = 6 + 4.17 = 10.17 ms。传输率 = 128 × 512 × 7200/60 = 65536 × 120 = 7,864,320 B/s ≈ 7.5 MB/s。
