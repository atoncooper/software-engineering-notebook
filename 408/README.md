## 0. 关于 408

### 0.1 考试结构

| 科目 | 分值 | 题型分布 | 难度定位 |
|------|------|----------|----------|
| 数据结构 | 45 | 2 单选 + 2 综合应用 | 算法题是分水岭 |
| 计算机组成原理 | 45 | 2 单选 + 2 综合应用 | 概念最多、计算最碎 |
| 操作系统 | 35 | 2 单选 + 2 综合应用 | PV 操作 + 虚拟内存为难点 |
| 计算机网络 | 25 | 1~2 单选 + 1 综合应用 | 协议栈细节多 |
| **合计** | **150** | 40 单选 (80分) + 7 综合 (70分) | — |

- 单选 40 × 2 = 80 分 (覆盖面广,基础分)
- 综合应用 7 × 10 = 70 分 (深度题,分科目分布)
- 考试时间 180 分钟,平均每题 ≤ 3 分钟

### 0.2 分数策略

**聪明人满分 (145+)** 路径:
- 单选 40 题全对 (80 分基础盘)
- 数据结构算法题写出最优解并严格符合 C 语法
- 组成原理 Cache/流水线/浮点计算零失误
- 操作系统 PV 操作、页面置换推演零失误
- 网络层子网划分、TCP 状态机零失误

**正常人 130+** 路径:
- 单选保 36+ (72 分)
- 数据结构算法题写出暴力解 + 部分最优 (拿 6~8 分)
- 综合题计算类零失误 (Cache、浮点、PV、子网、流水线)
- 概念类综合题 (对比、流程) 拿 80% 分数

**关键认知**:408 不考智商,考熟练度与细节。**130 → 140 的差距在细节,140 → 150 的差距在算法题**。

### 0.3 笔记设计原则

1. **考点全覆盖**:严格对照 2026 大纲,不漏一个知识点。
2. **分频标注**:每个知识点标 ⭐ (了解) / 🔥 (高频) / ⭐🔥 (必考核心)。
3. **四层结构**:概念 → 原理 → 计算 → 真题陷阱。
4. **可检索**:每章末附「高频考点速查表」与「典型真题编号」。
5. **算法题专项**:数据结构每章配 2~3 道算法题模板 (暴力→最优→边界)。

|------|------|------|------|----------|
| 01 线性表 | 顺序表、单/双/循环链表 | 🔥 | ★★ | 6~10 |

### 2.2 必覆盖知识点清单

**第 1 章 线性表**
- 顺序表:随机访问 O(1)、插入删除 O(n);动态扩容策略。
- 单链表:头插/尾插、逆置、找中点、判环、相交、合并。
- 双链表、循环链表、静态链表 (概念辨析)。
- 真题陷阱:链表头结点是否计入长度、删除节点的前驱判断。

**第 2 章 栈、队列、数组**
- 栈:括号匹配、表达式求值 (前/中/后缀转换)、递归栈深度。
- 队列:循环队列判空/判满 (牺牲一个单元 vs 计数器)、双端队列。
- 特殊矩阵:对称、三角、三对角、稀疏矩阵的坐标映射公式。
- 共享栈、链队列出队条件。

**第 3 章 树与二叉树** ⭐🔥
- 二叉树性质:n0 = n2 + 1、第 i 层最多 2^(i-1) 个、深度 k 最多 2^k - 1。
- 五种遍历 (先/中/后/层序/Morris) + 由遍历序列重建二叉树。
- 线索二叉树:ltag/rtag 标志位、中序线索化代码。
- 哈夫曼树与哈夫曼编码 (前缀码证明、WPL 计算)。
- 并查集:路径压缩 + 按秩合并,近似 O(α(n))。
- 二叉排序树:插入/删除 (3 种情况)、平衡调整 (LL/RR/LR/RL 四种旋转)。
- 树与森林:孩子兄弟表示法、与二叉树互转。

**第 4 章 图** ⭐🔥
- 存储:邻接矩阵 (适合稠密)、邻接表 (适合稀疏)、十字链表、邻接多重表。
- 遍历:DFS (栈/递归)、BFS (队列);连通分量与生成树。
- 最小生成树:Prim (稠密 O(V²))、Kruskal (稀疏 O(E log E))。
- 最短路:Dijkstra (非负权, O(V²))、Floyd (任意权, O(V³))、BFS (无权)、A* (了解)。
- 拓扑排序:入度法、DFS 法;关键路径 AOE 网 (ve/vl/e/l)、关键活动判断。
- 真题陷阱:图的连通性、有向图无环判断、Dijkstra 不能处理负权。

**第 5 章 查找**
- 顺序查找、折半查找 (判定树深度 ⌊log₂n⌋+1)、分块查找。
- B 树:插入 (分裂向上)、删除 (借/合并)、m 阶 B 树关键字范围 ⌈m/2⌉-1 ~ m-1。
- B+ 树:叶子链表、磁盘友好、与 B 树对比。
- 散列表:除留余数法、线性探测、平方探测、链地址法;ASL 成功/失败计算;装填因子 α。
- 真题陷阱:散列表查找失败 ASL 的计算口径。

**第 6 章 排序**
- 插入:直接插入、折半插入、希尔排序 (增量序列)。
- 交换:冒泡 (优化:标志位)、快速排序 (Partition 三种取枢、最坏 O(n²))。
- 选择:简单选择、堆排序 (大/小根堆调整、建堆 O(n))。
- 归并:二路归并 O(n log n)、k 路归并败者树。
- 基数排序: LSD/MSD,适合关键字位数少。
- 外部排序:多路归并、置换-选择 (生成初始归并段)、败者树、最佳归并树。
- 各排序算法稳定性、时间、空间、初始状态影响对比表 (必背)。

**第 7 章 算法题专项** (独立章节)
- 模板库:链表逆置、归并、二路归并、快排 Partition、二叉树重建、BFS/DFS、Dijkstra。
- 真题分类:线性表操作 (30%)、树操作 (25%)、图操作 (15%)、查找/排序应用 (30%)。
- 答题规范:C 语法严格、结构体定义、复杂度注释。

### 3.2 必覆盖知识点清单

**第 1 章 系统概述**
- 冯·诺依曼架构:存储程序、五大部件、指令流驱动。
- 层次结构:从微程序设计级到高级语言级 (6 层)。
- 性能指标:主频/CPI/MIPS/POFQ;CPU 时间 = 指令数 × CPI × 时钟周期。
- 真题陷阱:基准程序的局限性、Amdahl 定律。

**第 2 章 数据表示与运算** ⭐🔥 (计算重灾区)
- 进位计数制转换:任意进制互转、补码与移码。
- 定点数:原码、补码、反码、移码;范围对比表 (必背)。
- 浮点数 IEEE 754:短浮点 (1+8+23)、长浮点 (1+11+52);规格化、隐藏位、特殊值 (0、∞、NaN、非规格化数)。
- 浮点数四则运算:对阶 → 尾数加减 → 规格化 → 舍入 → 溢出判断。
- 加法器:串行进位、先行进位 (单级/两级);ALU 结构 (74181/74182)。
- 乘法:原码一位乘、补码一位乘 (Booth)、阵列乘法。
- 除法:原码恢复余数法、原码加减交替法。
- 校验码:奇偶校验 (奇偶位计算)、海明码 (k 位数据需 r 校验位,2^r ≥ k+r+1)、CRC (生成多项式模 2 除)。
- 真题陷阱:IEEE 754 与浮点数范围对应、海明码纠 1 检 2、CRC 余数与错误位置。

**第 3 章 存储器层次结构** ⭐🔥 (性价比最高的章节)
- SRAM vs DRAM:SRAM (cache, 触发器, 不需刷新)、DRAM (主存, 电容, 需刷新);刷新方式 (集中/分散/异步)。
- ROM 系列:掩膜、PROM、EPROM、EEPROM、Flash。
- 主存编址:字节编址 vs 字编址;地址线/数据线计算;存储器与 CPU 连接 (译码器 74LS138)。
- Cache:
  - 三种映射:直接映射 (主存字块标记 + Cache 字块地址 + 字块内地址)、全相联、组相联。
  - 替换算法:LRU、FIFO、随机、LFU。
  - 写策略:全写法 vs 写回法、写分配 vs 不按写分配。
  - 命中率计算、平均访问时间 = h·tc + (1-h)·(tc + tm)。
  - 真题陷阱:Cache 行大小、主存块大小、地址位数划分。
- 虚拟存储器:页式、段式、段页式;页表 (多级)、TLB (页表 Cache);有效位、修改位、访问位、脏位。
- 真题陷阱:TLB、Cache、Page 三者访问顺序;Cache 缺失 vs TLB 缺失关系。

**第 4 章 指令系统**
- 指令格式:操作码 (固定/扩展) + 地址码 (零/一/二/三地址)。
- 寻址方式 (必背):立即、直接、间接、寄存器、寄存器间接、基址、变址、相对。
- 偏移寻址:基址 (基址寄存器, 程序浮动)、变址 (变址寄存器, 数组循环)、相对 (PC, 转移)。
- CISC vs RISC 对比表 (复杂度、指令数、寄存器、流水线)。
- 真题陷阱:扩展操作码设计、寻址方式对指令长度的影响。

**第 5 章 中央处理器** ⭐🔥
- CPU 结构:ALU + CU + 寄存器 (PC、IR、MAR、MDR、PSW、通用寄存器)。
- 指令周期:取指、间址、执行、中断;机器周期、时钟周期。
- 数据通路:单总线、双总线、三总线;数据通路图阅读。
- 控制器:硬布线 (组合逻辑, 速度快、修改难)、微程序 (存储逻辑, 速度慢、灵活);微指令格式 (水平/垂直);微命令编码方式 (直接/字段直接/字段间接编码)。
- 指令流水线:
  - 五段:IF、ID、EX、MEM、WB。
  - 三种冲突:
    - 结构冲突 (资源):资源重复。
    - 数据冲突:RAW、WAR、WAW;定向 forwarding、停顿 stall、乱序。
    - 控制冲突:分支预测 (静态/动态)、延迟分支。
  - 流水线加速比 S = n·k / (k + n - 1) (k 段,n 条指令)。
- 超标量、超流水、动态调度 (Tomasulo 概念)。
- 真题陷阱:流水线时空图、数据冲突时序图、转发路径判断。

**第 6 章 总线**
- 总线分类:片内、系统、通信;数据/地址/控制线;串行/并行。
- 总线仲裁:集中式 (链式查询、计数器定时、独立请求)、分布式。
- 总线事务:请求 → 仲裁 → 地址 → 数据 → 释放。
- 总线带宽计算:带宽 = 工作频率 × (位宽/8)。
- 真题陷阱:同步/异步通信 (握手)、总线复用。

**第 7 章 输入输出系统**
- I/O 控制方式:程序查询、程序中断、DMA、通道。
- 中断:中断向量、向量地址、中断优先级 (硬件排队)、多重中断 (屏蔽字)。
- DMA:周期挪用 (窃取)、DMA 与中断对比;DMA 三个阶段 (预处理、数据传输、后处理)。
- I/O 接口:端口与接口、可编程接口 8255/8259。
- 真题陷阱:中断响应时机 (指令执行末)、DMA 与 CPU 访存冲突仲裁。

### 3.3 组成原理必背公式表

| 公式 | 含义 |
|------|------|
| CPU 时间 = IC × CPI × T | 性能公式 |
| 平均访问时间 = h·tc + (1-h)·(tc+tm) | Cache 命中率 |
| 加速比 S = n·k / (k+n-1) | 流水线 |
| 海明码 2^r ≥ k+r+1 | 校验位数 |
| MIPS = IC / (CPU 时间 × 10⁶) | 速度指标 |

### 4.2 必覆盖知识点清单

**第 1 章 概述**
- 操作系统特征:并发 (最基本)、共享、虚拟、异步。
- 功能:处理机、存储器、文件、设备管理。
- 发展:批处理 → 分时 → 实时 → 网络 → 分布式 → 嵌入式。

- 中断与异常 (内中断 vs 外中断)、系统调用 (访管指令)。
- 真题陷阱:并发与并行、系统调用与库函数。

**第 2 章 进程与线程** ⭐🔥
- 进程状态:三态 (就绪/运行/阻塞)、五态 (含创建/结束)、转换条件 (无 阻塞→运行)。
- PCB 内容:进程标识、处理机状态、进程调度信息、进程控制信息。
- 进程控制:创建 fork/创建、撤销、阻塞、唤醒、切换。
- 线程:用户级 vs 内核级;线程与进程对比 (资源/调度)。
- 进程通信:共享存储、消息传递、管道、套接字。
- 调度算法 (必背):
  - 作业调度:FCFS、SJF、优先级、高响应比优先 HRRN。
  - 进程调度:FCFS、SJF/SPF、优先级、时间片轮转 RR、多级反馈队列。
- 调度时机、切换过程、上下文切换开销。
- 真题陷阱:抢占式 vs 非抢占式、HRRN 计算、RR 时间片大小影响。

**第 3 章 同步与互斥** ⭐🔥 (综合题常客)
- 临界区四条件:空闲让进、忙则等待、有限等待、让权等待。
- 软件实现:Peterson 算法;硬件实现:TSL、XCHG、关中断。
- 信号量:整型、记录型 (P/V 操作);整型 vs 记录型区别。
- 经典问题 (必背模型 + 改写):
  - 生产者-消费者 (单/多生产者、单/多消费者)。
  - 读者-写者 (读者优先、写者优先、公平)。
  - 哲学家进餐 (避免死锁的 3 种解法)。
  - 吸烟者问题。
  - 理发师睡觉问题。
- 前驱图与同步实现。
- 真题陷阱:P/V 操作顺序 (先 P 私有信号量再 P 共享)、死锁避免。

**第 4 章 死锁**
- 死锁四必要条件:互斥、请求保持、不剥夺、循环等待。
- 处理策略:预防、避免、检测与解除、鸵鸟。
- 预防:破坏四条件 (SPOOLing 破坏互斥、一次性申请破坏请求保持、剥夺、顺序资源分配)。
- 避免:银行家算法 (Available、Max、Allocation、Need、Work、Finish)。
- 检测:资源分配图化简;解除:剥夺资源、撤销进程、回滚。
- 真题陷阱:死锁 vs 饥饿、安全状态 vs 不安全状态。

**第 5 章 内存管理** ⭐🔥
- 程序装入:绝对装入、可重定位装入 (静态重定位)、动态运行时装入 (动态重定位)。
- 链接:静态、装入时动态、运行时动态。
- 连续分配:单一连续、固定分区、动态分区 (首次/最佳/最坏/循环首次适应)。
- 分页:页表、地址变换 (页号 + 页内偏移);快表 TLB;多级页表;二级页表访存次数。
- 分段:段表、地址变换、共享与保护。
- 段页式:先分段再分页,3 次访存。
- 虚拟内存:请求分页、请求分段;缺页中断处理流程。
- 页面置换算法 (必背 + 推演):
  - OPT (最佳,不可实现)、FIFO (Belady 异常)、LRU、CLOCK (简单/改进型)、LFU。
- 抖动 (Thrashing)、工作集、驻留集。
- 真题陷阱:Belady 异常 (FIFO 独有)、LRU 与 CLOCK 性能对比、缺页率计算。

**第 6 章 文件管理**
- 文件结构:无结构、有结构 (流式、记录式)。
- 文件物理结构:连续、链接 (FAT)、索引 (inode);多级索引 (Unix inode)。
- 目录:单级、两级、树形、无环图;FCB 内容。
- 文件存储空间管理:空闲表、空闲链、位示图、成组链接法。
- 文件共享:硬链接、符号链接。
- 文件保护:访问控制表 ACL、口令、密码。
- 真题陷阱:inode 直接/一级/二级/三级索引计算、FAT 表项位数。

**第 7 章 I/O 管理**
- 设备分类:独占、共享、虚拟;块设备 vs 字符设备。
- I/O 控制方式 (与组成原理呼应):程序查询、中断、DMA、通道。
- I/O 软件层次:用户层 → 系统调用 → 驱动 → 中断处理。
- 缓冲:单缓冲、双缓冲、循环缓冲、缓冲池;缓冲引入的吞吐量计算。
- SPOOLing (假脱机):输入井/输出井、预输入/缓输出。
- 磁盘调度:FCFS、SSTF、SCAN、C-SCAN、LOOK、C-LOOK。
- 磁盘地址:C/H/S、物理 → 逻辑转换。
- 真题陷阱:SCAN 方向判断、双缓冲处理时间计算。

### 4.3 PV 操作答题模板 (示意)

```c
// 1. 定义信号量
semaphore mutex = 1;   // 互斥
semaphore empty = n;   // 同步
semaphore full  = 0;   // 同步

// 2. 生产者
producer() {
    P(empty);          // 先 P 同步
    P(mutex);          // 再 P 互斥
    // 临界区
    V(mutex);
    V(full);
}

// 3. 消费者
consumer() {
    P(full);
    P(mutex);
    // 临界区
    V(mutex);
    V(empty);
}
```

### 5.2 必覆盖知识点清单

**第 1 章 体系结构**
- OSI 七层 vs TCP/IP 四层 vs 五层协议 (教材常用)。
- 协议、服务、服务访问点 SAP;PDU (协议数据单元)。
- 各层功能与代表协议对应表 (必背)。

**第 2 章 物理层**
- 数据通信基础:信源、信宿、信道;基带/宽带、数字/模拟。
- 编码:NRZ、曼彻斯特 (以太网)、差分曼彻斯特 (令牌环);4B/5B、8B/10B。
- 调制:ASK、FSK、PSK、QAM。
- 奈奎斯特定理:无噪声信道,最大数据率 = 2W log₂V (b/s)。
- 香农定理:有噪声信道,C = W log₂(1+S/N) (b/s)。
- 信道复用:FDM、TDM、STDM、WDM、CDM (CDMA 编码)。
- 物理层设备:中继器、集线器 (Hub, 冲突域)。

**第 3 章 数据链路层** ⭐🔥
- 封装成帧:字符计数、字符填充 (转义)、零比特填充 (HDLC)、违规编码。
- 差错控制:检错 (CRC、奇偶)、纠错 (海明);反馈重传 ARQ (停止等待、回退 N、选择重传)。
- 流量控制:停止等待、滑动窗口 (发送窗口、接收窗口)。
- 可靠传输机制三种窗口对比表 (必背):
  - 停止等待:W_S = W_R = 1。
  - 回退 N (GBN):W_S > 1, W_R = 1。
  - 选择重传 (SR):W_S > 1, W_R > 1;窗口大小与序列号关系 W_S + W_R ≤ 2^n。
- 介质访问控制 MAC:
  - 信道划分 (FDM/TDM/WDM/CDM)。
  - 随机访问:ALOHA (纯/时隙)、CSMA/CD (以太网, 最小帧长 = 2 × 传播时延 × 带宽)。
  - 轮询:令牌环。
- 局域网:IEEE 802;以太网 (802.3) 帧格式、MAC 地址;VLAN (802.1Q) 标签、跨交换机 Trunk。
- 链路层设备:网桥 (隔离冲突域)、交换机 (自学习、生成树 STP)。
- 真题陷阱:广播域 vs 冲突域 (路由器/交换机/集线器各隔离什么)。

**第 4 章 网络层** ⭐🔥 (分值重灾区)
- IPv4:首部格式 (TTL、协议、首部校验和、分片标志 DF/MF、片偏移)。
- IP 地址:分类 (A/B/C/D/E)、私有地址范围、特殊地址 (网络号/主机号全 0/全 1 含义)。
- 子网划分:子网掩码、CIDR (无分类编址)、超网聚合、路由汇总。
- IPv6:128 位、首部简化、过渡 (双栈、隧道)。
- 路由算法与协议:
  - 静态 vs 动态。
  - 距离向量 RIP (跳数 ≤ 15, 30s 周期, UDP, 触发更新)。
  - 链路状态 OSPF (代价 = 10⁸/带宽, 区域划分, IP 直接承载, Hello/LSU)。
  - 路径向量 BGP (AS 间, TCP 179, 路径属性)。
- 路由表:目的网络、下一跳、接口、度量;最长前缀匹配原则。
- ARP:IP → MAC;广播请求、单播应答;ARP 缓存。
- DHCP:Discover → Offer → Request → ACK;广播/单播;租约。
- ICMP:差错报告 (目的不可达、超时、参数问题、重定向) + 询问 (回送、时间戳);Ping、Traceroute。
- 移动 IP:家乡代理、外地代理、隧道;三角路由。
- 网络层设备:路由器 (隔离广播域)、三层交换机。
- 真题陷阱:子网划分计算 (主机数 = 2^主机位 - 2)、路由聚合、最长前缀匹配实战。

**第 5 章 传输层** ⭐🔥
- TCP vs UDP 对比表 (必背):连接、可靠、顺序、流量、拥塞、首部开销、应用场景。
- TCP 首部:序列号、确认号、数据偏移、标志位 (URG/ACK/PSH/RST/SYN/FIN)、窗口、校验和、紧急指针。
- TCP 连接管理:
  - 三次握手:SYN → SYN+ACK → ACK;为什么不是两次 (防止旧连接)。
  - 四次挥手:FIN → ACK → FIN → ACK;2MSL 等待;半关闭状态。
  - 状态机:CLOSED、LISTEN、SYN_SENT、SYN_RCVD、ESTABLISHED、FIN_WAIT_1/2、CLOSE_WAIT、LAST_ACK、TIME_WAIT。
- TCP 可靠传输:序列号、确认、重传 (超时 RTO、快重传)、流量控制 (滑动窗口、零窗口探测)。
- TCP 拥塞控制 (必背算法 + 推演):
  - 慢开始:门限 ssthresh,cwnd 指数增长。
  - 拥塞避免:cwnd 线性增长。
  - 快重传:3 个重复 ACK。
  - 快恢复:门限减半,cwnd = ssthresh,线性增长。
  - 加性增、乘性减 (AIMD)。
- TCP 与 UDP 应用层归属 (DNS/HTTP/SMTP/FTP 等)。
- 真题陷阱:拥塞窗口推演 (发送窗口 = min(cwnd, rwnd))、TIME_WAIT 作用。

**第 6 章 应用层**
- 网络应用模型:C/S、P2P;层次命名。
- DNS:递归查询 vs 迭代查询;域名层级;资源记录;UDP 53。
- DHCP:见网络层 (跨网段需中继代理)。
- HTTP:无状态、Cookie;持久连接 vs 非持久;HTTP 1.0/1.1/2.0/3.0;HTTPS (TLS 握手)。
- 邮件系统:SMTP (推, TCP 25)、POP3 (拉, TCP 110)、IMAP (TCP 143);MIME。
- FTP:控制连接 (21) + 数据连接 (20, 主动模式;被动模式动态端口)。
- 万维网:URL、HTML、HTTP。
- 真题陷阱:DNS 递归 vs 迭代、SMTP/POP3 方向、HTTP 持久连接。
