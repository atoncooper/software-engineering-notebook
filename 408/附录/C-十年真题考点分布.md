## C.12 命题规律总结

1. **PV 操作必考** (8/10):五大模型 + 变形。
2. **Cache/流水线/浮点轮换** (计组综合题三大块)。
3. **链表/树/BST 轮换** (数据结构算法题)。
4. **子网/TCP/路由** (网络三大热点)。
5. **虚拟内存** (操作系统第二大热点)。

---

## C.13 复习优先级

按综合题频次:
1. PV 操作 (8 次) → 必背模型 + 变形
2. Cache (5 次) → 地址划分 + 推演
3. 子网/路由 (5 次) → 最长前缀匹配
4. 链表算法 (4 次) → 模板 + 真题
5. 树/BST (4 次) → 遍历 + 重建
6. 虚拟内存 (4 次) → 页表 + 置换
7. TCP/HTTP (4 次) → 状态机 + 报文
8. 流水线 (3 次) → 时空图 + 冲突
9. 浮点 (3 次) → IEEE754 + 对阶
