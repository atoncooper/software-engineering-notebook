# 附录 B:易混淆概念对照表

> 全科目易混淆点汇总,冲刺期对照复习。

## B.1 数据结构

| 易混点 | 辨析 |
|--------|------|
| 度 m 的树 vs m 叉树 | 前者必含度 m 节点;后者不要求 |
| 满二叉树 vs 完全二叉树 | 满必完全,完全未必满 |
| 树深 vs 树高 | 教材定义不同,看上下文 |
| 头指针 vs 头结点 | 头指针必有;头结点可选 |
| 头插法 vs 尾插法 | 头插逆序,尾插保序 |
| 顺序表 vs 数组 | 数组是物理实现,顺序表是逻辑结构 |
| 链表插入 O(1) vs O(n) | 仅改指针 O(1),含查找 O(n) |
| 双链表删自身 vs 单链表 | 双链表 O(1),单链表需前驱 |
| 先序+后序 | 不能唯一重建二叉树 |
| 直接前驱 vs 直接后继 | 前驱=左子树最右;后继=右子树最左 |
| 哈夫曼编码不唯一 | 左右可换、0/1 可换,但 WPL 唯一 |
| B 树 vs B+ 树 | B 关键字内部+叶子;B+ 只在叶子 |
| B 树根 vs 内部节点 | 根至少 2 子树,内部至少 ⌈m/2⌉ |
| 成功 vs 失败 ASL | 分母不同 (n vs m) |
| 线性 vs 平方探测 | 平方减少聚集但不能探查全表 |
| 链地址 α | 可 > 1;开放定址 α < 1 |
| 稳定 vs 不稳定排序 | "快选希堆"不稳定 |
| 大根堆 vs 升序 | 排序升序用大根堆 |
| 基数 vs 比较 | 基数不比较,突破下界 |
| 外排序 vs 内排序 | 外排序关注 I/O,趟数 = ⌈log_k r⌉ |

## B.2 计算机组成原理

| 易混点 | 辨析 |
|--------|------|
| 原码 vs 补码范围 | 补码多一个最小负数 |
| 移码 vs 补码 | 符号位相反,数值位同 |
| IEEE 754 规格化 vs 非规格化 | 前者隐藏 1,阶 1~254;后者 0.M,阶 1-Bias |
| 海明码 vs CRC | 海明纠 1 检 2;CRC 只检错 |
| 先行进位 vs 串行进位 | 前者并行 O(1);后者 O(n) |
| 单符号位 vs 双符号位 | 运算器用双,存储用单 |
| SRAM vs DRAM | SRAM 触发器不刷新;DRAM 电容刷新 |
| 集中刷新 vs 分散刷新 vs 异步刷新 | 异步最常用,无死时间 |
| 直接映射 vs 全相联 vs 组相联 | 直接块冲突严重;全相联复杂;组相联折中 |
| 全写法 vs 写回法 | 全写带宽高;写回需脏位 |
| 写分配 vs 不按写分配 | 写分配调入 Cache;不按写分配直接写主存 |
| TLB 缺失 vs 缺页 | TLB 缺失未必缺页;缺页必磁盘 I/O |
| Cache 缺失 vs TLB 缺失 | Cache 缺失访问主存;TLB 缺失访问页表 |
| 硬布线 vs 微程序 | 硬布线快;微程序灵活 |
| 水平型 vs 垂直型微指令 | 水平并行度高;垂直像机器指令 |
| 流水线三冲突 | 结构/数据/控制 |
| RAW vs WAR vs WAW | RAW 真相关,最常见 |
| 中断 vs 异常 | 外/异步 vs 内/同步 |
| DMA vs 中断 | DMA 直接访存,优先级高 |
| 独立编址 vs 统一编址 | 独立需 I/O 指令;统一用访存 |
| CISC vs RISC | CISC 微程序变长;RISC 硬布线定长 |

## B.3 操作系统

| 易混点 | 辨析 |
|--------|------|
| 进程 vs 程序 | 进程动态;程序静态 |
| 进程 vs 线程 | 进程资源单位;线程调度单位 |
| PCB vs FCB | PCB 管进程;FCB 管文件 |
| 五态无 阻塞→运行 | 必须先就绪 |
| 用户级 vs 内核级线程 | 用户级单进程并发;内核级可并行 |
| 管道 vs 消息队列 | 管道字节流;消息队列结构化 |
| 同步 vs 互斥 | 同步有先后;互斥排他 |
| 临界区四条件 | 空闲让进/忙则等待/有限等待/让权等待 |
| 让权等待违反者 | TSL、Peterson、整型信号量 |
| P 顺序 | 先同步,后互斥 |
| 记录型 value<0 | \|value\| = 等待进程数 |
| 死锁 vs 饥饿 | 死锁四条件;饥饿未必死锁 |
| 安全 vs 不安全 | 安全必不死锁;不安全未必死锁 |
| 银行家 vs 死锁检测 | 银行家事前;检测事后 |
| 动态重定位 vs 静态 | 动态运行时;静态装入时 |
| 分页 vs 分段 | 分页内部碎片;分段外部碎片 |
| TLB 命中访存 | 1 次 |
| 二级页表访存 | 3 次 |
| OPT vs FIFO vs LRU | OPT 不可实现;FIFO Belady;LRU 栈式 |
| Belady 异常 | FIFO 独有 |
| 硬链接 vs 软链接 | 硬链接共享 inode;软链接路径 |
| 连续 vs 链接 vs 索引 | 连续外部碎片;链接随机慢;索引 inode |
| 位示图 vs 空闲链 | 位示图位;空闲链块 |
| 单缓冲 vs 双缓冲 | 单 max+拷贝;双 max |
| SCAN vs LOOK | SCAN 到端;LOOK 到最远请求 |
| C-SCAN vs C-LOOK | 反向不服务 |
| SPOOLing | 独占变共享 (打印机) |

## B.4 计算机网络

| 易混点 | 辨析 |
|--------|------|
| OSI vs TCP/IP vs 五层 | OSI 7 层;TCP/IP 4 层;教材 5 层 |
| 协议 vs 服务 | 协议水平;服务垂直 |
| 表示层 vs 会话层 | 表示格式加密;会话管理 |
| PDU 各层 | 报文/段/包/帧/比特 |
| 并发 vs 并行 | 同时间段 vs 同时刻 |
| 奈奎斯特 vs 香农 | 无噪声 vs 有噪声 |
| 曼彻斯特 vs 差分曼彻斯特 | 中间跳变;边界跳=0 |
| 集线器 vs 交换机 vs 路由器 | 集线器不隔离;交换机隔离冲突;路由器都隔离 |
| 冲突域 vs 广播域 | 交换机隔离冲突不隔离广播 |
| CSMA/CD vs CSMA/CA | CD 有线边发边听;CA 无线 RTS/CTS |
| GBN vs SR | GBN 累计回退 N;SR 选择重传 |
| GBN 窗口 | $W_S \leq 2^n - 1$ |
| SR 窗口 | $W_S + W_R \leq 2^n$ |
| ARP 请求 vs 应答 | 广播请求;单播应答 |
| DHCP vs DHCP 中继 | 跨网段需中继 |
| RIP vs OSPF vs BGP | RIP 距离向量 UDP;OSPF 链路状态 IP;BGP 路径向量 TCP |
| IPv4 vs IPv6 | 32 位 vs 128 位 |
| 三次握手 vs 四次挥手 | 防旧 SYN;全双工独立关 |
| TIME_WAIT vs CLOSE_WAIT | TIME_WAIT 主动方等 2MSL;CLOSE_WAIT 被动方等应用 close |
| 快重传 vs 快恢复 | 3 重复 ACK;不回 1 回 ssthresh |
| 慢开始 vs 拥塞避免 | 指数 vs 线性 |
| UDP vs TCP | 无连接 vs 面向连接;报文 vs 字节流 |
| DNS 递归 vs 迭代 | 主机-本地递归;本地-根迭代 |
| SMTP vs POP3 | 推 vs 拉 |
| HTTP 1.0 vs 1.1 vs 2.0 | 非持久;持久;多路复用 |
| FTP 控制 vs 数据 | 21 vs 20 (主动) |
