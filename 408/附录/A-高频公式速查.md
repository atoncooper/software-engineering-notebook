# 附录 A:高频公式速查

> 全科目公式汇总,冲刺期默写清单。

---

## A.1 数据结构

| 公式 | 含义 |
|------|------|
| $n_0 = n_2 + 1$ | 二叉树叶子数 = 度 2 节点数 + 1 |
| 完全二叉树深度 | $\lfloor \log_2 n \rfloor + 1$ |
| n 节点二叉链表空指针 | $n + 1$ |
| 哈夫曼节点数 | $2n - 1$ (n 叶子) |
| 哈夫曼 WPL | 非叶节点权值之和 |
| 折半判定树深度 | $\lfloor \log_2 n \rfloor + 1$ |
| B 树非根关键字数 | $\lceil m/2 \rceil - 1$ ~ $m - 1$ |
| 顺序表插入平均移动 | $n/2$ |
| 顺序表删除平均移动 | $(n-1)/2$ |
| 循环队列队长 | $(rear - front + M) \% M$ |
| Catalan 数 | $C_n = \binom{2n}{n} / (n+1)$ |
| 流水线加速比 | $S = nk / (k+n-1)$ |

## A.2 计算机组成原理

| 公式 | 含义 |
|------|------|
| CPU 时间 | $IC \times CPI \times T$ |
| MIPS | $f / (CPI \times 10^6)$ |
| Amdahl 加速比 | $S = 1 / ((1-f) + f/r)$ |
| 海明码校验位 | $2^r \geq k + r + 1$ |
| 补码范围 (n位) | $-2^{n-1}$ ~ $2^{n-1} - 1$ |
| 移码定义 | $2^{n-1} + x$ |
| IEEE 754 规格化 | $(-1)^S \cdot 1.M \cdot 2^{E - 127}$ |
| 非规格化阶码 | $1 - Bias$ |
| Cache 平均访问时间 | $h \cdot t_c + (1-h)(t_c + t_m)$ |
| Cache 行内地址 | $\log_2(\text{行大小})$ |
| 先行进位 | $C_{i+1} = G_i + P_i C_i$ |
| 流水线加速比 | $nk / (k+n-1)$ |
| 总线带宽 | 频率 × 位宽 / 8 |

## A.3 操作系统

| 公式 | 含义 |
|------|------|
| 周转时间 | 完成 - 提交 |
| 带权周转 | 周转 / 服务时间 ≥ 1 |
| HRRN 响应比 | $R = 1 + 等待/服务$ |
| Need | $Max - Allocation$ |
| 页表访存 (无 TLB) | 2 次 |
| 二级页表访存 | 3 次 |
| 段页式访存 | 3 次 |
| 缺页率 | 缺页次数 / 总访问 |
| OPT | 不可实现,理论下界 |
| Belady 异常 | FIFO 独有 |
| 单缓冲吞吐量 | $1 / \max(T_c, T_t) + T_{copy}$ |
| 双缓冲吞吐量 | $1 / \max(T_c, T_t)$ |
| 磁盘访问时间 | 寻道 + 旋转 + 传输 |

## A.4 计算机网络

| 公式 | 含义 |
|------|------|
| 奈奎斯特 | $C = 2W \log_2 V$ |
| 香农 | $C = W \log_2(1 + S/N)$ |
| SNR (dB) | $10 \log_{10}(S/N)$ |
| CSMA/CD 最小帧 | $2\tau \cdot C$ |
| 以太网最小帧 | 64 字节 |
| 以太网 MTU | 1500 字节 |
| 802.1Q 标签 | 4 字节 |
| GBN 发送窗口 | $W_S \leq 2^n - 1$ |
| SR 窗口 | $W_S + W_R \leq 2^n$ |
| TCP 发送窗口 | $\min(cwnd, rwnd)$ |
| IPv4 首部固定 | 20 字节 |
| IPv6 首部固定 | 40 字节 |
| MAC 地址 | 48 位 |
| IPv4 地址 | 32 位 |
| IPv6 地址 | 128 位 |
