## 3. 命题规律

### 3.1 综合题分布

- **数据结构**:链表、树、图、散列轮流,算法题为主。
- **计组**:Cache、流水线、浮点三大块轮换。
- **操作系统**:PV 操作几乎每年必考;虚拟内存、磁盘调度次之。
- **网络**:TCP/子网/路由表为三大热点。

### 3.2 选择题热点

- 数据结构:性质 (n0=n2+1)、复杂度、稳定性。
- 计组:寻址方式、IEEE754、Cache 映射。
- 操作系统:状态转换、调度算法、置换算法。
- 网络:协议端口、子网计算、TCP 状态。

### 3.3 命题趋势

1. **综合化**:一题跨多章 (Cache+TLB+虚存)。
2. **代码化**:算法题越来越严 C 语法。
3. **场景化**:网络与 OS 题给真实场景。
4. **细节化**:选择题抠教材边角。

## 4. 复习优先级

### 4.1 第一优先 (最高频 + 高分值)

- 数据结构:树、图、排序、查找
- 计组:Cache、流水线、浮点
- 操作系统:PV、虚拟内存
- 网络:子网、TCP、路由

### 4.2 第二优先 (中频)

- 数据结构:链表、栈队列
- 计组:CPU、I/O
- 操作系统:进程线程、死锁
- 网络:链路层、应用层

### 4.3 第三优先 (低频但易得分)

- 计组:总线、概述
- 操作系统:概述、文件
- 网络:物理层、体系结构
