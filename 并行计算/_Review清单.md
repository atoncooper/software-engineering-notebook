# Review 清单 · 并行计算

> 单章 review 与全仓 review 的 checklist。

---

## 1. 单章 Review Checklist

完成每章后逐项检查：

### 1.1 结构完整性
- [ ] 十二节结构齐全（思维导图 → 问题定义 → 概念 → 原理 → 算法 → 工业对照 → 代码 → 陷阱 → 关系 → 面试速答 → 综合题 → 参考）
- [ ] 思维导图 ASCII 清晰、与正文一致
- [ ] 每节有小结或过渡

### 1.2 内容准确性
- [ ] 复杂度推导无错（$W$ / $C$ / $D$）
- [ ] 论文/基准引用准确（HPL/MLPerf/Top500）
- [ ] 硬件参数正确（H100/A100/MI300X/昇腾带宽/算力）
- [ ] 标记符号使用符合 [_标记规范.md](_标记规范.md)

### 1.3 工程化视角
- [ ] 工业实现对照表覆盖 NVIDIA / AMD / 国产
- [ ] 代码示例含可运行最小版 + 生产级版
- [ ] 生产级示例含错误检查 / 事件计时 / 调优参数
- [ ] 陷阱表覆盖常见误用、性能反模式

### 1.4 面试导向
- [ ] 面试速答表覆盖 8+ 高频问题
- [ ] 综合面试题 5+ 题，含答题要点
- [ ] 由浅入深排序

### 1.5 引用与链接
- [ ] 参考/延伸章节引用权威论文、基准、工具
- [ ] 跨文件链接使用相对路径
- [ ] 外部链接在脚注或参考节，不在正文嵌入

### 1.6 可读性
- [ ] 表格仅用于对比，非滥用
- [ ] ASCII 图优先于冗长文字
- [ ] 公式编号清晰
- [ ] 中英术语对照首次出现处提供

---

## 2. 全仓 Review Checklist

整仓 review 时检查：

### 2.1 一致性
- [ ] 符号统一（见 [_符号约定.md](_符号约定.md)）
- [ ] 术语统一（见 [_术语表.md](_术语表.md)）
- [ ] 标记使用统一（见 [_标记规范.md](_标记规范.md)）
- [ ] 章节编号连续无跳号
- [ ] 状态图例与实际完成度一致

### 2.2 覆盖度
- [ ] §1-§22 核心主题无遗漏
- [ ] 体系结构 / 编程模型 / 算法 / 通信 / 工业实战 各板块完整
- [ ] NVIDIA / AMD / 国产硬件在各章节均有对照
- [ ] 千卡训练案例覆盖近 3 年主流大模型

### 2.3 交叉引用
- [ ] 相关章节相互链接
- [ ] 与仓库其他子项目（分布式系统/深度学习/LLM/机器学习）的关联章节已链接
- [ ] 无死链

### 2.4 时效性
- [ ] MLPerf / Top500 引用为最新版本
- [ ] GPU 参数为最新一代（H100/B200/MI300X/昇腾 910B/C）
- [ ] 论文清单覆盖近 3 年关键工作（FSDP / Ring-Attention / DeepSeek-EP）

### 2.5 可维护性
- [ ] 每章 600-1200 行（与分布式系统项目对齐）
- [ ] 大章节拆分为多文件
- [ ] README 导航表与实际文件一致

---

## 3. Review 流程

```
1. 作者自检（按 §1 单章 Checklist）
2. 交叉检查（按 §2 全仓 Checklist 抽样 3 章）
3. 时效性更新（每季度检查硬件/基准变更）
4. 工业案例库每半年补充新大模型训练数据
```
