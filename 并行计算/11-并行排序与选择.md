## 一、问题定义

### 1.1 解决什么问题

排序是数据库、搜索引擎、推荐系统、数据分析的核心算子。并行排序的挑战:
- 比较排序串行下界 $O(n\log n)$,并行下界 $O(\log n)$ 深度;
- 不同分布(均匀/偏斜)适用不同算法;
- GPU/CPU/分布式各自最优算法不同。

### 1.2 应用场景

| 场景 | 推荐算法 |
|------|----------|
| 单机多核 | 并行归并、Sample Sort |
| GPU | Bitonic、Radix |
| 分布式 | Sample Sort、TeraSort |
| 流式 | Merge Tree |
| Top-K | 堆 + 并行规约 |

## 三、原理与机制

### 3.1 比较排序下界 🎓

- **Work 下界**:$W = \Omega(n\log n)$(决策树叶子数 $\geq n!$);
- **Depth 下界**:$D = \Omega(\log n)$(每次比较信息量 1 bit,需 $\log n$ 比较区分一个元素的位置)。

🔥 **理想并行**:$T_P = W/P = (n\log n)/P$,$P=n$ 时 $T = \log n$。

### 3.2 并行归并排序 📜

串行归并:$W = O(n\log n)$,$D = O(n)$(归并串行)。

**并行化**:
- 分治:两半并行排序(递归并行);
- 归并:用**并行归并**($O(\log n)$ 深度)。

```
parallel_merge_sort(A):
    if |A| <= base: serial_sort(A); return
    parallel:
        left = parallel_merge_sort(A[:mid])
        right = parallel_merge_sort(A[mid:])
    parallel_merge(left, right, A)
```

**并行归并**(Cole 1988):
- 找两序列的中位数 $a_m, b_m$;
- 比较 $a_m, b_m$,确定分界;
- 递归合并两半,$D = O(\log n)$。

**复杂度**:
- $W = O(n\log n)$;
- $D = O(\log^2 n)$(每层归并 $O(\log n)$);
- $\Phi = n/\log n$。

### 3.3 Sample Sort 📜🔥

**桶排序的并行版**,适合分布式/GPU。

```
sample_sort(A, P):
    1. 各处理器从本地数据抽 $s$ 个样本
    2. AllGather 所有样本 → 全局样本集 $S$
    3. 排序 $S$,选 $P-1$ 个 splitter 等分 $S$
    4. Broadcast splitters
    5. 各处理器按 splitters 把本地数据分到 $P$ 个桶
    6. All-to-All:每处理器把桶 $i$ 发给处理器 $i$
    7. 各处理器本地排序收到的桶
```

**复杂度**:
- 计算:$O((n/P)\log(n/P))$(本地排序);
- 通信:$O(n/P)$(All-to-All);
- 适合大 $n$,$P$ 不极大。

🔥 **Hadoop TeraSort / Spark sort** 都是 Sample Sort 变体。

### 3.4 Bitonic Sort 📜🎓

**Bitonic 序列**:先增后减(或循环移位后)。
```
[1,3,5,7,6,4,2,0]  ← 先增后减,Bitonic
```

**Bitonic Merge**:把 Bitonic 序列排序。
```
bitonic_merge(A):
    # A 是 Bitonic,长度 n
    for i in 0..n/2-1:
        if A[i] > A[i+n/2]: swap(A[i], A[i+n/2])
    # 现在前半 < 后半,各自 Bitonic
    parallel: bitonic_merge(A[:n/2]); bitonic_merge(A[n/2:])
```

**Bitonic Sort**:递归构造 Bitonic 序列再合并。
```
bitonic_sort(A):
    if |A| == 1: return
    bitonic_sort(A[:n/2])        # 升序
    bitonic_sort(A[n/2:], desc=True)  # 降序
    # 现在 A 是 Bitonic(前半升后半降)
    bitonic_merge(A)
```

**复杂度**:
- $W = O(n\log^2 n)$(每层 $O(n\log n)$,共 $\log n$ 层);
- $D = O(\log^2 n)$(每层 $O(\log n)$);
- $\Phi = n$。

🔥 **优势**:
- **数据无关**(比较模式固定)→ 适合 GPU/SIMD;
- **排序网络**(可硬件化);
- 深度 $O(\log^2 n)$ 接近下界 $O(\log n)$。

**劣势**:$W = O(n\log^2 n)$ 比归并的 $O(n\log n)$ 多一个 $\log$。

### 3.5 并行 Radix 排序 🎓

按位(基 $r$)排序,从低位到高位(LSD)或高位到低位(MSD)。

```
radix_sort(A, bits=32, r=8):  # 8-bit 基
    for offset in 0, 8, 16, 24:
        # 按第 offset 位排序
        count = histogram(A, offset, r=256)
        prefix = exclusive_scan(count)
        scatter(A, prefix, offset)
```

**并行化**:
- **Histogram**:每线程统计本地桶;
- **Exclusive Scan**:Blelloch 并行 scan(见 §3);
- **Scatter**:按 prefix 并行写。

**复杂度**:
- $W = O(n \cdot \text{bits}/\log r)$;
- $D = O(\text{bits}/\log r \cdot \log n)$;
- 适合 GPU(无分支、规则访存)。

🔥 **cuSTL/Thrust `sort`** 默认用 Radix(整数)或 Merge(浮点)。

### 3.6 Top-K 选择 🎓

找前 K 大/小元素,不必全排序。

**串行**:Quickselect 平均 $O(n)$,堆 $O(n\log K)$。

**并行 Top-K**:
1. 各线程本地 Top-K(堆);
2. 归约所有本地 Top-K(树形 merge)。

```
parallel_topk(A, K):
    parallel:
        local_topk = heap_k(A[my_range], K)
    # 树形 merge
    while P > 1:
        parallel:
            merged = merge(local_topk_i, local_topk_{i+1})
            local_topk_i = topk(merged, K)
        P /= 2
    return local_topk_0
```

**复杂度**:$O((n/P)\log K + \log P \cdot K\log K)$。

## 四、算法 / 流程

### 4.1 选型决策

```
数据规模?
├─ 单机小(n<1M)→ std::sort(已优化)
├─ 单机大→ 并行归并 / OpenMP task
├─ GPU→ Bitonic(教学)/ Radix(生产,整数)/ Merge(浮点)
├─ 分布式→ Sample Sort
└─ 流式→ Merge Tree

数据类型?
├─ 整数→ Radix(无分支,快)
├─ 浮点→ Merge / Bitonic
└─ 字符串→ Sample Sort + 本地快排

K 选择?
├─ K 小→ Quickselect
├─ K 中→ nth_element
└─ Top-K 流→ 堆 + 并行归约
```

### 4.2 Sample Sort 通信流程

```
1. 各 rank 本地抽样 s 个 → [s*P] 个样本
2. AllGather → 全局样本
3. 排序样本,选 P-1 个 splitter
4. Bcast splitters
5. 各 rank 把本地数据按 splitters 分 P 桶
6. Alltoall:桶 i 发给 rank i
7. 各 rank 本地排序
```

## 六、代码示例

### 6.1 最小可运行版(教学):OpenMP 并行归并排序

```cpp
// file: parallel_merge_sort.cpp
// 编译: g++ -O3 -fopenmp parallel_merge_sort.cpp -o pms
#include <vector>
#include <algorithm>
#include <cstdio>
#include <omp.h>

void merge(int* a, int lo, int mid, int hi, int* tmp) {
    int i = lo, j = mid, k = lo;
    while (i < mid && j < hi)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i < mid) tmp[k++] = a[i++];
    while (j < hi) tmp[k++] = a[j++];
    for (int t = lo; t < hi; ++t) a[t] = tmp[t];
}

void merge_sort(int* a, int lo, int hi, int* tmp, int depth) {
    if (hi - lo < 1000) {
        std::sort(a + lo, a + hi);
        return;
    }
    int mid = lo + (hi - lo) / 2;
    if (depth < 4) {
        #pragma omp task shared(a, tmp)
        merge_sort(a, lo, mid, tmp, depth + 1);
        #pragma omp task shared(a, tmp)
        merge_sort(a, mid, hi, tmp, depth + 1);
        #pragma omp taskwait
    } else {
        merge_sort(a, lo, mid, tmp, depth + 1);
        merge_sort(a, mid, hi, tmp, depth + 1);
    }
    merge(a, lo, mid, hi, tmp);
}

int main() {
    const int n = 1 << 22;
    std::vector<int> a(n), tmp(n);
    for (int i = 0; i < n; ++i) a[i] = (i * 16807) % n;
    
    double t0 = omp_get_wtime();
    #pragma omp parallel
    {
        #pragma omp single
        merge_sort(a.data(), 0, n, tmp.data(), 0);
    }
    double t1 = omp_get_wtime();
    
    printf("n=%d sorted=%d time=%.2fms threads=%d\n",
           n, std::is_sorted(a.begin(), a.end()), (t1-t0)*1000,
           omp_get_max_threads());
    return 0;
}
```

### 6.2 手把手:CUDA Bitonic Sort

```cpp
// file: bitonic_sort.cu
// 编译: nvcc -O3 -arch=sm_80 bitonic_sort.cu -o bs
#include <cuda_runtime.h>
#include <cstdio>
#include <vector>

#define CK(x) do { auto _e=(x); if(_e!=cudaSuccess){printf("err\n");exit(1);}} while(0)

// Bitonic Sort kernel(单次比较+交换)
__global__ void bitonic_step(int* a, int j, int k, int n) {
    int i = threadIdx.x + blockIdx.x * blockDim.x;
    int ixj = i ^ j;
    if (i < ixj && ixj < n) {
        bool ascending = ((i & k) == 0);
        if ((a[i] > a[ixj]) == ascending) {
            int t = a[i]; a[i] = a[ixj]; a[ixj] = t;
        }
    }
}

int main() {
    const int N = 1 << 20;  // 必须 2 的幂
    std::vector<int> h_a(N);
    for (int i = 0; i < N; ++i) h_a[i] = (i * 16807) % N;
    
    int *d_a;
    CK(cudaMalloc(&d_a, N * sizeof(int)));
    CK(cudaMemcpy(d_a, h_a.data(), N*sizeof(int), cudaMemcpyHostToDevice));
    
    int block = 256;
    int grid = (N + block - 1) / block;
    
    cudaEvent_t s, e; cudaEventCreate(&s); cudaEventCreate(&e);
    cudaEventRecord(s);
    
    // Bitonic Sort: k 是当前 bitonic 块大小,j 是 merge 步长
    for (int k = 2; k <= N; k <<= 1) {
        for (int j = k >> 1; j > 0; j >>= 1) {
            bitonic_step<<<grid, block>>>(d_a, j, k, N);
        }
    }
    
    cudaEventRecord(e); CK(cudaDeviceSynchronize());
    float ms = 0; cudaEventElapsedTime(&ms, s, e);
    
    CK(cudaMemcpy(h_a.data(), d_a, N*sizeof(int), cudaMemcpyDeviceToHost));
    bool ok = std::is_sorted(h_a.begin(), h_a.end());
    printf("N=%d sorted=%d time=%.2fms\n", N, ok, ms);
    
    CK(cudaFree(d_a));
    return 0;
}
```

🔥 **Bitonic Sort GPU 要点**:
- 数据无关 → 完美 SIMD;
- 每步一次比较交换,无分支;
- 总步数 $O(\log^2 N)$,每步 $O(N)$ 工作;
- 实测比 thrust::sort 慢(因 Radix 更适合 GPU),但教学价值高。

### 6.3 手把手:MPI Sample Sort

```cpp
// file: sample_sort_mpi.cpp
// 编译: mpicxx -O3 sample_sort_mpi.cpp -o ss
// 运行: mpirun -np 4 ./ss 1000000
#include <mpi.h>
#include <vector>
#include <algorithm>
#include <random>
#include <cstdio>
#include <cstdlib>

int main(int argc, char** argv) {
    MPI_Init(&argc, &argv);
    int rank, P;
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &P);
    
    int N = argc > 1 ? atoi(argv[1]) : 1000000;
    int local_n = N / P;
    
    // 1. 各 rank 生成本地数据
    std::vector<int> local(local_n);
    std::mt19937 rng(42 + rank);
    for (int i = 0; i < local_n; ++i) local[i] = rng() % 1000000;
    
    double t0 = MPI_Wtime();
    
    // 2. 各 rank 抽 s 个样本
    int s = 10 * P;  // 过采样
    std::vector<int> samples(s);
    for (int i = 0; i < s; ++i) samples[i] = local[rng() % local_n];
    
    // 3. AllGather 所有样本
    std::vector<int> all_samples(s * P);
    MPI_Allgather(samples.data(), s, MPI_INT,
                  all_samples.data(), s, MPI_INT, MPI_COMM_WORLD);
    
    // 4. 排序样本,选 P-1 个 splitter
    std::sort(all_samples.begin(), all_samples.end());
    std::vector<int> splitters(P - 1);
    for (int i = 0; i < P - 1; ++i)
        splitters[i] = all_samples[(i + 1) * s];
    
    // 5. 各 rank 按 splitter 分桶
    std::vector<std::vector<int>> buckets(P);
    for (int x : local) {
        int b = std::upper_bound(splitters.begin(), splitters.end(), x)
                - splitters.begin();
        buckets[b].push_back(x);
    }
    
    // 6. Alltoall:准备发送大小
    std::vector<int> send_counts(P), recv_counts(P);
    for (int i = 0; i < P; ++i) send_counts[i] = buckets[i].size();
    MPI_Alltoall(send_counts.data(), 1, MPI_INT,
                 recv_counts.data(), 1, MPI_INT, MPI_COMM_WORLD);
    
    // 7. Alltoallv:发送桶数据
    std::vector<int> send_displ(P), recv_displ(P);
    send_displ[0] = recv_displ[0] = 0;
    for (int i = 1; i < P; ++i) {
        send_displ[i] = send_displ[i-1] + send_counts[i-1];
        recv_displ[i] = recv_displ[i-1] + recv_counts[i-1];
    }
    int total_recv = recv_displ[P-1] + recv_counts[P-1];
    std::vector<int> send_buf, recv_buf(total_recv);
    for (int i = 0; i < P; ++i)
        for (int x : buckets[i]) send_buf.push_back(x);
    
    MPI_Alltoallv(send_buf.data(), send_counts.data(), send_displ.data(),
                  MPI_INT, recv_buf.data(), recv_counts.data(),
                  recv_displ.data(), MPI_INT, MPI_COMM_WORLD);
    
    // 8. 各 rank 本地排序
    std::sort(recv_buf.begin(), recv_buf.end());
    
    double t1 = MPI_Wtime();
    
    // 验证:各 rank 内部有序,且 max(rank i) < min(rank i+1)
    int local_max = recv_buf.empty() ? -1 : recv_buf.back();
    int local_min = recv_buf.empty() ? -1 : recv_buf.front();
    std::vector<int> all_max, all_min;
    if (rank == 0) { all_max.resize(P); all_min.resize(P); }
    MPI_Gather(&local_max, 1, MPI_INT, all_max.data(), 1, MPI_INT, 0, MPI_COMM_WORLD);
    MPI_Gather(&local_min, 1, MPI_INT, all_min.data(), 1, MPI_INT, 0, MPI_COMM_WORLD);
    
    if (rank == 0) {
        bool ok = true;
        for (int i = 0; i < P - 1; ++i)
            if (all_max[i] > all_min[i+1]) { ok = false; break; }
        printf("Sample Sort N=%d P=%d time=%.3fs valid=%d\n",
               N, P, t1-t0, ok);
    }
    
    MPI_Finalize();
    return 0;
}
```

🔥 **Sample Sort 要点**:
- 抽样过采样($10P$ 个)保证 splitter 均匀;
- Alltoall 是通信瓶颈(不规则);
- 各 rank 收到的数据范围不重叠 → 全局有序。

### 6.4 手把手:并行 Top-K

```cpp
// file: topk.cpp
// 编译: g++ -O3 -fopenmp topk.cpp -o tk
#include <vector>
#include <queue>
#include <random>
#include <algorithm>
#include <cstdio>
#include <omp.h>

int main() {
    const int N = 10'000'000;
    const int K = 100;
    
    std::vector<int> data(N);
    std::mt19937 rng(42);
    for (int i = 0; i < N; ++i) data[i] = rng();
    
    double t0 = omp_get_wtime();
    
    // 各线程本地 Top-K
    int T = omp_get_max_threads();
    std::vector<std::priority_queue<int, std::vector<int>, std::greater<>>>
        local_topk(T);
    
    #pragma omp parallel
    {
        int tid = omp_get_thread_num();
        auto& heap = local_topk[tid];
        
        #pragma omp for schedule(static)
        for (int i = 0; i < N; ++i) {
            if ((int)heap.size() < K) heap.push(data[i]);
            else if (data[i] > heap.top()) {
                heap.pop();
                heap.push(data[i]);
            }
        }
    }
    
    // 归约所有本地 Top-K
    std::priority_queue<int, std::vector<int>, std::greater<>> global_topk;
    for (auto& h : local_topk) {
        while (!h.empty()) {
            if ((int)global_topk.size() < K) global_topk.push(h.top());
            else if (h.top() > global_topk.top()) {
                global_topk.pop();
                global_topk.push(h.top());
            }
            h.pop();
        }
    }
    
    double t1 = omp_get_wtime();
    
    // 验证
    std::vector<int> sorted(N);
    std::copy(data.begin(), data.end(), sorted.begin());
    std::sort(sorted.begin(), sorted.end(), std::greater<int>());
    int true_top = sorted[K - 1];
    int got_top = global_topk.top();
    
    printf("Top-%d: time=%.2fms valid=%d (got_min=%d true_min=%d)\n",
           K, (t1-t0)*1000, got_top == true_top, got_top, true_top);
    return 0;
}
```

## 七、常见陷阱与最佳实践 ⚠️

| 陷阱 | 后果 | 对策 |
|------|------|------|
| Bitonic 用于非 2 的幂 N | 越界 | padding 到 2 的幂 |
| Sample Sort 过采样不足 | 桶不均 | $s \geq 10P$ |
| Alltoall 不规则 | 通信瓶颈 | 用 Alltoallv + 计数前置 |
| Radix 基太大 | 共享内存溢出 | $r=8$ 位起步 |
| Top-K 用全排序 | 浪费 | 用堆或 nth_element |
| GPU 用比较排序 | 慢 | 整数用 Radix |
| 归并排序无深度阈值 | task 爆炸 | 设 depth 转串行 |
| 并行归并非最优 | 深度 $O(n)$ | 用 Cole 并行归并 $O(\log n)$ |
| 忽视数据分布 | 偏斜致桶不均 | Sample Sort + 过采样 |
| 字符串用 Radix | 复杂 | 用 Sample Sort |

## 十、综合面试题

1. **基础**:为什么 Bitonic Sort 适合 GPU 而快排不适合?
   - 答:Bitonic 数据无关(比较模式固定),无分支发散,访存规则。快排分支依赖数据(pivot),导致 warp divergence + 不规则访存,GPU 效率低。

2. **进阶**:1TB 数据在 1000 节点上排序,选什么算法?通信量多少?
   - 答:Sample Sort。每节点 1GB 数据,抽 $s=10000$ 样本,AllGather 10MB(小)。Alltoall 1GB/节点(每节点发 1GB 给 1000 节点,各 1MB)。本地排序 $O((n/P)\log(n/P))$。通信量 $O(n/P)$,接近下界。

3. **深度**:证明 Bitonic Merge 的正确性(0-1 原理)。
   - 答:0-1 原理:若排序网络对所有 0/1 序列正确,则对任意序列正确。Bitonic Merge 输入是 Bitonic 0/1 序列(形如 00..011..100..0)。第一步比较 $i$ 与 $i+n/2$:前半全 0 后半全 1 时,所有比较不交换,得前半 0 后半 1;前半全 1 后半全 0 时,全交换,得前半 0 后半 1;混合时,前半 min 后半 max,递归可证。故 Bitonic Merge 正确。

4. **设计**:设计一个 GPU Top-K 算法,处理 1 亿元素取 Top-100。
   - 答:(1) 每 block 用共享内存堆维护本地 Top-K(100);(2) 扫描所有元素,堆插入;(3) block 间归约:每 block 输出 100,全局 100*blockCount 个;(4) 第二轮 kernel 再取 Top-100。复杂度 $O(N/B + B\log K)$,$B$=block 数。

5. **工程**:Spark 的 sortByKey 为什么比 collect + sort 快?
   - 答:(1) Range Partitioning(Sample Sort)把数据按 key 范围分到各节点,各节点内有序,全局即有序;(2) 无需 collect 到单机(避免单点瓶颈);(3) 各节点并行排序;(4) shuffle 时按范围,减少数据移动。

6. **学术**:比较并行归并($W=O(n\log n), D=O(\log^2 n)$)与 Bitonic($W=O(n\log^2 n), D=O(\log^2 n)$)的 Work-Delay 最优性。
   - 答:并行归并 $W$ 最优(达 $O(n\log n)$ 下界),但实现复杂。Bitonic $W$ 多一个 $\log$ 因子,但数据无关易硬件化。Cole 1988 给出 $W=O(n\log n), D=O(\log n)$ 的并行归并,达深度下界,但常数大,实际少用。工程上 Bitonic 在 GPU 更流行。
