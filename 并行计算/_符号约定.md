# 符号约定 · 并行计算

> 全仓统一数学 / 复杂度 / 通信 / 体系结构符号。

---

## 1. 通用

| 符号 | 含义 |
|------|------|
| $P$ | 处理器/进程/线程数（Parallelism degree） |
| $p_i$ | 第 $i$ 个处理器 |
| $n$ | 问题规模（输入大小） |
| $T_1$ | 串行运行时间（work） |
| $T_P$ | $P$ 个处理器并行运行时间 |
| $T_\infty$ | 无限处理器下的运行时间（span / critical path） |
| $S_P$ | 加速比 $S_P = T_1 / T_P$ |
| $E_P$ | 并行效率 $E_P = S_P / P$ |
| $f$ | 可并行占比 |
| $\pi$ | 峰值算力（ops/s） |
| $\beta$ | 峰值带宽（bytes/s） |
| $I$ | 算术强度（ops/byte） |
| $\hat{B}$ | 实测带宽 |
| $L$ | 通信延迟 |
| $g$ | 通信间隙（LogP） |
| $o$ | 通信开销（LogP） |

---

## 2. 复杂度三维

| 符号 | 含义 |
|------|------|
| $W$ | 工作（总操作数），$W = T_1$ |
| $D$ | 深度（关键路径长度），$D = T_\infty$ |
| $C$ | 通信复杂度（字节数或消息数） |
| $W/P$ | 理想并行时间下界 |
| $D$ | 并行时间下界（critical path） |

## 5. 通信与集合原语

| 符号 | 含义 |
|------|------|
| AllReduce | 全规约 |
| AllGather | 全收集 |
| ReduceScatter | 规约散射 |
| Broadcast | 广播 |
| $P$ | 参与进程数 |
| $\alpha$ | 启动延迟 |
| $\beta$ | 网络带宽 |
| $m$ | 消息大小（字节） |
| $T_{\text{ring}}(P, m)$ | Ring 算法时间 $= 2(P-1)\alpha + \frac{2(P-1)}{P}m\beta$ |
| $T_{\text{tree}}(P, m)$ | Tree 算法时间 $= 2\log_2 P \cdot \alpha + 2\log_2 P \cdot m\beta$ |

## 7. 性能模型

| 表达式 | 含义 |
|--------|------|
| $S_P = \frac{1}{(1-f)+f/P}$ | Amdahl 定律 |
| $S_P = P - \alpha(P-1)$ | Gustafson 定律 |
| $T_P \ge \max(T_1/P, T_\infty)$ | Work-Span 下界 |
| $\text{Attainable} = \min(\pi I, \beta I, \hat{B})$ | Roofline |
| $T_{\text{BSP}} = \sum_s (w_s + h_s g + L)$ | BSP 模型 |
