## 一、问题定义

### 1.1 解决什么问题 ⭐

- **规模痛点**：社交图(Facebook ~30亿点)、Web 图(千亿边)、知识图谱、GNN 训练中的邻居采样。单机内存装不下,单线程遍历几小时起步。
- **不规则访存**：图是稀疏非结构化数据,邻居表长度从 1 到 10^6 都有,cache 命中率低,内存延迟主导。
- **负载不均**：幂律图(power-law)下 1% 的点拥有 50% 的边,简单按点均分会导致严重倾斜。
- **同步密集**：BFS/SSSP 每层都要全局同步,迭代次数 = 图直径,小世界图直径 ~20,大规模同步开销巨大。

### 1.2 与传统串行方案的区别

| 维度 | 串行 (Dijkstra / Bellman-Ford) | 并行 |
|------|-------------------------------|------|
| 数据结构 | 优先队列 / 邻接表 | CSR + frontier + 分区 |
| 同步 | 隐式(算法串行推进) | 显式 BSP / 异步 |
| 负载均衡 | 单线程不涉及 | 必须显式处理(power-law) |
| 容错 | 进程崩=全部重算 | checkpoint + 子图重算 |
| 终止检测 | 单机局部 | 全局 reduce |

### 1.3 硬件/平台差异概述

| 平台 | 代表框架 | 适用图规模 | 特点 |
|------|---------|-----------|------|
| 共享内存多核 | Ligra, Galois, GraphChi(磁盘) | 10^8 边 | 编程简单,NUMA 是主要瓶颈 |
| GPU | Gunrock, CuGraph, GraphX-GPU | 10^9 边 | 适合 frontier 大的层,小 frontier 利用率低 |
| 分布式 CPU | Pregel, GraphX, PowerGraph, Gemini | 10^11 边 | 通信主导,partition 质量决定性能 |
| 分布式 GPU | DGX + NCCL 上的 GNN | 10^10 边 | 多机 Alltoall 邻居 |

## 三、原理与机制

### 3.1 直觉

图算法并行的本质:**把"点/边"作为并行单元**,而不是把"算法步骤"作为并行单元。BFS 的每一层、PageRank 的每一次迭代,都是一次对全体边/点的批量操作。难点不是算法本身,而是:

1. **访存不规则** —— 邻居表跨度大,预取失效。
2. **负载倾斜** —— hub 点处理 10^6 邻居,叶子点处理 1 个。
3. **通信放大** —— 边跨机器时,邻居信息要走网络。
4. **同步代价** —— BSP 每轮栅栏,异步难收敛性证明。

### 3.2 形式化定义 / 计算复杂度

**BFS(work-depth model):**
- $W = O(|V| + |E|)$ (每条边最多被一次 frontier 探查)
- $D = O(\text{diameter})$ (层数 = 直径)
- 并行度 $W/D \approx |E| / \text{diameter}$,小世界图直径 ~20,并行度极高。

**PageRank(BSP, $T$ 次迭代):**
$$
PR(v) = \frac{1-d}{N} + d \sum_{u \in N^{-}(v)} \frac{PR(u)}{\text{outdeg}(u)}
$$
- 每超步 $W = O(|E|)$,$C = O(|V|)$ (点值 broadcast)
- 总 $W = O(T \cdot |E|)$,$D = O(T)$

**SSSP(Bellman-Ford 并行):**
- $D = O(\text{diameter})$ 而非串行 $O(|V|)$
- $W = O(\text{diameter} \cdot |E|)$ 最坏

### 3.3 关键性质 ⭐

1. **方向优化(direction optimization)** 🔥:BFS/SSSP 可从"自顶向下"(扫 frontier 出边)切换到"自底向上"(扫未访问点的入边),后者在 frontier 大时省访存。Beamer 论文给出 3-5x 加速。
2. **幂律图的 hub 灾难**:一个 hub 点的邻居跨多机,导致每轮通信放大。PowerGraph 提出 vertex-cut 把 hub 切成多份。
3. **push vs pull**:push = 沿出边推值(写竞争);pull = 沿入边拉值(读竞争,但 cache 友好)。
4. **收敛性**:异步模型下 PageRank 收敛需要严格证明(Bertsekas-Tsitsiklis),BSP 自动满足。

## 四、算法 / 流程

### 4.1 并行 BFS(自顶向下 + 自底向上混合)🔥

```
Input: 图 G=(V,E), 源点 s
frontier = {s}, dist[s] = 0
while frontier not empty:
    if |frontier| < |V| / threshold:   # 小 frontier 用 top-down
        next = parallel_for v in frontier:
                 for u in neighbors_out(v):
                    if atomic_CAS(dist[u], INF, dist[v]+1):
                        next.add(u)
    else:                              # 大 frontier 用 bottom-up
        next = parallel_for v in unvisited:
                 for u in neighbors_in(v):
                    if u in frontier:
                        dist[v] = dist[u] + 1
                        next.add(v); break
    frontier = next
```

**复杂度**:$W = O(|V|+|E|)$,$D = O(\text{diameter})$。

### 4.2 PageRank(BSP, pull 模型)

```
repeat T times:
    parallel_for v in V:
        sum = 0
        for u in neighbors_in(v):
            sum += PR[u] / outdeg[u]
        new_PR[v] = (1-d)/N + d * sum
    PR = new_PR
    # 全局 reduce 检查 |new_PR - PR| < eps 提前退出
```

### 4.3 SSSP(Delta-Stepping)🎓

把边权按 $\Delta$ 分桶,松弛操作按桶顺序并行处理:

```
Bucket ← buckets indexed by floor(dist/Δ)
Bucket[0] = {s}
for i = 0, 1, 2, ...:
    while Bucket[i] not empty:
        Req = {(v, min edge from u in Bucket[i])}  # 重边取最小
        Bucket[i] = empty
        parallel_for (v, w) in Req: atomic_relax(dist[v], w)
        # 重新把更新的点放入对应桶
```

$\Delta$ 太小 → 桶多同步多;太大 → 退化为 Bellman-Ford。典型 $\Delta = \text{avg edge weight}$。

## 六、代码示例

### 6.1 MPI PageRank(教学版,CSR + pull)🔥

```cpp
// pagerank_mpi.cpp  — 编译: mpicxx -O3 -std=c++17 pagerank_mpi.cpp -o pr
// 运行:   mpirun -np 4 ./pr graph.mtx 100 1e-6
#include <mpi.h>
#include <cstdio>
#include <vector>
#include <cmath>
#include <fstream>
#include <algorithm>

using namespace std;

int main(int argc, char** argv) {
    MPI_Init(&argc, &argv);
    int rank, P;
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &P);

    // 1. 主进程读图(CSR),按点均匀分片到各进程
    int N, M;
    vector<int> row_ptr, col_idx, outdeg;
    if (rank == 0) {
        ifstream f(argv[1]);
        int tmp; f >> N >> M >> tmp;  // 简化mtx头
        vector<vector<int>> adj(N);
        for (int i = 0; i < M; ++i) {
            int u, v; f >> u >> v;
            adj[u].push_back(v);
        }
        outdeg.assign(N, 0);
        for (int u = 0; u < N; ++u) {
            outdeg[u] = adj[u].size();
            for (int v : adj[u]) { row_ptr.push_back(u); col_idx.push_back(v); }
        }
        // 转成 CSR
        vector<int> r(N+1, 0);
        for (int u = 0; u < N; ++u) r[u+1] = r[u] + adj[u].size();
        row_ptr = r;
        col_idx.clear();
        for (int u = 0; u < N; ++u) for (int v : adj[u]) col_idx.push_back(v);
    }
    MPI_Bcast(&N, 1, MPI_INT, 0, MPI_COMM_WORLD);
    MPI_Bcast(&M, 1, MPI_INT, 0, MPI_COMM_WORLD);
    if (rank != 0) { row_ptr.assign(N+1, 0); col_idx.assign(M, 0); outdeg.assign(N, 0); }
    MPI_Bcast(row_ptr.data(), N+1, MPI_INT, 0, MPI_COMM_WORLD);
    MPI_Bcast(col_idx.data(), M, MPI_INT, 0, MPI_COMM_WORLD);
    MPI_Bcast(outdeg.data(), N, MPI_INT, 0, MPI_COMM_WORLD);

    // 2. 本地负责的点区间 [lo, hi)
    int lo = rank * N / P, hi = (rank + 1) * N / P;
    int local_n = hi - lo;

    // 3. 初始化 PR
    vector<double> PR(N, 1.0 / N), newPR(local_n);
    int T = atoi(argv[2]);
    double eps = atof(argv[3]);
    double d = 0.85;

    // 4. BSP 迭代
    for (int t = 0; t < T; ++t) {
        // pull 模型:本地 v 的入边贡献来自全局 PR
        // 注意:这里 col_idx 是出边,要构造 in-edges 才能真正 pull
        // 简化:用 push 模型 (rank 拥有 u, 计算 u -> v 的贡献)
        vector<double> contrib(local_n, (1.0 - d) / N);
        for (int u = lo; u < hi; ++u) {
            int s = row_ptr[u], e = row_ptr[u+1];
            for (int j = s; j < e; ++j) {
                int v = col_idx[j];
                // v 落在哪个 rank?
                int vr = v * P / N;
                // 简化:全 reduce 而非点对点
                contrib[v - vr * N / P] += d * PR[u] / outdeg[u];  // 注:此处省略跨 rank 发送
            }
        }
        // 4.1 Allgather 全局新 PR
        vector<double> tmp(local_n);
        for (int i = 0; i < local_n; ++i) tmp[i] = contrib[i];
        MPI_Allgather(tmp.data(), local_n, MPI_DOUBLE,
                      newPR.data(), local_n, MPI_DOUBLE, MPI_COMM_WORLD);
        // 4.2 计算收敛
        double diff = 0;
        for (int i = 0; i < N; ++i) diff += fabs(newPR[i] - PR[i]);
        PR = newPR;
        double global_diff;
        MPI_Allreduce(&diff, &global_diff, 1, MPI_DOUBLE, MPI_SUM, MPI_COMM_WORLD);
        if (rank == 0) printf("iter %d diff %.2e\n", t, global_diff);
        if (global_diff < eps) break;
    }
    if (rank == 0) {
        double sum = 0; for (double x : PR) sum += x;
        printf("PR sum = %.6f (should be 1.0)\n", sum);
        printf("Top-5: ");
        vector<pair<double,int>> r(N);
        for (int i = 0; i < N; ++i) r[i] = {PR[i], i};
        sort(r.begin(), r.end(), greater<>());
        for (int i = 0; i < 5; ++i) printf("[%d]=%.4f ", r[i].second, r[i].first);
        printf("\n");
    }
    MPI_Finalize();
    return 0;
}
```

⚠️ 上面是教学简化版(把跨 rank 贡献直接累加到本地 slot,实际工程用 Alltoallv 或 GraphX 的 shuffle)。生产代码用 6.2。

### 6.2 OpenMP Ligra-style BFS(top-down + bottom-up)

```cpp
// bfs_ligra.cpp  — 编译: g++ -O3 -fopenmp -std=c++17 bfs_ligra.cpp -o bfs
#include <bits/stdc++.h>
#include <omp.h>
using namespace std;

int N, M;
vector<int> row_ptr, col_idx;  // CSR
vector<int> dist;

void bfs_top_down(const vector<int>& frontier, vector<int>& next) {
    #pragma omp parallel for schedule(dynamic, 64)
    for (int i = 0; i < (int)frontier.size(); ++i) {
        int u = frontier[i];
        for (int j = row_ptr[u]; j < row_ptr[u+1]; ++j) {
            int v = col_idx[j];
            // CAS: 把 INF 换成 dist[u]+1
            int old = __sync_val_compare_and_swap(&dist[v], INT_MAX, dist[u]+1);
            if (old == INT_MAX) {
                #pragma omp critical
                next.push_back(v);
            }
        }
    }
}

void bfs_bottom_up(const vector<char>& in_frontier, vector<int>& next) {
    vector<int> local_next;
    #pragma omp parallel for schedule(dynamic, 64) private(local_next)
    for (int v = 0; v < N; ++v) {
        if (dist[v] != INT_MAX) continue;
        for (int j = row_ptr[v]; j < row_ptr[v+1]; ++j) {
            int u = col_idx[j];   // 这里假设 col_idx 是入边;实际需构建 CSR_in
            if (in_frontier[u]) {
                dist[v] = dist[u] + 1;
                local_next.push_back(v);
                break;
            }
        }
        #pragma omp critical
        next.insert(next.end(), local_next.begin(), local_next.end());
    }
}

void bfs(int s) {
    dist.assign(N, INT_MAX);
    dist[s] = 0;
    vector<int> frontier = {s};
    int threshold = N / 20;   // 启发式
    while (!frontier.empty()) {
        vector<int> next;
        if ((int)frontier.size() < threshold) {
            bfs_top_down(frontier, next);
        } else {
            vector<char> in_f(N, 0);
            for (int u : frontier) in_f[u] = 1;
            bfs_bottom_up(in_f, next);
        }
        frontier = move(next);
    }
}

int main() {
    // 读图略
    double t0 = omp_get_wtime();
    bfs(0);
    printf("BFS done in %.3fs, reached %zu nodes\n",
           omp_get_wtime() - t0, count_if(dist.begin(), dist.end(), [](int d){return d!=INT_MAX;}));
}
```

## 七、常见陷阱与最佳实践 ⚠️

| 陷阱 | 后果 | 对策 |
|------|------|------|
| 用 push 模型在 hub 上写竞争 | atomic 卡死,加速比 <1 | 改 pull,或局部累加再 reduce |
| 全图每轮 Allgather PR | 通信 O(N×P) 爆炸 | 按 owner 分片 Alltoallv |
| top-down 用于大 frontier | frontier 大时扫出边浪费 | 切换 bottom-up |
| CSR 不分 NUMA | 跨 socket 访存延迟 2x | first-touch 按线程分布 |
| vertex-cut 不去重 | hub 副本过多 PR 失真 | PowerGraph 加权聚合 |
| BFS 不收敛 | 用 float 距离累加溢出 | 用 int / double,加 round-check |
| 没做终止检测 | 空轮 BSP 也耗 100ms | 用 MPI_Allreduce LAND |
| GNN 采样跨机 | 一跳采样 RPC 多次 | 2-hop 缓存 + partition 局部性 |

## 十、综合面试题

1. **设计一个支持十亿点、百亿边的实时 PageRank 服务**
   - 答题要点:
     - 存储:边分区(vertex-cut,PowerGraph 风格),每分区本地 CSR。
     - 计算: BSP,每轮 pull 模型,本地 reduce + Allgather 点值。
     - 增量:对动态边用异步 PR,边变更触发局部重算 + LRU 缓存。
     - 容错:checkpoint 每 N 超步,失败回滚。
     - 监控:diff 收敛曲线、每轮通信量、hub 副本数。

2. **BFS 在 GPU 上的性能瓶颈是什么?为什么小 frontier 利用率低?**
   - 答题要点:
     - GPU 适合 frontier 大的场景,edge-parallel 把每条边丢一个线程。
     - 小 frontier 时线程数 < SM 数,warp 利用率低。
     - top-down 的随机写 dist[] 引起 atomic 冲突。
     - 解法:方向优化 + warp-coalesced 访问 + bitmap frontier。

3. **图划分对分布式图算法性能的影响定量分析**
   - 答题要点:
     - 通信量 $\propto$ 跨分区边数(edge-cut)或 hub 副本数(vertex-cut)。
     - edge-cut 用 metis,典型 5-10% 跨边。
     - vertex-cut 用 PowerGraph, hub 切成 $\lceil \sqrt{d} \rceil$ 份平衡。
     - 实测:1D vs 2D 在 hub-heavy 图上 2-3x 差距。
