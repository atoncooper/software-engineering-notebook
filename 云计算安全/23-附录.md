#### CVSS v3.1 向量

```
CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H
       │     │    │    │    │   │   │   │
       │     │    │    │    │   │   │   └─ A 可用性影响(H 高)
       │     │    │    │    │   │   └─ I 完整性影响
       │     │    │    │    │   └─ C 机密性影响
       │     │    │    │    └─ S 范围(U 不变 / C 改变)
       │     │    │    └─ UI 用户交互(N 不需 / R 需要)
       │     │    └─ PR 权限要求(N 无 / L 低 / H 高)
       │     └─ AC 攻击复杂度(L 低 / H 高)
       └─ AV 攻击向量(N 网络 / A 邻近 / L 本地 / P 物理)
```

### 23.7.5 安全基线检查脚本

```bash
#!/bin/bash
# AWS 安全基线快速检查

echo "=== Root MFA ==="
aws iam get-account-summary --query 'SummaryMap.Users' --output text

echo "=== Root Access Keys ==="
aws iam get-account-summary --query 'SummaryMap.AccountAccessKeysPresent' --output text

echo "=== 所有用户 MFA ==="
for user in $(aws iam list-users --query 'Users[*].UserName' --output text); do
  mfa=$(aws iam list-mfa-devices --user-name $user --query 'MFADevices' --output text)
  if [ -z "$mfa" ]; then
    echo "WARN: $user 无 MFA"
  fi
done

echo "=== CloudTrail ==="
aws cloudtrail describe-trails --query 'trailList[*].Name'

echo "=== GuardDuty ==="
aws guardduty list-detectors --query 'DetectorIds'

echo "=== S3 公共访问 ==="
for bucket in $(aws s3 ls --query 'Buckets[*].Name' --output text); do
  block=$(aws s3api get-public-access-block --bucket $bucket 2>/dev/null)
  if [ -z "$block" ]; then
    echo "WARN: $bucket 未配置 Public Access Block"
  fi
done
```

⚠️ **使用陷阱**:

| 陷阱 | 表现 | 改进 |
|------|------|------|
| 速查替代学习 | 只查表不读章节 | 速查为辅,章节为主 |

| 忽略权限 | 命令需高权限 | 最小权限 |

✅ **最佳实践**:

- 面试前刷速查表;
- 工程时查服务映射;
- 出事时按模板走;
- 定期更新本地速查;
- 跨云时确认差异;
- 命令先 dry-run。
