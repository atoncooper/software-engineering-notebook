# 符号约定 · 云计算安全

> 全仓统一数学/密码学/系统符号。

---

## 1. 通用

| 符号 | 含义 |
|------|------|
| $\mathbf{x}$ | 向量（小写粗体） |
| $X$ | 矩阵（大写） |
| $P(\cdot)$, $p(\cdot)$ | 概率（离散/连续） |
| $\mathbb{E}$ | 期望 |
| $\mathbb{1}[\cdot]$ | 指示函数 |
| $\|\cdot\|$ | 范数（默认 $L_2$） |
| $\oplus$ | 异或 |
| $\|$ | 拼接 |
| $\{0,1\}^n$ | $n$ 位比特串 |
| $\stackrel{\$}{\leftarrow}$ | 随机均匀采样 |

## 2. 密码学

| 符号 | 含义 |
|------|------|
| $k$ | 密钥 |
| $k_{\text{pub}}, k_{\text{priv}}$ | 公钥/私钥 |
| $\text{Enc}_k(m)$ | 对称加密 |
| $\text{Dec}_k(c)$ | 对称解密 |
| $\text{Sign}_{k_{\text{priv}}}(m)$ | 数字签名 |
| $\text{Verify}_{k_{\text{pub}}}(m, \sigma)$ | 签名验证 |
| $\text{H}(m)$ | 哈希 |
| $\text{HMAC}_k(m)$ | 消息认证码 |
| $\text{KDF}(k, \text{info})$ | 密钥派生函数 |
| $\text{AEAD}_k(m, \text{ad})$ | 认证加密 |
| $\text{IV}, \text{Nonce}$ | 初始向量/随机数 |
| $\Pi$ | 加密方案整体 |
| $\mathcal{A}$ | 敌手 |
| $\mathcal{O}$ | 预言机 |
| $\text{Adv}^{\text{PRF}}_{\mathcal{A}}$ | 区分器优势 |

## 3. 访问控制

| 符号 | 含义 |
|------|------|
| $S$ | 主体 (Subject) |
| $O$ | 客体 (Object) |
| $A$ | 动作 (Action) |
| $\text{perm}(S, O, A)$ | 权限决策函数 |
| $\text{attr}(S)$ | 主体属性集 |
| $\text{policy}(s, o, a, \text{ctx})$ | ABAC 策略函数 |

## 4. 概率/熵

| 符号 | 含义 |
|------|------|
| $H(X)$ | 香农熵 |
| $H(X \| Y)$ | 条件熵 |
| $I(X; Y)$ | 互信息 |
| $D_{\text{KL}}(P \| Q)$ | KL 散度 |

## 5. 时序

| 符号 | 含义 |
|------|------|
| $t$ | 时间戳 |
| $\Delta t$ | 时间间隔 |
| TTL | 生存时间 |
| $\tau_{\text{exp}}$ | 凭证过期时间 |

## 6. 容灾

| 符号 | 含义 |
|------|------|
| RPO | 恢复点目标（最大可容忍数据丢失量） |
| RTO | 恢复时间目标（最大可容忍停机时间） |
| MTTR | 平均恢复时间 |
| MTBF | 平均故障间隔 |

## 7. 复杂度

| 符号 | 含义 |
|------|------|
| $\lambda$ | 安全参数（如 128/256 位） |
| $\text{negl}(\lambda)$ | 可忽略函数 |
| $\text{poly}(\lambda)$ | 多项式函数 |
