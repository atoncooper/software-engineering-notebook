> 个人软件工程、机器学习与系统设计方向的长期学习与面试笔记仓库。
>
> 目标：构建一套 **持久化、严谨、相互关联** 的知识体系，把碎片化的问题转化为结构化的、可追溯、可复用的知识。
>
> 内容覆盖：**软件工程系统分析与设计 · 机器学习 · 深度学习 · 计算机视觉 · 分布式系统 · 数据库 · 并行计算 · LLM · Agent 开发 · 基础设施 · 408 考研**。

## 一、项目定位

本仓库不是「速查表」，而是一套面向 **工程实践 + 学术严谨 + 面试纵深** 三位一体的学习笔记。

每篇笔记遵循统一结构：

1. **问题定义与边界**：解决什么、不解决什么
2. **直觉解释**：先讲直觉，再上公式
3. **形式化定义与推导**：第一性原理，标明每一步的几何 / 统计 / 物理意义
4. **算法流程**：伪代码 + 复杂度分析
5. **代码实现**：从零实现（教学）+ 库 API 实现（工程）双版本
6. **常见陷阱与调参经验**：工程化视角
7. **与其他方法的关系**：横向对比表
8. **面试速答**：高频问题的一句话答案
9. **综合面试题**：由浅入深，含答题要点
10. **参考与延伸**：书籍、论文、跨文件链接

详细协作规范见 [CLAUDE.md](./CLAUDE.md)。

## 五、写作约定

- **语言与框架**：深度学习代码以 **PyTorch** 为主；经典 ML 以 **scikit-learn** 为主；后端示例以 **Java + Go** 双语言对照
- **数学符号**：向量小写粗体 $\mathbf{x}$，矩阵大写 $X$，概率 $P(\cdot)$，期望 $\mathbb{E}$
- **图示**：优先 ASCII 图说明结构；复杂图示标注来源
- **公式**：关键推导步骤必须标明几何 / 统计意义，不省略中间步骤
- **代码**：从零实现版（教学用）+ 库 API 版（工程用）双版本
- **跨文件链接**：相关概念使用相对路径链接，便于跳转
- **优先级**：正确性 > 完整性 > 速度
