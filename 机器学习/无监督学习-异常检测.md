# 无监督学习 —— 异常检测

> 异常检测是从无标签（或少量标签）数据中找"少数与众不同"的样本：欺诈、故障、入侵、病灶、传感器漂移。
> 它与聚类互为姊妹：聚类关注"大多数的群结构"，异常检测关注"少数偏离者"。
> 本文按 **统计 → 密度（LOF/COF）→ 隔离（iForest）→ 边界（OCSVM）→ 重构（AE/VAE）→ 时序** 顺序展开，强调各类方法的假设与适用边界。

---

```
                            │
   ┌────────────────┬───────┴────────┬─────────────────┐
   │                │                │                 │
 统计方法        密度方法         隔离方法          重构方法

```

## 一、问题定义

### 1.1 异常类型

| 类型 | 描述 | 例子 |
|------|------|------|
| 点异常 | 单点偏离整体 | 信用卡单笔异常金额 |
| 上下文异常 | 在特定上下文中异常 | 7 月气温骤降到 0℃ |
| 集体异常 | 一组点共同异常 | 心电图某段节律失常 |

### 1.2 输出形式

- **评分**：$s(\mathbf{x}) \in \mathbb{R}$，越大越异常（或越小越异常）。便于调阈值。
- **二分类**：$y \in \{0, 1\}$。需阈值。

### 1.3 监督程度

| 设定 | 训练数据 | 典型方法 |
|------|----------|----------|
| 无监督 | 仅正常+异常混合 | iForest、LOF |
| 半监督 | 仅正常样本 | OCSVM、AE 重构 |
| 弱监督 | 少量异常 + 大量正常 | PU 学习、不平衡分类 |

### 1.4 评估难点

- 类别极不平衡：accuracy 无意义，看 Precision@k、Recall@k、AUC、PR-AUC。
- 标注成本高，常需人工复核 top-N。
- 异常本身分布漂移：旧异常模式失效，需持续更新。

## 二、统计方法

### 2.1 单维 3σ 与盒图

- **3σ 准则**：高斯假设下，$|x - \mu| > 3\sigma$ 的概率 < 0.3%。
- **盒图**：$[Q_1 - 1.5 \text{IQR}, Q_3 + 1.5 \text{IQR}]$ 之外为异常。IQR = $Q_3 - Q_1$。

盒图比 3σ 鲁棒：用四分位数代替均值/方差，不受极端值影响。

### 2.2 多维高斯

$$
p(\mathbf{x}) = \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}\exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})\right)
$$

异常分数 $= -\log p(\mathbf{x})$ 或马氏距离平方 $(\mathbf{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})$。

**局限**：高斯假设强；多维下需 $\Sigma$ 可逆，小样本需正则或对角化。

### 2.3 KDE（核密度估计）

非参数估计：

$$
\hat{p}(\mathbf{x}) = \frac{1}{n h^d}\sum_i K\left(\frac{\mathbf{x} - \mathbf{x}_i}{h}\right)
$$

$K$ 为核（高斯），$h$ 为带宽。低密度点为异常。

**局限**：$O(n)$ 单点评估、带宽选择难、高维失效（维数灾难）。

### 2.4 HBOS（直方图异常评分）

每维独立做直方图，异常分数 $= \sum_i -\log p_i(x_i)$。假设各维独立 → 极快，适合基线。

## 三、密度方法：LOF

### 3.1 直觉

不仅看绝对密度，还看**相对密度**：点在自身邻域密度 vs 邻居邻域密度。若比邻居稀疏得多 → 异常。

### 3.2 定义

- **k-距离** $d_k(\mathbf{x})$：$\mathbf{x}$ 到第 $k$ 近邻的距离。
- **可达距离**：

$$
\text{reach-dist}_k(\mathbf{x}, \mathbf{y}) = \max(d_k(\mathbf{y}), d(\mathbf{x}, \mathbf{y}))
$$

直觉：把 $\mathbf{x}$ 到 $\mathbf{y}$ 的距离"抬到"至少 $d_k(\mathbf{y})$，避免 $\mathbf{y}$ 簇内点距离抖动干扰。

- **局部可达密度**：

$$
\text{lrd}_k(\mathbf{x}) = \frac{1}{\frac{1}{k}\sum_{\mathbf{y} \in N_k(\mathbf{x})} \text{reach-dist}_k(\mathbf{x}, \mathbf{y})}
$$

- **LOF**：

$$
\text{LOF}_k(\mathbf{x}) = \frac{1}{k}\sum_{\mathbf{y} \in N_k(\mathbf{x})} \frac{\text{lrd}_k(\mathbf{y})}{\text{lrd}_k(\mathbf{x})}
$$

### 3.3 解读

- $\text{LOF} \approx 1$：与邻居密度相当（正常）。
- $\text{LOF} > 1$：比邻居稀疏（异常）。
- $\text{LOF} < 1$：比邻居稠密（簇内核心）。

### 3.4 优缺点

| 优点 | 缺点 |
|------|------|
| 处理变密度簇 | $O(n^2)$ 朴素，需 KD 树/球树加速 |
| 局部视角，识别局部异常 | 高维失效 |
| 不需训练（惰性） | $k$ 选择敏感 |
| 评分连续 | 大数据内存大 |

### 3.5 COF（链式异常）

LOF 用平均可达距离，对链式（线状）异常不敏感。COF 用最短路径链接邻居，对链式异常更鲁棒。

### 3.6 kNN 异常评分

更简单：异常分数 $= $ 到第 $k$ 近邻的距离。无相对密度修正，但工程上常够用且更快。

## 四、隔离方法：Isolation Forest

### 4.1 直觉

异常点"少且不同"，更容易被**随机划分**隔离。构造随机树时，异常点平均路径长度更短。

### 4.2 算法

```
iTree(X, e, e_max):
  if e >= e_max or |X| <= 1: return 叶节点 {size: |X|}
  随机选特征 q
  随机选切分点 p ∈ [min X_q, max X_q]
  X_l = {x ∈ X : x_q < p}, X_r = {x ∈ X : x_q >= p}
  return 内节点 {q, p, left: iTree(X_l, e+1, e_max),
                          right: iTree(X_r, e+1, e_max)}

iForest:
  采 t 棵子样本 (size ψ, 通常 256)
  对每棵建 iTree，深度限制 ⌈log2 ψ⌉
```

### 4.3 异常评分

$$
s(\mathbf{x}) = 2^{-\frac{E(h(\mathbf{x}))}{c(\psi)}}
$$

- $h(\mathbf{x})$：$\mathbf{x}$ 在树中的路径长度（根到叶的边数）。
- $E(h(\mathbf{x}))$：在 $t$ 棵树上的平均。
- $c(\psi) = 2H(\psi - 1) - 2(\psi - 1)/n$：二叉搜索树平均失败查找长度（归一化常数）。

**解读**：
- $s \to 1$：异常（路径很短）
- $s \to 0.5$：正常
- $s < 0.5$：可能整片密集（少见）

### 4.4 为何快

- 每棵树只采 $\psi = 256$ 样本，深度 $\le \lceil \log_2 \psi \rceil = 8$。
- 森林规模 $t \approx 100$，构建 $O(t \psi \log \psi)$，评估 $O(t \log \psi)$ 每点。
- 远快于 LOF 的 $O(n^2)$。

### 4.5 优缺点

| 优点 | 缺点 |
|------|------|
| 线性复杂度、超快 | 对轴对齐异常敏感（非轴对齐时效果差） |
| 不需距离度量 | 高维下随机切分效率下降 |
| 处理变密度 | 对密集小簇内的异常识别弱 |
| 自然处理全局 + 局部 | 阈值需调 |

### 4.6 扩展

- **Extended iForest (EIF)**：用随机超平面（非轴对齐）切分，提升高维与非轴对齐异常表现。
- **Deep iForest**：用神经网络学习表示后再 iForest。
- **SCiForest**：自适应选切分特征。

## 五、边界方法：One-Class SVM

### 5.1 思路

在特征空间中找一个超平面/超球，把大多数正常样本"包起来"，超球外的为异常。等价于在原点作为负类的二分类 SVM。

### 5.2 OCSVM 形式（Schölkopf）

$$
\min_{\mathbf{w}, \boldsymbol{\xi}, \rho} \frac{1}{2}\|\mathbf{w}\|^2 + \frac{1}{\nu n}\sum_i \xi_i - \rho
$$
$$
\text{s.t. } \mathbf{w}^\top \phi(\mathbf{x}_i) \ge \rho - \xi_i, \quad \xi_i \ge 0
$$

- $\rho$ 为边界偏移；$\nu \in (0, 1]$ 控制训练误差上限与支持向量比例下限。
- 决策函数 $f(\mathbf{x}) = \text{sign}(\mathbf{w}^\top\phi(\mathbf{x}) - \rho)$。

### 5.3 SVDD 形式（Tax & Duin）

找最小超球：

$$
\min_{R, \mathbf{a}, \boldsymbol{\xi}} R^2 + \frac{1}{\nu n}\sum_i \xi_i
$$
$$
\text{s.t. } \|\phi(\mathbf{x}_i) - \mathbf{a}\|^2 \le R^2 + \xi_i, \quad \xi_i \ge 0
$$

异常分数 $= \|\phi(\mathbf{x}) - \mathbf{a}\|^2 - R^2$。

### 5.4 OCSVM 与 SVDD 等价

特定核（如 RBF）下，OCSVM 与 SVDD 给出相同决策边界。

### 5.5 核选择

- **RBF 核**最常用：$\gamma$ 控制边界紧致度。
- $\gamma$ 大：边界紧贴样本（过拟合）；$\gamma$ 小：边界过松（欠拟合）。
- $\nu$ 与 $\gamma$ 强相关，需联合调参。

### 5.6 优缺点

| 优点 | 缺点 |
|------|------|
| 核方法灵活，可处理非线性 | 训练 $O(n^2)$ 内存、$O(n^2 \sim n^3)$ 时间 |
| 理论扎实 | $\gamma, \nu$ 调参敏感 |
| 适合中小数据 | 大数据需近似（SGD-OCSVM、核近似） |
| 边界明确 | 假设原点远离数据，特征需缩放 |

## 六、重构方法：自编码器

### 6.1 思路

只在正常样本上训练 AE，学到正常数据的低维表示。异常样本偏离训练分布，**重构误差大** → 异常。

### 6.2 异常评分

$$
s(\mathbf{x}) = \|\mathbf{x} - g_\theta(f_\phi(\mathbf{x}))\|^2
$$

或归一化为 $s = \|\mathbf{x} - \hat{\mathbf{x}}\|^2 / \|\mathbf{x}\|^2$。

### 6.3 变体

- **DAE（去噪 AE）**：输入加噪，重构原始。学到的表示更稳健，异常分数更可靠。
- **VAE**：概率化，可计算 $\log p(\mathbf{x})$ 作异常分数。
- **深度 SVDD**：把 AE 编码空间约束为最小超球（类似 SVDD 但深度网络）。
- **MemAE（Memory AE）**：编码器查询记忆矩阵，避免 AE 对异常也"过度通用"。

### 6.4 陷阱

- AE 容量过大时可能对异常也重构得很好 → 异常分数失效。需控制瓶颈维度与正则。
- 输入维度高时需 CNN/Transformer AE。
- 训练数据中混入异常会污染模型 → 需先粗筛或用鲁棒损失。

## 七、时序异常检测

### 7.1 统计时序模型

- **ARIMA 残差**：拟合 ARIMA，残差超阈值即异常。
- **Holt-Winters**：季节分解后看残差。
- **STL 分解**：趋势 + 季节 + 残差，残差超 3σ 为异常。

### 7.2 深度时序模型

- **LSTM/Transformer 预测**：用历史预测下一步，预测误差大为异常。
- **DeepAR / TFT**：概率预测，给定置信区间外的为异常。
- **VAE for 时序**：$\log p(\mathbf{x})$ 评分。

### 7.3 时序异常的难点

- **上下文异常**：值本身正常但时间点不对（如夜间流量激增）。需结合时间特征。
- **集体异常**：单点看不出，一段连续异常才显著。需滑动窗口评分。
- **概念漂移**：正常模式本身变化，需在线更新模型。
- **标注难**：常需运维专家复核。

### 7.4 工程流程

```
原始时序 → 平滑/去噪 → 特征工程（时域/频域/统计）
       → 模型预测/重构 → 残差/重构误差
       → 滑动窗口聚合（max/mean/std）
       → 阈值（动态如 EWMA + 3σ 或 POT 极值理论）
       → 告警（去抖、抑制、合并）
```

## 八、Python 实现

### 8.1 从零实现 LOF

```python
import numpy as np
from sklearn.neighbors import NearestNeighbors

class LOFScratch:
    def __init__(self, k: int = 20):
        self.k = k

    def fit(self, X: np.ndarray):
        self.X = X
        nn = NearestNeighbors(n_neighbors=self.k + 1).fit(X)
        dists, idxs = nn.kneighbors(X)
        self.k_dists = dists[:, -1]                       # 第 k 近邻距离
        self.nn_idxs = idxs[:, 1:]                        # 不含自身
        self.nn_dists = dists[:, 1:]
        self.lrd_ = self._local_reach_density()
        return self

    def _reach_dist(self, i: int, j: int) -> float:
        return max(self.k_dists[j], np.linalg.norm(self.X[i] - self.X[j]))

    def _local_reach_density(self) -> np.ndarray:
        n = len(self.X)
        lrd = np.empty(n)
        for i in range(n):
            reach = [self._reach_dist(i, j) for j in self.nn_idxs[i]]
            lrd[i] = 1.0 / (np.mean(reach) + 1e-12)
        return lrd

    def score(self, X: np.ndarray) -> np.ndarray:
        # 对训练集已算；对新点需重新查邻居
        return self._lof_train() if X is self.X else self._lof_new(X)

    def _lof_train(self) -> np.ndarray:
        n = len(self.X)
        lof = np.empty(n)
        for i in range(n):
            neighbor_lrds = self.lrd_[self.nn_idxs[i]]
            lof[i] = np.mean(neighbor_lrds) / self.lrd_[i]
        return lof

    def _lof_new(self, X: np.ndarray) -> np.ndarray:
        nn = NearestNeighbors(n_neighbors=self.k + 1).fit(self.X)
        dists, idxs = nn.kneighbors(X)
        lof = np.empty(len(X))
        for i, (d, neighbors) in enumerate(zip(dists, idxs)):
            reach = np.maximum(self.k_dists[neighbors[1:]], d[1:])
            lrd_i = 1.0 / (np.mean(reach) + 1e-12)
            lof[i] = np.mean(self.lrd_[neighbors[1:]]) / lrd_i
        return lof


def test_lof_flags_outlier():
    rng = np.random.default_rng(0)
    X = rng.normal(0, 1, (100, 2))
    X = np.vstack([X, [[10, 10]]])  # 明显异常点
    lof = LOFScratch(k=10).fit(X)
    scores = lof.score(X)
    assert scores[-1] == scores.max()
    assert scores[-1] > 2.0
```

### 8.2 从零实现 iForest

```python
import numpy as np
import random

class IsolationTree:
    def __init__(self, max_depth: int):
        self.max_depth = max_depth
        self.tree = None

    def fit(self, X: np.ndarray, depth: int = 0):
        if depth >= self.max_depth or len(X) <= 1:
            return {"size": len(X)}
        q = random.randrange(X.shape[1])
        x_min, x_max = X[:, q].min(), X[:, q].max()
        if x_min == x_max:
            return {"size": len(X)}
        p = random.uniform(x_min, x_max)
        mask = X[:, q] < p
        return {
            "q": q, "p": p,
            "left": self.fit(X[mask], depth + 1),
            "right": self.fit(X[~mask], depth + 1),
        }

    def path_length(self, x: np.ndarray, node=None, depth=0) -> int:
        if node is None:
            node = self.tree
        if "size" in node:
            # 用 c(n) 调整未达叶的截断
            return depth + _c_factor(node["size"])
        if x[node["q"]] < node["p"]:
            return self.path_length(x, node["left"], depth + 1)
        return self.path_length(x, node["right"], depth + 1)


def _c_factor(n: int) -> float:
    if n <= 1:
        return 0.0
    return 2.0 * (np.log(n - 1) + 0.5772156649) - 2.0 * (n - 1) / n


class IsolationForestScratch:
    def __init__(self, n_trees: int = 100, sample_size: int = 256, seed: int = 0):
        self.n_trees = n_trees
        self.sample_size = sample_size
        self.seed = seed
        self.trees: list[IsolationTree] = []

    def fit(self, X: np.ndarray):
        rng = np.random.default_rng(self.seed)
        self.max_depth = int(np.ceil(np.log2(self.sample_size)))
        self.c_norm = _c_factor(self.sample_size)
        n = len(X)
        for _ in range(self.n_trees):
            idx = rng.choice(n, min(self.sample_size, n), replace=False)
            tree = IsolationTree(self.max_depth)
            tree.tree = tree.fit(X[idx])
            self.trees.append(tree)
        return self

    def score(self, X: np.ndarray) -> np.ndarray:
        scores = np.empty(len(X))
        for i, x in enumerate(X):
            avg_path = np.mean([t.path_length(x) for t in self.trees])
            scores[i] = 2 ** (-avg_path / self.c_norm)
        return scores


def test_iforest_flags_outlier():
    rng = np.random.default_rng(0)
    X = rng.normal(0, 1, (200, 2))
    X = np.vstack([X, [[8, 8]]])
    iso = IsolationForestScratch(n_trees=100, sample_size=128, seed=0).fit(X)
    scores = iso.score(X)
    assert scores[-1] == scores.max()
    assert scores[-1] > 0.6
```

### 8.4 自编码器异常检测（PyTorch）

```python
import torch
import torch.nn as nn

class AnomalyAE(nn.Module):
    def __init__(self, d: int, k: int):
        super().__init__()
        self.enc = nn.Sequential(
            nn.Linear(d, 64), nn.ReLU(),
            nn.Linear(64, k),
        )
        self.dec = nn.Sequential(
            nn.Linear(k, 64), nn.ReLU(),
            nn.Linear(64, d),
        )

    def forward(self, x):
        z = self.enc(x)
        return self.dec(z), z


def train_anomaly_ae(X_normal: torch.Tensor, k: int = 8, epochs: int = 50):
    model = AnomalyAE(X_normal.shape[1], k)
    opt = torch.optim.Adam(model.parameters(), lr=1e-3)
    loader = torch.utils.data.DataLoader(
        torch.utils.data.TensorDataset(X_normal), batch_size=64, shuffle=True
    )
    for _ in range(epochs):
        for (x,) in loader:
            xhat, _ = model(x)
            loss = ((x - xhat) ** 2).mean()
            opt.zero_grad(); loss.backward(); opt.step()
    return model


def anomaly_scores(model, X):
    with torch.no_grad():
        xhat, _ = model(X)
        return ((X - xhat) ** 2).mean(dim=1)
```

```python
"""
信用卡欺诈：极不平衡 ( fraud < 0.5% )
无监督方法对比（iForest / LOF / OCSVM / AE）。
"""
import numpy as np
import torch
from sklearn.ensemble import IsolationForest
from sklearn.neighbors import LocalOutlierFactor
from sklearn.svm import OneClassSVM
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import precision_recall_curve, auc
from sklearn.model_selection import train_test_split

# 模拟数据（实际用 Kaggle Credit Card Fraud 数据集）
rng = np.random.default_rng(0)
n_normal, n_fraud = 20000, 80
X_normal = rng.normal(0, 1, (n_normal, 10))
X_fraud = rng.normal(3, 1, (n_fraud, 10))
X = np.vstack([X_normal, X_fraud])
y = np.concatenate([np.zeros(n_normal), np.ones(n_fraud)])

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=42
)
# 训练集故意只用正常样本（半监督设定）
X_train_normal = X_train[y_train == 0]
scaler = StandardScaler().fit(X_train_normal)
Xtr = scaler.transform(X_train_normal)
Xte = scaler.transform(X_test)

models = {
    "iForest": IsolationForest(n_estimators=200, contamination=0.004,
                               random_state=42).fit(Xtr),
    # novelty=True 才能在测试集评分
    "LOF": LocalOutlierFactor(n_neighbors=50, novelty=True,
                              contamination=0.004).fit(Xtr),
    "OCSVM": OneClassSVM(kernel="rbf", gamma="scale", nu=0.004).fit(Xtr),
}

for name, m in models.items():
    scores = -m.score_samples(Xte)  # 统一为"越大越异常"
    prec, rec, _ = precision_recall_curve(y_test, scores)
    pr_auc = auc(rec, prec)
    top_k_precision = (y_test[np.argsort(-scores)[:100]].sum()) / 100
    print(f"{name:10s}  PR-AUC={pr_auc:.4f}  P@100={top_k_precision:.3f}")
```

**典型观察**：
- iForest 最快，PR-AUC 与 LOF 接近。
- LOF 对局部异常敏感但慢。
- OCSVM 调参敏感，$\gamma$ 不当会全标或全漏。
- 欺诈数据分布漂移快，需定期重训 + 监控。

## 十、常见陷阱

| 陷阱 | 后果 | 对策 |
|------|------|------|
| 训练集混入异常 | OCSVM/AE 边界偏 | 用鲁棒估计或先粗筛 |
| 未标准化 | 大尺度特征主导 | StandardScaler / RobustScaler |
| contamination 设错 | 阈值偏 | 不知比例时用 "auto" 或看分数分布 |
| 高维直接用 LOF/KDE | 距离趋同失效 | 先 PCA/UMAP 降维或用 iForest |
| 单一阈值 | 漂移下误报多 | 动态阈值（EWMA + 3σ, POT） |
| 评估用 accuracy | 不平衡下虚高 | PR-AUC、Precision@k、Recall@k |
| 忽略时序依赖 | 误把正常突变当异常 | 加时序特征、滑动窗口 |
| AE 容量过大 | 对异常也重构好 | 限瓶颈、加正则、用 DAE/MemAE |
| OCSVM $\gamma$ 不调 | 边界全贴或全松 | 网格搜索 + $\nu$ 联调 |
| iForest 高维非轴对齐异常 | 切不到 | 用 Extended iForest 或先降维 |

## 十一、与其他方法的关系

| 方法 | 关系 |
|------|------|
| iForest ↔ 随机森林 | 都是随机划分；iForest 用路径长度而非标签 |
| LOF ↔ DBSCAN | 都基于密度；DBSCAN 把低密度点标噪声 |
| OCSVM ↔ SVM | OCSVM 是把原点当负类的二分类 SVM |
| OCSVM ↔ SVDD | RBF 核下等价 |
| AE 异常 ↔ PCA 重构 | 线性 AE = PCA；PCA 残差即异常分数 |
| Deep SVDD ↔ AE + SVDD | 把 SVDD 推广到深度网络 |
| 统计方法 ↔ 假设检验 | 3σ、卡方、Grubbs 都是假设检验视角 |
| 半监督异常 ↔ PU 学习 | 仅正例 + 未标注，可用 PU 框架 |
| 异常检测 ↔ 主动学习 | top-N 异常人工复核 → 标注 → 监督模型迭代 |

## 十二、面试速答

| 问 | 答 |
|----|-----|
| iForest 为何快？ | 子样本 256 + 深度 $\log_2$ 限制，线性复杂度。 |
| iForest 为何有效？ | 异常少且不同，随机切分易隔离，路径短。 |
| LOF 的核心思想？ | 局部相对密度：点 vs 邻居的密度比。 |
| LOF 与 kNN 异常的区别？ | kNN 只看绝对距离，LOF 加局部密度修正，处理变密度。 |
| OCSVM 的 $\nu$ 含义？ | 训练误差上限 + 支持向量比例下限。 |
| OCSVM 与 SVDD 关系？ | RBF 核下等价。 |
| 为何 AE 能做异常检测？ | 在正常上训练，异常重构误差大。 |
| AE 容量过大的风险？ | 对异常也重构好，分数失效。 |
| 为何不用 accuracy 评估异常？ | 极不平衡，accuracy 虚高，用 PR-AUC / P@k。 |
| 高维异常怎么办？ | 先降维或用 iForest（不依赖距离）。 |
| 时序异常的难点？ | 上下文异常、集体异常、概念漂移。 |
| 统计 3σ 的局限？ | 高斯假设、对极端值敏感；盒图更鲁棒。 |
| 训练集混入异常的影响？ | OCSVM/AE 边界被拉偏；iForest/LOF 相对鲁棒。 |
| 半监督 vs 无监督异常？ | 半监督仅正常训练，OCSVM/AE；无监督混合训练，iForest/LOF。 |

## 十三、综合面试题

1. **推导 LOF 的相对密度思路。**
   - 单看密度 $\text{lrd}(\mathbf{x})$ 不够：稠密区正常点也可能密度低。
   - 比较 $\mathbf{x}$ 与其邻居的密度比：$\text{LOF} = \text{mean}_{\mathbf{y} \in N_k(\mathbf{x})} \text{lrd}(\mathbf{y}) / \text{lrd}(\mathbf{x})$。
   - 若 $\mathbf{x}$ 比邻居稀疏（$\text{lrd}(\mathbf{x})$ 小），LOF > 1 → 异常。
   - 用可达距离避免簇内距离抖动。

2. **iForest 的评分公式推导。**
   - 路径长度 $h(\mathbf{x})$ 越短越异常。
   - 归一化：$s = 2^{-E[h]/c(\psi)}$，$c(\psi)$ 为 BST 平均失败查找长度。
   - $E[h] \to 0 \Rightarrow s \to 1$（异常）；$E[h] \to c(\psi) \Rightarrow s \to 0.5$（正常）。
   - 用 $2^{-x}$ 把路径长度映射到 $[0, 1]$。

3. **为何 iForest 用子样本而非全量？**
   - 子样本隔离异常更彻底（正常点不会被"挤"在异常附近）。
   - 256 样本已足够稳定，更大样本稀释隔离效果。
   - 工程上加速度：树构造 $O(\psi\log\psi)$，远快于全量。

4. **OCSVM 与 SVDD 的等价性。**
   - OCSVM 优化 $\frac{1}{2}\|\mathbf{w}\|^2 + \frac{1}{\nu n}\sum\xi_i - \rho$。
   - SVDD 优化 $R^2 + \frac{1}{\nu n}\sum\xi_i$。
   - 特定核下两者对偶问题一致，决策函数相同。
   - 直觉：OCSVM 用超平面把数据与原点分开；SVDD 用超球包数据，原点视为反例。

5. **AE 异常检测的失败模式。**
   - 容量过大：AE 学到恒等映射，对异常也重构好。
   - 训练污染：训练集含异常，模型"见怪不怪"。
   - 模式塌缩：VAE 后验塌缩到先验，分数无差异。
   - 高维输入：重构误差被噪声维度主导。
   - 对策：限瓶颈、加正则、用 DAE/MemAE、监控分数分布。

6. **如何在不平衡数据上评估异常检测？**
   - 不用 accuracy（多数类压倒）。
   - PR-AUC：聚焦正例（异常），不平衡下比 ROC-AUC 更敏感。
   - Precision@k / Recall@k：业务关心 top-N 复核。
   - F1（带阈值调优）。
   - 监控误报率（FPR）：运维成本约束。

7. **设计一个实时欺诈检测系统。**
   - 离线：用历史正常 + 少量欺诈训练 iForest / OCSVM / AE。
   - 在线：特征实时计算 → 多模型打分 → 加权融合 → 动态阈值（EWMA + 3σ 或 POT）。
   - 规则兜底：金额阈值、IP 黑名单等强规则。
   - 反馈闭环：人工复核 top-N → 标注 → 定期重训。
   - 监控：分数分布漂移、误报率、漏报率、延迟。

8. **如何选 LOF vs iForest vs OCSVM？**
   - 数据规模：大用 iForest（快）；中小用 LOF/OCSVM。
   - 异常类型：变密度局部异常用 LOF；全局轴对齐异常用 iForest；非线性边界用 OCSVM。
   - 维度：高维避免 LOF/KDE，用 iForest 或先降维。
   - 调参成本：iForest 最少；OCSVM $\gamma, \nu$ 敏感。
   - 实践：多模型集成，分数融合或投票。

9. **时序异常如何处理集体异常？**
   - 单点评分看不出，需滑动窗口聚合：max/mean/std over window。
   - 或序列模型（LSTM/Transformer）预测误差，沿时间累积。
   - 窗口内连续超阈值才告警（去抖）。
   - 上下文异常：把时间特征（小时、星期）作为输入，模型学到"此时此地正常"。

10. **POT（Peaks Over Threshold）动态阈值。**
    - 极值理论：超阈值部分近似 GPD（广义帕累托分布）。
    - 选初始阈值 $u$，拟合 GPD 尾参数，计算 $q$ 分位数（如 0.999）为告警阈值。
    - 适应分布漂移：定期重拟合尾部分布。
    - 比 3σ / EWMA 对长尾更稳健，避免阈值被极端值拉爆。

## 十四、公式速查卡

| 公式 | 表达式 |
|------|--------|
| 马氏距离 | $d_M^2 = (x-\mu)^\top\Sigma^{-1}(x-\mu)$ |
| LOF | $\frac{1}{k}\sum_{y \in N_k(x)} \text{lrd}(y)/\text{lrd}(x)$ |
| 可达距离 | $\max(d_k(y), d(x,y))$ |
| 局部可达密度 | $1/\text{mean reach-dist}$ |
| iForest 评分 | $s = 2^{-E[h(x)]/c(\psi)}$ |
| 归一化常数 | $c(\psi) = 2H(\psi-1) - 2(\psi-1)/\psi$ |
| OCSVM 目标 | $\min \frac{1}{2}\|w\|^2 + \frac{1}{\nu n}\sum\xi - \rho$ |
| SVDD 目标 | $\min R^2 + \frac{1}{\nu n}\sum\xi$ |
| AE 异常分数 | $\|x - g(f(x))\|^2$ |
| HBOS | $\sum_i -\log p_i(x_i)$ |
