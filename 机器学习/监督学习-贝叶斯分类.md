# 监督学习 —— 贝叶斯分类

> 贝叶斯分类是生成模型的代表：不直接学 $P(y\mid\mathbf{x})$，而是建模 $P(\mathbf{x}\mid y)P(y)$ 再用贝叶斯公式反推。朴素贝叶斯虽"朴素"，在文本分类中仍是强力基线；贝叶斯网络是概率图模型的入门。

## 一、问题定义

### 1.1 生成模型 vs 判别模型

| 类型 | 学习目标 | 代表 |
|------|----------|------|
| 判别 | $P(y\mid\mathbf{x})$ | 逻辑回归、SVM、神经网络 |
| 生成 | $P(\mathbf{x}\mid y)P(y)$ | 朴素贝叶斯、GMM、HMM、贝叶斯网络 |

**生成模型优势**：

- 可生成新样本
- 处理缺失值
- 适合半监督学习
- 类别先验可调整

**判别模型优势**：

- 直接优化目标，精度通常更高
- 不需建模特征分布
- 计算更高效

### 1.2 贝叶斯决策论

给定输入 $\mathbf{x}$，预测 $\hat{y}$ 使期望损失最小：

$$
\hat{y} = \arg\min_y \sum_{c} L(c, y) P(c \mid \mathbf{x})
$$

### 1.3 0-1 损失下的最优分类器

$L(c, y) = \mathbb{1}[c \neq y]$ 时：

$$
\hat{y} = \arg\max_y P(y \mid \mathbf{x})
$$

即**后验概率最大化**。

**证明**：

$$
\mathbb{E}[L] = \sum_c \mathbb{1}[c \neq y] P(c\mid\mathbf{x}) = 1 - P(y\mid\mathbf{x})
$$

最小化 $\mathbb{E}[L]$ 等价于最大化 $P(y\mid\mathbf{x})$。

---

## 二、贝叶斯公式与后验

### 2.1 贝叶斯公式

$$
P(y \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid y) P(y)}{P(\mathbf{x})} = \frac{P(\mathbf{x} \mid y) P(y)}{\sum_c P(\mathbf{x} \mid c) P(c)}
$$

- $P(y)$：先验
- $P(\mathbf{x}\mid y)$：似然
- $P(y\mid\mathbf{x})$：后验
- $P(\mathbf{x})$：证据（归一化常数）

### 2.2 分母可省略

分类时只需比较各类后验相对大小：

$$
\hat{y} = \arg\max_y P(\mathbf{x}\mid y) P(y)
$$

因 $P(\mathbf{x})$ 对所有类相同。

## 三、朴素贝叶斯

### 3.1 条件独立假设

$$
P(\mathbf{x} \mid y) = \prod_{j=1}^d P(x_j \mid y)
$$

即给定类别 $y$，各特征条件独立。这是"朴素"的来源——现实中很少成立，但实践中效果出奇好。

### 3.2 分类器

$$
\hat{y} = \arg\max_y P(y) \prod_j P(x_j \mid y)
$$

为避免下溢，取对数：

$$
\hat{y} = \arg\max_y \left[\log P(y) + \sum_j \log P(x_j \mid y)\right]
$$

### 3.3 MLE 参数估计

**先验**：$P(y = c) = \frac{N_c}{N}$（频率）

**似然**（离散特征）：

$$
P(x_j = v \mid y = c) = \frac{N_{c, j, v}}{N_c}
$$

$N_{c, j, v}$ 为类别 $c$ 中特征 $j$ 取值 $v$ 的样本数。

### 3.4 拉普拉斯平滑

**零概率问题**：若某 $P(x_j = v\mid y = c) = 0$，整个乘积为 0，抹去其他特征证据。

**解决**：加伪计数：

$$
P(x_j = v \mid y = c) = \frac{N_{c, j, v} + \alpha}{N_c + \alpha V_j}
$$

$\alpha = 1$ 为拉普拉斯平滑，$\alpha \in (0, 1)$ 为 Lidstone 平滑，$V_j$ 为特征 $j$ 的取值数。

### 3.5 拉普拉斯平滑的贝叶斯合法性

由 [Beta-Dirichlet 共轭](./数学基础-概率与统计.md#6.4-共轭先验)：

- 似然：类别分布 $\text{Mult}(\boldsymbol{\pi})$
- 先验：$\text{Dir}(\boldsymbol{\alpha})$
- 后验：$\text{Dir}(\boldsymbol{\alpha} + \mathbf{n})$
- 后验均值：$\hat{\pi}_k = \frac{\alpha_k + n_k}{\sum_k \alpha_k + n_k}$

拉普拉斯平滑即 $\alpha_k = \alpha$ 时的后验均值。**拉普拉斯平滑 = Dirichlet 先验下的 MAP 估计**。

## 四、三种朴素贝叶斯变体

### 4.1 Gaussian NB（连续特征）

假设 $P(x_j \mid y = c) \sim \mathcal{N}(\mu_{c, j}, \sigma_{c, j}^2)$：

$$
P(x_j \mid y = c) = \frac{1}{\sqrt{2\pi\sigma_{c, j}^2}} \exp\!\left(-\frac{(x_j - \mu_{c, j})^2}{2\sigma_{c, j}^2}\right)
$$

MLE：$\hat{\mu}_{c, j} = \bar{x}_{c, j}$，$\hat{\sigma}_{c, j}^2 = \text{Var}(x_j \mid y = c)$。

### 4.2 Multinomial NB（计数特征）

文档分类中，特征为词频。假设文档由类别 $c$ 下多项分布生成：

$$
P(\mathbf{x} \mid y = c) = \frac{(\sum_j x_j)!}{\prod_j x_j!} \prod_j \theta_{c, j}^{x_j}
$$

$\theta_{c, j}$ 为类别 $c$ 生成词 $j$ 的概率，带拉普拉斯平滑：

$$
\hat{\theta}_{c, j} = \frac{N_{c, j} + \alpha}{N_c + \alpha V}
$$

$N_{c, j}$ 为类别 $c$ 中词 $j$ 的总频次。

### 4.3 Bernoulli NB（二值特征）

文档表示为词是否出现的二值向量：

$$
P(\mathbf{x} \mid y = c) = \prod_j \theta_{c, j}^{x_j} (1 - \theta_{c, j})^{1 - x_j}
$$

**与多项 NB 区别**：Bernoulli 考虑词不出现的证据，Multinomial 不考虑。

### 4.4 适用场景

| 变体 | 适用 | 典型应用 |
|------|------|----------|
| Gaussian | 连续特征 | 鸢尾花、传感器 |
| Multinomial | 词频/计数 | 文本分类 |
| Bernoulli | 二值特征 | 垃圾邮件（词是否出现） |
| Complement | 类别不平衡 | 不平衡文本 |
| Categorical | 离散类别 | 类别特征 |

## 五、贝叶斯网络

### 5.1 定义

贝叶斯网络是有向无环图（DAG）：

- 节点：随机变量
- 有向边：条件依赖关系

**联合分布的因子分解**：

$$
P(X_1, \dots, X_n) = \prod_{i=1}^n P(X_i \mid \text{Pa}(X_i))
$$

$\text{Pa}(X_i)$ 为 $X_i$ 的父节点集。

### 5.2 d-划分（d-separation）

判断给定证据 $\mathbf{Z}$ 时 $X \perp Y \mid \mathbf{Z}$ 是否成立。路径被阻断的条件取决于路径上节点的连接方式。

#### 三种基本结构

**链式** $A \to B \to C$：

- 默认 $A \not\perp C$（信息从 $A$ 流向 $C$）
- 给定 $B$：$A \perp C \mid B$（阻断）

**分叉** $A \leftarrow B \to C$：

- 默认 $A \not\perp C$
- 给定 $B$：$A \perp C \mid B$

**V 形（collider）** $A \to B \leftarrow C$：

- 默认 $A \perp C$（共同后果不相关）
- 给定 $B$ 或其后代：$A \not\perp C \mid B$（"解释消除"效应）

#### d-划分规则

路径 $p$ 被阻断，若路径上存在中间节点 $X$ 满足：

1. $X$ 是链或分叉的中间节点，且 $X \in \mathbf{Z}$
2. $X$ 是 collider，且 $X \notin \mathbf{Z}$ 且 $X$ 的后代都不在 $\mathbf{Z}$

若所有路径都被阻断，则 $X \perp Y \mid \mathbf{Z}$。

### 5.3 典型贝叶斯网络

**隐马尔可夫模型（HMM）**：

$$
\text{states } z_1 \to z_2 \to \dots \to z_T, \quad z_t \to x_t
$$

满足齐次马尔可夫性：$P(z_t \mid z_{<t}) = P(z_t \mid z_{t-1})$。

**LDA 主题模型**：

```
α → θ_d → z_{d,n} → w_{d,n} ← β ← φ_k
```

文档-主题分布 $\theta_d$、主题-词分布 $\phi_k$ 由 Dirichlet 先验生成。

### 5.4 推断

**精确推断**：

- 变量消除（Variable Elimination）：按顺序求和消除变量
- 信念传播（Belief Propagation）：树结构精确，一般图为近似

**近似推断**：

- MCMC：吉布斯采样等
- 变分推断：用简单分布 $q$ 近似后验 $p$，最小化 $\text{KL}(q\|p)$

详见 [数学基础-概率与统计 EM 与变分推断](./数学基础-概率与统计.md#6.5-期望最大化em)。

## 六、算法流程与复杂度

| 阶段 | 复杂度 |
|------|--------|
| 训练（Gaussian NB） | $O(nd)$ |
| 训练（Multinomial NB） | $O(nd)$ |
| 推理 | $O(Kd)$ |
| 贝叶斯网络精确推断 | NP-hard（一般图） |

朴素贝叶斯是少数训练与推理都 $O(nd)$ 的算法，工业上极快。

## 七、代码实现（工业级）

### 7.1 从零实现：Gaussian NB

```python
"""
工业级 Gaussian Naive Bayes。
支持多分类、方差平滑、对数概率避免下溢。
"""
from __future__ import annotations
from dataclasses import dataclass
from typing import Optional
import numpy as np


@dataclass
class GaussianNBConfig:
    var_smoothing: float = 1e-9  # 方差下界，防止数值不稳定


class GaussianNB:
    def __init__(self, config: GaussianNBConfig = GaussianNBConfig()):
        self.config = config
        self.classes_: Optional[np.ndarray] = None
        self.mean_: Optional[np.ndarray] = None      # (K, d)
        self.var_: Optional[np.ndarray] = None        # (K, d)
        self.priors_: Optional[np.ndarray] = None     # (K,)

    def fit(self, X: np.ndarray, y: np.ndarray) -> "GaussianNB":
        n, d = X.shape
        self.classes_ = np.unique(y)
        K = len(self.classes_)
        self.mean_ = np.zeros((K, d))
        self.var_ = np.zeros((K, d))
        self.priors_ = np.zeros(K)
        # 全局方差作为平滑基底
        epsilon = self.config.var_smoothing * X.var(axis=0).max()
        for k, c in enumerate(self.classes_):
            Xk = X[y == c]
            self.mean_[k] = Xk.mean(axis=0)
            self.var_[k] = Xk.var(axis=0) + epsilon
            self.priors_[k] = len(Xk) / n
        return self

    def _joint_log_likelihood(self, X: np.ndarray) -> np.ndarray:
        """联合对数概率 P(y=k, x)，避免下溢。"""
        n, d = X.shape
        K = len(self.classes_)
        jll = np.zeros((n, K))
        for k in range(K):
            log_prior = np.log(self.priors_[k])
            # 高斯对数密度
            log_likelihood = -0.5 * np.sum(
                np.log(2 * np.pi * self.var_[k])
                + (X - self.mean_[k]) ** 2 / self.var_[k],
                axis=1
            )
            jll[:, k] = log_prior + log_likelihood
        return jll

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        jll = self._joint_log_likelihood(X)
        # log-sum-exp 归一化
        log_norm = jll.max(axis=1, keepdims=True)
        probs = np.exp(jll - log_norm)
        probs /= probs.sum(axis=1, keepdims=True)
        return probs

    def predict(self, X: np.ndarray) -> np.ndarray:
        return self.classes_[self._joint_log_likelihood(X).argmax(axis=1)]
```

### 7.2 从零实现：Multinomial NB

```python
class MultinomialNB:
    """多项朴素贝叶斯，带拉普拉斯平滑。"""
    def __init__(self, alpha: float = 1.0):
        self.alpha = alpha
        self.classes_: Optional[np.ndarray] = None
        self.feature_log_prob_: Optional[np.ndarray] = None  # (K, V)
        self.class_log_prior_: Optional[np.ndarray] = None

    def fit(self, X: np.ndarray, y: np.ndarray) -> "MultinomialNB":
        n, V = X.shape
        self.classes_ = np.unique(y)
        K = len(self.classes_)
        # 类别先验（带平滑）
        class_count = np.array([(y == c).sum() for c in self.classes_])
        self.class_log_prior_ = np.log(class_count + self.alpha) - \
                                np.log(class_count.sum() + self.alpha * K)
        # 特征条件概率（带平滑）
        feature_count = np.zeros((K, V))
        for k, c in enumerate(self.classes_):
            feature_count[k] = X[y == c].sum(axis=0)
        smoothed = feature_count + self.alpha
        self.feature_log_prob_ = (np.log(smoothed) -
                                   np.log(smoothed.sum(axis=1, keepdims=True)))
        return self

    def predict(self, X: np.ndarray) -> np.ndarray:
        # log P(y|x) ∝ log P(y) + sum_j x_j log P(j|y)
        jll = X @ self.feature_log_prob_.T + self.class_log_prior_
        return self.classes_[jll.argmax(axis=1)]
```

### 7.3 sklearn 工业级用法

```python
import numpy as np
from sklearn.naive_bayes import GaussianNB, MultinomialNB, BernoulliNB, ComplementNB
from sklearn.datasets import load_iris, fetch_20newsgroups
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
from sklearn.pipeline import Pipeline
from sklearn.model_selection import cross_val_score

# 连续特征：鸢尾花
X, y = load_iris(return_X_y=True)
gnb = GaussianNB()
print(f"Gaussian NB 准确率: {cross_val_score(gnb, X, y, cv=5).mean():.4f}")

# 文本分类：20Newsgroups
categories = ["alt.atheism", "soc.religion.christian", "comp.graphics", "sci.med"]
train = fetch_20newsgroups(subset="train", categories=categories, random_state=42)
test = fetch_20newsgroups(subset="test", categories=categories, random_state=42)

pipe = Pipeline([
    ("tfidf", TfidfVectorizer(stop_words="english", max_features=10000)),
    ("clf", MultinomialNB(alpha=0.1))
])
pipe.fit(train.data, train.target)
print(f"Multinomial NB 文本分类准确率: "
      f"{pipe.score(test.data, test.target):.4f}")

# 类别不平衡用 Complement NB
pipe_imb = Pipeline([
    ("tfidf", TfidfVectorizer(stop_words="english")),
    ("clf", ComplementNB())
])
```

import pytest
from sklearn.datasets import make_classification, make_blobs


def test_gaussian_nb_recovers_well_separated():
    """线性可分数据应达到高准确率。"""

## 八、实战案例：垃圾邮件分类

```python
"""
垃圾邮件分类：Bernoulli NB vs Multinomial NB。
"""
import numpy as np
from sklearn.naive_bayes import MultinomialNB, BernoulliNB, ComplementNB
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.pipeline import Pipeline
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.metrics import classification_report, roc_auc_score

# 模拟数据
spam_keywords = ["free", "win", "money", "click", "offer", "limited", "deal"]
ham_keywords = ["meeting", "report", "project", "schedule", "review"]

np.random.seed(42)
emails, labels = [], []
for _ in range(500):
    if np.random.rand() < 0.4:  # 40% spam
        n_words = np.random.randint(5, 20)
        words = [np.random.choice(spam_keywords) for _ in range(n_words)]
        labels.append(1)
    else:
        n_words = np.random.randint(5, 20)
        words = [np.random.choice(ham_keywords) for _ in range(n_words)]
        labels.append(0)
    emails.append(" ".join(words))

emails, labels = np.array(emails), np.array(labels)

# 三种 NB 对比
for name, clf in [("Multinomial", MultinomialNB(alpha=0.1)),
                  ("Bernoulli", BernoulliNB(alpha=0.1)),
                  ("Complement", ComplementNB(alpha=0.1))]:
    pipe = Pipeline([
        ("vec", CountVectorizer(binary=(name == "Bernoulli"))),
        ("clf", clf)
    ])
    scores = cross_val_score(pipe, emails, labels,
                              cv=StratifiedKFold(5, shuffle=True, random_state=42),
                              scoring="f1")
    print(f"{name} NB F1: {scores.mean():.4f} ± {scores.std():.4f}")
```

**典型结果**：

- Multinomial NB 用词频，常略优于 Bernoulli
- Complement NB 在类别不平衡时更稳健
- 朴素贝叶斯是文本分类的强基线，性能常与 SVM、深度模型相当

## 九、常见陷阱

| 陷阱 | 后果 | 对策 |
|------|------|------|
| 未平滑 | 零概率抹去证据 | 拉普拉斯/Lidstone 平滑 |
| 用 Gaussian 处理离散特征 | 假设失效 | 用 Multinomial/Categorical |
| 高相关特征 | 条件独立假设失效，但通常仍可用 | 实践中容忍 |
| 概率未取对数 | 下溢 | log-space 计算 |
| 类别先验偏差 | 预测偏向多数类 | 调整先验或 class_prior |
| 文本未预处理 | 高维稀疏 | TF-IDF、停用词 |
| 方差为 0 | 数值不稳定 | var_smoothing |

## 十一、面试速答

| 问 | 答 |
|----|-----|
| 朴素贝叶斯为何"朴素"？ | 假设特征条件独立（给定类别），现实中很少成立，但简化计算且效果常不错。 |
| 拉普拉斯平滑的原理与必要性？ | 加伪计数避免零概率抹去证据；贝叶斯视角即 Dirichlet 先验的 MAP。 |
| 朴素贝叶斯如何处理连续特征？ | Gaussian NB 假设特征条件正态，估计 $\mu, \sigma^2$；或离散化后用 Multinomial。 |
| 生成 vs 判别模型？ | 生成建模 $P(x,y)$，可生成样本、处理缺失值、半监督；判别直接学 $P(y\mid x)$，精度通常更高。 |
| d-划分的三种结构？ | 链 $A\to B\to C$、分叉 $A\leftarrow B\to C$、V 形 $A\to B\leftarrow C$。前两者给定 $B$ 时 $A\perp C$；V 形相反，默认独立，给定 $B$ 反而相关。 |
| 为何朴素贝叶斯文本分类好？ | 文本词袋模型接近条件独立假设；高维稀疏下判别模型过拟合，朴素贝叶斯高偏差低方差。 |
| 朴素贝叶斯的偏差-方差？ | 高偏差（条件独立假设）低方差（参数少）；小数据上优于判别模型。 |
| 共轭先验作用？ | 后验解析可算，无需数值积分；多项似然 + Dirichlet 先验 = Dirichlet 后验。 |
| 贝叶斯网络 vs 马尔可夫随机场？ | 有向 vs 无向；前者因子分解 $P(X_i\mid \text{Pa})$，后者因子分解为团势能。 |
| 朴素贝叶斯如何处理类别不平衡？ | 调整 class_prior；或用 Complement NB。 |
| 为何 V 形结构默认独立？ | $A \to B \leftarrow C$ 中 $A, C$ 是 $B$ 的独立原因，无其他信息时不相关。但给定 $B$（共同后果）后，知道 $A$ 影响 $B$ 反推 $C$，故变得依赖。 |
| 朴素贝叶斯与逻辑回归的关系？ | 后者在条件分布 $P(y\mid x)$ 上建模；前者联合 $P(x, y)$。线性可分时形式相似但参数估计不同。 |

## 十二、综合面试题

1. **证明 0-1 损失下后验最大化是最优的。**
   - 见第 1.3 节。$\mathbb{E}[L] = 1 - P(y\mid\mathbf{x})$，最小化即最大化后验。

2. **推导朴素贝叶斯的 MLE 估计。**
   - 对数似然 $\ell = \sum_i \log P(y_i) + \sum_i \sum_j \log P(x_{ij} \mid y_i)$。参数独立可分离，分别最大化。$P(y = c) = N_c/N$，$P(x_j = v \mid y = c) = N_{c, j, v}/N_c$。

3. **解释拉普拉斯平滑的贝叶斯合法性。**
   - 多项似然 + Dirichlet($\alpha$) 先验 → Dirichlet($\alpha + \mathbf{n}$) 后验。后验均值 $\hat{\pi}_k = (\alpha_k + n_k)/(\alpha_0 + n)$ 即拉普拉斯平滑估计。$\alpha = 1$ 对应均匀先验。

4. **d-划分规则的形式化定义。**
   - 路径 $p$ 被 $\mathbf{Z}$ 阻断，若路径上存在中间节点 $W$ 满足：(a) $W$ 是链或分叉的中间节点且 $W \in \mathbf{Z}$；或 (b) $W$ 是 collider 且 $W \notin \mathbf{Z}$ 且 $W$ 的后代都不在 $\mathbf{Z}$。若所有 $X$ 到 $Y$ 的路径都被阻断，则 $X \perp Y \mid \mathbf{Z}$。

5. **为何朴素贝叶斯在文本分类中表现好？**
   - 文本词袋模型中，给定主题，词出现概率近似条件独立（主题决定词汇分布）。高维稀疏下判别模型参数多、易过拟合；朴素贝叶斯参数仅 $O(KV)$，高偏差低方差，小数据下优势明显。

6. **生成模型 vs 判别模型的偏差-方差分析。**
   - 生成模型参数少（$P(x\mid y)$ 与 $P(y)$），高偏差低方差，小数据下优。判别模型参数多（直接学 $P(y\mid x)$），低偏差高方差，大数据下优。Ng & Jordan 2001 证明在数据量小时 GDA（生成）优于 LR，数据量大时反之，有理论分界点。

7. **贝叶斯网络的因子分解为何简化推断。**
   - 完整联合分布需 $O(2^n)$ 参数；因子分解后仅需 $\prod_i |\text{Pa}(X_i)| \cdot |X_i|$。稀疏结构下参数与推断成本大幅降低。

8. **朴素贝叶斯的"条件独立"假设失效时为何仍可能有效？**
   - 分类只需后验排序正确，不需概率精确。条件独立假设系统性偏差在各类间相似，相互抵消，不影响排序。这是"朴素"却有效的核心原因。

9. **比较 Multinomial NB 与 Bernoulli NB 在文本分类中的差异。**
   - Multinomial 用词频，长文档权重更大；Bernoulli 用词是否出现，对短文档友好。Multinomial 不考虑词不出现的证据，Bernoulli 考虑。经验上 Multinomial 在多数文本任务略优。

10. **解释 V 形结构的"解释消除"效应。**
    - $A \to B \leftarrow C$，默认 $A \perp C$。但若观测到 $B$（如 $B$ 表示"地面湿"），知道 $A$（"下雨"）会降低 $C$（"洒水车"）的概率——$B$ 已被 $A$ 解释，不再需要 $C$。这是后验依赖的本质。

## 十三、公式速查卡

| 公式 | 表达式 |
|------|--------|
| 贝叶斯公式 | $P(y\mid\mathbf{x}) = P(\mathbf{x}\mid y)P(y)/P(\mathbf{x})$ |
| 朴素贝叶斯 | $\hat{y} = \arg\max_y P(y)\prod_j P(x_j\mid y)$ |
| 拉普拉斯平滑 | $P(x_j=v\mid y=c) = (N_{c,j,v} + \alpha)/(N_c + \alpha V)$ |
| Gaussian NB | $P(x_j\mid c) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp(-(x-\mu)^2/(2\sigma^2))$ |
| Multinomial NB | $P(\mathbf{x}\mid c) \propto \prod_j \theta_{c,j}^{x_j}$ |
| 贝叶斯网络分解 | $P(X_1, \dots, X_n) = \prod_i P(X_i\mid \text{Pa}(X_i))$ |
| Dirichlet 后验 | $\text{Dir}(\boldsymbol{\alpha} + \mathbf{n})$ |
| ELBO | $\mathbb{E}_q[\log p(\mathbf{x},\mathbf{z})] - \mathbb{E}_q[\log q(\mathbf{z})]$ |
