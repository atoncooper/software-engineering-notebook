# 监督学习 —— 支持向量机（SVM）

> SVM 是监督学习理论最美的方法：最大间隔思想给出鲁棒性保证，对偶理论与核技巧提供高维非线性分类的优雅方案。本文系统化推导硬/软间隔 SVM 的对偶，深入讨论核函数的本质、SMO 算法、SVR，并与逻辑回归对比。

## 一、问题定义

### 1.1 最大间隔的动机

给定线性可分数据 $\{(\mathbf{x}_i, y_i)\}$，$y_i \in \{-1, +1\}$。存在无穷多个超平面能分开它们，选哪个？

**最大间隔原则**：选离最近样本最远的超平面。直觉：间隔越大，对噪声鲁棒性越强，泛化越好。

### 1.2 函数间隔 vs 几何间隔

超平面 $(\mathbf{w}, b)$：

- **函数间隔**：$\hat{\gamma}_i = y_i(\mathbf{w}^\top\mathbf{x}_i + b)$
- **几何间隔**：$\gamma_i = y_i(\mathbf{w}^\top\mathbf{x}_i + b)/\|\mathbf{w}\|$

函数间隔对 $(\mathbf{w}, b)$ 整体缩放不变（但优化时会发散）；几何间隔是真正的距离，对 $\|\mathbf{w}\|$ 不变。

### 1.3 优化目标

最大化几何间隔：

$$
\max_{\mathbf{w}, b} \;\gamma = \frac{1}{\|\mathbf{w}\|} \min_i y_i(\mathbf{w}^\top\mathbf{x}_i + b)
$$

等价于（固定函数间隔为 1）：

$$
\min_{\mathbf{w}, b} \;\frac{1}{2}\|\mathbf{w}\|^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^\top\mathbf{x}_i + b) \ge 1, \;\forall i
$$

## 二、硬间隔 SVM

### 2.1 原问题

$$
\min_{\mathbf{w}, b} \;\frac{1}{2}\|\mathbf{w}\|^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^\top\mathbf{x}_i + b) \ge 1
$$

凸二次规划（QP）：目标凸，约束线性。

### 2.2 拉格朗日函数

引入乘子 $\alpha_i \ge 0$：

$$
\mathcal{L}(\mathbf{w}, b, \boldsymbol{\alpha}) = \frac{1}{2}\|\mathbf{w}\|^2 - \sum_i \alpha_i [y_i(\mathbf{w}^\top\mathbf{x}_i + b) - 1]
$$

### 2.3 对 $\mathbf{w}, b$ 求偏导置零

$$
\nabla_\mathbf{w}\mathcal{L} = \mathbf{w} - \sum_i \alpha_i y_i \mathbf{x}_i = 0 \;\Rightarrow\; \mathbf{w} = \sum_i \alpha_i y_i \mathbf{x}_i
$$

$$
\frac{\partial \mathcal{L}}{\partial b} = -\sum_i \alpha_i y_i = 0 \;\Rightarrow\; \sum_i \alpha_i y_i = 0
$$

### 2.4 代回得对偶问题

将 $\mathbf{w} = \sum_i \alpha_i y_i \mathbf{x}_i$ 代入 $\mathcal{L}$：

$$
\mathcal{L} = \frac{1}{2}\|\sum_i \alpha_i y_i \mathbf{x}_i\|^2 - \sum_i \alpha_i y_i (\sum_j \alpha_j y_j \mathbf{x}_j^\top \mathbf{x}_i) - \sum_i \alpha_i y_i b + \sum_i \alpha_i
$$

第二项与第一项相消（注意 $\mathbf{w}^\top\mathbf{w} = \sum_{ij}\alpha_i\alpha_j y_i y_j \mathbf{x}_i^\top\mathbf{x}_j$），第三项因 $\sum\alpha_i y_i = 0$ 消失：

$$
\max_\boldsymbol{\alpha} \;\sum_i \alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_i y_j \mathbf{x}_i^\top\mathbf{x}_j
$$
$$
\text{s.t.} \quad \alpha_i \ge 0, \;\sum_i \alpha_i y_i = 0
$$

### 2.5 KKT 条件与支持向量

| 条件 | 含义 |
|------|------|
| $\alpha_i \ge 0$ | 对偶可行 |
| $y_i(\mathbf{w}^\top\mathbf{x}_i + b) - 1 \ge 0$ | 原始可行 |
| $\alpha_i [y_i(\mathbf{w}^\top\mathbf{x}_i + b) - 1] = 0$ | 互补松弛 |

**互补松弛**：

- $\alpha_i > 0 \Rightarrow y_i(\mathbf{w}^\top\mathbf{x}_i + b) = 1$：样本在间隔边界上，称为**支持向量**
- $\alpha_i = 0 \Rightarrow$ 样本对 $\mathbf{w}$ 无贡献

**关键性质**：解仅依赖支持向量，其他样本可任由变化（不影响解）。这是 SVM 稀疏性的来源。

### 2.6 偏置 $b$ 的求解

对任一支持向量 $i$（$\alpha_i > 0$）：

$$
b = y_i - \mathbf{w}^\top\mathbf{x}_i
$$

工程上对所有支持向量求平均以稳定。

### 2.7 决策函数

$$
f(\mathbf{x}) = \text{sign}\!\left(\sum_i \alpha_i y_i \mathbf{x}_i^\top\mathbf{x} + b\right)
$$

仅依赖支持向量（$\alpha_i > 0$）。

## 三、软间隔 SVM

### 3.1 动机

数据线性不可分时，硬间隔无可行解。允许部分样本违反间隔，但加以惩罚。

### 3.2 松弛变量 $\xi_i$

$$
\min_{\mathbf{w}, b, \boldsymbol{\xi}} \;\frac{1}{2}\|\mathbf{w}\|^2 + C\sum_i \xi_i
$$
$$
\text{s.t.} \quad y_i(\mathbf{w}^\top\mathbf{x}_i + b) \ge 1 - \xi_i, \quad \xi_i \ge 0
$$

$\xi_i$ 度量样本 $i$ 违反间隔的程度：

- $0 \le \xi_i \le 1$：在间隔内但分类正确
- $\xi_i > 1$：分类错误

$C$ 是惩罚系数，权衡间隔大小与违反程度。

### 3.3 合页损失

消除 $\xi_i$：

$$
\xi_i = \max(0, 1 - y_i(\mathbf{w}^\top\mathbf{x}_i + b))
$$

目标变为：

$$
\min_{\mathbf{w}, b} \;\frac{1}{2}\|\mathbf{w}\|^2 + C\sum_i \max(0, 1 - y_i f(\mathbf{x}_i))
$$

后项即**合页损失** $L_{\text{hinge}}(y, f) = \max(0, 1 - yf)$。

### 3.4 软间隔的对偶

拉格朗日函数引入 $\alpha_i \ge 0, \mu_i \ge 0$：

$$
\mathcal{L} = \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_i \xi_i - \sum_i \alpha_i[y_i(\mathbf{w}^\top\mathbf{x}_i + b) - 1 + \xi_i] - \sum_i \mu_i \xi_i
$$

对 $\mathbf{w}, b, \xi_i$ 求偏导置零：

- $\mathbf{w} = \sum_i \alpha_i y_i \mathbf{x}_i$
- $\sum_i \alpha_i y_i = 0$
- $C - \alpha_i - \mu_i = 0 \Rightarrow \alpha_i \in [0, C]$

代回得对偶：

$$
\max_\boldsymbol{\alpha} \;\sum_i \alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_i y_j \mathbf{x}_i^\top\mathbf{x}_j
$$
$$
\text{s.t.} \quad 0 \le \alpha_i \le C, \;\sum_i \alpha_i y_i = 0
$$

与硬间隔仅差 $\alpha_i \le C$ 的上界。

### 3.5 支持向量的分类

| $\alpha_i$ | 位置 |
|------------|------|
| $\alpha_i = 0$ | 非支持向量，间隔外 |
| $0 < \alpha_i < C$ | 在间隔边界上（$\xi_i = 0$） |
| $\alpha_i = C$ | 在间隔内或违反（$\xi_i > 0$） |

### 3.6 $C$ 的作用：偏差-方差权衡

- $C \to \infty$：不允许违反，趋向硬间隔，过拟合风险高
- $C \to 0$：宽松违反，间隔大，欠拟合风险高

## 四、核技巧

### 4.1 核函数的本质

对偶问题与决策函数中 $\mathbf{x}_i$ 仅以内积 $\mathbf{x}_i^\top\mathbf{x}_j$ 形式出现。**用核函数 $K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^\top \phi(\mathbf{x}_j)$ 替换内积**，等价于在特征空间 $\phi(\mathbf{x})$ 中学习，但无需显式计算 $\phi$。

**关键**：$\phi$ 可能为无限维，但 $K$ 计算复杂度不变。

### 4.2 Mercer 定理

函数 $K: \mathcal{X} \times \mathcal{X} \to \mathbb{R}$ 是有效核 $\Leftrightarrow$ 对任意有限样本集 $\{\mathbf{x}_i\}$，核矩阵 $K_{ij} = K(\mathbf{x}_i, \mathbf{x}_j)$ 半正定。

**等价表述**：$K$ 是某希尔伯特空间 $\mathcal{H}$ 上的内积。

### 4.3 常用核函数

| 核 | 公式 | 特点 |
|----|------|------|
| 线性 | $K = \mathbf{x}^\top\mathbf{z}$ | 等价无映射 |
| 多项式 | $(\mathbf{x}^\top\mathbf{z} + c)^d$ | 有限维，度数 $d$ |
| RBF | $\exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2)$ | 无限维，$\gamma = 1/(2\sigma^2)$ |
| Sigmoid | $\tanh(\kappa\mathbf{x}^\top\mathbf{z} + c)$ | 仅特定参数满足 Mercer |
| 拉普拉斯 | $\exp(-\|\mathbf{x}-\mathbf{z}\|/(2\sigma))$ | L1 距离，更鲁棒 |

### 4.4 RBF 核的无限维直觉

$$
K(\mathbf{x}, \mathbf{z}) = \exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2) = e^{-\gamma\|\mathbf{x}\|^2} e^{-\gamma\|\mathbf{z}\|^2} e^{2\gamma \mathbf{x}^\top\mathbf{z}}
$$

最后一项展开：

$$
e^{2\gamma \mathbf{x}^\top\mathbf{z}} = \sum_{k=0}^\infty \frac{(2\gamma)^k}{k!}(\mathbf{x}^\top\mathbf{z})^k
$$

$(\mathbf{x}^\top\mathbf{z})^k$ 展开为所有 $k$ 阶单项式，故 RBF 对应**无限维**特征空间，理论上可分任意非线性数据。

**实践含义**：$\gamma$ 大 → 仅近邻影响 → 高方差过拟合；$\gamma$ 小 → 远样本也相似 → 高偏差欠拟合。

### 4.5 核函数的构造规则

若 $K_1, K_2$ 是核，则以下也是核：

- $K_1 + K_2$（和）
- $c K_1$（$c > 0$ 数乘）
- $K_1 \cdot K_2$（积）
- $f(\mathbf{x}) K_1(\mathbf{x}, \mathbf{z}) f(\mathbf{z})$（点乘）

### 4.6 核方法的局限

- 核矩阵 $O(n^2)$ 存储，$O(n^3)$ 求解，大数据不可行
- 参数选择（$\gamma, d, C$）需 CV
- 仅内积可表达的问题才能核化

## 五、SMO 算法

### 5.1 思想

对偶问题有 $n$ 个变量 $\alpha_i$ 加两个约束。SMO（Sequential Minimal Optimization）每次仅优化两个 $\alpha$（最少可解约束的变量数），固定其余。

### 5.2 两变量更新的合法性

由约束 $\sum\alpha_i y_i = 0$，固定其他变量时：

$$
\alpha_1 y_1 + \alpha_2 y_2 = -\sum_{i \neq 1,2}\alpha_i y_i = \zeta
$$

故 $\alpha_2$ 可由 $\alpha_1$ 表示，问题降为一维。一维 QP 有闭式解。

### 5.3 更新公式

记误差 $E_i = f(\mathbf{x}_i) - y_i$，预测 $\alpha_2^{new,unclipped} = \alpha_2^{old} + \frac{y_2(E_1 - E_2)}{\eta}$，$\eta = K_{11} + K_{22} - 2K_{12}$。

根据 $y_1, y_2$ 是否同号，计算 $\alpha_2$ 的上下界 $L, H$，clip：

$$
\alpha_2^{new} = \text{clip}(\alpha_2^{new,unclipped}, L, H)
$$

$$
\alpha_1^{new} = \alpha_1^{old} + y_1 y_2(\alpha_2^{old} - \alpha_2^{new})
$$

更新 $b$、误差缓存，进入下一对。

### 5.4 启发式选择

- 外层循环选违反 KKT 最严重的 $\alpha_1$
- 内层循环选使 $|E_1 - E_2|$ 最大的 $\alpha_2$

### 5.5 复杂度

经验复杂度 $O(n^2 \sim n^3)$，比通用 QP 求解器快数倍。

## 六、支持向量回归（SVR）

### 6.1 $\epsilon$-不敏感损失

$$
L_\epsilon(y, f) = \max(0, |y - f| - \epsilon)
$$

误差在 $\epsilon$ 内不计损失，超出部分线性增长。

### 6.2 优化问题

$$
\min_{\mathbf{w}, b, \boldsymbol{\xi}, \boldsymbol{\xi}^*} \;\frac{1}{2}\|\mathbf{w}\|^2 + C\sum_i(\xi_i + \xi_i^*)
$$
$$
\text{s.t.} \quad y_i - \mathbf{w}^\top\mathbf{x}_i - b \le \epsilon + \xi_i
$$
$$
\mathbf{w}^\top\mathbf{x}_i + b - y_i \le \epsilon + \xi_i^*
$$
$$
\xi_i, \xi_i^* \ge 0
$$

### 6.3 对偶与决策函数

对偶类似分类，但有两套乘子 $\alpha_i, \alpha_i^*$（上下违反）。决策：

$$
f(\mathbf{x}) = \sum_i (\alpha_i - \alpha_i^*) K(\mathbf{x}_i, \mathbf{x}) + b
$$

仅 $\alpha_i \neq \alpha_i^*$ 的样本（在 $\epsilon$ 管外）是支持向量。

## 七、SVM 与其他方法的等价与对比

### 7.1 SVM = 合页损失 + L2 正则

$$
\min_{\mathbf{w}, b} \;\frac{1}{2}\|\mathbf{w}\|^2 + C\sum_i \max(0, 1 - y_i(\mathbf{w}^\top\mathbf{x}_i + b))
$$

对照 [线性模型 SRM](./监督学习-线性模型.md#1.2-erm-与-srm)：$\frac{1}{2}\|\mathbf{w}\|^2$ 即 L2 正则，合页损失即损失项。

### 7.2 与逻辑回归的对比

| 维度 | SVM | 逻辑回归 |
|------|-----|----------|
| 损失 | 合页 $\max(0, 1-yf)$ | 对数 $\log(1+e^{-yf})$ |
| 概率 | 无直接概率 | 输出概率 |
| 解稀疏 | 是（仅支持向量） | 否（所有样本） |
| 鲁棒性 | 合页损失有"平坦区" | 对数损失对异常敏感 |
| 凸性 | 凸 | 凸 |
| 核化 | 自然 | 可但少用 |

### 7.3 损失函数的几何

```
Loss
  │
  │╲  ← 指数（AdaBoost）
  │ ╲
  │  ╲ ← 对数（LR）
  │   ╲     ___
  │    ╲___╱  ← 合页（SVM，1 后为 0）
  │
  └────────── yf
  0    1
```

合页损失在 $yf \ge 1$ 时为 0，对"足够正确"的样本不再惩罚——这是稀疏性的根源。

## 八、算法流程与复杂度

| 阶段 | 复杂度 | 说明 |
|------|--------|------|
| 训练（核 SVM） | $O(n^2 \sim n^3)$ | 核矩阵 + QP 求解 |
| 训练（线性 SVM） | $O(nd \cdot T)$ | Pegasos 等 |
| 推理 | $O(|SV| \cdot d)$ 或 $O(|SV| \cdot n)$（核） | 仅支持向量 |

**为何 SVM 在大数据集上不如树模型**：

- 核 SVM $O(n^3)$ 不可扩展
- 线性 SVM 可扩展但表达力有限
- 树模型 $O(nd \log n)$，且天然处理类别特征

## 九、代码实现（工业级）

### 9.1 从零实现：简化 SMO

```python
"""
简化版 SMO 算法（Platt 1998 的精简版）。
仅用于教学，工业场景用 sklearn 或 LIBSVM。
"""
from __future__ import annotations
from dataclasses import dataclass
from typing import List, Tuple
import numpy as np


@dataclass
class SVMConfig:
    C: float = 1.0
    kernel: str = "linear"
    gamma: float = 0.5
    tol: float = 1e-3
    max_passes: int = 10


class SVM:
    def __init__(self, config: SVMConfig):
        self.config = config
        self.alpha: np.ndarray = None
        self.b: float = 0.0
        self.X: np.ndarray = None
        self.y: np.ndarray = None

    def _kernel(self, X1: np.ndarray, X2: np.ndarray) -> np.ndarray:
        if self.config.kernel == "linear":
            return X1 @ X2.T
        elif self.config.kernel == "rbf":
            sq1 = (X1 ** 2).sum(axis=1, keepdims=True)
            sq2 = (X2 ** 2).sum(axis=1)
            d2 = sq1 + sq2 - 2 * X1 @ X2.T
            return np.exp(-self.config.gamma * d2)
        else:
            raise ValueError(f"未知核: {self.config.kernel}")

    def fit(self, X: np.ndarray, y: np.ndarray) -> "SVM":
        n = X.shape[0]
        self.X, self.y = X, y.astype(float)
        self.alpha = np.zeros(n)
        self.b = 0.0
        K = self._kernel(X, X)
        passes = 0
        while passes < self.config.max_passes:
            num_changed = 0
            for i in range(n):
                E_i = self._error(K, i)
                if ((self.y[i] * E_i < -self.config.tol and self.alpha[i] < self.config.C) or
                    (self.y[i] * E_i > self.config.tol and self.alpha[i] > 0)):
                    j = self._select_j(i, n)
                    E_j = self._error(K, j)
                    alpha_i_old, alpha_j_old = self.alpha[i], self.alpha[j]
                    L, H = self._bounds(i, j)
                    if L == H:
                        continue
                    eta = 2 * K[i, j] - K[i, i] - K[j, j]
                    if eta >= 0:
                        continue
                    self.alpha[j] -= self.y[j] * (E_i - E_j) / eta
                    self.alpha[j] = np.clip(self.alpha[j], L, H)
                    if abs(self.alpha[j] - alpha_j_old) < 1e-5:
                        continue
                    self.alpha[i] += self.y[i] * self.y[j] * (alpha_j_old - self.alpha[j])
                    b1 = (self.b - E_i
                          - self.y[i] * (self.alpha[i] - alpha_i_old) * K[i, i]
                          - self.y[j] * (self.alpha[j] - alpha_j_old) * K[i, j])
                    b2 = (self.b - E_j
                          - self.y[i] * (self.alpha[i] - alpha_i_old) * K[i, j]
                          - self.y[j] * (self.alpha[j] - alpha_j_old) * K[j, j])
                    if 0 < self.alpha[i] < self.config.C:
                        self.b = b1
                    elif 0 < self.alpha[j] < self.config.C:
                        self.b = b2
                    else:
                        self.b = (b1 + b2) / 2
                    num_changed += 1
            passes = passes + 1 if num_changed == 0 else 0
        return self

    def _error(self, K: np.ndarray, i: int) -> float:
        return float((self.alpha * self.y) @ K[:, i] + self.b - self.y[i])

    def _select_j(self, i: int, n: int) -> int:
        j = i
        while j == i:
            j = np.random.randint(n)
        return j

    def _bounds(self, i: int, j: int) -> Tuple[float, float]:
        if self.y[i] != self.y[j]:
            return (max(0, self.alpha[j] - self.alpha[i]),
                    min(self.config.C, self.config.C + self.alpha[j] - self.alpha[i]))
        else:
            return (max(0, self.alpha[i] + self.alpha[j] - self.config.C),
                    min(self.config.C, self.alpha[i] + self.alpha[j]))

    def decision_function(self, X: np.ndarray) -> np.ndarray:
        sv = self.alpha > 0
        K = self._kernel(X, self.X[sv])
        return K @ (self.alpha[sv] * self.y[sv]) + self.b

    def predict(self, X: np.ndarray) -> np.ndarray:
        return np.sign(self.decision_function(X)).astype(int)
```

### 9.2 sklearn 工业级用法

```python
import numpy as np
from sklearn.svm import SVC, SVR, LinearSVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.model_selection import GridSearchCV, cross_val_score
from sklearn.datasets import make_moons

# 非线性可分数据
X, y = make_moons(n_samples=500, noise=0.2, random_state=42)
y = np.where(y == 0, -1, 1)

# 核 SVM 调参
pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("svm", SVC(kernel="rbf"))
])
param_grid = {
    "svm__C": [0.1, 1, 10, 100],
    "svm__gamma": ["scale", "auto", 0.01, 0.1, 1]
}
grid = GridSearchCV(pipe, param_grid, cv=5, scoring="accuracy", n_jobs=-1)
grid.fit(X, y)
print(f"最优参数: {grid.best_params_}, 准确率: {grid.best_score_:.4f}")

# 大规模线性 SVM
# LinearSVC 比 SVC(kernel="linear") 快得多
from sklearn.datasets import make_classification
X_big, y_big = make_classification(n_samples=100000, n_features=20, random_state=0)
linear_svm = LinearSVC(C=1.0, loss="hinge", max_iter=10000, dual=False)
linear_svm.fit(X_big, y_big)
```

## 十、实战案例：RBF 核 SVM 调参

```python
"""
完整流程：数据生成 → 标准化 → CV 调 C 与 gamma → 评估。
"""
import numpy as np
import matplotlib.pyplot as plt
from sklearn.svm import SVC
from sklearn.datasets import make_moons
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import GridSearchCV
from sklearn.metrics import accuracy_score


def plot_decision_boundary(clf, X, y, ax=None):
    """绘制 SVM 决策边界与支持向量。"""
    if ax is None:
        ax = plt.gca()
    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    xx, yy = np.meshgrid(np.linspace(x_min, x_max, 200),
                          np.linspace(y_min, y_max, 200))
    Z = clf.decision_function(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)
    ax.contour(xx, yy, Z, levels=[-1, 0, 1], linestyles=["--", "-", "--"],
                colors="k", alpha=0.5)
    ax.scatter(X[:, 0], X[:, 1], c=y, cmap="bwr", s=20, edgecolors="k")
    ax.scatter(clf.support_vectors_[:, 0], clf.support_vectors_[:, 1],
                s=100, facecolors="none", edgecolors="y", linewidths=1.5)


X, y = make_moons(n_samples=500, noise=0.2, random_state=42)
X = StandardScaler().fit_transform(X)

# C 与 gamma 的联合搜索（log 网格）
param_grid = {
    "C": np.logspace(-2, 3, 6),
    "gamma": np.logspace(-3, 2, 6)
}
grid = GridSearchCV(SVC(kernel="rbf"), param_grid, cv=5,
                    scoring="accuracy", n_jobs=-1)
grid.fit(X, y)
print(f"最优参数: C={grid.best_params_['C']}, "
      f"gamma={grid.best_params_['gamma']}, "
      f"准确率: {grid.best_score_:.4f}")

plot_decision_boundary(grid.best_estimator_, X, y)
```

**调参经验**：

- $C$ 与 $\gamma$ 在 log 网格上搜索
- $C$ 大、$\gamma$ 大 → 过拟合；$C$ 小、$\gamma$ 小 → 欠拟合
- $C$ 与 $\gamma$ 乘积近似常数时性能相近（Bergstra 经验）

## 十一、常见陷阱

| 陷阱 | 后果 | 对策 |
|------|------|------|
| 未标准化 | RBF 核尺度失真 | 必须标准化 |
| $\gamma$ 过大 | 过拟合（每个点独占一区） | CV 调参 |
| $C$ 过大 | 过拟合 + 数值不稳 | log 网格搜索 |
| 类别不平衡 | 决策偏向多数类 | `class_weight="balanced"` |
| 大数据用核 SVM | $O(n^3)$ 不可行 | 用 LinearSVC 或树模型 |
| 概率输出 | SVM 无直接概率 | `probability=True` 用 Platt Scaling |
| 多分类 | SVM 原生二分类 | OvR / OvO |
| 核矩阵内存 | $O(n^2)$ 爆炸 | Nyström 近似 |

## 十三、面试速答

| 问 | 答 |
|----|-----|
| 为何用对偶而非原问题？ | 对偶暴露内积结构使核技巧可行；约束变为简单的 $\alpha \in [0, C]$；解仅依赖支持向量稀疏。 |
| SVM 的对偶推导？ | 拉格朗日函数 → 对 $\mathbf{w}, b, \xi$ 求导置零 → 代回 → 得对偶 $\max \sum\alpha_i - \frac{1}{2}\sum\alpha_i\alpha_j y_i y_j K_{ij}$，约束 $0 \le \alpha_i \le C, \sum\alpha_i y_i = 0$。 |
| 支持向量定义？ | $\alpha_i > 0$ 的样本，在间隔边界或违反间隔。仅它们决定决策函数。 |
| 核函数本质？ | $K(\mathbf{x}, \mathbf{z}) = \phi(\mathbf{x})^\top\phi(\mathbf{z})$，避免显式计算 $\phi$；可映射到无限维。 |
| 为何 RBF 映射到无限维？ | $e^{2\gamma \mathbf{x}^\top\mathbf{z}}$ 泰勒展开为 $\sum (2\gamma)^k (\mathbf{x}^\top\mathbf{z})^k/k!$，含所有阶单项式。 |
| 软间隔 $C$ 的作用？ | 偏差-方差权衡。$C$ 大 → 严格惩罚违反 → 过拟合；$C$ 小 → 宽容 → 欠拟合。 |
| SVM 与逻辑回归区别？ | 损失（合页 vs 对数）；稀疏（仅 SV vs 全样本）；概率（无 vs 有）。 |
| Mercer 定理？ | $K$ 有效 $\Leftrightarrow$ 核矩阵半正定。 |
| SMO 思想？ | 每次仅优化两个 $\alpha$（最少满足等式约束），一维 QP 闭式解。 |
| SVM 为何大数据不如树？ | 核 SVM $O(n^3)$ 不可扩展；线性 SVM 表达力有限；树模型 $O(nd \log n)$。 |
| 合页损失为何稀疏？ | $yf \ge 1$ 时损失为 0，梯度为 0，对应 $\alpha_i = 0$。 |
| $\gamma$ 与 $\sigma$ 关系？ | RBF 中 $\gamma = 1/(2\sigma^2)$，$\gamma$ 大即 $\sigma$ 小，影响范围小。 |

## 十四、综合面试题

1. **从原问题完整推导软间隔 SVM 对偶。**
   - 见第 3.4 节。关键步骤：构造拉格朗日（含 $\alpha \ge 0, \mu \ge 0$）→ 对 $\mathbf{w}, b, \xi$ 求偏导置零得 $\mathbf{w} = \sum\alpha_i y_i \mathbf{x}_i$、$\sum\alpha_i y_i = 0$、$\alpha_i + \mu_i = C$ → 代回消去 $\mu$ 得 $\alpha \in [0, C]$。

2. **证明互补松弛给出支持向量。**
   - KKT 条件 $\alpha_i [y_i f(\mathbf{x}_i) - 1 + \xi_i] = 0$ 与 $\mu_i \xi_i = 0$。若 $\alpha_i \in (0, C)$：$\mu_i = C - \alpha_i > 0$ 故 $\xi_i = 0$，且 $y_i f(\mathbf{x}_i) = 1$，样本在间隔边界。若 $\alpha_i = 0$：非支持向量。若 $\alpha_i = C$：$\xi_i \ge 0$，可能违反。

3. **解释核技巧为何能学习非线性分类器。**
   - 决策函数 $f(\mathbf{x}) = \sum\alpha_i y_i K(\mathbf{x}_i, \mathbf{x}) + b$。若 $K = \phi(\mathbf{x}_i)^\top\phi(\mathbf{x})$，等价于在 $\phi$-空间学习线性 SVM。$\phi$ 可为非线性映射甚至无限维，但 $K$ 计算复杂度不变。

4. **Mercer 定理的充要性证明思路。**
   - 必要：$K$ 是内积 ⇒ 核矩阵 $K_{ij} = \phi(\mathbf{x}_i)^\top\phi(\mathbf{x}_j)$ ⇒ $\mathbf{v}^\top K \mathbf{v} = \|\sum v_i \phi(\mathbf{x}_i)\|^2 \ge 0$。
   - 充分：$K$ 半正定 ⇒ Cholesky 分解 $K = V\Lambda V^\top$ ⇒ 定义 $\phi(\mathbf{x}_i) = \Lambda^{1/2} V_{i:}$ ⇒ $K_{ij} = \phi(\mathbf{x}_i)^\top\phi(\mathbf{x}_j)$。

5. **比较 SVM、逻辑回归、AdaBoost 的损失函数与鲁棒性。**
   - 损失：合页 $\max(0, 1-yf)$、对数 $\log(1+e^{-yf})$、指数 $e^{-yf}$。
   - 鲁棒性：指数对 $yf < 0$ 增长过快，对异常值敏感；对数次之；合页在 $yf > 1$ 后为 0，最鲁棒。
   - 稀疏：仅合页稀疏（$\alpha_i = 0$ on $yf > 1$）。

6. **SMO 为何每次仅优化两个变量？**
   - 约束 $\sum\alpha_i y_i = 0$ 是等式约束。若只优化一个 $\alpha_i$，该约束被破坏。优化两个时，可由 $\alpha_1 y_1 + \alpha_2 y_2 = \text{const}$ 解出关系，降为一维问题，闭式解。

7. **解释 RBF 核的 $\gamma$ 参数对模型复杂度的影响。**
   - $K(\mathbf{x}, \mathbf{z}) = \exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2)$。$\gamma$ 大 → 仅近邻相似 → 决策边界复杂（高方差）；$\gamma$ 小 → 远样本也相似 → 决策边界平滑（高偏差）。等价于高斯分布方差 $\sigma^2 = 1/(2\gamma)$。

8. **SVM 如何处理多分类？**
   - OvR：训练 $K$ 个二分类（每类 vs 其余），预测取最大决策值。简单但类别不平衡敏感。
   - OvO：训练 $K(K-1)/2$ 个二分类（每对两类），投票决定。复杂但更准。
   - sklearn 默认 OvR；LIBSVM 默认 OvO。

9. **SVR 与 SVM 分类的对偶有何异同？**
   - 同：都用核技巧、稀疏解、$C$ 控制正则。
   - 异：SVR 用 $\epsilon$-不敏感损失，引入两套乘子 $\alpha, \alpha^*$（上下违反）；分类仅一套 $\alpha$。SVR 的支持向量是 $\epsilon$ 管外的样本。

10. **证明线性 SVM 等价于 L2 正则化的合页损失最小化。**
    - 软间隔 SVM 原问题消去 $\xi$：$\min \frac{1}{2}\|\mathbf{w}\|^2 + C\sum\max(0, 1 - y_i(\mathbf{w}^\top\mathbf{x}_i + b))$。
    - 令 $\lambda = 1/(2nC)$，等价于 $\min \frac{1}{n}\sum L_{\text{hinge}} + \lambda\|\mathbf{w}\|^2$，即 SRM 形式。

## 十五、公式速查卡

| 公式 | 表达式 |
|------|--------|
| 几何间隔 | $\gamma_i = y_i(\mathbf{w}^\top\mathbf{x}_i + b)/\|\mathbf{w}\|$ |
| 硬间隔原问题 | $\min \frac{1}{2}\|\mathbf{w}\|^2$ s.t. $y_i f(\mathbf{x}_i) \ge 1$ |
| 软间隔原问题 | $\min \frac{1}{2}\|\mathbf{w}\|^2 + C\sum\xi_i$ |
| 对偶目标 | $\max_\alpha \sum\alpha_i - \frac{1}{2}\sum\alpha_i\alpha_j y_i y_j K_{ij}$ |
| 对偶约束 | $0 \le \alpha_i \le C$，$\sum\alpha_i y_i = 0$ |
| $\mathbf{w}$ 解 | $\mathbf{w} = \sum\alpha_i y_i \mathbf{x}_i$ |
| 决策函数 | $f(\mathbf{x}) = \sum\alpha_i y_i K(\mathbf{x}_i, \mathbf{x}) + b$ |
| 合页损失 | $\max(0, 1 - yf)$ |
| $\epsilon$-不敏感 | $\max(0, \|y - f\| - \epsilon)$ |
| RBF 核 | $\exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2)$ |
| SMO 更新 | $\alpha_2^{new} = \text{clip}(\alpha_2 + y_2(E_1 - E_2)/\eta, L, H)$ |
