# 无监督学习 —— 聚类

> 聚类是把"没有标签"的数据按相似度自动分组：同簇内尽量相似，异簇间尽量不同。
> 它既是探索性数据分析的核心工具，也是降维、异常检测、推荐召回、半监督学习的上游模块。
> 本文按 **K-Means → 层次聚类 → DBSCAN → GMM → 谱聚类** 的顺序展开，强调几何直觉、概率视角与工程陷阱。

## 一、问题定义

### 1.1 什么是聚类

给定无标签样本 $X = \{\mathbf{x}_1, \dots, \mathbf{x}_n\}, \mathbf{x}_i \in \mathbb{R}^d$，求划分 $C_1, \dots, C_K$ 使得：

$$
\bigcup_{k=1}^K C_k = X, \quad C_i \cap C_j = \emptyset\ (i \neq j)
$$

并最小化某类"簇内紧密度"目标。聚类本质是**组合优化**，但多数目标 NP-hard，故实际算法都是启发式。

### 1.2 三大流派

| 流派 | 代表 | 核心假设 | 形状假设 |
|------|------|----------|----------|
| 原型聚类 | K-Means, GMM | 每簇有一个原型（均值/中心） | 凸、球形 |
| 密度聚类 | DBSCAN, HDBSCAN | 簇 = 高密度连通区域 | 任意形状 |
| 层次聚类 | AGNES, DIANA | 簇间有嵌套关系 | 任意，由 linkage 决定 |
| 图聚类 | 谱聚类 | 簇 = 图上的稠密子图 | 任意，由相似图决定 |

### 1.3 应用场景

- 客户分群（RFM、画像）
- 文档/新闻主题分组
- 图像分割、颜色量化
- 异常检测的前置（小簇 = 异常）
- 半监督学习的标签传播起点
- 推荐召回中的 item 分桶

## 二、K-Means

### 2.1 直觉

随机选 $K$ 个中心 → 每点归入最近中心 → 中心更新为簇内均值 → 重复直至稳定。

### 2.2 目标函数

最小化簇内平方和（Within-Cluster Sum of Squares, WCSS）：

$$
\min_{C, \boldsymbol{\mu}} \sum_{k=1}^K \sum_{\mathbf{x} \in C_k} \|\mathbf{x} - \boldsymbol{\mu}_k\|^2
$$

其中 $\boldsymbol{\mu}_k = \frac{1}{|C_k|}\sum_{\mathbf{x} \in C_k} \mathbf{x}$。

### 2.3 EM 视角

K-Means 是 GMM 在以下假设下的特例：
- 各簇协方差 $\Sigma_k = \sigma^2 I$（各向同性、同方差）
- 各簇先验 $\pi_k$ 相等
- 软分配退化为硬分配（$\sigma \to 0$）

**E 步**（固定 $\boldsymbol{\mu}$，更新分配）：

$$
r_{nk} = \begin{cases} 1, & k = \arg\min_j \|\mathbf{x}_n - \boldsymbol{\mu}_j\|^2 \\ 0, & \text{otherwise} \end{cases}
$$

**M 步**（固定分配，更新中心）：

$$
\boldsymbol{\mu}_k = \frac{\sum_n r_{nk} \mathbf{x}_n}{\sum_n r_{nk}}
$$

### 2.4 算法流程

```
输入: X ∈ R^{n×d}, K, 最大迭代 T, 容差 ε
1. 初始化中心 μ_1,...,μ_K (随机选 K 个样本 / K-Means++)
2. for t = 1..T:
   a. E 步: 每个 x_n 分到最近中心 → r_{nk}
   b. M 步: μ_k ← 簇内均值
   c. 若 ||μ^{(t)} - μ^{(t-1)}|| < ε: break
3. 返回 {C_1,...,C_K}, {μ_1,...,μ_K}
```

**复杂度**：每次迭代 $O(nKd)$。$n$ 大时常用 Mini-Batch K-Means。

### 2.5 收敛性

- 每次迭代 WCSS 单调不增（E 步选最近中心必降，M 步均值最小化 SSE）。
- 有限状态空间（分配方案有限）→ 必收敛。
- 但收敛到**局部最优**，依赖初始化。

### 2.6 K-Means++ 初始化

随机选第一个中心；之后每个新中心以正比于 $D(\mathbf{x})^2$ 的概率选取，$D(\mathbf{x})$ 为到已选中心的最小距离。

**理论保证**：期望目标值 $\le 8(\ln K + 2) \cdot \text{OPT}$，即 $O(\log K)$ 近似比。

### 2.7 K 的选择

| 方法 | 思路 | 缺点 |
|------|------|------|
| 肘部法则 | 画 WCSS vs $K$，选拐点 | 拐点不明确 |
| 轮廓系数 | $\max_K$ silhouette | 计算开销 $O(n^2)$ |
| Gap statistic | 与零假设下 WCSS 比较 | 需参考分布采样 |
| Calinski-Harabasz | 簇间/簇内方差比 | 倾向凸簇 |
| Davies-Bouldin | 簇间距离/簇内紧度比 | 越小越好 |

### 2.8 K-Means 的几何局限

- **形状假设**：凸球形簇。环形、月牙形会被劈成两半。
- **尺度敏感**：未标准化时大尺度特征主导，必须预处理。
- **离群点敏感**：均值被极端点拉偏。可用 K-Medoids（中心必须是真实样本点）缓解。
- **K 固定**：不能自适应簇数。DBSCAN/HDBSCAN 可。

## 三、层次聚类

### 3.1 自底向上（AGNES）与自顶向下（DIANA）

- **AGNES**（Agglomerative）：每个样本自成一簇，反复合并最近的两簇。
- **DIANA**（Divisive）：所有样本成一簇，反复分裂。

AGNES 更常用。一旦合并不可撤销（贪心）。

### 3.2 簇间距离（linkage）

| linkage | 定义 | 特点 |
|---------|------|------|
| single | $\min_{i \in A, j \in B} d(i,j)$ | 链式效应，易拉长 |
| complete | $\max_{i \in A, j \in B} d(i,j)$ | 紧凑，偏好球形 |
| average | $\frac{1}{|A||B|}\sum d(i,j)$ | 折中 |
| ward | 合并使 WCSS 增量最小 | 与 K-Means 同目标，需欧氏 |

### 3.3 算法（AGNES）

```
1. 初始化: 每点自成一簇
2. 计算所有簇对距离
3. while 簇数 > K:
   a. 找最近簇对 (A, B)
   b. 合并 A, B
   c. 更新与新簇的距离 (Lance-Williams 公式)
4. 返回层次树 (可切到任意 K)
```

**复杂度**：$O(n^3)$ 朴素，$O(n^2 \log n)$ 用优先队列。$n > 10^4$ 不实用。

### 3.4 Lance-Williams 公式

新簇 $C_{AB} = A \cup B$ 与簇 $C$ 的距离可由原距离递推：

$$
d(C_{AB}, C) = \alpha_A d(A,C) + \alpha_B d(B,C) + \beta d(A,B) + \gamma |d(A,C)^2 - d(B,C)^2|
$$

不同 linkage 对应不同系数，避免每次重算所有点对距离。

### 3.5 树状图与切分

层次聚类的产物是一棵**树状图（dendrogram）**。在某一高度横切，得到对应 $K$ 的划分。优势：不需预先指定 $K$，可在不同粒度上观察结构。

## 四、DBSCAN

### 4.1 核心思想

簇 = 由密度可达关系形成的连通区域。能识别任意形状，并自动标记噪声点。

### 4.2 定义

- **$\epsilon$-邻域**：$N_\epsilon(\mathbf{x}) = \{\mathbf{y} : d(\mathbf{x}, \mathbf{y}) \le \epsilon\}$
- **核心点**：$|N_\epsilon(\mathbf{x})| \ge \text{MinPts}$
- **边界点**：非核心，但在某核心点邻域内
- **噪声点**：既非核心也非边界

**密度直达**：核心点 $\mathbf{x}$ 直接可达邻域内的点 $\mathbf{y}$。

**密度可达**：存在链 $\mathbf{x} = \mathbf{p}_1 \to \mathbf{p}_2 \to \dots \to \mathbf{p}_m = \mathbf{y}$，每步密度直达（注意：方向性，中间点必须为核心点）。

**密度相连**：存在 $\mathbf{o}$ 使 $\mathbf{x}, \mathbf{y}$ 都从 $\mathbf{o}$ 密度可达。

**簇** = 由密度相连关系导出的极大点集。

### 4.3 算法

```
输入: X, ε, MinPts
1. 对每个未访问点 p:
   a. 若 p 是核心点:
      - 新建簇 C, 加入 p
      - 对 p 的 ε-邻域内每个点 q:
        * 若 q 未访问: 访问 q; 若 q 是核心点, 把 q 的邻域加入扩展队列
        * 若 q 未归属任何簇: 加入 C
   b. 否则: 暂时标记噪声 (后续可能被某核心点纳入成为边界点)
2. 返回所有簇 + 噪声
```

**复杂度**：$O(n \log n)$ 用 KD 树/球树；$O(n^2)$ 朴素。

### 4.4 $\epsilon$ 与 MinPts 选择

- **MinPts 经验**：$2d - 1$ 或 $\ge 3$，数据量大时上调。
- **$\epsilon$ 选择**：对每个点求到第 $k=\text{MinPts}$ 近邻的距离，排序画 k-distance 图，选拐点。
- **密度不均**：DBSCAN 单组参数难处理密度差异大的簇 → 用 HDBSCAN 或 OPTICS。

### 4.5 优缺点

| 优点 | 缺点 |
|------|------|
| 任意形状 | $\epsilon$, MinPts 敏感 |
| 自动定簇数 | 密度差异大时失效 |
| 标记噪声 | 高维距离失效（维数灾难） |
| 无需初始化 | 边界点归属不稳定（取决于访问顺序） |

## 五、GMM（高斯混合模型）

### 5.1 模型

$$
p(\mathbf{x}) = \sum_{k=1}^K \pi_k \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \Sigma_k), \quad \sum_k \pi_k = 1
$$

引入隐变量 $z_n \in \{1, \dots, K\}$ 表示样本 $\mathbf{x}_n$ 所属簇：

$$
p(\mathbf{x}_n, z_n = k) = \pi_k \mathcal{N}(\mathbf{x}_n \mid \boldsymbol{\mu}_k, \Sigma_k)
$$

### 5.2 EM 推导

**目标**：最大化对数似然

$$
\ell = \sum_n \log \sum_k \pi_k \mathcal{N}(\mathbf{x}_n \mid \boldsymbol{\mu}_k, \Sigma_k)
$$

直接求导有 $\log\sum$ 嵌套，难解析。EM 迭代。

**E 步**：计算责任（后验概率）

$$
\gamma_{nk} = p(z_n = k \mid \mathbf{x}_n) = \frac{\pi_k \mathcal{N}(\mathbf{x}_n \mid \boldsymbol{\mu}_k, \Sigma_k)}{\sum_j \pi_j \mathcal{N}(\mathbf{x}_n \mid \boldsymbol{\mu}_j, \Sigma_j)}
$$

$N_k = \sum_n \gamma_{nk}$ 为簇 $k$ 的有效样本数。

**M 步**：以 $\gamma_{nk}$ 为权重更新参数

$$
\boldsymbol{\mu}_k = \frac{1}{N_k}\sum_n \gamma_{nk} \mathbf{x}_n
$$

$$
\Sigma_k = \frac{1}{N_k}\sum_n \gamma_{nk}(\mathbf{x}_n - \boldsymbol{\mu}_k)(\mathbf{x}_n - \boldsymbol{\mu}_k)^\top
$$

$$
\pi_k = \frac{N_k}{n}
$$

### 5.3 与 K-Means 关系

- K-Means = $\Sigma_k = \sigma^2 I$、$\pi_k$ 等先验、硬分配的 GMM。
- GMM 软分配，可处理椭圆簇；协方差可对角化（参数少）或共享（类似 LDA）。
- GMM 是**生成模型**，可采样新数据。

### 5.4 协方差约束

| 类型 | 参数量 | 适用 |
|------|--------|------|
| full | $K \cdot d(d+1)/2$ | 数据足、需柔性 |
| tied | $d(d+1)/2$ | 簇间形状相似 |
| diag | $K \cdot d$ | 默认，特征独立近似 |
| spherical | $K$ | ≈ K-Means 但软分配 |

## 六、谱聚类

### 6.1 思路

把数据建成相似图，聚类 = 图划分（最小割）。但最小割容易切出孤立点，故改为平衡划分（RatioCut / Normalized Cut），再松弛为特征值问题。

### 6.2 步骤

1. **构相似图**：kNN 图或 $\epsilon$-邻域图，权重 $W_{ij} = \exp(-\|\mathbf{x}_i - \mathbf{x}_j\|^2/(2\sigma^2))$。
2. **度矩阵** $D = \text{diag}(\sum_j W_{ij})$。
3. **拉普拉斯矩阵**：
   - 非归一化：$L = D - W$
   - 归一化：$L_{\text{sym}} = I - D^{-1/2} W D^{-1/2}$（Ng-Jordan-Weiss）
   - 随机游走：$L_{\text{rw}} = I - D^{-1}W$（Shi-Malik）
4. **求前 $K$ 个最小特征向量** $\mathbf{u}_1, \dots, \mathbf{u}_K$，列堆叠成 $U \in \mathbb{R}^{n \times K}$。
5. **行归一化**（Ng et al.）：$T_{ij} = U_{ij}/\sqrt{\sum_j U_{ij}^2}$。
6. **对 $U$ 的行向量做 K-Means**，得到簇分配。

### 6.3 为什么有效

- 拉普拉斯矩阵 $L$ 的最小特征值为 0，对应特征向量为常数（全 1）。前 $K$ 个特征向量构成"理想的 $K$ 维嵌入"，使同簇点在嵌入空间中接近，K-Means 在嵌入空间中容易分割。
- 谱聚类能处理非凸簇（如月牙、同心圆），因为相似图绕过了欧氏几何的凸性约束。
- 复杂度：特征分解 $O(n^3)$ 朴素，稀疏矩阵 $O(nK)$ 用 Lanczos。

### 6.4 RatioCut 与 Ncut 的松弛

- RatioCut：$\min \sum_k \frac{\text{cut}(C_k, \bar{C}_k)}{|C_k|}$
- Ncut：$\min \sum_k \frac{\text{cut}(C_k, \bar{C}_k)}{\text{vol}(C_k)}$，$\text{vol}$ 为度之和

将指示向量松弛为实数向量，问题转化为 $L$（或 $L_{\text{sym}}$）的 Rayleigh 商最小化，解为前 $K$ 个特征向量。

## 七、聚类评估

### 7.1 内部指标（无真值）

| 指标 | 定义 | 越大/小 |
|------|------|---------|
| 轮廓系数 | $\frac{b - a}{\max(a, b)}$ | 越大（[-1, 1]） |
| Calinski-Harabasz | $\frac{\text{SS}_B / (K-1)}{\text{SS}_W / (n-K)}$ | 越大 |
| Davies-Bouldin | $\max_{j \neq k}\frac{s_i + s_j}{d_{ij}}$ 的平均 | 越小 |
| Dunn | $\min_{i \neq j} d(C_i,C_j) / \max_k \text{diam}(C_k)$ | 越大 |

**轮廓系数**：$a$ = 点到同簇其他点平均距离，$b$ = 点到最近异簇点平均距离。
- $s \to 1$：分类理想
- $s \to 0$：簇边界模糊
- $s < 0$：可能错分

### 7.2 外部指标（有真值）

| 指标 | 思路 | 范围 |
|------|------|------|
| ARI | 修正后的 Rand 指数，扣除随机期望 | [-1, 1]，0 = 随机 |
| NMI | $I(Y; C)/\sqrt{H(Y)H(C)}$ | [0, 1] |
| V-measure | 调和的同质性与完整性 | [0, 1] |
| FMI | Fowlkes-Mallows | [0, 1] |

**ARI 公式**：

$$
\text{ARI} = \frac{\binom{n}{2}^{-1}\sum_{ij}\binom{n_{ij}}{2} - \left[\sum_i\binom{a_i}{2}\sum_j\binom{b_j}{2}\right]/\binom{n}{2}}{\frac{1}{2}\left[\sum_i\binom{a_i}{2} + \sum_j\binom{b_j}{2}\right] - \left[\sum_i\binom{a_i}{2}\sum_j\binom{b_j}{2}\right]/\binom{n}{2}}
$$

其中 $n_{ij}$ 为同时属于真值类 $i$ 和聚类 $j$ 的样本数，$a_i, b_j$ 为边际。

### 7.3 稳定性指标

- **ARI / NMI 在多次随机初始化下的方差**：方差大说明结果不稳定，簇结构不可靠。
- **共识聚类（consensus clustering）**：对多次重采样结果求共现矩阵，衡量稳定性。

## 八、PyTorch / scikit-learn 实现

### 8.1 从零实现 K-Means

```python
import numpy as np

class KMeansScratch:
    def __init__(self, k: int, max_iter: int = 100, tol: float = 1e-4, seed: int = 0):
        self.k = k
        self.max_iter = max_iter
        self.tol = tol
        self.seed = seed

    def _init_pp(self, X: np.ndarray, rng: np.random.Generator) -> np.ndarray:
        n = X.shape[0]
        centers = np.empty((self.k, X.shape[1]), dtype=X.dtype)
        centers[0] = X[rng.integers(n)]
        d2 = np.full(n, np.inf)
        for i in range(1, self.k):
            d2 = np.minimum(d2, ((X - centers[i - 1]) ** 2).sum(axis=1))
            probs = d2 / d2.sum()
            centers[i] = X[rng.choice(n, p=probs)]
        return centers

    def fit(self, X: np.ndarray):
        rng = np.random.default_rng(self.seed)
        self.centers_ = self._init_pp(X, rng)
        for _ in range(self.max_iter):
            labels = self._assign(X)
            new_centers = np.array([
                X[labels == k].mean(axis=0) if np.any(labels == k) else self.centers_[k]
                for k in range(self.k)
            ])
            shift = np.linalg.norm(new_centers - self.centers_)
            self.centers_ = new_centers
            if shift < self.tol:
                break
        self.labels_ = self._assign(X)
        return self

    def _assign(self, X: np.ndarray) -> np.ndarray:
        # (n, k) 距离矩阵，避免三重循环
        d2 = ((X[:, None, :] - self.centers_[None, :, :]) ** 2).sum(axis=2)
        return d2.argmin(axis=1)

    def inertia(self, X: np.ndarray) -> float:
        labels = self._assign(X)
        return float(((X - self.centers_[labels]) ** 2).sum())


def test_kmeans_finds_two_blobs():
    rng = np.random.default_rng(0)
    X = np.vstack([rng.normal(0, 0.3, (50, 2)), rng.normal(5, 0.3, (50, 2))])
    km = KMeansScratch(k=2, seed=0).fit(X)
    assert (km.labels_[:50] == km.labels_[0]).all()
    assert (km.labels_[50:] == km.labels_[50]).all()
    assert km.labels_[:50].mean() != km.labels_[50:].mean()
```

### 8.2 PyTorch 批量 K-Means（GPU 友好）

```python
import torch

def kmeans_torch(X: torch.Tensor, k: int, n_iter: int = 100, tol: float = 1e-4):
    # X: (n, d)
    n = X.shape[0]
    idx = torch.randperm(n, device=X.device)[:k]
    centers = X[idx].clone()
    for _ in range(n_iter):
        # 距离: (n, k)，用 (a-b)^2 = a^2 - 2ab + b^2 避免 (n, k, d) 中间张量
        d2 = (X ** 2).sum(1, keepdim=True) \
             - 2 * X @ centers.T \
             + (centers ** 2).sum(1)
        labels = d2.argmin(1)
        new_centers = torch.stack([
            X[labels == j].mean(0) if (labels == j).any() else centers[j]
            for j in range(k)
        ])
        shift = (new_centers - centers).norm()
        centers = new_centers
        if shift < tol:
            break
    return labels, centers
```

```python
sc = SpectralClustering(n_clusters=3, affinity="rbf", gamma=1.0,
                        assign_labels="kmeans", random_state=42)

# 评估
sil = silhouette_score(X, labels)            # 内部
ari = adjusted_rand_score(y_true, labels)    # 外部（有真值时）
```

```python
import matplotlib.pyplot as plt
from sklearn.metrics import silhouette_score

def elbow_and_silhouette(X, k_range=range(2, 11)):
    inertias, sils = [], []
    for k in k_range:
        km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(X)
        inertias.append(km.inertia_)
        sils.append(silhouette_score(X, km.labels_))
    fig, ax = plt.subplots(1, 2, figsize=(10, 3))
    ax[0].plot(k_range, inertias, "-o"); ax[0].set_title("Elbow (WCSS)")
    ax[1].plot(k_range, sils, "-o");  ax[1].set_title("Silhouette")
    return fig
```

## 九、实战案例：客户分群

```python
"""
RFM 客户分群：Recency / Frequency / Monetary，电商场景经典。
"""
import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

# 假设 df 有列: recency, frequency, monetary
np.random.seed(0)
df = pd.DataFrame({
    "recency":   np.random.exponential(30, 1000),
    "frequency": np.random.poisson(5, 1000),
    "monetary":  np.random.lognormal(6, 1, 1000),
})

# 1. 对数变换压缩长尾
df_log = np.log1p(df)

# 2. 标准化（K-Means 尺度敏感）
X = StandardScaler().fit_transform(df_log)

# 3. 选 K
for k in range(2, 8):
    km = KMeans(k, n_init=10, random_state=42).fit(X)
    print(f"k={k}  silhouette={silhouette_score(X, km.labels_):.3f}")

# 4. 拟合最终模型
km = KMeans(4, n_init=10, random_state=42).fit(X)
df["segment"] = km.labels_

# 5. 描述各簇（逆 log 还原看均值）
profile = df.groupby("segment")[["recency","frequency","monetary"]].mean()
print(profile)
```

## 十、常见陷阱

| 陷阱 | 后果 | 对策 |
|------|------|------|
| 未标准化 | 大尺度特征主导 K-Means | StandardScaler / RobustScaler |
| 假设球形簇强行用 K-Means | 月牙形被劈两半 | 用 DBSCAN / 谱聚类 |
| $\epsilon$ 过大 | DBSCAN 把所有点并一簇 | k-distance 图调参 |
| MinPts 过小 | 噪声被当簇 | 至少 $\ge 3$，维度高则 $2d-1$ |
| 高维直接聚类 | 距离趋同，聚类失效 | 先 PCA/UMAP 降维 |
| K-Means 单次初始化 | 陷入局部最优 | `n_init=10`+ K-Means++ |
| 用 inertia 比 K | 总单调下降误导 | 配合轮廓 / Gap |
| 层次聚类在大数据 | $O(n^3)$ 爆炸 | 先抽样或用 BIRCH |
| GMM 协方差 full + 小样本 | $\Sigma$ 奇异 | 用 diag 或加正则 |
| 谱聚类 $\sigma$ 不调 | 相似图过稠/过稀 | 自适应 $\sigma$（局部尺度）或 kNN 图 |

|------|------|

## 十二、面试速答

| 问 | 答 |
|----|-----|
| K-Means 的目标函数？ | $\min \sum_k \sum_{x \in C_k}\|x-\mu_k\|^2$，WCSS。 |
| K-Means 为何必收敛？ | E/M 两步单调不增 WCSS，状态有限必到不动点。 |
| K-Means 为何是局部最优？ | 目标非凸，初始化决定盆地。 |
| K-Means++ 干了什么？ | 按 $D^2$ 概率抽中心，期望近似比 $O(\log K)$。 |
| K-Means 与 GMM 关系？ | K-Means = 各向同性、同方差、等先验的硬分配 GMM。 |
| EM 中 E/M 各做什么？ | E 算隐变量后验（责任），M 在该后验下最大化参数似然。 |
| DBSCAN 三类点？ | 核心、边界、噪声。簇 = 密度相连的极大集。 |
| DBSCAN 为何能识别任意形状？ | 簇定义在密度连通性上，不依赖中心，无凸性约束。 |
| 谱聚类为何有效？ | 拉普拉斯前 $K$ 特征向量给出理想嵌入，K-Means 在嵌入空间易分割。 |
| 谱聚类的 $L_{\text{sym}}$ vs $L_{\text{rw}}$？ | $L_{\text{sym}}$ 行归一化更稳；$L_{\text{rw}}$ 直接收敛到随机游走谱。 |
| 轮廓系数范围与含义？ | $[-1,1]$，越近 1 越好，<0 暗示错分。 |
| ARI 为何优于 Rand？ | 扣除随机期望，0 = 随机一致，负 = 反相关。 |
| 层次聚类 linkage 区别？ | single 链式、complete 紧凑、average 折中、ward 等价 K-Means 目标。 |
| 聚类如何选 K？ | 肘部 + 轮廓 + Gap + 业务可解释性，多法交叉验证。 |
| 高维聚类怎么办？ | 先降维（PCA/UMAP），或用余弦 + 谱聚类。 |
| K-Medoids vs K-Means？ | Medoids 中心为真实样本，对离群点鲁棒，但计算更贵（PAM $O(n^2)$）。 |
| HDBSCAN 相比 DBSCAN？ | 自动选 $\epsilon$，处理变密度，输出层级结构 + 稳定性分数。 |

## 十三、综合面试题

1. **推导 K-Means 的 M 步为何是均值。**
   - $\frac{\partial}{\partial \boldsymbol{\mu}_k}\sum_{\mathbf{x} \in C_k}\|\mathbf{x} - \boldsymbol{\mu}_k\|^2 = -2\sum_{\mathbf{x} \in C_k}(\mathbf{x} - \boldsymbol{\mu}_k) = 0 \Rightarrow \boldsymbol{\mu}_k = \text{mean}(C_k)$。
   - 几何意义：均值最小化点到中心的平方距离和，是质心。

2. **证明 K-Means++ 的期望近似比。**
   - 设最优 WCSS 为 $\text{OPT} = \sum_x D^*(x)^2$，其中 $D^*$ 为到最近最优中心的距离。
   - K-Means++ 第 $i$ 个中心期望使剩余 $D^2$ 减少 $\text{OPT}/K$（按概率分布的期望贡献）。
   - 累积 $K$ 步后，期望 WCSS $\le 8(\ln K + 2)\text{OPT}$（Arthur & Vassilvitskii 2007）。证明用 Jensen 与 $\ln$ 调和级数。

3. **EM 为什么单调不减似然？**
   - EM 是坐标上升：E 步在当前参数下选最优下界（ELBO），M 步最大化 ELBO。
   - $\ell(\theta^{(t+1)}) \ge \text{ELBO}(\theta^{(t+1)}; q^{(t)}) \ge \text{ELBO}(\theta^{(t)}; q^{(t)}) = \ell(\theta^{(t)})$。
   - 等号在收敛点成立。

4. **DBSCAN 在密度差异大的数据上为何失败？**
   - 单组 $(\epsilon, \text{MinPts})$：稀疏簇要大 $\epsilon$，稠密簇要小 $\epsilon$。
   - 大 $\epsilon$ 把稠密簇和稀疏簇合并；小 $\epsilon$ 把稀疏簇判为噪声。
   - 解法：HDBSCAN 在不同 $\epsilon$ 上构建层级，按稳定性选簇；或 OPTICS 可达距离图。

5. **谱聚类为什么用前 $K$ 个最小特征向量？**
   - $L$ 半正定，0 特征值对应常向量（全连通图）。
   - $K$ 个连通分量对应 $K$ 重 0 特征值，特征向量是各分量的指示向量（分段常数）。
   - 图近似 $K$ 个连通分量时，前 $K$ 个特征向量"接近"指示向量，K-Means 在嵌入空间易恢复划分。
   - 这是 RatioCut/Ncut 整数规划的松弛解。

6. **K-Means 与 PCA 的等价关系（Ding & He 2004）。**
   - 连续松弛下，K-Means 目标可写为迹最大化 $\text{tr}(H^\top X X^\top H)$，$H$ 为簇指示矩阵。
   - PCA 同样最大化 $\text{tr}(U^\top X X^\top U)$。
   - 故 K-Means 的簇指示向量张成 $X$ 的前 $K-1$ 主成分子空间。即 K-Means ≈ 主子空间投影 + 阈值切分。

7. **GMM 中协方差矩阵奇异时怎么办？**
   - 簇内样本 $< d$ 或共线时 $\Sigma_k$ 不可逆，密度发散。
   - 对策：协方差加正则 $\Sigma_k + \lambda I$；改用 diag/tied；限制 $\pi_k$ 下限防"塌缩到一点"。

8. **轮廓系数与 ARI 的本质区别？**
   - 轮廓系数是**内部指标**，依赖簇内/簇间距离，无需真值，但有偏好（凸簇偏好）。
   - ARI 是**外部指标**，比较划分与真值的一致性，扣除随机基线，但需要标注。
   - 实践：无标注用轮廓 + 稳定性，有标注用 ARI/NMI。

9. **Mini-Batch K-Means 为何快？损失多少？**
   - 每次迭代只用 $b \ll n$ 个样本更新中心，复杂度 $O(bKd)$。
   - 随机梯度引入噪声，中心抖动但收敛到附近；Sculley (2010) 证明在大量数据上精度损失 < 1% 而速度提升 10x+。

10. **聚类结果不稳定怎么办？**
    - 多次随机初始化，用共识矩阵衡量稳定性。
    - 用 K-Means++ + `n_init=10`。
    - 改用层次聚类（确定性，除距离相同 tie-break）。
    - 用 Bootstrap 重采样评估簇稳定性。

## 十四、公式速查卡

| 公式 | 表达式 |
|------|--------|
| K-Means 目标 | $\min \sum_k \sum_{x \in C_k}\|x-\mu_k\|^2$ |
| K-Means 中心更新 | $\mu_k = \frac{1}{|C_k|}\sum_{x \in C_k} x$ |
| K-Means++ 概率 | $p(x) = D(x)^2 / \sum_x D(x)^2$ |
| GMM 密度 | $p(x) = \sum_k \pi_k \mathcal{N}(x \mid \mu_k, \Sigma_k)$ |
| GMM 责任 | $\gamma_{nk} = \frac{\pi_k \mathcal{N}(x_n \mid \mu_k, \Sigma_k)}{\sum_j \pi_j \mathcal{N}(x_n \mid \mu_j, \Sigma_j)}$ |
| GMM $\Sigma$ 更新 | $\Sigma_k = \frac{1}{N_k}\sum_n \gamma_{nk}(x_n - \mu_k)(x_n - \mu_k)^\top$ |
| 轮廓系数 | $s = (b-a)/\max(a,b)$ |
| Davies-Bouldin | $\frac{1}{K}\sum_i \max_{j \neq i}\frac{s_i + s_j}{d_{ij}}$ |
| 拉普拉斯（归一化） | $L_{\text{sym}} = I - D^{-1/2} W D^{-1/2}$ |
| RatioCut 松弛 | $\min \text{tr}(F^\top L F),\ F^\top F = I$ |
