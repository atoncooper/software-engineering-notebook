## 一、问题定义

评估的根本目的是回答三个问题：

1. **泛化性能**：模型在未见数据上表现如何？
2. **模型选择**：在多个候选中选哪个？
3. **超参调优**：超参取什么值最优？

三者必须用**独立的数据划分**，否则会泄漏信息导致评估虚高。

### 1.1 数据划分原则

```
全部数据
   │
   ├─→ 训练集 (60-80%)：拟合模型参数
   │
   ├─→ 验证集 (10-20%)：调超参、选模型
   │
   └─→ 测试集 (10-20%)：仅在最终评估时用一次
```

**嵌套划分**（严谨评估）：

- 外层：评估泛化性能
- 内层：调超参

### 1.2 信息泄漏的典型场景

| 场景 | 后果 |
|------|------|
| 在全数据上做归一化再划分 | 测试集统计量泄漏到训练 |
| 在全数据上做特征选择 | 选出的特征偏向测试集 |
| 时序数据随机划分 | 未来信息泄漏到训练 |
| 重复使用测试集调参 | 测试集变成验证集 |

## 二、分类指标体系

### 2.1 混淆矩阵

二分类：

|  | 预测正 | 预测负 |
|--|-------|-------|
| 真实正 | TP | FN |
| 真实负 | FP | TN |

### 2.2 基础指标

| 指标 | 公式 | 含义 |
|------|------|------|
| Accuracy | $\frac{TP+TN}{TP+TN+FP+FN}$ | 整体正确率 |
| Precision | $\frac{TP}{TP+FP}$ | 预测为正的准确率 |
| Recall (TPR) | $\frac{TP}{TP+FN}$ | 真实正被找出的比例 |
| F1 | $\frac{2 \cdot P \cdot R}{P + R}$ | P 与 R 的调和平均 |
| Specificity (TNR) | $\frac{TN}{TN+FP}$ | 真实负被正确判负 |
| FPR | $\frac{FP}{FP+TN}$ | 假正率，ROC 横轴 |

### 2.3 F1 的推广：F-β

$$
F_\beta = (1 + \beta^2) \cdot \frac{P \cdot R}{\beta^2 P + R}
$$

- $\beta = 1$：F1，P 与 R 等权
- $\beta = 2$：更重视 Recall（如疾病筛查）
- $\beta = 0.5$：更重视 Precision（如垃圾邮件）

### 2.4 多分类平均

对 $K$ 类，分别计算每类的 P/R/F1，再聚合：

| 平均方式 | 公式 | 适用 |
|----------|------|------|
| Macro | $\frac{1}{K}\sum_k P_k$ | 类别均衡时 |
| Micro | 全局 TP/FP/FN 合并计算 | 类别不平衡时 |
| Weighted | 按样本数加权 | 报告常用 |

**Micro F1 = Accuracy**（当所有样本都参与且每类一个预测时）。

### 2.5 何时用何指标

| 场景 | 推荐指标 |
|------|----------|
| 类别均衡 | Accuracy |
| 类别不平衡、关注少数类 | PR 曲线、AUC-PR、F1 |
| 概率排序质量 | AUC-ROC |
| 概率校准 | Brier Score |
| 顶部精度 | Precision@k、NDCG |

## 三、ROC 与 AUC

### 3.1 ROC 曲线

横轴 FPR，纵轴 TPR。通过调整阈值从 1 到 0 扫描得到。

```
TPR │       ┌────── 1
    │      ╱
    │    ╱
    │  ╱
    │╱
    └──────────── FPR
    0            1
```

对角线 = 随机分类器；左上角 $(0, 1)$ = 完美分类器。

### 3.2 AUC 的概率意义 ⭐

$$
\text{AUC} = P(\text{score}_+ > \text{score}_-)
$$

即随机抽一对正负样本，正样本得分高于负样本的概率。

**证明（Mann-Whitney U 统计量）**：

设正样本得分 $\{s_+^{(i)}\}_{i=1}^{n_+}$，负样本 $\{s_-^{(j)}\}_{j=1}^{n_-}$。定义：

$$
U = \sum_{i, j} \mathbb{1}[s_+^{(i)} > s_-^{(j)}]
$$

则：

$$
\widehat{\text{AUC}} = \frac{U}{n_+ n_-}
$$

这是 AUC 的非参数估计，无分布假设。

**推导**：设正负得分独立同分布，连续（无平局）：

$$
P(s_+ > s_-) = \int\int \mathbb{1}[s_+ > s_-] p_+(s_+) p_-(s_-) \, ds_+ ds_-
$$

经验估计即 $\frac{1}{n_+ n_-}\sum_{i,j}\mathbb{1}[s_+^{(i)} > s_-^{(j)}]$。

### 3.3 ROC vs PR 曲线

| 维度 | ROC | PR |
|------|-----|-----|
| 横轴 | FPR | Recall |
| 纵轴 | TPR | Precision |
| 基线 | 对角线 0.5 | 水平线 = 正例比例 |
| 类别不平衡影响 | 不敏感（FP 率分母大） | 敏感 |
| 适合场景 | 类别均衡 | 类别不平衡、关注少数类 |

**工程经验**：负样本远多于正样本时（如欺诈检测，正例 0.1%），ROC 看似很高（FPR=0.001 仍小）但 PR 暴露问题。

### 3.4 AUC 的工程实现

```python
import numpy as np
from sklearn.metrics import roc_auc_score

def auc_mann_whitney(y_true: np.ndarray, y_score: np.ndarray) -> float:
    """
    Mann-Whitney U 统计量实现的 AUC。
    复杂度 O(n log n)，比朴素 O(n^2) 更快。
    """
    pos = y_score[y_true == 1]
    neg = y_score[y_true == 0]
    n_pos, n_neg = len(pos), len(neg)
    # 合并后按得分排序，计算 rank
    all_scores = np.concatenate([pos, neg])
    ranks = np.argsort(np.argsort(all_scores)) + 1  # 1-indexed
    sum_ranks_pos = ranks[:n_pos].sum()
    U = sum_ranks_pos - n_pos * (n_pos + 1) / 2
    return U / (n_pos * n_neg)
```

## 四、回归指标

| 指标 | 公式 | 特点 |
|------|------|------|
| MSE | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ | 对大误差敏感 |
| RMSE | $\sqrt{\text{MSE}}$ | 与 $y$ 同量纲 |
| MAE | $\frac{1}{n}\sum|y_i - \hat{y}_i|$ | 鲁棒 |
| $R^2$ | $1 - \frac{\sum(y - \hat{y})^2}{\sum(y - \bar{y})^2}$ | 解释方差比，≤1 |
| MAPE | $\frac{100\%}{n}\sum\left|\frac{y - \hat{y}}{y}\right|$ | 相对误差 |
| RMSLE | $\sqrt{\frac{1}{n}\sum(\log(1+y) - \log(1+\hat{y}))^2}$ | 对数尺度，适合长尾 |

### 4.1 $R^2$ 的解读

- $R^2 = 1$：完美预测
- $R^2 = 0$：等价于预测均值
- $R^2 < 0$：比预测均值还差（模型有偏）

**注意**：$R^2$ 在测试集上可能为负，因为 $\sum(y - \bar{y})^2$ 用训练集均值。

### 4.2 MSE 的偏差-方差-噪声分解

$$
\mathbb{E}[(y - \hat{f}(\mathbf{x}))^2] = \underbrace{(f - \mathbb{E}\hat{f})^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}[(\hat{f} - \mathbb{E}\hat{f})^2]}_{\text{Var}} + \sigma^2
$$

测试 MSE = 不可约噪声 $\sigma^2$ + 可优化部分（偏差 + 方差）。详见 [监督学习-线性模型第九节](./监督学习-线性模型.md#九、偏差-方差权衡)。

## 五、概率校准

### 5.1 为何需要校准

模型输出的"概率"未必反映真实频率。例如逻辑回归输出 0.7 的样本中，真实正例比例可能不是 70%。

### 5.2 Brier Score

$$
\text{BS} = \frac{1}{n}\sum_i (\hat{p}_i - y_i)^2
$$

越小越好。是概率预测的 MSE。

### 5.3 可靠性图

将预测概率分箱（如 10 等分），每箱画"预测均值 vs 实际正例比例"。完美校准在对角线上。

### 5.4 校准方法

| 方法 | 原理 |
|------|------|
| Platt Scaling | 用逻辑回归拟合 $\hat{p}' = \sigma(a\hat{p} + b)$ |
| Isotonic Regression | 非参数单调映射，更灵活但需更多数据 |
| Temperature Scaling | 深度学习常用，仅缩放 logits：$T$ 单参数 |

```python
from sklearn.calibration import CalibratedClassifierCV

# 5 折交叉校准
calibrated = CalibratedClassifierCV(estimator, method="isotonic", cv=5)
calibrated.fit(X_train, y_train)
```

## 六、交叉验证

### 6.1 K 折交叉验证

将数据分 $K$ 份，每次用 $K-1$ 份训练、1 份验证，循环 $K$ 次：

```python
from sklearn.model_selection import KFold, cross_val_score

kf = KFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(model, X, y, cv=kf, scoring="neg_mean_squared_error")
```

### 6.2 分层 K 折

类别不平衡时，普通 K 折可能某折无正例。分层 K 折保证每折类别比例一致：

```python
from sklearn.model_selection import StratifiedKFold
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
```

### 6.3 留一法（LOO）

$K = n$。每折留一个样本。无偏但方差大、计算贵。等价于 [折刀法估计](./数学基础-概率与统计.md#六、参数估计)。

### 6.4 嵌套交叉验证

外层评估性能，内层调超参：

```
外层 5 折
  │
  └─→ 每个外层训练集 → 内层 3 折调超参 → 最优超参 → 训练 → 外层测试
```

```python
from sklearn.model_selection import GridSearchCV, cross_val_score

inner_cv = KFold(n_splits=3)
outer_cv = KFold(n_splits=5)
grid = GridSearchCV(model, param_grid, cv=inner_cv)
nested_score = cross_val_score(grid, X, y, cv=outer_cv)
```

**用途**：避免"用同一份数据调参又评估"导致的乐观偏差。

### 6.5 时序交叉验证

时序数据不能随机划分（未来不能泄漏到过去）。Walk-forward：

```
折 1: 训练 [1, 2, 3]   测试 [4]
折 2: 训练 [1, 2, 3, 4] 测试 [5]
折 3: 训练 [1, 2, 3, 4, 5] 测试 [6]
```

```python
from sklearn.model_selection import TimeSeriesSplit
tscv = TimeSeriesSplit(n_splits=5)
```

### 6.6 K 的选择

| $K$ | 偏差 | 方差 | 计算 |
|-----|------|------|------|
| 5 | 中 | 中 | 中 |
| 10 | 低 | 中 | 高 |
| LOO | 最低 | 最高 | 最高 |

经验：$K = 5$ 或 $10$ 是较好的折中。类别不平衡用分层。

### 6.7 重复交叉验证

5 折 × 3 重复 = 15 次评估，进一步降方差。代价是计算量。

## 七、超参搜索

### 7.1 Grid Search

穷举预设网格：

```python
param_grid = {"alpha": [0.01, 0.1, 1, 10, 100]}
grid = GridSearchCV(model, param_grid, cv=5)
```

**缺点**：维度灾难，$d$ 个超参每个 $k$ 个值需 $k^d$ 次训练。

### 7.2 Random Search

Bergstra & Bengio (2012) 证明随机搜索常优于网格搜索，因为：

- 重要超参与不重要超参混合时，随机搜索有更高概率探索重要维度
- 同样预算下覆盖更广

```python
from sklearn.model_selection import RandomizedSearchCV
from scipy.stats import loguniform

param_dist = {"alpha": loguniform(1e-3, 1e3)}
search = RandomizedSearchCV(model, param_dist, n_iter=50, cv=5)
```

### 7.3 贝叶斯优化

建模超参 → 性能的函数，用采集函数智能选下一个超参。

**高斯过程 + 采集函数**：

- 目标：最小化 $f(\mathbf{x})$（验证误差）
- 高斯过程建模 $f$ 的后验：均值 $\mu(\mathbf{x})$ + 方差 $\sigma^2(\mathbf{x})$
- 采集函数（EI，Expected Improvement）：

$$
\text{EI}(\mathbf{x}) = \mathbb{E}[\max(f_{\text{best}} - f(\mathbf{x}), 0)]
$$

平衡**探索**（高 $\sigma$ 区域）与**利用**（低 $\mu$ 区域）。

**TPE（Tree-structured Parzen Estimator）**：Optuna 默认，建模 $p(x|y)$ 而非 $p(y|x)$，对条件超参友好。

### 7.4 多保真度方法

**Hyperband**：基于"好配置早显苗头"假设，先用小资源筛掉差的，再给好的更多资源。

**BOHB**：BO + Hyperband，结合贝叶斯优化与早停。

### 7.5 工具对比

| 工具 | 特点 |
|------|------|
| sklearn GridSearchCV | 简单、单机 |
| Optuna | TPE、可视化、剪枝 |
| Ray Tune | 分布式、可扩展 |
| Hyperopt | TPE 经典实现 |
| Weights & Biases Sweeps | 集成实验管理 |

### 7.6 Optuna 实战

```python
import optuna
from sklearn.datasets import fetch_california_housing
from sklearn.linear_model import Ridge
from sklearn.model_selection import cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

def objective(trial):
    alpha = trial.suggest_float("alpha", 1e-3, 1e3, log=True)
    model = Pipeline([
        ("scaler", StandardScaler()),
        ("ridge", Ridge(alpha=alpha))
    ])
    score = cross_val_score(model, X, y, cv=5,
                            scoring="neg_mean_squared_error").mean()
    return -score

X, y = fetch_california_housing(return_X_y=True)
study = optuna.create_study(direction="minimize",
                            sampler=optuna.samplers.TPESampler(seed=42))
study.optimize(objective, n_trials=50)
print(f"最优 alpha: {study.best_params}, RMSE: {np.sqrt(study.best_value):.4f}")
```

## 八、过拟合与欠拟合诊断

### 8.1 学习曲线

横轴训练样本数，纵轴训练/验证误差：

```
误差 │ 训练误差
     │ ╲──────
     │  ╲
     │   ╲   验证误差
     │    ╲___╱──────
     │
     └────────────── 样本数
```

| 形态 | 诊断 |
|------|------|
| 训练低、验证高、有差距 | 过拟合 |
| 训练高、验证高 | 欠拟合 |
| 两者接近且低 | 拟合良好 |
| 训练低、验证高、加样本仍差距 | 严重过拟合，需正则或简化模型 |

### 8.2 验证曲线

横轴超参（如 $\alpha$），纵轴训练/验证误差：

- $\alpha$ 小：训练低、验证高（过拟合）
- $\alpha$ 大：两者都高（欠拟合）
- 中间最优

### 8.3 过拟合对策

| 类别 | 方法 |
|------|------|
| 数据 | 增加样本、数据增强 |
| 模型 | 简化结构、减少参数 |
| 正则 | L1/L2、Dropout、Early Stopping |
| 集成 | Bagging 降方差 |
| 训练 | 提前停止、学习率衰减 |

### 8.4 欠拟合对策

- 增加模型容量
- 减少正则
- 特征工程（多项式、交互项）
- 训练更久

## 九、偏差-方差权衡的完整推导

### 9.1 设定

$y = f(\mathbf{x}) + \epsilon$，$\mathbb{E}\epsilon = 0$，$\text{Var}(\epsilon) = \sigma^2$。训练集 $\mathcal{D}$ 给出估计 $\hat{f}_\mathcal{D}$。

### 9.2 分解

测试误差（平方损失）：

$$
\mathbb{E}_\mathcal{D}\mathbb{E}_{\epsilon}\left[(y - \hat{f}_\mathcal{D}(\mathbf{x}))^2\right]
$$

记 $\bar{f}(\mathbf{x}) = \mathbb{E}_\mathcal{D}\hat{f}_\mathcal{D}(\mathbf{x})$。

$$
\begin{aligned}
\mathbb{E}_\mathcal{D}\mathbb{E}_\epsilon[(y - \hat{f})^2]
&= \mathbb{E}_\mathcal{D}\mathbb{E}_\epsilon[(f + \epsilon - \hat{f})^2] \\
&= \mathbb{E}_\mathcal{D}\mathbb{E}_\epsilon[(f - \hat{f})^2 + 2(f - \hat{f})\epsilon + \epsilon^2] \\
&= \mathbb{E}_\mathcal{D}[(f - \hat{f})^2] + \sigma^2 \\
&= \mathbb{E}_\mathcal{D}[(\hat{f} - \bar{f} + \bar{f} - f)^2] + \sigma^2 \\
&= \mathbb{E}_\mathcal{D}[(\hat{f} - \bar{f})^2] + (\bar{f} - f)^2 + \sigma^2 \\
&= \underbrace{\text{Var}(\hat{f})}_{\text{方差}} + \underbrace{\text{Bias}(\hat{f})^2}_{\text{偏差}^2} + \underbrace{\sigma^2}_{\text{噪声}}
\end{aligned}
$$

### 9.3 集成方法与偏差-方差

| 方法 | 偏差 | 方差 |
|------|------|------|
| Bagging（RF） | 不变 | 降低 |
| Boosting（GBDT） | 降低 | 略升 |
| Stacking | 降低 | 降低 |

**Bagging 降方差的数学**：$B$ 个独立基模型平均后方差降为 $\text{Var}/B$。实际有相关性，降到 $\rho\sigma^2 + (1-\rho)\sigma^2/B$，$\rho$ 为相关系数。RF 通过特征随机化降低 $\rho$。

## 十、类别不平衡处理

### 10.1 评估陷阱

- Accuracy 在不平衡下失效：99% 负例时全预测负例仍有 99% 准确率
- 用 Precision/Recall/F1/AUC-PR 替代

### 10.2 重采样

| 方法 | 原理 |
|------|------|
| 欠采样 | 减少多数类 |
| 过采样 | 复制少数类 |
| SMOTE | 在少数类样本间插值生成新样本 |
| ADASYN | 自适应合成，关注难分样本 |
| Tomek Links | 删除边界冲突样本 |

### 10.3 SMOTE 算法

对每个少数类样本 $\mathbf{x}_i$：

1. 找 $k$ 近邻（同类）
2. 随机选一个 $\mathbf{x}_{nn}$
3. 合成 $\mathbf{x}_{new} = \mathbf{x}_i + \lambda(\mathbf{x}_{nn} - \mathbf{x}_i)$，$\lambda \sim U(0, 1)$

**陷阱**：

- 在高维下退化（距离失效）
- 在类边界合成噪声
- 过采样后未交叉验证会信息泄漏

### 10.4 代价敏感学习

类权重调整：$\mathcal{L} = \sum_i w_{y_i} \ell_i$，少数类 $w$ 大。

```python
from sklearn.linear_model import LogisticRegression
model = LogisticRegression(class_weight="balanced")  # 自动按 1/freq
```

### 10.5 阈值调整

模型默认阈值 0.5 不平衡下不优。用验证集找最大化 F1（或业务目标）的阈值。

## 十一、数据泄露防范

### 11.1 典型场景

| 场景 | 错误做法 | 正确做法 |
|------|----------|----------|
| 标准化 | 全数据 fit | 训练集 fit，验证测试 transform |
| PCA | 全数据 fit | 在 Pipeline 内，CV 自动隔离 |
| 特征选择 | 全数据选 | 训练集内选 |
| 目标编码 | 全数据编码 | K 折目标编码 |
| 时序 | 随机划分 | 时序划分 |
| 重复样本 | 随机划分 | 按组划分（GroupKFold） |

### 11.2 Pipeline 的必要性

```python
# 正确：所有预处理在 CV 内
pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("model", Ridge())
])
cross_val_score(pipe, X, y, cv=5)  # 每折独立 fit scaler

# 错误：全数据标准化
X_scaled = StandardScaler().fit_transform(X)  # 泄漏！
cross_val_score(Ridge(), X_scaled, y, cv=5)
```

### 11.3 时序数据的 look-ahead bias

- 用未来统计量（如全数据均值）训练
- 滚动窗口统计未排除当前点
- 特征计算包含未来信息

## 十二、模型选择的信息论视角

### 12.1 AIC

$$
\text{AIC} = 2k - 2\log\hat{L}
$$

$k$ 参数数，$\hat{L}$ 最大似然。惩罚复杂度，平衡拟合与简洁。

### 12.2 BIC

$$
\text{BIC} = k\log n - 2\log\hat{L}
$$

样本量 $n$ 越大惩罚越重。比 AIC 更倾向简单模型。

### 12.3 与偏差-方差关系

- AIC/BIC 是渐近等价于留一交叉验证（线性模型）
- 大样本下 BIC 一致（选出真模型），AIC 更注重预测

### 12.4 MDL（最小描述长度）

模型选择 = 数据压缩。编码长度 = 模型长度 + 数据给定模型长度。与贝叶斯模型选择 [贝叶斯因子](./数学基础-概率与统计.md#7.4-贝叶斯模型选择) 等价。

## 十三、代码实现（工业级）

### 13.1 完整评估框架

```python
"""
工业级模型评估框架。
支持：嵌套 CV、多指标、概率校准、类别不平衡。
"""
from __future__ import annotations
from dataclasses import dataclass, field
from typing import Dict, List, Callable, Optional
import numpy as np
from sklearn.base import clone
from sklearn.model_selection import StratifiedKFold, GridSearchCV
from sklearn.metrics import (
    accuracy_score, precision_score, recall_score, f1_score,
    roc_auc_score, average_precision_score, brier_score_loss,
    mean_squared_error, r2_score
)
from sklearn.calibration import CalibratedClassifierCV


@dataclass
class EvalResult:
    metrics: Dict[str, float]
    per_fold: Dict[str, List[float]]
    best_params: Optional[dict] = None


def evaluate_classifier(
    estimator,
    X, y,
    param_grid: Optional[dict] = None,
    cv: int = 5,
    scoring: str = "f1",
    calibrate: bool = False
) -> EvalResult:
    """分类模型评估。"""
    outer_cv = StratifiedKFold(n_splits=cv, shuffle=True, random_state=42)
    metrics_per_fold = {m: [] for m in
                        ["accuracy", "precision", "recall", "f1", "auc", "auc_pr", "brier"]}
    best_params = None

    for fold, (tr, te) in enumerate(outer_cv.split(X, y)):
        X_tr, X_te = X[tr], X[te]
        y_tr, y_te = y[tr], y[te]

        # 内层调超参
        if param_grid:
            inner_cv = StratifiedKFold(n_splits=3, shuffle=True, random_state=fold)
            grid = GridSearchCV(clone(estimator), param_grid,
                                cv=inner_cv, scoring=scoring, n_jobs=-1)
            grid.fit(X_tr, y_tr)
            model = grid.best_estimator_
            best_params = grid.best_params_
        else:
            model = clone(estimator).fit(X_tr, y_tr)

        # 概率校准
        if calibrate and hasattr(model, "predict_proba"):
            model = CalibratedClassifierCV(model, method="isotonic", cv=3)
            model.fit(X_tr, y_tr)

        # 预测
        y_pred = model.predict(X_te)
        if hasattr(model, "predict_proba"):
            y_proba = model.predict_proba(X_te)[:, 1]
        else:
            y_proba = y_pred

        metrics_per_fold["accuracy"].append(accuracy_score(y_te, y_pred))
        metrics_per_fold["precision"].append(precision_score(y_te, y_pred, zero_division=0))
        metrics_per_fold["recall"].append(recall_score(y_te, y_pred, zero_division=0))
        metrics_per_fold["f1"].append(f1_score(y_te, y_pred, zero_division=0))
        metrics_per_fold["auc"].append(roc_auc_score(y_te, y_proba))
        metrics_per_fold["auc_pr"].append(average_precision_score(y_te, y_proba))
        metrics_per_fold["brier"].append(brier_score_loss(y_te, y_proba))

    summary = {k: float(np.mean(v)) for k, v in metrics_per_fold.items()}
    return EvalResult(metrics=summary, per_fold=metrics_per_fold, best_params=best_params)
```

## 十四、实战案例：信用卡欺诈检测

```python
"""
Kaggle Credit Card Fraud Detection 风格流程。
类别极度不平衡（欺诈 ~0.17%）。
"""
import numpy as np
from sklearn.datasets import make_classification
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import StratifiedKFold
from sklearn.metrics import (
    classification_report, roc_auc_score, average_precision_score,
    precision_recall_curve
)
from imblearn.pipeline import Pipeline  # 注意是 imblearn 的 Pipeline
from imblearn.over_sampling import SMOTE


# 模拟欺诈数据
X, y = make_classification(n_samples=10000, n_features=30,
                            n_informative=10, weights=[0.99, 0.01],
                            random_state=42)

# 基线：无处理的逻辑回归
base = LogisticRegression(max_iter=1000, class_weight=None)
base.fit(X[:8000], y[:8000])
pred = base.predict(X[8000:])
proba = base.predict_proba(X[8000:])[:, 1]
print("基线:")
print(classification_report(y[8000:], pred))
print(f"AUC-ROC: {roc_auc_score(y[8000:], proba):.4f}")
print(f"AUC-PR:  {average_precision_score(y[8000:], proba):.4f}")

# 处理不平衡：class_weight + SMOTE
pipe = Pipeline([
    ("smote", SMOTE(random_state=42)),
    ("clf", RandomForestClassifier(n_estimators=100, random_state=42))
])
pipe.fit(X[:8000], y[:8000])
proba2 = pipe.predict_proba(X[8000:])[:, 1]
pred2 = (proba2 > 0.5).astype(int)
print("\nSMOTE + RF:")
print(classification_report(y[8000:], pred2))
print(f"AUC-ROC: {roc_auc_score(y[8000:], proba2):.4f}")
print(f"AUC-PR:  {average_precision_score(y[8000:], proba2):.4f}")

# 阈值优化：找最大化 F1 的阈值
prec, rec, thr = precision_recall_curve(y[8000:], proba2)
f1 = 2 * prec * rec / (prec + rec + 1e-12)
best_thr = thr[f1.argmax()]
print(f"\n最优阈值: {best_thr:.4f}，F1: {f1.max():.4f}")
```

**典型结果**：处理不平衡后 AUC-PR 提升 2-5 倍（AUC-ROC 提升不明显，因 ROC 对不平衡不敏感）。

| 陷阱 | 后果 | 对策 |

## 十六、面试速答

| 问 | 答 |
|----|-----|
| AUC 的概率意义？ | 随机抽一对正负样本，正样本得分高于负样本的概率。Mann-Whitney U 统计量。 |
| ROC vs PR 曲线选择？ | 类别均衡用 ROC；不平衡用 PR。ROC 对不平衡不敏感。 |
| 偏差-方差分解？ | $\mathbb{E}[(y-\hat{f})^2] = \text{Bias}^2 + \text{Var} + \sigma^2$。模型复杂度 ↑ → 偏差 ↓ 方差 ↑。 |
| 为何类别不平衡时 Accuracy 失效？ | 全预测多数类仍高 Accuracy。用 F1/AUC-PR。 |
| K 折 CV 中 K 怎么选？ | 5 或 10 折中。LOO 偏差小方差大，计算贵。 |
| 嵌套 CV 的目的？ | 外层评估、内层调参，避免"用同一份数据调参又评估"的乐观偏差。 |
| Grid vs Random vs Bayesian？ | Grid 维度灾难；Random 同预算覆盖广；Bayesian 智能探索，效率最高。 |
| 过拟合对策？ | 数据增强、简化模型、正则化、Early Stopping、Bagging。 |
| 数据泄露场景？ | 全数据预处理、特征选择、目标编码；用 Pipeline + CV 内部隔离。 |
| SMOTE 原理与陷阱？ | 少数类近邻插值；高维退化、边界噪声、过采样未 CV 会泄漏。 |
| F1 macro vs micro？ | macro 等权各类，micro 合并全局。不平衡关注少数类用 macro。 |
| 为何不能在测试集调参？ | 测试集会变成"第二个验证集"，评估虚高，无泛化保证。 |
| AIC vs BIC？ | AIC = $2k - 2\log L$，预测导向；BIC = $k\log n - 2\log L$，大 $n$ 惩罚重，一致。 |
| 概率校准方法？ | Platt Scaling（LR 拟合）、Isotonic（非参数单调）、Temperature Scaling（深度学习）。 |

## 十七、综合面试题

1. **完整推导偏差-方差分解。**
   - 见第 9.2 节。关键步骤：$y = f + \epsilon$，引入 $\bar{f} = \mathbb{E}_\mathcal{D}\hat{f}$，平方展开 $(\hat{f} - f)^2 = [(\hat{f} - \bar{f}) + (\bar{f} - f)]^2$，交叉项期望为 0。

2. **证明 AUC = Mann-Whitney U。**
   - 见第 3.2 节。$\text{AUC} = P(s_+ > s_-) = \iint \mathbb{1}[s_+ > s_-] p_+ p_- ds_+ ds_-$，经验估计 $\frac{1}{n_+ n_-}\sum_{i,j}\mathbb{1}[s_+^{(i)} > s_-^{(j)}]$，即 $U/(n_+ n_-)$。

3. **LOO 交叉验证与 AIC 的关系。**
   - 线性模型下 LOO 误差有闭式近似：$\text{LOO}_i = (y_i - \hat{y}_i)/(1 - h_{ii})$，$h_{ii}$ 为帽子矩阵对角。$\sum \text{LOO}_i^2$ 与 AIC 渐近等价（Stone, 1977）。这是 AIC 预测导向的合法性。

4. **解释贝叶斯优化的 EI 采集函数。**
   - $\text{EI}(\mathbf{x}) = \mathbb{E}[\max(f^* - f(\mathbf{x}), 0)]$，$f^*$ 当前最优。GP 后验下闭式：$\text{EI} = (f^* - \mu)\Phi\!\left(\frac{f^* - \mu}{\sigma}\right) + \sigma\phi\!\left(\frac{f^* - \mu}{\sigma}\right)$。第一项利用（$\mu$ 小），第二项探索（$\sigma$ 大）。

5. **类别不平衡的所有处理方法。**
   - 数据层：欠采样、过采样、SMOTE、ADASYN、Tomek Links。
   - 算法层：class_weight、Focal Loss、代价敏感学习。
   - 评估层：F1、AUC-PR、避免 Accuracy。
   - 决策层：阈值调整。

6. **解释为何 Bagging 降低方差而 Boosting 降低偏差。**
   - Bagging 平均 $B$ 个独立基模型，方差降为 $\sigma^2/B$（完全独立）或 $\rho\sigma^2 + (1-\rho)\sigma^2/B$（相关）。偏差不变。
   - Boosting 串行加性建模，每轮拟合上一轮的残差，逐步降低训练误差（偏差）。新模型引入相关性，方差略升但总体降偏差为主。

7. **为何不能在全数据上做特征选择？**
   - 特征选择用全部数据时，选出的特征偏向测试集统计特性，相当于用测试集信息训练。评估时这些特征在测试集上表现好，但泛化到新数据会退化。正确做法：在 CV 内层、训练折上做特征选择。

8. **嵌套 CV 如何给出无偏泛化估计？**
   - 外层每次留一折作测试，内层在外层训练集上调超参。每次外层的测试集从未参与该次超参选择，模拟"新数据"。最终取外层 $K$ 个测试误差的均值，是无偏估计。

9. **概率校准与 Brier Score 的关系。**
   - Brier Score $\frac{1}{n}\sum(\hat{p}_i - y_i)^2$ 可分解为校准损失 + 精度损失。校准损失衡量预测概率与经验频率的差距；精度损失衡量能否区分正负样本。Platt/Isotonic 减小校准损失但不改精度。

10. **SMOTE 在什么情况下会失效？**
    - 高维：距离度量退化（[维数灾难](./监督学习-KNN与距离度量.md#八、维数灾难)），近邻不可信。
    - 类边界：在多数类区域合成少数类样本，引入噪声。
    - 重叠类：合成样本可能落入多数类区域。
    - 严重不平衡（< 1%）：少数类样本太少，近邻不可靠。
    改进：Borderline-SMOTE、ADASYN 关注难分样本；或用代价敏感学习。

## 十八、公式速查卡

| 公式 | 表达式 |
|------|--------|
| 偏差-方差分解 | $\mathbb{E}[(y-\hat{f})^2] = \text{Bias}^2 + \text{Var} + \sigma^2$ |
| F1 | $\frac{2PR}{P+R}$ |
| F-β | $(1+\beta^2)\frac{PR}{\beta^2 P + R}$ |
| AUC | $P(s_+ > s_-)$ |
| Mann-Whitney U | $U = \sum_{i,j}\mathbb{1}[s_+^{(i)} > s_-^{(j)}]$ |
| AIC | $2k - 2\log\hat{L}$ |
| BIC | $k\log n - 2\log\hat{L}$ |
| Brier | $\frac{1}{n}\sum(\hat{p}_i - y_i)^2$ |
| EI（贝叶斯优化） | $(f^*-\mu)\Phi(z) + \sigma\phi(z)$，$z = (f^*-\mu)/\sigma$ |
| LOO 残差 | $(y_i - \hat{y}_i)/(1 - h_{ii})$ |
