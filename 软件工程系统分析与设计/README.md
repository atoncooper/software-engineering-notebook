## 四、每篇笔记的统一结构

每篇笔记遵循以下结构，便于快速定位：

1. **开篇定义与边界**：解决什么问题、不解决什么问题
2. **核心概念 / 模式列表**：附结构图与难度标记
3. **Java + Go 双语言示例**：对照体会静态 vs 动态、继承 vs 组合
4. **陷阱与坏味道**：过度设计的反例
5. **与其他概念的关系**：横向对比表
6. **综合面试题**：由浅入深，含答题要点
7. **参考与延伸**：书籍、论文、跨文件链接

## 五、面试高频考点速查

### 5.1 设计原则类
- SOLID 五原则的定义、反例、相互冲突
- DRY vs WET、KISS vs 过度工程、YAGNI 的边界
- 迪米特法则与"最小知识"
- CQS / CQRS 的本质区别

### 5.2 设计模式类
- 单例的线程安全（双重检查锁、静态内部类、枚举）
- 工厂方法 vs 抽象工厂
- 策略模式消除 if-else 的实战
- 观察者与发布订阅的区别
- 责任链在网关 / Filter 中的应用
- 代理 vs 装饰器 vs 适配器的区别
- 组合模式与树形结构

### 5.3 架构与范式类
- 高内聚低耦合的量化判定
- 扇入扇出、作用域 vs 控制域
- Robert Martin 组件原则与主序列
- 康威定律与 Inverse Conway
- 分层架构的依赖方向
- MVC 的演化（MVP / MVVM / Flux）
- Active Record vs Data Mapper
- C/S vs B/S vs P2P

### 5.4 DFx 类
- MTBF / MTTR / MTTF 的关系
- 可用性「几个 9」的计算
- 熔断、限流、降级、隔离的选用
- 幂等性的设计与实现
- Little 法则与系统容量
- Amdahl 定律与并行加速比
- 缓存三大问题：穿透 / 击穿 / 雪崩
- P99 延迟的含义与测量
- USE 方法 vs RED 方法
