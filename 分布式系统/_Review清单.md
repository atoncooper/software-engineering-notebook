# Review 清单

> 单章与全仓 review 的检查项。每章完成后逐项打勾。

---

## 1. 单章 Review Checklist

### 结构完整性
- [ ] 6 层结构齐备（定义/原理/学术/工业/面试/论文）
- [ ] 章首有「本章导读」blockquote
- [ ] 章首有「章节地图」ASCII 图或 Mermaid
- [ ] 章末有「TODO」与「交叉引用」小节

### 术语与符号
- [ ] 术语首次出现有英文（如 **Quorum（法定人数）**）
- [ ] 术语表（`_术语表.md`）已同步新增术语
- [ ] 数学符号与 `_符号约定.md` 一致
- [ ] 缩写首次出现给出全称

### 准确性
- [ ] 每条论断有引用（论文 / 官方文档 / 书）
- [ ] 论文引用核对原文（不依赖记忆）
- [ ] 工程参数核对官方文档（标注版本号 + 日期）
- [ ] 定理陈述标注出处 `[作者 年份]`
- [ ] 无幻觉 API、无臆造定理、无错误参数

### 图示与代码
- [ ] 至少 1 张关键图（Mermaid 或 ASCII）
- [ ] 伪代码用 ` ```pseudocode ` 块，Python-like 缩进
- [ ] 关键算法代码片段 < 50 行（Go 优先）
- [ ] 图示有图号与标题（如「图 5-1 Raft 选举流程」）

### 工业实战
- [ ] 系统名 + 版本号 + 文档链接
- [ ] 调优要点标注 🔥
- [ ] 陷阱标注 ⚠️
- [ ] 事故案例链接到 §22 案例库

### 面试要点
- [ ] 每题含：骨架 / 关键点 / 加分项 / 常见追问
- [ ] 每题标 ⭐
- [ ] 面试问题数量 5-15 个

### 交叉引用
- [ ] 前置章链接可达
- [ ] 后续章链接可达
- [ ] 横向章链接可达
- [ ] 论文链接到 §19 论文清单

### 标记规范
- [ ] ⭐🔥📜⚠️ 使用符合 `_标记规范.md`
- [ ] 🎓 仅用于学术小节标题
- [ ] 🏭 仅用于工业小节标题
- [ ] 不出现标记叠加（如 ⭐🔥）

### 版本与日期
- [ ] 工业实战小节标注系统版本号
- [ ] 引用文档标注「访问于 YYYY-MM-DD」
- [ ] 事故案例标注事发日期

---

## 2. 全仓 Review Checklist（M5 里程碑）

### 章节覆盖
- [ ] 24 章全部成文
- [ ] 无 TODO 占位（或明确延后并记录原因）
- [ ] README 索引表 24 章状态全 `✅`

### 一致性
- [ ] 术语表覆盖全部首次出现术语
- [ ] 符号约定全仓一致
- [ ] 所有交叉引用链接可达（无死链）
- [ ] 对比表列头格式统一（系统 / 算法 → 故障模型 → 复杂度 → 容错 → Leader → 工程代表 → 备注）

### 索引与导航
- [ ] README 顶部「快速导航表」完整
- [ ] README 底部「阅读顺序图」完整
- [ ] §19 论文清单 22 篇全部有链接 + 一句话贡献
- [ ] §22 案例库 10 个案例全部有来源链接

### 风格一致
- [ ] H1 用 ` —— ` 分隔
- [ ] 章节序号统一（十进制 `## 5.1`）
- [ ] 分节用 `---` 水平线
- [ ] 与同级目录约定一致

### 质量抽检
- [ ] 抽检 5 章，每章无事实错误
- [ ] 抽检 5 章论文引用，全部可溯源
- [ ] 抽检 5 章工程参数，全部与官方文档一致

## 3. Phase 验收标准

### Phase 1（核心理论）
- [ ] §1/§2/§3/§4/§5 + §21 部分（FLP/CAP/线性一致性）可读
- [ ] 面试可答 CAP / Paxos / Raft / 复制类问题

### Phase 2（可靠性工程）
- [ ] §6/§7/§10/§11/§12/§14 可读
- [ ] 面试可答事务 / 锁 / 幂等 / 容错类问题

### Phase 3（工业系统）
- [ ] §8/§9/§13/§15/§16/§17 可读
- [ ] 面试可答系统设计题（KV / MQ / 流处理）

### Phase 4（面试 / 论文 / 案例）
- [ ] §18/§19/§20/§21（剩余）/§22 可读
- [ ] 全仓 review 通过

---

## 4. 使用方式

1. 写完一章 → 对照「单章 Review Checklist」逐项打勾
2. 完成一个 Phase → 对照「Phase 验收标准」
3. 全部完成 → 对照「全仓 Review Checklist」做 M5 验收
4. 发现遗漏 → 在对应章「TODO」小节登记，不阻塞当前章交付
