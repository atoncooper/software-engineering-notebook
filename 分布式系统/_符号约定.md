# 符号约定

> 全仓数学符号与变量统一约定。每章使用前需与本表一致；新增符号时同步更新。

---

## 1. 系统与节点

| 符号 | 含义 | 典型取值 | 示例 |
|------|------|---------|------|
| $n$ | 系统总节点数 | $\geq 1$ | Raft 集群 $n=3$ 或 $5$ |
| $f$ | 可容忍故障节点数 | $f < n/2$（非拜占庭）<br>$f < n/3$（拜占庭） | $n=3, f=1$ |
| $p_i$ | 进程 $i$ | $i \in \{1, 2, \dots, n\}$ | $p_1, p_2$ |
| $\Pi$ | 进程集合 | $\{p_1, \dots, p_n\}$ | — |

## 2. 复制与 Quorum

| 符号 | 含义 | 典型关系 |
|------|------|---------|
| $N$ | 副本数（replication factor） | — |
| $W$ | 写 Quorum 大小 | $W > N/2$ |
| $R$ | 读 Quorum 大小 | $R > N/2$ |
| — | 强一致性 Quorum 条件 | $W + R > N$ |
| — | 容错条件 | $W, R \leq N - f$ |

## 3. 时间与时钟

| 符号 | 含义 |
|------|------|
| $C_i$ | 进程 $p_i$ 的逻辑时钟 |
| $VC_i$ | 进程 $p_i$ 的向量时钟 |
| $C_i(e)$ | 事件 $e$ 在 $C_i$ 上的时间戳 |
| $\epsilon$ | 时钟误差（uncertainty） |
| $HLC$ | 混合逻辑时钟时间戳 $(pt, l, c)$ |
| $pt$ | 物理时间部分 |
| $l$ | 逻辑部分 |
| $c$ | 计数器部分 |
| $\Delta$ | TrueTime 误差区间半宽 |
| $T_{commit}$ | Commit Wait 时长 |

## 4. 共识算法

| 符号 | 含义 |
|------|------|
| $n$ | 提案编号（Paxos） / 任期（Raft） |
| $v$ | 提案值 |
| $\text{lastAccepted}(i)$ | Acceptor $i$ 已接受的最大编号提案 |
| $\text{promised}(i)$ | Acceptor $i$ 承诺的最小编号 |
| $\text{commitIndex}$ | Raft 已提交日志索引 |
| $\text{matchIndex}[i]$ | Leader 与 follower $i$ 匹配的日志索引 |
| $\text{nextIndex}[i]$ | Leader 下次发给 follower $i$ 的日志索引 |
| $\text{currentTerm}$ | Raft 当前任期 |
| $\text{voteFor}$ | Raft 本任期投票对象 |

## 5. 分布式事务

| 符号 | 含义 |
|------|------|
| $T_i$ | 事务 $i$ |
| $TS(T_i)$ | 事务 $i$ 的时间戳 |
| $RS(T_i)$ | 事务 $i$ 的读集 |
| $WS(T_i)$ | 事务 $i$ 的写集 |
| $2PC$ | 两阶段提交 |
| $3PC$ | 三阶段提交 |

## 6. 消息队列与流

| 符号 | 含义 |
|------|------|
| $HW$ | High Watermark（高水位） |
| $LEO$ | Log End Offset（日志末端偏移） |
| $ISR$ | In-Sync Replicas（同步副本集） |
| $OSR$ | Out-of-Sync Replicas |
| $AR$ | All Replicas = $ISR \cup OSR$ |
| $offset$ | 消费位移 |

## 7. 分片与路由

| 符号 | 含义 |
|------|------|
| $k$ | 分片键 |
| $S$ | 分片（槽）总数 |
| $hash(k)$ | 分片键哈希 |
| $replica(i)$ | 虚拟节点 $i$ 对应的物理节点 |

## 8. 时序与事件

| 符号 | 含义 |
|------|------|
| $e \to e'$ | $e$ happens-before $e'$ |
| $e \| e'$ | $e$ 与 $e'$ 并发 |
| $e_1 \prec e_2$ | $e_1$ 在 $e_2$ 之前（同进程内全序） |

## 9. 性能指标

| 符号 | 含义 |
|------|------|
| $T_{rtt}$ | 往返时延（round-trip time） |
| $T_{prop}$ | 传播时延 |
| $T_{proc}$ | 处理时延 |
| $T_{queue}$ | 排队时延 |
| $P99$ | 99 分位延迟 |
| $QPS$ | 每秒查询数 |
| $TPS$ | 每秒事务数 |

---

## 维护规则

1. 每章使用数学符号前，必须与本表对照一致。
2. 新增符号时按主题分类插入。
3. 同一概念在不同章使用不同符号时，必须在此显式声明别名。
4. LaTeX 公式中所有变量必须有出处。
